# WP1 · 入口体检：为什么 5 播放？

> 2026-10-31 18:20　取证：`Workspace/tmp/wp1_probe.json`、`wp1_peer.json`、截图 `shot_video_page.png`
> 结论先行：**稿件被发到了「游戏 → 网络游戏」分区（tid 65），不是知识区**。
> 这是发布脚本的 bug，也是 5 播放最直接、最可执行的解释。

## 发现 1【P0 · 根因】分区错了：剪辑教程在游戏流量池里

| 证据 | 值 |
| --- | --- |
| 公开接口 `x/web-interface/view` 返回 | `tid: 65`，`tname: ""`（空，异常信号） |
| B 站分区表（biliup tid-ref + 两个独立来源交叉） | **tid 65 = 游戏区 → 网络游戏**；我们想要的 122 = 知识区 → 野生技能协会 |
| 赛道 160 条样本的分区分布 | **122 野生技能协会 29.4%**、183 影视剪辑 11.3%、230 软件应用 8.8%——我们一条都没沾上 |

**为什么会发错（脚本 bug，两处叠加）**：

1. `publish_bilibili.mjs` 的 `setZone()`（L409–441）只在**单级列表** `.drop-list-v2-item` 里点"知识"。
   但 B 站投稿分区是**两级结构**（一级"知识" + 二级"野生技能协会"），只点一级、不选二级，
   提交时二级缺失，后端落到默认 tid。脚本头部注释还写着「新版无二级」——当时的观察就是错的。
2. 发布后的回读校验只读 `.select-controller` 的 **UI 显示文本**（"知识"），没有回读**真实 tid**。
   所以日志显示"分区 ? → 知识"、校验 PASS，实际上库是 65。**UI 会撒谎，接口不会。**

**后果**：剪辑教程被推进游戏流量池，目标观众（学剪辑的人）根本看不到它。
5 播放低于新稿 P25(10.5) 到此有了直接解释——**先修入口，再谈内容**。

**怎么改（要人拍板）**：
- B 站分区**发布后不可修改**（旧规如此；新版是否放开待核实）。若确实不可改：
  **删除重投**——现稿只有 5 播放 1 分享，没有可失去的；重投时分区选 122 野生技能协会，
  同时把发现 2/3 的标题、标签一起改掉，一次到位。**删除是不可逆动作，等你点头。**
- 无论是否重投，脚本必须修：`setZone` 支持两级选择；发布后**用公开接口回读 `tid === 122`**，不一致即 FAIL。

## 发现 2【P1】标题：33 字，超中位 50%，且塞的是"制作规格"不是"观众收益"

| 项 | 值 |
| --- | --- |
| 现标题 | `5 个剪辑提速技巧｜英文原声 + 中英双语字幕，照着做能省一半时间`（33 字） |
| 赛道中位 | **22 字**（113 条 HOT 样本） |
| 桌面端 | 完整显示（截图核实） |
| 移动端/分享卡片 | 未测，但 33 字超中位 50%，移动端两行内必然挤压 |

关键不是长度，是**内容**：`英文原声 + 中英双语字幕` 说的是"我怎么做的"，观众只关心"我能得到什么"。
对照赛道爆款句式（`3分钟学会12种无缝转场！新手VLOG旅拍必看`），收益承诺占比 41%、含数字 24%。

**改成什么**（示例，按 22 字内）：`剪辑提速 5 招，第 3 个直接省一半时间`（18 字）——
保留数字、砍掉规格词、把最狠的收益放到钩子位置。重投时一并改。

## 发现 3【P1】标签：7 个里 2 个是自造词，最高频的词全没沾

| 我们的 7 个标签 | 赛道命中情况 |
| --- | --- |
| 后期 / 视频剪辑 / 效率 / 剪辑教程 / 剪辑技巧 | ✅ 命中赛道高频（分别 ×8 / ×34 / ×8 / ×22 / 赛道词根） |
| **创作者工具** | ❌ 自造词，赛道 0 次出现，零搜索流量 |
| **中英双语** | ❌ 同上 |

**赛道高频词我们没用的**：`剪辑`×45（最高频词根，我们只用了长词）、`影视剪辑`×38、`教程`×22、`剪映`×17、`PR`×14、`视频教程`×11、`自媒体`×8。

**改成什么**：删"创作者工具""中英双语"，补 `剪辑`、`影视剪辑`、`教程`、`视频制作`（×8）。
标签上限 10 个，现有 5 个有效 + 4 个 = 9 个，刚好。

## 发现 4【P2】发布时段：15:22 可接受，非最优

赛道发布高峰：13 点(×18)、17 点(×15)、21 点(×13)、15 点(×12)。
15:22 处于第二梯队。若重投，选 **17 点前后**或 21 点，顺手优化。

## 发现 5【P2】视频页侧栏推荐其实是对的

"接下来播放"全是剪映/剪辑教程（【400集】剪映教程等），说明**内容相似度匹配没问题**——
错的是分区带来的**分发入口**，不是内容识别。这进一步支持"先修入口、先不动内容"。
