## 2. 环境感知（关键约束，直接决定技术选型）

| 探测项 | 结果 | 影响 |
| --- | --- | --- |
| ffmpeg/ffprobe | **缺失** | 必须自己装（视频处理的地基） |
| PowerShell / curl 出网 | **被拦**（TLS 连接被关闭；curl 返回 000） | 不能用 PS/curl 下载 |
| Node fetch 出网 | **可用** | 所有下载动作走 Node |
| gyan.dev / GitHub Release 资产 | ~13KB/s 或超时，不可用 | 换镜像源 |
| npmmirror `/-/binary/ffmpeg-static/` | **可用（b6.1.1，约 2MB/s）** | 选定 ffmpeg 6.1.1 essentials (GPLv3) |
| Node 子进程 pipe stdio | **EPERM**（沙箱禁命名管道） | 拆掉所有 `spawnSync(...{encoding:'utf8'})` 写法，改 fd 重定向 |
| python | 3.12 存在但**无 numpy/cv2/torch**；pip 出网 120s 超时 | 本轮不用 python 生态，纯 ffmpeg+Node |
| GPU | 无 `nvidia-smi` | 只能 CPU 编码 |
| 磁盘 | C 393GB / D 363GB 可用 | 无压力 |
| 素材 | 无任何原视频 | 需自建可复现素材（合成 + 公开授权真实片段） |
| 字体 | simhei/msyh/arial 存在；ffmpeg 找不到默认 fonts.conf | 需自建 fontconfig 配置，且必须用 `font=` 家族名 |

> 结论：这是一台"能出网但只有 Node 能出网、没有 ffmpeg、没有 python 生态、不能用管道"的 Windows 机器。
> 因此选型定为 **ffmpeg(静态构建) + Node 标准库** 的单文件流水线，不引入任何 npm 依赖。

## 3. 本轮假设（若与你的预期不符，请在反馈里直接否定）

1. "原视频"= 一段**已经拍好/导出的原始素材**（含废镜头、黑场、空镜、停顿），待做删减与规整，而不是需要从零剪辑的原始多机位素材。
2. "剪辑、修订"在本轮 = **删掉无信息段 + 规整成片规格 + 加转场/响度/标题**；不包括语义级取舍（高光/主题/口误）。
3. "交付"= 一个成片文件 + 可解释的剪辑决策单 + 一份报告（能被二次修版、能被人复核），而不是只给一个 mp4。
4. 目标规格默认 1280×720@30 / H.264 High / AAC −16 LUFS（可参数化为竖屏或其他规格）。

## 4. 最小闭环定义与"连通"的判据

**闭环**：原视频 → 信号分析 → 剪辑决策 → 渲染 → 交付包。

连通的判据（本轮自定，必须客观可测）：

| 判据 | 阈值 | 怎么测 |
| --- | --- | --- |
| 决策正确性 | 与真值 IoU ≥ 0.90；过切 ≤ 0.6s；漏切 ≤ 0.6s；每段存活率达标；切点误差 ≤ 0.6s | `Tool/verify_edl.mjs` 对比 `ground_truth.json` |
| 成片合格性 | H.264/yuv420p/CFR/AAC48k；响度 ≈ −16 LUFS 且峰值 ≤ −1 dBTP；无残留黑场；音画时长差 < 0.1s | `Tool/qa_report.mjs` |

**为什么必须造真值**：没有真值，"剪得好不好"只能靠嘴说。合成素材与"真实素材+已知插入废镜头"两种方式都能让真值机器可读，从而把"我觉得可以"变成"数据显示 IoU=1.0"。

## 5. 规划（按信息增益/成本排序）

1. 装 ffmpeg（地基，阻塞一切）——低风险高收益。
2. 打通"信号分析→决策→渲染"最小链路，先用合成素材对拍（真值明确，快速暴露解析/边界问题）。
3. 上真实素材（编码特性、运动、码率分布完全不同），修误切。
4. 加交付件（EDL/报告/时间轴图/质检），让结果可复核、可二次修版。
5. 沉淀：脚本进 `Tool/`、坑写进注释与 `Tool.md`、一键验收脚本。

## 6. 过程中的真实踩坑（含解决方式，供下一轮省时间）

| # | 现象 | 根因 | 解决 |
| --- | --- | --- | --- |
| 1 | ffmpeg 下载 2 分钟只到 2.3MB | gyan.dev 限速 ~13KB/s | 换 npmmirror 二进制镜像（13.3s 拿到 79MB） |
| 2 | 所有 `spawnSync` 调用 status=null / `EPERM` | 沙箱禁命名管道 | 日志重定向到 fd 文件再读回（`Tool/lib/ff.mjs`） |
| 3 | 合成素材 ffmpeg 报 `More input link labels ... 1 > 0` | 源滤镜链误加输入标签 | 源写 `filter[out]`，不是 `[out]filter` |
| 4 | 黑场切了但"冻帧+静音"段没切 | 同类切除段先被合并再判断重叠，导致部分区间被跳过 | 引入区间差集 `subtract()`，只加未覆盖部分 |
| 5 | `scenes=0`，切点吸附失效 | 正则写成 `lavfi.scd.time=`，实际是 `:` | 修正正则（实测 scdet 正常输出 6 个切点） |
| 6 | 中文标题显示为方块 | `fontfile=C\:/...` 静默回退默认衬线 + 无 fontconfig 配置 | 改用 `font=SimHei`，并由 `lib/ff.mjs` 自建 fonts.conf |
| 7 | 验收脚本 boundary=FAIL，但显然剪对了 | 指标缺陷：真值里相邻 drop 段被合法合并后，内部边界被误判为错误 | 边界误差改为"并集边界对并集边界"比较 |
| 8 | 真实素材用例响度显示 −70 LUFS | 该公开片段本身无音轨（文档已标注），流水线行为正确 | 质检脚本识别"素材静音"→响度项标记不适用 |
| 9 | `reproduce.ps1` 报"字符串缺少终止符" | 本机是 **Windows PowerShell 5.1**，含中文的 .ps1 无 BOM 会被按 ANSI 解析 | 存为 UTF-8 with BOM（`[System.IO.File]::WriteAllText(..., UTF8Encoding($true))`） |
