# 小循环 11 · 感知

## 起点（人的观察）

人看长片案例后给了一句很关键的判断：

> "之前那个视频的字幕内容是关于'视频剪辑'这种'技能型知识'的，你翻译的就很好。"
> 又说："**不要给工厂下定义，工厂是持续循环迭代升级的**。"

所以这一轮不是写"工厂只做知识型内容"这种边界文档，而是：
**把人观察到的"这类内容能做好"，变成可计算、可判定、可复现的东西** —— 能力画像 + 分诊 + 专项强化，随版本迭代。

## 为什么知识型内容确实更好（前几轮已量化的事实）

| | 知识型（l2 教学片） | 剧情片（TOS 90s） |
| --- | --- | --- |
| 识别 WER | 6.1% | 28.4% |
| 语音覆盖 | 99.8% | 50–60% |
| 翻译缺陷（句末标点/术语） | 0 / 0 | 机翻后语义仍偏 |
| 与人工参考相似度 | 94.1% | — |

机制上：知识型内容"信息主要在文字里"，术语可枚举，语域平稳，无画面梗，识别环境干净（单人近场麦）。
剧情片恰好把这几条全反过来。

## 本轮问题（都可验证）

1. **能不能自动分诊**？给一条视频，用可计算信号（语音覆盖、置信度、配乐占比、短句占比、句长、术语密度）判断它当前更接近哪类，并给出策略建议。
2. **数值与单位能不能规范化**？知识型的命门是"说错数值"（`minus sixty sixteen l u fs`），能不能在送翻译前规范成 `−16 LUFS`，且**只在单位语境**动数字（`two hours` 不许变 `2 hours`）。
3. **术语能不能自动候选**？273 行手工找术语不现实，能不能从转录里挑出"该进术语表的词"。
4. 这些改动会不会**破坏已有链路**（小循环 6/8/9/10 的验收）？

## 判据

- 分诊：l2 → knowledge、TOS → narrative；配乐占比 TOS ≫ l2；
- 规范化：源句出现 `−16 LUFS` / `15 Mbps`、**幂等**、不误伤普通数字；
- 端到端：规范化后中文出现 `−16 LUFS`/`15 Mbps` 且无"负十六/卢夫斯"；对照组（`--no-unit-norm`）拿不到；
- 术语候选：长片能产出非空候选，l2 能挑出单位术语；
- 回归：小循环 6 的文本验收仍 PASS。
