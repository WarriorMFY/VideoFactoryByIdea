# 小循环 3 · 感知与规划（真实外语素材验证）

开始：2026-10-27 15:40（人指令："你自行去网上下载一下外语素材，先自己跑通验证"）

## 1. 人反馈与本轮响应

上一轮（小循环 2）我明确写了"素材是 TTS 合成、真人原声未测"。人的指令就是补这个缺口，且要求**自己找素材、自己跑通**。

响应策略：
- 不去问"你要什么素材"，自己按三条硬约束筛：**可达（本机网络）+ 有真实人声 + 许可证清楚**；
- 不拿"跑通"当结论，必须**用真值或替代性判据量化**；真实素材没有讲稿 → 切 reference-free 模式（只验字幕自身合理性）；
- 更重要的是：**真实素材暴露的 bug 要修掉并回归**，而不是绕过去。

## 3. 需要验证的假设

| 假设 | 验证方式 | 结果 |
| --- | --- | --- |
| 剪辑规则对真实影视素材安全 | 跑 EDL，检查是否误剪对白 | **被推翻**：对白被当黑场剪掉（见下） |
| 小模型 ASR 在真实混音上可用 | 4 种音频预处理对照 + 人工核对台词 | **部分被推翻**：词准确率仅约 55–65% |
| 字幕能随剪辑正确重映射 | remap + verify 自检 | 成立（4 条全保住、无越界/重叠） |
| 断句参数对真实对白够用 | 对比 `--min-sent` 24 vs 12 | **原默认不对**：短句被合并导致机翻串味 |

## 4. 暴露的问题与修复（本轮核心）

1. **对白被剪（严重）**：黑场 `pix_th=0.10` 把暗场景判成黑场；且台词压在黑底字幕卡上时同样被判黑场。
   → 收紧黑场参数（0.04 / pic 0.98 / dur 0.30），并新增 **`--protect <transcript.json>` 语音保护**（识别到语音的区间一律不剪，只采信 conf≥0.5 的词，两侧 0.25s 余量）。
2. **识别质量**：影视混音（音乐/音效/低语）下置信度 0.816；加 `afftdn` 降噪 + 300–3400Hz 带通后 0.918，并把关键错词 "are the gatekeepers" 纠正为 "of the gatekeepers"。
3. **短句合并**：`--min-sent` 24 → 12，避免"两句并一句再机翻"造成的译文串味。
4. **质检阈值与剪辑阈值不一致**：QA 用更敏感的 0.12/0.10，把剪辑时够不上黑场的暗场反复报缺陷 → 统一为 0.30/0.04/0.98。
5. **已知取舍**：语音保护会连带保住"对白压在黑屏上"的那段黑屏 → 验收里单列为「仅残留黑场告警」，不当失败。

## 5. 验收判据（reference-free）

真实素材无官方逐句讲稿，WER 与句界误差**不可测**，因此本轮判据改为：

- 译文覆盖 100%、中文可读性 ≤20 字/秒、重映射无越界/重叠/最短 ≥0.5s（字幕自身合理性）；
- 成片质检（编码/响度/音画同步）通过；
- **剪辑一致性**：两次渲染 EDL 必须相同（防字幕错位）；
- 额外：对白是否保住（对比加/不加语音保护的 EDL）。

## 6. 遗留

- 真实语音识别准确率不足（55–65%）：正后台下载 128MB 的 `vosk-model-en-us-0.22-lgraph` 做对照；更大的模型/Whisper 需要新的下载通道。
- 无标点导致断句与机翻质量受限。
- 音画绑定，无法"保音频换画面"。
