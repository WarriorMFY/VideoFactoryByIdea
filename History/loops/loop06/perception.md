## 2. 感知（决定路线的三个探测）

| 探测 | 结果 | 决策 |
| --- | --- | --- |
| LLM API Key | `DEEPSEEK/OPENAI/ANTHROPIC/MOONSHOT/DASHSCOPE/SILICONFLOW` **全部未设置**；端点可达但返回 401 | 自动精译走不通 → 精译做成 `--mt agent`（人/LLM 产出译文文件 + 按句校验），并在验收里作为"质量上限"对照 |

## 3. 假设与验证

| 假设 | 验证方式 | 结果 |
| --- | --- | --- |
| 规则化标点恢复能对齐人工标点 | 用 TTS 讲稿当真值算句界 F1 / 句末标点 / WER | **成立**：F1 **1.00**、句末标点 **100%**、WER 不变 6.1% |
| 标点能减少机翻缺陷 | 同一素材对比"句末缺标点 / 术语错误" | **成立**：7/7 → **0/0**、1 → **0** |
| 相似度能反映翻译质量 | 与人工精译比对 | **部分反驳**：同义改写也扣分（机翻 47.2% vs 精译 94.1%，但机翻并非"差一半"）→ 改用**缺陷计数**做主判据，相似度降为参考 |
| 阅读速度可自动控制 | `--cps` 节流 | **部分成立**：能延长/拆分，但下一条紧邻时物理时间不够 → 改为**报告超标条数**，不假装修好 |
| 影视素材也能用同一套标点规则 | 对 Sintel 素材跑一遍 | **初期失败**：`median×3` 阈值 0.28s 把 `you don't / long as i can remember` 切成两句 → 改 **p80 分位数**阈值后 4 句正确 |

## 4. 判据（本轮自定）

- 标点：句界 F1 ≥ 0.85、句末标点 ≥ 85%、去标点后 WER ≤ 10%（证明只补标点没改词）；
- 翻译：句末缺标点 = 0、术语错误 = 0；相似度只做参考；
- 精译后端：与人工参考相似度 ≥ 85%（证明链路能承载人工级译文）；
- 回归：`verify_subs` 仍 PASS（WER/覆盖/句界/可读性）。
