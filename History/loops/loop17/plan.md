# 小循环 17 · 计划：TED 类演讲视频的剪辑创新点深度调研

> 开轮：2026-11-02 08:24，人指令：「开一轮循环去深度调研一下，像这种 TED 视频演讲有哪些剪辑创新点。」
> 大循环时间窗口：2026-10-27 10:44 → 2026-11-03 10:44（开轮时剩约 26 小时）

## 1. 这轮要回答的问题

不是「别人怎么剪」，而是**「哪些剪辑手法能让我们的演讲视频在完播率/推荐流上真正拿到分，且我们现有流水线做得到」**。

拆成三个子问题：

| # | 子问题 | 判定证据 |
| --- | --- | --- |
| Q1 | 演讲类视频的剪辑手法有哪些可枚举的维度？ | 形成分类法（taxonomy），每个维度有实例视频 |
| Q2 | 哪些维度是**TED 官方/头部创作者已经在用**、而我们没用的？ | 逐条对照我们的成片 |
| Q3 | 每条手法的成本、收益、风险各是什么？ | 优先级矩阵 + 我们工具链的可实现性判定 |

## 2. 调研方法（四条线并行）

| 线 | 做法 | 产出 |
| --- | --- | --- |
| A 外部资料 | TED 官方制作说明、TED-Ed 动画范式、中文演讲赛道头部 UP 的剪辑语言、切片号手法、学术侧（镜头长度/字幕/注意力）证据 | 手法清单 + 出处 |
| B 竞品实测 | 对 2–3 条真实竞品成片做**可量化**特征提取：平均镜头长度、剪辑频率、画面变化率、字幕样式、镜头类型分布 | 数值对照表 |
| C 自身基线 | 对我们 5 条长片 + 5 条摘要跑同一套指标，明确「我们和对手差在哪」 | 自身基线 |
| D 可行性 | 每条手法落到我们工具链（ffmpeg / vfactory / make_digest / make_ass）能不能做、缺什么 | 可做/半可做/做不了 |

**原则：能量化的一律量化，不能量化的标「定性」并写清依据。不把推断写成结论。**

## 3. 工作包

### `[x]` WP1 · 感知：素材与度量工具盘点
- 盘点 `History/bench/`、`Prototype/loop14_talk/` 里可用的对标与自身素材
- 确认度量工具能力：`kb_audit.sh`（帧间差异）、`frame_sheet.mjs`（抽帧）、`verify_edl`（剪辑决策）
- 需要新写一个「剪辑节奏画像」工具：抽帧 → 帧差 → 镜头切分 → 镜头长度分布

### `[x]` WP2 · 外部调研（线 A）
- TED 官方剪辑语言 / TED-Ed 动画范式
- 中文赛道：演讲搬运号的剪辑处理、切片号钩子结构
- 学术与行业证据：镜头长度与注意力、动态字幕与完播、信息密度

### `[x]` WP3 · 量化对照（线 B+C）
- 竞品 vs 我们：镜头长度、剪辑频率、画面变化幅度、字幕动效
- 结论必须带数值与复现命令

### `[x]` WP4 · 收敛：创新点清单与优先级
- 分类法（taxonomy）：语言层 / 画面层 / 节奏层 / 信息层 / 交互层
- 每条：做什么 / 谁在用 / 成本 / 预期收益 / 风险 / 我们能否实现
- 优先级矩阵，输出「立刻做 / 下轮做 / 观望 / 不做」

### `[x]` WP5 · 验证 demo
- 挑 top-3 创新点，用现有素材做 60 秒片段
- 判据：不是 PPT，是真的能播；与现状对照看得出差别
