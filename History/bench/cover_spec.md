## 一、赛道爆款的共同规律（30 张逐张看过）

1. **大字标题近乎必备**：30/30 中 26 张有明显大字标题；其余 4 张全部是**人脸/操作特写**充当视觉锚点。没有一张是"风景空镜+小字"。
2. **主标题短而粗**：主流 4–10 字，白/黄粗体 + 黑描边或色块底（01、05、10、14、21、27 黄字黑底最常见，约 1/3）。
3. **文字层数少**：主标题 + ≤1 行副标 + 可选角标，总共 ≤3 处文字。副标例："4个镜友人特效手法"（02）、"一个镜头就能拍全"（27）。
4. **高对比是硬通货**：黑底黄字（10、14）、黑底白字红框（24"剪辑就是硬切"，95w）、亮底红字（03、20、28）。**没有一张把灰字放在深色纹理上**。
5. **视觉锚点三类**：人脸特写（05、13、17、28）、手部操作特写（19 手机、29 相机、30 绿幕）、高对比纯色底（10、24）。教程赛道尤其吃"手在操作"的画面。
6. 角标放左上/右上，内容是"数量词/身份"（"10个""VLOG神器"），没有一张写"样片/测试"类自贬词。

## 二、可量化规范（给 WP3 用）

| # | 规范 | 量化标准 |
| --- | --- | --- |
| S1 | 主标题 | ≤10 字；字号占画面高度 ≥18%（1080p 下 ≥190px）；白/黄粗体+黑描边 ≥8px 或色块底 |
| S2 | 文字元素总数 | ≤3 处：主标题 + 副标（≤14 字、1 行）+ 角标（≤6 字） |
| S3 | 视觉锚点 | 人脸特写（占高 ≥60%）/ 手部操作特写 / 高对比纯色底，三选一；**禁止风景空镜无锚点** |
| S4 | 文字对比度 | 文字与所在背景区域亮度差 ≥100（或强制描边/色块）；禁止灰字叠深色纹理 |
| S5 | 角标 | 左上或右上；禁止"样片/测试/工厂"类自贬词 |
| S6 | 多行主标题 | 每行 ≤6 字，最多 2 行 |
