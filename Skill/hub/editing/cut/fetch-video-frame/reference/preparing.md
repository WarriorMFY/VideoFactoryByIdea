# 抽帧与拼图细则（prepare.py）

> 只定义机械抽帧的参数与产物结构，不涉及「哪一帧算命中」的判读（那在 `judging.md`）。

## 输入

- 视频链接（http/https）或本地路径，作为第一个位置参数。
- 链接用 urllib 下载到 `<out>/video.mp4`；已是本地文件则只读、不复制、不改动。

## 抽样参数

| 参数 | 默认 | 含义 |
| --- | --- | --- |
| `--step` | 0.5 | 抽样间隔（秒）。越小帧越密，但拼图页数越多。 |
| `--per-sheet` | 20 | 每张拼图放多少帧（网格 5 列）。 |
| `--cell` | 240 | 单格宽度（像素），高度按视频宽高比自动算。 |
| `--start` / `--end` | 全片 | 只在此时间范围内抽样，用于已知大致位置的二次细看。 |
| `--max-frames` | 400 | 抽样总帧上限，防超长视频刷屏；超出则等距稀释并在 meta 标注。 |

## 产物结构

```
<out>/
├── video.mp4          下载得到的视频（本地输入时不生成）
├── frames/            f000000.png … 逐帧图，文件名含源帧号
├── sheet-01.png …     拼图，每格角标 `mm:ss.mmm | f<帧号>`
└── meta.json          视频参数 + 帧清单（file/frame/time）+ 拼图清单 + 稀释标记
```

## 规则

- 时间以 `帧号 / fps` 计，不用请求时间；拼图角标与 `meta.json` 的 `time` 必须一致。
- 分辨率、fps 从视频头读取；`fps` 缺失时按 24 记并在 meta 标注 `fps_assumed`。
- 抽帧是等间隔机械行为，**不做任何内容判断**；拼图只用于导航，不能替代通看全片。
- 只读源视频；`--out` 目录不存在则创建，已存在的同名产物覆盖。
