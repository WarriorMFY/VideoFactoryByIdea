## 一、三条结论

1. **「有哪些接口」和「哪些能用」是两件事。** 标准模型 API 有 42 个文生图 + 60 个文生视频端点（D；快照共 420 端点），官网宣称 189 图像模型／322 视频模型（A，口径不同不与上数相加）；但本账号 `apiType=NORMAL`（C），标准模型 API 返回 `1014 标准模型API仅限企业级-共享API Key调用`（B §33.2）。当前唯一能付费跑通的是 AI 应用（webapp）通道。
2. **价格是两套体系，不可直接换算。** 标准 API 走人民币目录价（文生图最低 **¥0.03/张**、文生视频最低 **¥0.3/秒**）；AI 应用走积分 `chargedPoint`（文生图约 **11 积分/张**、480P/5s 视频约 **10.54–24.33 积分/条**）。`consumeMoney`／`consumeCoins`／`thirdPartyConsumeMoney` 全为 null（C），API 层拿不到积分→人民币换算。
3. **省钱的主战场不是换更便宜的模型，是减少付费次数。** 一轮完整验证可从 **68.87 积分压到 ≈22.7–36.0（−48%～−67%）**，靠零成本层前置、L3 一次一张、L4 只跑一条、失败只重跑失败层。

## 八、止损纪律

1. 每轮设积分上限（**建议 40**；原 30 已不够覆盖 5s 上限），触顶即停、先归因再决定是否追加。
2. 每个 task 实跑后只读回查 `usage.chargedPoint` 落盘留痕；**不按参数推算费用**（10.54 vs 20.57 成因未查明）。
3. 失败先分两类：卡面可改 → 改后只重跑受影响层；模型边界 → 记边界、不改卡（P5）。
4. 应用市场不返价格，**不要为「找更便宜的」批量试跑应用**；一次四应用比价就花 **97.73 积分**，接近推荐方案四轮的钱。
5. 非交互的批量送验可排在 00:00–10:00，但**先确认该折扣是否覆盖 AI 应用通道与当前 appId**（官网横幅只明确 H3 RH Enhanced）。
6. **不要靠拉长时长省钱**：9s 单条 22.61–29.58 看似低于两条 5s 上限（48.66），但 Circle12 实测切点 5.58／7.58s，与卡内 30/36.7/33.3% 不符——省下的钱换来时间轴失控。
