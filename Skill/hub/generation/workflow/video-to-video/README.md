## 口径三条

1. **先看 webappId 再看使用量**：top40 里 14 条没有 app（含 VIP-Wan 编辑 31014、LTX2.3 去水印 21934），只能复制工作流，进不了「一条一账」。
2. **webapp 无价目**：10 条价格候选路径全 404，页面「运行消耗」不进 API；实跑一条读余额差。锚：i2v 5s ≈ 21.4 积分，Animate 类重工作流按 2–3 倍估。
3. **标准 API 价目只作比价参考**（15 个有价），不能按它做预算——本账号调不了。
