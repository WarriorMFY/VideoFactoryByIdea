# 判定口径（Circle27 首版）

> 初值为假设，首轮基线跑完后用实测校准；校准记录写进报告。顺序：先 `metrics.json`，再看 sheet。

## 自动指标（`measure.py`，全部相对锚图，输出缩到锚尺寸）

| 指标 | 回答什么 | 用法 |
| --- | --- | --- |
| `ncc_global` / `ssim_gray` | 整体像不像原图 | 总漂移；景别组不适用 |
| `edge_ssim` | 构图/轮廓锁没锁 | 光线、画风、表情组的**非目标漂移**主指标 |
| `d_luma_pct` / `luma_std` | 光线变没变 | 光线组的**目标达成**指标 |
| `sat_mean` / `hist_l1` | 色彩/画风漂没漂 | 画风组目标指标；其余组当漂移指标 |
| `lap_var` | 锐度/笔触（磨皮还是加细节） | 辅助判断，别单看 |
| `face_ratio` / `face_ratio_x` | 人脸占图高比 | 景别（人物）的目标指标；**需可选 YuNet 模型，缺模型则人工** |
| `face_ssim` | 人脸区结构相似 | 长相漂移；表情组会自然下降，需人工分辨 |

> OpenCV 5 已移除 Haar 级联。`models/README.md` 放 `face_detection_yunet_2023mar.onnx` 即启用自动人脸指标；没有模型时字段为 null，不报错，全部改人工终判。

## 判定档（三档人工终判，数字只作证据）

| 变量 | 目标达成（初值） | 非目标漂移（初值） |
| --- | --- | --- |
| 景别（B） | `face_ratio_x` 相邻档递增 ≥15%，胸像 ≥1.8× | `hist_l1` ≤0.08 色彩锁定；`face_ssim` ≥0.85 长相锁定 |
| 景别（A） | 人工：画面主体占比与视野明显变化 | `hist_l1` ≤0.08；画风保持写实摄影 |
| 光线 | `|d_luma_pct|` ≥8 或 `luma_std` 变化 ≥20%，且方向对 | `edge_ssim` ≥0.90 无／0.80–0.90 轻微／<0.80 明显 |
| 画风 | `hist_l1` ≥0.12 且笔触/饱和度明显变化 | 只作参考：主体轮廓与位置不漂（人工） |
| 表情 | 人工看人脸裁片：平静/微笑/惊讶 | `edge_ssim` 与 `face_ssim`；`face_ssim` 下降含长相漂移，需人工分辨 |

## 基线校准

- 每条基线把「保持原图不变」跑一遍，得到采样噪声底：`ssim`/`edge_ssim`/`hist_l1`/`face_ssim`。
- 后续判「漂移」必须**超过基线值**；未超过的一律记「采样噪声内」。

## Circle27 实测校准（2026-11-23，Flux3）

基线噪声强烈依赖锚类型，**A/B 不能共用阈值**：

| 基线 | ncc | ssim | edge | hist | 画像 |
| --- | --- | --- | --- | --- | --- |
| 风景锚 | 0.78–0.82 | 0.32–0.40 | 0.18–0.23 | 0.13–0.14 | 连“保持原图”都做不到，偶发天空伪影；景别变量不可测 |
| 人物锚 | 0.89–0.92 | 0.86–0.89 | 0.86–0.89 | 0.78–0.88 | 构图/服装/姿态保持；**脸与发型全换、背景转暖** |

用法修正（经 15 条成功实验复核）：

- **ncc 是景别推近的最佳代理**：B 基线 0.89 → 半身 0.42/0.34 → 胸像 0.06/0.005，单调可分；裁切不需要 `face_ratio`（模型未装也行）。
- **dsat 在低饱和锚上放大严重**（背景浅灰→暖色即可 +200–600%），B 组不能单看 dsat，必须配 `hist_l1` + 视觉。
- **光线只有强信号可测**：黄昏逆光 `dluma` −32~−40%、hist 0.34–0.40；正午/清晨在指标上几乎不可分辨。`dluma ≥8` 的初值门槛过低，建议判“达成”用 `|dluma| ≥15% 或 hist ≥0.25`。
- **“长相锁定 `face_ssim ≥0.85`”当前通道达不到**：基线就换脸，此档作废，改记“身份不可保”为通道硬边界。
- 温和编辑（表情组）保持度最高（ncc 0.94–0.98，dsat +2~21%）；大幅编辑（胸像/逆光）必然伴随色彩与身份大漂。
- 失败也是结果：805 失败 5/20 且未扣费，记录为边界点，不在本轮重跑。
