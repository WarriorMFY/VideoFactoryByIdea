- 共 20 条（18 变量 + 2 基线），预算估算 ≈ 401 积分。
- 优先级：A-V1 → A-V2 → A-V3 → B-V1 → B-V2 → B-V3；预算不够砍尾部。
- 为什么 B 从七分身起：锚已是全身，再往「远景全身」推需要凭空造环境，会把「景别变化」变成「内容新增」。

## prompt 模板

```text
把<目标变量>改为<档位>；其余全部保持不变：<逐项锁定清单>。
```

- 锁定清单逐项点名：主体外形与位置、构图、景别、光线方向与色温、画风与笔触、细节、文字。
- 一条只描述一个变化；禁止「优化／美化／提升清晰度」类词。
- 同组锁定段逐字一致，只换目标句（脚本记 `prompt_sha1`，可核对）。

## 加一条新实验

1. 新锚放 `anchors/`，在表里登记尺寸与 SHA1；
2. 新 prompt 放 `prompts/<id>.txt`，沿用模板；
3. `run.py --id <id> --group <组> --var <变量> --level <档位> --anchor ... --budget 600`；
4. `measure.py` → `sheet.py` → 进报告。
