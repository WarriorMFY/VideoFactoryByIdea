# t2i 判据（无锚版）

> i2i 有锚图可量 ncc/ssim；t2i 无锚，判据是四样：尺寸、清晰度、镜像对称度、物件完成度。
> 数字先出，眼睛后看。

## 一、尺寸核对

| 项 | 判据 |
| --- | --- |
| 档位 | `18:resolution` 只有 1k/2k/4k；1k 输出尺寸随比例变（3:4 → 880×1184，16:9 按实测记录） |
| 核对 | `metrics.json` 的 `size` 与同档位历史值一致即过；不一致报警（通道可能换了底座） |

## 二、清晰度（`lap_var`，Laplacian 方差）

| 值 | 档位 | 含义 |
| --- | --- | --- |
| < 80 | 糊 | 背景大面积雾化或缩放失真——检查是否小图放大 |
| 80-300 | 中 | 正常成片带 |
| > 300 | 锐 | 细节丰富，但可能过锐（纹理噪点） |

同组内 `lap_var` 突变（±50%）说明提示词风格变了或采样异常。

## 三、镜像对称度（`mirror_ncc`，本通道特有）

> 本通道（G-2.0 低价版）**倾向镜像对称构图**（Circle4 §33.4 实测）。左右翻转后的 NCC 衡量这个倾向。

| 值 | 含义 | 处置 |
| --- | --- | --- |
| ≥ 0.90 | 疑似镜像构图 | 不对称动作卡（出拳/侧身）不可用此条；对称需求（正面肖像/对称建筑）反而合适 |
| 0.75-0.90 | 大体对称 | 可用，但动作卡要人工确认左右手 |
| < 0.75 | 无镜像倾向 | 安全 |

第二档通道 `2061698064745852930`（19.60/张，+77% 价）无此倾向——不对称动作卡预算够就换档。

## 四、物件完成度（人工，必须写记录）

- 提示词里的物件是否**全部出现**（数清楚：几个人、几件道具）
- 位置/遮挡/朝向是否符合卡片约束
- 结论写成「缺什么 / 错什么」，不许写「整体不错」

## 五、什么算边界点

| 现象 | 归类 | 处置 |
| --- | --- | --- |
| 物件全在但风格偏了 | 能力边界 | 记下来，换表述试一条 |
| 物件缺了 | 提示词没锁住 | 改卡（具体化、前置主体），重跑 |
| 出现镜像翻转（左右手反了） | 通道副作用 | 记 `mirror_flag`，动作卡换通道 |
| `lap_var` 断崖下跌 | 通道异常 | 记 charged，报警 |

## 六、成本纪律

- ~11 积分/张（10.72-12.10 浮动），估价按 12；
- 一条一账，`charged` 记原文；
- 批量验证优先 1k，2k/4k 只留给终稿。
