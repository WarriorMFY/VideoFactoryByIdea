# ai-director · 核心手册

> 链内**唯一数值源**。语义判断（事件链完成度、像不像）不写这里，写在各 stage。
> 每条数必须带出处（Circle / 任务号）。没实跑过的只许写「未实测」，不许写估值。
> 改动须附一次实跑，不接受「感觉」。§1–8 是事实层，§9 是方法层，两者互不越界。

## 1 锚（四类，顺序锁死）

| 锚 | 回答 | 载体 | 锁定判据 | 已知失效 |
| --- | --- | --- | --- | --- |
| 风格 | 世界长什么样 | 1 图 + 风格词 | 用户选定即锁 | 抽数 <4 时容易锁到偶然 |
| 空间 | 戏发生在哪 | 图 + 空间描述 | `lap_var`/`sat_mean` 与风格锚同带；构图留出站位 | 只喂文字会另画场景（SSIM 0.22） |
| 身份 | 谁在演 | 正脸 + 全身 | 关键帧对肖像 `ncc ≥0.75`（**未落数**：人工框 + 角度光照差时量出 0.145 / 0.190，无判别力 — 圈 30） | 景别推近 + 姿态改动叠加时丢脸；判据在「正脸锚 vs 3/4 侧光帧」下未成立 |
| 镜头 | 这一刻的画面 | 关键帧 + 动作卡 | 事件清单全中 + `mirror_ncc <0.90` | 单图锚必丢场景，须双图 |

纪律：换锚＝换基准，下游全链重走；一锚一账（prompt 快照 + 任务号 + 实扣 + 度量）。

## 2 阈值

| 层 | 指标 | 阈值 | 失效条件 |
| --- | --- | --- | --- |
| 空间锚 | `lap_var`/`sat_mean` 同带 | ±50% | 风格锚自身偏色 |
| 关键帧 | 对空间锚 SSIM | 单图 0.22 / 双图 0.50 为分水岭（圈 30 双图加人：0.431 / 0.304） | 构图被指令大改 |
| 关键帧 | `mirror_ncc` | <0.90 | 对称场景本身合法 |
| 视频 | 首帧锚 NCC | ≥0.90（历史 0.956；圈 30 油画锚两段 0.8309 / 0.8308，偏松非崩） | 首帧必被重绘，此项只证「没跑偏」 |
| 视频 | 时长偏差 | ≤0.25s | 通道帧数档位跳变 |
| 视频 | 运镜 or 溶解 | hf 中段/两端 <0.75 **且** 中段不快 → 溶解；快 → 运镜带模糊 | 只拿 hf 单判必误 |
| 视频 | 锚是否填反 | 看「首帧×A 是否显著 > 首帧×B」 | 两锚本身相似时交叉项无判别力（0.55 属正常） |
| 剪辑 | 尺寸/帧率/黑边 | 一致，无黑边 | 前科 122px 黑边 |
| 剪辑 | 切点噪声 | 6–8 帧 | — |

| H3 首帧 i2v | `2113790012012720129` | 22.78–27.20/条 | 姿态类小动作 | 朝向类零响应；镜头固定不可控 |
| VACE 首尾帧 | 自带工作流 | 19.04–47.77/条 | 两端锁 0.96–0.99 | 中段仍脑补；末帧可能顿 |

## 4 边界（已证，别再试）

| 现象 | 证据 | 绕法 |
| --- | --- | --- |
| 运动方向由首帧主导 | 换 prompt 后两版 ncc 均 0.7622 | 换首帧构图，不加措辞 |
| 自动缓慢推镜 | prompt 反复写「固定」无效 | 近景帧预留推近余量 |
| 长镜头上限 | 5–6s | 拆段或首尾帧 |
| 首帧必被重绘 | hf 7.2 vs 同缩基线 10.7，抹 3.5–3.8，与出片宽度无关 | 要保笔触只能走剪辑（不重绘像素） |
| 锚越像视频帧越保得住 | SSIM 0.9753 vs 0.8482 | 锚自带运动模糊反而更好 |
| 末帧顿帧 | 49 帧版一帧涨 0.087；129 帧版平稳 6.7–7.6 | **片长给够，末帧是走到的不是拽到的** |
| 图生图重画主体 | 白鹿面积 −34%、剪影 IoU 0.60 | 增益场合成，不指望提示词锁姿态 |

## 5 修复（半过四招）

| 招 | 用在 | 代价 | 副作用 |
| --- | --- | --- | --- |
| 换首帧重抽 | 方向/朝向错 | 一次出片 | 前一次全废（**不算修复，算重做**） |
| 局部重绘 | 局部脏、多物 | 一次 i2i | 周围易串色 |
| 首尾帧锁 | 落点不准 | 一次首尾帧 | 中段可能溶解 |
| retime | 节奏快慢 | 0 | 不改内容 |
| 只重跑末段 | 尾巴崩 | 半条 | 接缝需 crossfade |

## 7 账

`起始 − Σ charged = 结束`，不平不许结圈。
稳定度三数：**抽数**（几次过线）、**过线率**（一次过/总抽）、**单镜积分**（含废片）。
废片必须留，删了这圈等于白跑。

## 8 改动规则

1. 只有实跑能改数，每条数带 Circle/任务号。
2. 「未实测」的条目只许补，不许当判据引用。
3. 语义判断进 stage，不进本文件。
4. 本文件与 stage 冲突时以本文件为主，stage 改。
5. 卡与产物字段可对齐其他链的写法，但**不引用其他链的文件**（跨技能只能引 `hub/`）。

## 9 生长协议

### 9.1 台阶

| 档 | 内容 | 升级条件 |
| --- | --- | --- |
| L0 | 单张静帧，画风稳住 | 用户认可风格锚 |
| L1 | 单镜微动（只水动 / 只抬头） | 该镜一次过线 |
| L2 | 单镜有事件（走出、转身、递物） | 事件链完成度全中 |
| L3 | 两镜同场景同人（锚复用首次受检） | 两镜人景双守 |
| L4 | 四到五镜多场景 | 一致性抽样不崩 |
| L5 | 长片 / 批量（资产复用率） | 三数可复现 |

升级门槛：**待实测**。圈 26 停在 L2、圈 28 在 L3，尚无一个档位跑出过两圈连续数据，所以不写数。

### 9.2 失败五分类（现为六类，圈 30 加「观察失效」）

| 类别 | 症状 | 处置 | 去向 |
| --- | --- | --- | --- |
| 通道故障 | 805、NO_API_KEY、超时 | 零扣费则原样重试，不记教训 | 不进技能 |
| 判据失效 | 好片与废片量出同一个数 | **先补判据**，否则后面全是盲跑 | §2 加「失效条件」 |
| 能力边界 | 朝向零响应、自动推镜、5–6s 硬限 | 记下来，改设计绕开，不再重试同一句 prompt | §4 |
| 表达失败 | 写「涟漪」出 3D 同心圆 | 换词重试，属提示词层 | stage 的 prompt 段 |
| 观察失效 | 抽帧判「状态没变」，动态里其实变了（圈 30：四等分抽帧间隔 1.67s，漏掉压纸中段，误判戏眼不成立） | 否定结论先在动态逐帧复核；抽帧只判构图、接缝、溶解、多手、尺寸 | 各 stage 的观察纪律 |
| 流程缺失 | 空间锚从未进关键帧 | 升为铁律 | `SKILL.md` 铁律 |

### 9.3 三数与停手

三数同 §7，从同一份 `experiments.jsonl` 算，不另建账。
停手信号只有两条：连续两圈同一处失败 → 是判据或设计问题，不是运气；废片被删 → 这圈白跑。

### 9.4 一圈只加一个变量

同一圈内改两处，出问题分不清是谁造成的。要同时试两条路，拆成两个 `proj/` 项目各跑一次，分别记账。

### 9.5 结圈回写

技能靠这一节长大。结圈时按四类分流，不许混写：

| 类型 | 例 | 去向 |
| --- | --- | --- |
| 事实（数、价、边界） | 首帧 NCC 0.83、SSIM 0.43 | §1–4，每条带 Circle / 任务号 |
| 语义（像不像、戏眼成没成立） | 「纸被压平了」 | 对应 stage，不进本文件（§8.3） |
| 一次性现象 | 805、当轮产物、某张废片 | 只留 `Log/`，不进技能 |
| 方法（怎么看、怎么判） | 抽帧判不出状态联动 | §9.2 + 该 stage 的观察纪律 |

纪律四条：

1. **没有实跑不改数**；「未实测」只许补，不许升格成判据（§8.1 / §8.2）。
2. **每圈最多回写三条**，其余进 `evidence/changelog.md` 的候选区——单圈噪声不许把技能带偏。
3. 回写前先问：这条换个通道还成立吗？只在单通道成立的，写进 stage 的「本通道」段，不写进 §1–4。
4. 每次回写在 `evidence/changelog.md` 追加一行（日期 · 圈 · 文件 · 条目 · 依据 · 谁点头）。**技能改过什么必须可追**，否则下一圈不知道自己在什么基础上改。
