# proj · 实验归档

一次实验 = 一个项目 = 一个归档单元。**这里只放结论，过程留在当轮 `Log/Circle<N>/`。**

## 两种形态

| 形态 | 用在 | 内容 |
| --- | --- | --- |
| 单文件 `pNN-短名.md` | 立项即规格、无独立剧本的实验（p01、p02） | 项目卡 + 结论 |
| 目录 `pNN-短名/` | 有独立剧本或附件的实验（p03 起） | `index.md`（项目卡）+ 剧本/规格的指针 |

目录形态只是把「项目卡」放进 `index.md`，其余规则不变；附件仍优先留在圈内，proj 只放指针。

## 三条硬规则

1. **只记结论**：拿得走的判断与规则。抽卡明细、废片清单、逐帧曲线一律不进这里。
2. **一条规则一行**，可判真假，不写「效果不错」这类形容词。
3. **能指回证据**：结论末尾给 Log 指针，本技能文档允许指 `Log/`（作证据），代码不许 import。

## 文件格式

文件名 `p<两位序号>-<中文短名>.md`，序号只增不改，归档后不再编辑；有新结论另开新项目。

```md
# pNN 短名

| 项 | 值 |
| --- | --- |
| 档位 | L0–L5 |
| 圈 | Circle<N>（日期） |
| 变量 | 这一圈只加的那一个 |
| 三数 | 抽 X · 过线 X/Y · 单镜 ≈Z |
| 状态 | 已归档 / 部分成立 |

## 结论
1. …
## 带走的规则
- …（将来进 SKILL.md 铁律或 core.md §4/§9 的候选）

## 过程
`Log/Circle<N>/`
```

## 与台阶账的分工

`proj/` 记**一个实验想了什么、证到了什么**；`evidence/steps.md` 记**技能现在站在第几档**，一行一圈，只写结论不写理由。
