# ⑦ 剪辑与声

节奏在这里定，不许回生成端抠像素。段级重跑是本链独有的权力：只重跑坏的那一段。

## 步骤

1. **统一规格**：目标尺寸帧率写死（如 3:4 672×928@24），逐段缩放并**裁掉黑边**（前科 122px）。
2. **拼段**：按卡序接，切点留 6–8 帧噪声余量；接缝差跳变就补 3 帧 crossfade。
3. **声音三轨**：
   - 对白 TTS：段卡 `audio.dialogue`，逐条生成，按画面时长上限截断。
   - 音效：`audio.sfx[]` 时间点投放，误差 ≤3 帧。
   - 配乐：全片一条，按段落表切；响度先统一再混。
4. **口型不做**：明确不追 lip-sync，靠景别与遮挡规避。
5. **验收 + 平账**：成片给用户过目；`起始 − Σ charged = 结束`，不平不许结圈。

## 通过线

- 全片尺寸帧率一致，无黑边，无 >50ms 静音断层。
- 每段戏眼在成片里仍成立（拼起来没有互相削弱）。
- 账平；废片与修复记录都在。

## 产物

`Log/Circle<N>/edit/`：`final.mp4`、`segments.json`（切点/时长/来源段）、`audio/`（对白与音效）、`ledger.json`。

## 不过怎么办

- 接缝跳 → 先看是不是两段色阶不同，用调色对齐比 crossfade 更省。
- 声音与画面不同步 → 单段重带声音比重做画面便宜得多，先试这个。
- 时长超标 → 剪节奏，不要回 05 加抽。
