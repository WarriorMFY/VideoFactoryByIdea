# ① 定轴拆卡

一卡 = 一个因果事件，不是一句形容词。「戏眼」= 这张卡必须成立的那一件事，用来判这镜过没过。

## 步骤

1. 按因果切：谁的什么动作，导致画面发生什么不可逆变化。切不动就是同一卡。
2. 每卡填四格：**景别**、**机位**、**动作**、**终态**（末帧停在什么状态）。
3. 写戏眼：一句「必须成立的事」，要能被判成立/不成立，不许写「氛围凄美」这类。
4. 定卡序：相邻两卡的终态与下一卡起态必须能接，接不上就补一卡过渡或合并。

## 通过线

- 删掉任意一张卡，故事是否缺一块？缺 → 真卡；不缺 → 语气卡，降级为别的卡的修饰。
- 每卡四格无空，戏眼可判真假。
- 卡数与预算相称：一卡对应至少一次视频出片，超过软上限一半就得砍。

## 产物

`Log/Circle<N>/cards/`：`card-01.md` … 每卡一份；目录级 `manifest` 记卡号、景别、戏眼。

## 不过怎么办

- 戏眼写不出来 → 这卡是气氛，合进相邻卡，别硬拍。
- 两卡终态接不上 → 中间补一卡「过渡动作」，或改成首尾帧两锚（见 `core.md` §3）。
- 卡数超预算 → 先砍戏眼最弱的一卡，不要砍视频抽数。
