# ② 风格锚

全链的画风基准。锁错一次，下游全废，所以这一段的钱不能省。

## 步骤

1. 写四件：**风格**（片子像什么）＋**材质**（绢/胶片/平涂）＋**光影**（光源与方向）＋**色板**（主色与禁色）。
2. 先定**分叉方式**，再抽 ≥4 张：
   - **同路子单维对照**（只改明暗、只改镜头、只改笔法）：用来试关键词稳不稳。
   - **跨媒介分叉**（换媒介或换造型逻辑：明暗立形 / 景深立形 / 线立形 / 块面立形）：用来找真正不同的方向。
   - 圈 29 在纸本里换笔法只出两极；圈 30 跨油画 / 摄影 / 绢本 / 木刻，四张真分开了——**想分开就别在同一路子里换形容词**。
3. 拼版并排给用户看，由用户指一张；AI 不自选。
4. 定稿图落盘并记关键词，后续所有 prompt 都带这段词。

## 通过线

- 抽数 ≥4（少于此容易锁到偶然）。
- 用户明确点名一张。
- `mirror_ncc <0.90`：G-2.0 有镜像对称倾向，对称场景正好，不对称陈设要警惕。
- 候选里至少两张风格接近，说明关键词稳定；四张各异说明词没写死。
  - 但**跨媒介分叉时四张必然各异，这是预期**——此时的判据换成「四张都认得出是同一个场景」。别拿上一行的标准去否掉一次成功的分叉。

## 产物

`Log/Circle<N>/style/`：`style-anchor-locked.png`、`style-compare.png`（拼版）、`prompt.txt`（关键词快照）、`experiments.jsonl`（每抽一条：任务号/实扣/度量）。

## 不过怎么办

- 四张互不相干 → 关键词太少，补材质与色板，重抽一轮。
- 质感对但布局错 → 布局不是这一段的活，去 02，别在风格锚上抠构图。
- 想换更贵的通道追质感 → 先算账：官流单张 ≈50，是 G-2.0 的 4–5 倍（见 `core.md` §3）。
