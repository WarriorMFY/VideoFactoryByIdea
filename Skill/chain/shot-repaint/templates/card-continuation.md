# 延续卡模板

用于氛围、光照、介质流动在段内渐变的镜头（过场、空镜、慢推）。整卡两份：上面是卡，下面是提示词。

```markdown
---
name: <段>-<场景>-<主变化>
desc: <一句话：场景 + 机位 + 段内主要变化>
axis: 起因（<触发物>）→ 传导（<介质>）→ 结果（<可指认的末态>）
---

| 项 | 内容 |
| --- | --- |
| 主体 | <主体是什么，位置、材质、数量> |
| 起始态 | <首帧此刻的状态；只写会被改变的那几项> |
| 动作时序 | 0–<x>s <第一段变化>；<x>–<y>s <第二段变化>；<y>–<段长>s <收束> |
| 接触事件 | <A 与 B、C 与 D> |
| 位移 | <哪部分移动、朝哪、整体还是局部> |
| 结果态 | <末态与起始态的差，写可指认的形态，不写程度副词> |
| 禁止 | 不切镜、不改机位、不增删构件、不让人物入画、<字幕取舍> |
```

```text
同一<场景>、同一<主体>、同一机位与同一冷暖布光，写实电影质感，镜头不动。

动作：<按时间顺序写变化，一句一段；量与幅度用相对说法，不写精确数值>。

不要切镜，不要改变景别，<不要出现人物>，<不要出现文字／保留原有文字>。
```

## 写作禁忌

- 不照抄首帧已满足的描述——那等于要求「保持原样」。
- 不写精确数值（圈数、百分比、占画面几分之几），见 `../reference/limits.md`。
- 不写左右方位指派，用持械手／防御手这类功能位替代。
- 变化幅度用「偏大／偏小、更亮一档」这类相对量。
