# ② 取帧配卡

首帧是**像素锚**，卡与提示词是**语义指令**。锚决定构图与画风，指令决定在锚允许的范围内发生什么。

## 步骤

1. **抽帧**：`python scripts/keyframes.py --table segments.json --outdir keys`。源片带转场时加 `--pad 1`，把首尾各向内收一帧。
2. **选卡型**：
   - **延续卡**（`templates/card-continuation.md`）——要求氛围、光照、介质流动在段内渐变。适合过场、空镜。
   - **事件卡**（`templates/card-event.md`）——要求一处构件或主体发生可命名的变化。适合有叙事的镜头。
   - 两者不能只靠换词来区分：事件卡必须给出「时刻 + 位置 + 结果态」。
3. **写提示词**：末行固定写禁项（不切镜、不改景别、不入画人物、不出现文字）。
4. **对齐时长**：卡内时间轴的总长与段长一致；投给模型的是通道档位，不是段长。

## 写作要点

- **不要照抄画面里已有的东西**。把首帧已经满足的描述再写一遍，等于告诉模型「保持原样」，这是「太像」的最常见来源。
- 事件写在**主体所在区域**，不要写在画面边角：位置指令有效，但模型只在被指定的那块做改动。
- 可数量词与精确比例不要指望被执行，写法见 `reference/limits.md`。

## 通过线

- 占位符 `<...>` 全部清空。
- 卡内时间轴总长 = 段长（±0.1s）。
- 提示词里没有「左右」这类被证实无效的方位指派。

## 产物

`keys/<段>-first-f<n>.png`、`keys/<段>-last-f<n>.png`、`cards/<段>.md`、`prompts/<段>.txt`。
