# SkillViewer · 技能挂载树速览

## 何时用

- 想快速看清某个技能由哪些子技能、参考、脚本、模板组成。
- 交接或盘点技能库，需要一张带说明的结构图。

## 何时不用

- 要修改、新建、废弃技能（本技能只读）。
- 要查看 `Skill/` 以外的目录，或要评判技能质量。

## 步骤

1. 确定技能名：`Skill/` 下的目录名，或 `Skill/` 开头的子路径。
2. 运行 `python Skill/meta/skill-viewer/scripts/view_tree.py <技能名|桶/技能>`，把完整输出贴回对话。
3. 问用户「是否留痕？」；给目录后加 `--out <目录>` 重跑，脚本自动命名 `<技能名>-tree.md`。
4. 用户要可折叠界面时，改跑 `--html <目录>`，生成单文件 `<技能名>-tree.html` 并打开预览；可叠加 `--out`。
5. 用户只要某类文件时加 `--filter .md,.py`（逗号分隔，默认全部）；HTML 页面顶部也能按后缀即时筛选。
6. HTML 的描述有两种互斥模式，顶部「描述」开关切换：`side` 右侧常驻（默认）、`hover` 悬停浮出；生成时可用 `--mode hover` 指定默认。

## 输出

- 目录行只有名称，不挂描述；文件行是 `名称  ← 一句话描述`，描述只从该文件自身取（如 SKILL.md 读自己的 frontmatter）；取不到写「（无自带描述）」。
- 不编写、不补全、不跨节点拼凑，也不从父目录抄描述；抽取优先级见 `reference/extraction.md`。

## 边界

- 只读 `Skill/`；不改被查看的文件，不提交 git。
- 长描述默认截到首句；要看全文加 `--full`。
