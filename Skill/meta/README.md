# 技能库 · Meta

> PS: 当前文件LLM只读!
>
> 目标: 一切命令技能化，规范化，可控制，可维护！
>
> 规则1: 技能不止要写明何时触发，也要写明何时不触发!
>
> 规则2: 技能得大小(专指Skill.md)不能超过30-40行（依据：5 秒内人可把握的信息量 ≈ 300 字 ≈ 30 行；上限 40 行留给一张表格。当前技能先不动，只作新增技能的硬门）
>
> 规则3: 遵循模块化设计原则，简单优于复杂，组合胜于堆叠！
>
> 规则4: 唯一真相源原则，头部文件只领方向与概要不要包含下方文件中的细则，同样下方文件不要出现纲领
>
> 规则5: 技能内部保持70%以上自包含独立，30%可以引用外部

## 技能清单

| 技能 | 一句话 | 何时用 |
| --- | --- | --- |
| `skill-viewer/` | 只读输出任一技能挂载树，每个文件附一句摘自其自身的描述 | 想看清某技能由哪些文件组成 |
| `smoke-test/` | 无费用冒烟：依赖、Prompt 一致性、L3/L4 送验替身、抽帧拼图、可选在线查账 | 改完东西想确认工线还能不能跑 |
