# 阶段③ 文生图

## 何时用

- ② 自检七项全过，要先用一张图验构图、要素、明暗。
- 图已出但要补量覆盖表。

## 何时不用

- 卡还没过自检 → 回 `stages/02-instance-card/`。
- 图已过线、要继续出视频 → `stages/04-video/`，本阶段不再重复拼装。

## 三个动作

1. **拼装**：`scripts/compose.py` 只做拼接，顺序固定「固定变量 → 反向 → 主卡」，`【固定变量卡】`／`【反向卡】` 标签由脚本加，主卡不加。模式二选一：`full`（默认，带两张伴生）／`main`（只发主卡）。
2. **出图**：`scripts/run_still.py`，通道与节点见 `reference/channels.md`；先出 1 张，别一次抽多张。
3. **判读**：卡里每个维度一行，三档打分（`1` 命中／`0.5` 部分／`0` 未出现），逐行写证据。

## 四个直送断言（任一失败即中止，不提交任务）

| 断言 | 含义 |
| --- | --- |
| `VERBATIM` | 每张卡正文在投递体中逐字节出现 |
| `ORDER` | 卡出现顺序 = 声明顺序 |
| `NO_REWRITE` | 写盘后重读，与内存字符串完全相同 |
| `AUX_SHARE` | 仅 `full` 模式，实数 ≤10，超限报错并给出超出字数 |

## 交付物

- `image/prompt-image.txt`、`<tag>.png`、`<tag>.png.prompt.txt`（三者缺一视为未发送）
- 覆盖表：维度／判据／分／证据秒数

## 通过线

加权覆盖 ≥70% 才进 ④；未过线**先改卡**，不许「再跑一次碰运气」。归因按 `reference/judging.md`：同一项 ≥2 条独立样本都失分才算卡片问题。
