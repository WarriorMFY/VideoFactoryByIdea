# 一句话描述的抽取细则

> 本文件只定义「一句话描述从哪取、怎么截」，不重复 `SKILL.md` 的触发条件与步骤。
> 总原则：**只摘录节点自身已有的文字，不编写、不推断、不跨节点拼凑。** 取不到就输出 `（无自带描述）`。

## 目录节点

**目录不挂描述，只列名称。** 目录是容器，不摘录它的说明——描述归它内部的 `SKILL.md` 文件自己所有，在文件节点上显示。目录名本身也不算描述（它是标识，不是说明）。

## 文件节点

每个文件显示一句摘自**该文件自身**的描述；不因为与父目录同名同句就去重或改写。

| 类型 | 来源（按优先级） |
| --- | --- |
| `*.md` | frontmatter `description` → 首个 `#` 标题 → 首个 `>` 引用行 → 正文首个非空行 |
| `*.py` | 模块 docstring 首行 → 首个 `#` 注释行 → 无 |
| `*.json` | 顶层 `description` 字段 → 无（`name`／`version` 是标识，不算描述） |
| 其他（图片、音频、数据等） | 无 |

## 截断规则

1. 取到的字符串压成单行，去除首尾空白与引号。
2. 取**首句**：到第一个 `。`／`！`／`？`／`;`，含标点；无句末标点则取整行（默认上限 120 字，超出截断并加 `…`）。
3. `--full` 参数：跳过截断，输出完整描述（仍为单行）。
4. 描述里含占位符（`<...>`）或模板指令时**原样保留**，不翻译、不补全。

## 为什么这样定

- `card-experiment-chain-v2` 的四个阶段是嵌在 `stages/` 里的子技能，各有自己的 `SKILL.md` description；目录只作容器，描述由各自的 `SKILL.md` 文件节点显示，做到「一句话看懂这一文件」，而不用进目录翻正文（对应 Meta 规则4：唯一真相源）。
- `scripts/*.py` 都有模块 docstring 首行，正好是一句用途说明；`templates/*.md` 的 `description: |` 首行是「介绍：…」，也是现成的一句话。
- 宁可显示 `（无自带描述）`，也不替节点编一句——编出来的描述会变成第二份真相源。

## 展示形态

- 对话输出：目录行只有 `名称/`；文件行是 `名称  ← 描述`，整份平铺。
- `--html <目录>`：同一份数据渲染成单文件 HTML，每个目录节点可点击展开／折叠，附带「全部展开／全部折叠」。HTML 不引入外部依赖，描述口径与对话输出完全一致。
- `--filter .md,.py`：只保留命中后缀的文件节点，目录为保持树连通而保留，过滤后变空的目录不显示；不传则展示全部文件。文本与 HTML 两种形态都支持。
- HTML 顶部有「文件类型」筛选芯片（从树中实际出现的后缀自动生成，默认全选，点「全部」恢复）：按后缀即时隐藏／显示文件节点，空目录随之隐藏；此为纯展示过滤，不改树、不改抽取结果。
- HTML 的描述展示有**两种互斥模式**，顶部「描述」开关切换，任何时刻只显示一种：
  - `side`（默认）：一句话常驻节点右侧；不生成悬浮浮层。
  - `hover`：行内描述隐藏，鼠标悬停**文件**节点才浮出该文件的一句话描述；目录无描述、无浮层。
  - 两模式同源于同一份抽取结果，切换只改展示、不改数据；生成时 `--mode hover` 可改默认，非法值回退 `side`。
- 两种形态都只读 `Skill/`，都不编写描述；HTML 不是第二份真相源，它只是同一棵树的另一种排版。

## 边界

- 不读取 `Skill/` 以外目录；符号链接不跟随。
- 不做评分、不做推荐、不改被查看的文件；`--out` / `--html` 只写用户指定目录下的结果文件。
