# 边界 · 必失败场景与处置

> 抠图的成功率不取决于模型多贵，取决于「主体与背景在像素上是否可分」。下面是本项目实测与公开已知的硬边界。

## 一、五类硬边界

| 场景 | 为什么难 | 处置 |
| --- | --- | --- |
| 半透明物（玻璃杯、水、烟） | 一个像素 = 前景×a + 背景×(1−a)，求解 a 需要解方程，单模型只能猜 | 归「不可解」，交人审；不要反复重跑 |
| 毛发、纱、羽饰 | 需要 0–1 连续软蒙版；二值分割必出锯齿 | 加 `--alpha`（rembg 的 alpha matting），仍不足则人审 |
| 主体与背景同色（白衬衫贴白墙） | 颜色/纹理上无边 | 换模型无效；只能人工画选区分层 |
| 主体贴画边、出画 | 没有背景包围，模型只能沿边切 | 轻微可用；成片用需扩边（先 pad 再抠再裁回） |
| 多主体同框 | 模型按「显著主体」给一张整体蒙版 | 逐个裁小图分别抠，或人审分离 |

## 二、四个易被忽略的失真

1. **背景色渗透（白边/灰边）**：抠出的半透明边缘仍带原背景色，换到深色底会显一圈白。
   处置：蒙版先腐蚀 1px 再羽化；或反过来把新背景先铺成原背景的近似色。
2. **阴影默认丢失**：模型只认主体，不认投影。要保留投影必须人工补一层。
3. **细节缺块**：细长道具（枪管、天线、鞋带）常被当背景剔掉，属「主体不缺块」这条通过线的常见失分点。
4. **分辨率缩放**：模型内部按固定边长推理，小主体（占画面 <3%）细节会糊；先把主体裁出来再放大抠。

## 三、视频里的抠图（本技能不承诺）

逐帧独立抠 → 边界每帧抖一次，成片闪烁。要出视频必须上时序模型（或剪辑软件的人像跟踪），
或退一步：**静帧抠好 → 合成静态层 → 让镜头动**。本技能只保证单帧。

## 四、判断顺序

```text
边缘有无背景色残留 → 主体有无缺块 → 软边是否自然
        ↓不过                ↓不过            ↓不过
   换模型重跑        看是否属"同色/贴边"      加 --alpha
        ↓仍不过
     交人审（不自行修边）
```
