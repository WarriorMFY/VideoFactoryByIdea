# 投递体：直送拼接

> 根 `AGENTS.md` 的「整卡逐字节直送」「伴生卡合计 ≤ 基础卡 10%」是本规则的上位原文；本文只是它的操作细则，冲突以 AGENTS 为准。

## 规则

1. 只剥 YAML frontmatter，正文逐字节保留；不抽字段、不合并句子、不改标点。
2. 顺序固定：固定变量卡 → 反向卡 → 主卡。`【固定变量卡】`／`【反向卡】` 标签由脚本加，主卡不加。
3. 只有两种模式：
   - `full`：主卡 + 两张伴生卡（默认）
   - `main`：只发主卡，投递体 = 卡正文，逐字节相同
4. `aux_share = (len(fixed) + len(anti)) / len(main) × 100`，必须 ≤ 10。
5. 超限处理：删形容词、把细项移到质检表；**不许压缩主卡来凑比例**。
6. 写盘统一以单个换行结尾；提交时按 `rstrip("\n")` 去掉，快照存去尾版。

## 断言（任一失败即中止，不提交任务）

| 断言 | 含义 |
| --- | --- |
| `VERBATIM` | 每张卡正文在投递体中逐字节出现 |
| `ORDER` | 卡出现顺序 = 声明顺序 |
| `NO_REWRITE` | 写盘后重读，内容与内存字符串完全相同 |
| `AUX_SHARE ≤ 10` | 仅 full 模式，实数打印，超限报错并给出超出字数 |

## 反例（一律禁止）

- 用正则抽「画面：」后的句子重拼。
- 把百分比换成秒数，或同一时间点写两遍。
- 在投递体里另加防干扰句——只能写进伴生卡，且计入 10%。
- 声称「已按卡发送」但没落快照：无快照视为未发送。
