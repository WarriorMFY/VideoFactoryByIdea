# 元卡（templates/meta/）

> 元卡是起草骨架，不是合规样本。搬运前按 `Doc/Cards/spec.md` 裁剪：只留 frontmatter、一级标题、轴说明、单张两列表。

| 文件 | 卡种 | 管什么（一维） |
| --- | --- | --- |
| `01-figure.md` | 形象卡 | 角色外形、体态、服饰 |
| `02-face.md` | 脸部卡 | 五官与表情 |
| `03-style.md` | 画风/意境卡 | 怎么画（笔触、色调、材质） |
| `04-action.md` | 动作卡 | 动作过程与受力 |
| `05-camera.md` | 镜头卡 | 怎么看（景别/机位/运镜/焦点/切换） |
| `06-voiceover.md` | 旁白卡 | 文案与语气 |
| `07-ui.md` | UI 提示卡 | 界面元素与布局 |
| `08-time-scale.md` | 时间缩放卡 | 快慢与时间质感 |
| `09-anti.md` | 反向卡 | 不许出现什么 |
| `10-composite.md` | 联合卡 | 多卡合成的整场 |
| `11-prompt.md` | 生图语义卡 | 词库与同义词 |
| `12-terrain.md` | 地貌卡元卡片 | 地形/水系/植被/气候/动物/异常 |

## 三步派生

1. **选元卡**：一次只选管一个维度的一张；要两维就写两张，别混。
2. **填实例**：把 `<占位>` 换成本次的具体实体（地名、物种、季节）。元卡里的占位符不许留到实例卡。
3. **配伴生卡**：`templates/companion-fixed.md`（固定变量）+ `templates/companion-anti.md`（反向），合计 ≤ 主卡 10%。

## 边界

- 元卡只进本目录，不进 `RAG/`；`RAG/` 只收用户验收过的实例卡。
- 元卡可以随时改；实例卡改版必须新开一条 chain（旧卡不删）。
