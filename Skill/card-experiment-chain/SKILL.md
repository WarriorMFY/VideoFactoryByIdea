# 卡片实验链

## 何时用

- 有一张元卡或实例卡草稿，要在指定模型／通道上验证它画不画得出来。
- 要接着某条 `chain-*` 复验、改卡、加样本。

## 何时不用

- 只改卡措辞、不打算送验。
- 想把卡入库 RAG：本技能只做到「提交候选」，入库必须用户另行验收。

## 一条链长什么样

```
Log/Circle<id>/<卡片家族>/chain-<NN>-<tag>/
├─ card-*.md        本次送验的全部卡快照（不跨链引用，旧卡不删）
├─ image/ video/    prompt 正文、样本、样本旁 prompt 快照
├─ _diag/           切点、抽帧、量测
└─ manifest.json    卡哈希、任务、消耗、产物、判读
```

循环边界（新建／结束）只由用户声明，本技能不得自行开轮或收尾。细则见 `reference/archive.md`。

## 七道闸门

| 闸 | 动作 | 未通过就停，不许烧积分 |
| --- | --- | --- |
| G0 立项 | 选元卡；写清自变量轴／因变量轴；报一次性预算 | 轴写不出，或余额 < 预估×1.2 |
| G1 实例卡 | 按元卡填实体；配固定变量卡与反向卡 | 出现左右词、多张主表、时间双编码 |
| G2 投递体 | `compose.py` 直送拼接并断言 | VERBATIM／ORDER／NO_REWRITE／AUX≤10% 任一不过 |
| G3 图段 | 先出 1 张图看构图与要素 | 覆盖表 < 70%，不上视频 |
| G4 视频段 | 指定通道与时长索引；快照随片落盘 | 任务失败或快照未落盘 |
| G5 判读 | `diff.py` 出客观切点；人看全片打三档分 | 分数、证据帧、归因未写全 |
| G6 归档 | manifest、账本、报告、预览 | 链内不能离线复现 |

## 铁律

1. **直送**：脚本只拼接，不抽字段、不改写、不调语序。
2. **10%**：反向卡＋固定变量卡合计 ≤ 主卡字数的 10%，超了把细项转质检表。
3. **单编码**：卡内时间只写一种形式（秒数），段数即切分指令。
4. **旧卡不删**：改卡就新开链，或把旧卡复制进新链。
5. **先图后视频**：图不过线不发视频。
6. **人工验收**：任何 PASS、任何入库、任何经验条目，必须用户明确确认。
7. **不入 RAG**：技能终止于「候选」，不替用户拍板。
8. **循环边界归用户**：不建轮、不结轮。

## 脚本

| 脚本 | 用途 |
| --- | --- |
| `new_chain.py` | 建链、快照卡、算 sha1、写 manifest 骨架 |
| `compose.py` | 唯一生成器：直送拼接 + 四项断言 |
| `run_still.py` | 文生图（G-2.0，16:9／1k） |
| `run_video.py` | 文生视频（H3，时长索引），写 `.prompt.txt` 快照 |
| `diff.py` | 帧差找硬切点 |
| `sheet.py` | 抽帧拼条 |
| `ledger.py` | 预算账本：status／add／触线 STOP |
