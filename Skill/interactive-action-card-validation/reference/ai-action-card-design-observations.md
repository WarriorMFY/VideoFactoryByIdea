# AI 动作卡片设计观测经验：从「空间指令」转向「因果交互」

> 来源：用户提炼（2026-11-15 11:58）。定位：**设计规范**，不属于验收层（L1/L2）的检查项。
> 本文件为原文归置，未改写。与实测冲突之处另见文末「本仓库实测修订」，读时两条都看。

## 核心结论（一句话）

当前大模型极不擅长空间位置判断（如左脚在前、右脚在后、左手还是右手），动作卡设计应全面放开这些空间关系的限制，交由 LLM 自由决定；卡片真正需要聚焦与死磕的是「因果关系」（如：先格挡，后反击），同时利用 LLM 对「击打部位/接触点」（如：打中胸口正中）的高对齐能力，来锚定画面的物理真实性。

## 三大核心观测洞察

### 1. 空间盲区：放弃微观坐标，拥抱镜像随机

- **现象**：无论是文生图还是视频模型，对「左右手」、「前后脚」的绝对解剖学坐标极度不敏感，即使写满限制词，也大概率会画出镜像反转或反关节的「怪物」。
- **经验**：不要在卡片里写死「右手推掌，左弓步」。使用**「主攻手/辅助手」**、**「进攻手/防御手」**替代，甚至完全留白。只要整体姿态是向前发力的，观众根本不在乎是哪只手。

### 2. 因果高地：大模型是优秀的「事件发生器」

- **现象**：模型听不懂「向左转体 30 度」，但能完美听懂「A 攻击，B 格挡后反击」。
- **经验**：动作卡的骨架必须建立在**「防反逻辑（攻防转换）」**上。确保「防守接触 → 攻击命中」的因果关系严密，攻防转换的瞬间连贯不卡顿。这是让动作具备「打击感」的底层逻辑。

### 3. 接触锚点：部位识别是指令的「安全区」

- **现象**：模型对「胸口正中」、「咽喉」、「小臂外侧」这种宏观/中线部位的识别率极高。
- **经验**：将抽象的「发力」转化为具体的**「部位接触」**。写死「打中胸口」或「按住咽喉」，比写死「用哪只手打」有用得多。

## 最佳实践：动作卡设计词汇替换表

| 设计维度 | ❌ 传统写法（容易触发空间幻觉） | ✅ 优化写法（顺应模型能力） |
| --- | --- | --- |
| **肢体指定** | 主体A的左手/右手 | **进攻手/防御手、主攻手/辅助手、持械手/空手** |
| **步伐指定** | 左脚上前，右腿蹬直 | **前腿微屈，后腿蹬地发力**（不限制左右） |
| **动作指令** | 躯干向左拧转 45 度 | **重心前压、身体顺势扭转** |
| **接触指令** | 手掌拍击对方左胸 | **手掌重重按在对方胸口正中** |
| **物理反馈** | 目标后退两步 | **目标因受击而后仰失衡/被击飞倒地** |

## 示范案例：防反击飞卡（交互导向版）

基于上述经验优化的极简卡片，不给大模型设空间陷阱，只死磕因果与部位：

```md
---
name: action-counter-strike-fly
type: action
scope: execution
description: |
  介绍：主体B挥拳进攻，主体A使用防御手进行格挡，并在接触瞬间顺势使用另一只主攻手直击主体B胸口，将其击飞。
  何时使用：用于验证格挡反击到击飞倒地的完整物理互动因果。
---
# 动作卡：防反·直击胸口击飞
> **【空间免责声明】**：本卡不限制左右手与前后脚，模型可自由分配，只需满足物理因果与部位接触。
## 关键帧列表
| 关键帧（自变量：帧号/阶段/进度） | 动作状态（因变量：可观测动作描述） |
|---|---|
| K0 / 攻击与格挡 / 0% | 角色=主体B重心前压，手臂挥出重拳；主体A重心微沉，抬起**防御手**在身体中线前方；武器/接触=主体A的**防御手小臂与主体B的来拳发生物理接触（格挡成立）**；目标=主体B的出拳轨迹被阻挡；位移=双方原地站立；同步=双方肢体在画面中形成明显撞击点 |
| K1 / 顺势反击一气呵成 / 50% | 角色=主体A在格挡接触的同一拍，防御手向外侧拨开来拳，**另一只主攻手顺势直线送出**，重心向前贯穿；武器/接触=主体A的主攻手**准确击中主体B的胸口正中**（接触的高光瞬间）；目标=主体B胸口受力，上半身猛烈后仰，双脚开始离地；位移=主体A重心连续前移；同步=防守解除与攻击命中在同一拍完成 |
| K2 / 击飞与收招定势 / 100% | 角色=主体A保持出拳后的余势，重心下沉，稳固站立；主体B躯干向后倒飞、四肢松展；武器/接触=**无接触**，主体A的攻击手脱离主体B胸口；目标=主体B向后倒飞并重重砸向地面；位移=主体B发生大幅度向后位移并触地；同步=主体A的收势定格与主体B砸地的瞬间同步 |
```

**总结**：把「空间控制权」让渡给模型，把「因果控制权」和「接触控制权」牢牢抓在卡片设计者手里。这是当前 AI 视频/生图抽帧验证最高效的玩法。
