## 总纲

右列（因变量列）的 5 个字段，为适配 AI 生成特性，已从「解剖学坐标系」全面转向「因果交互与物理反馈」。协作逻辑：

| 字段 | 负责 | 一句话 |
| --- | --- | --- |
| 角色 | 怎么打 | 姿态与重心 |
| 武器/接触 | 打在哪 | 精准的接触锚点 |
| 目标 | 打出什么效果 | 受力与生理反馈 |
| 位移 | 空间怎么变 | 压迫与击退 |
| 同步 | 节奏对不对 | 因果事件的咬合 |

放弃对「左右空间感」的苛求，把约束全部放在物理因果、接触反馈、空间位移上——出错率大幅降低，打击感与逻辑自洽得以保留。

## 1. 角色=（Role / Actor）

**含义**：画面中发起动作的主体（通常是主体A）的宏观姿态、重心状态、肢体功能。

**填写原则**

- **拒绝绝对坐标**：绝对不写「左手、右腿」，改用「防御手、主攻手、另一只手、前腿 / 后腿」。
- **强调物理状态**：重点写重心起伏（重心微沉、重心向前贯穿）、躯干宏观状态（贴身突进、沉肩坠肘）。
- **连贯性**：一气呵成的动作要体现顺势（如「在接触的同一拍，防御手拨开……身体瞬间突进」）。

## 2. 武器/接触=（Weapon / Contact）

**含义**：物理交互发生的具体方式与精准落点。AI 最容易理解、也最能让画面具备「打击感」的核心锚点。

**填写原则**

- **明确接触点**：利用 AI 极强的部位识别能力，写死「打在胸口正中」「小臂与主攻手发生物理接触」。
- **明确接触状态**：写清是格挡（防）、顶入（攻），还是脱离（无接触）。
- **强调发力瞬间**：可标注高光瞬间，如「死死砸中 / 顶入主体B的胸口正中」。

## 3. 目标=（Target）

**含义**：承受方（通常是主体B）的受力反馈与生理状态。在 AI 视频里，「受力反馈」比「攻击动作」本身更能决定画面的真实感。

**填写原则**

- **动作传导**：不只写被打中，要写身体连锁反应（躯干瞬间佝偻、上半身猛烈后仰、双脚开始离地）。
- **丧失行动力**：终结动作（K2）必须写出彻底败北（向后倒飞、失去反抗能力）。

## 4. 位移=（Displacement）

**含义**：双方在空间位置上的相对变化与重心移动。

**填写原则**

- **主体A的压迫**：写前压、上步、趟步，强调「不回收、不落定」，体现力量感。
- **主体B的溃败**：写大幅度空间变化，如「向后发生大幅度位移并触地」。
- **K2 拉开距离**：终结帧写双方拉开空间（B 倒飞），以「一静（A 定势）一动（B 倒飞）」构建压制感。

## 5. 同步=（Synchronization）

**含义**：该关键帧中，决定动作成立与否的「因果卡点（Timing）」。

**填写原则**

- **同拍爆发**：攻防转换没有时间差（如「防守解除与攻击命中在同一拍完成」）。
- **物理对齐**：写清两个事件在视觉上的咬合（如「防御手拨开的瞬间，另一只手顶中胸口」）。
- **定格对比**：终结帧强调收尾同步（如「主体A的铁塔定势与主体B背部砸地的瞬间同步」）。

## 本仓库实测修订与冲突（2026-11-15 补，勿删）

上文五条原则与 `SKILL.md` 的验收项有 5 处摩擦，落地时按本节处理；未裁定的不自行调和。

| # | 原文 | 冲突 | 处理 |
| --- | --- | --- | --- |
| 1 | 角色「改用……前腿 / 后腿」 | **与 L2 1.2 直接冲突**：前 / 后 属空间语义，同类部位（两只脚）禁用 | 已验证替代：`承重腿 / 发力腿`。本文的「前腿 / 后腿」按 1.2 视为不可用 |
| 2 | 角色「在接触的同一拍，防御手拨开……身体瞬间突进」 | 与 L2 2.1③ 冲突：同时性归 `同步` 键；写进角色即成「一事两写」 | 角色只留姿态与重心，「同一拍」一律归 `同步` |
| 3 | 角色「通常是主体A」/ 目标「通常是主体B」 | 与实测不符：K0 的施动方是出拳的 B，角色键写的是 B 的重心前压 | `角色` = 本帧所有发出动作的主体，不固定为 A；`目标` = 承接反馈的一方 |
| 4 | 武器/接触「写死打在胸口正中」 | §54 实测：卡内两个部位词会互相污染，落点合并到第一个 | 部位词**全卡只留一个**；单帧只承诺 1–2 个可判读关系 |
| 5 | 「终结动作（K2）」「K2 拉开距离」 | 本仓库现为四帧卡（K0–K3），K2 是第三帧不是末帧 | 一律理解成「末帧 / 100% 帧」 |

另有一条非冲突的实测支持：原文「同步＝同拍爆发、物理对齐」与 L2 2.1③（`同步` 必须写出两主体在同一拍各自在做什么）完全一致，§75 改卡即按此执行。
