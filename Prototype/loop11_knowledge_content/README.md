# 小循环 11 · 知识型内容链路：分诊 + 数值单位规范化 + 术语候选

> 这一轮不定义工厂能做什么、不能做什么。工厂是持续迭代的，这里只做一件事：
> **把"这类内容现在能自动到什么程度"变成可计算、可判定、可复现的证据**，并顺手把这条路上最影响发布质量的短板补掉。

## 1. 为什么做这一轮

你看长片案例后指出：之前那条**讲"视频剪辑技巧"的教学片，翻译质量明显更好**。这判断有数据支持（小循环 2/6）：

| | 教学片（l2） | 剧情片（TOS 90s） |
| --- | --- | --- |
| 识别 WER | **6.1%** | 28.4% |
| 语音覆盖 | **99.8%** | 50–60% |
| 翻译缺陷（句末标点/术语） | **0 / 0** | 机翻语义仍偏 |
| 与人工参考相似度 | **94.1%** | — |

原因不是"我偏心"，而是这类内容的四件事恰好都对：**信息在文字里、术语可枚举、语域平稳、识别环境干净**。
所以这一轮把这条路上能自动化的部分做扎实：先能**判断**内容形态，再**修数值单位**，再**自动挑术语**。

## 2. 三个新工具

### ① `classify_content.mjs` — 内容分诊（当前版本的能力画像）

用 6 个可计算信号打分（不依赖我看画面）：

| 信号 | 教学片 l2 | 电影 TOS 90s | 为什么能区分 |
| --- | --- | --- | --- |
| 语音覆盖（有词时长/总时长） | **90%** | 23% | 口播/旁白几乎铺满；剧情片大量无对白段落 |
| 识别平均置信 | 0.967 | 0.885 | 近场麦 vs 影混音 |
| **有声但无词（配乐/音效占比）** | **0%** | **73%** | 关键信号（见下） |
| 短句占比（≤3 词） | 0% | 44% | 喊叫/碎片化对白 |
| 句均词数 | 14.4 | 4.4 | 口播句子完整 |
| 术语/单位密度 | 见 l2 规范化后 | 0 | 知识型天然高 |

综合得分：**l2 = knowledge 0.95，TOS = narrative 0.17**，并给出当前建议（翻译后端、CPS、是否需要人工校对）。

> 参数踩过的坑：最初用"能量动态范围 p90−p10"判断有没有配乐，结果**判反**——
> TTS 词间起伏大（18dB），配乐反而平稳（9dB）。换成"有声但无词的帧占比"后才稳定。

### ② `normalize_units.mjs` + `lib/units.mjs` — 数值与单位规范化

知识型内容的命门是"说错数"：ASR 把 `−16 LUFS` 念成 `minus sixty sixteen l u fs`，机翻再逐字翻就废了。

```
minus sixty sixteen l u fs   →   −16 LUFS
fifteen megabits per second  →   15 Mbps
sixty frames per second      →   60 fps
four k                       →   4K
two hours                    →   two hours（不数字化，避免误伤）
```

- **只在单位语境**动数字；每次替换留痕（`normalization.changes`）；
- **幂等**（第二遍 0 处改动），所以重跑字幕不会漂；
- 中文侧也统一：`负十六 LUFS` / `零下16LUFS` / `-16 LUFS` → `−16 LUFS`；
- 可用 `--no-unit-norm` 关掉（对照组用）。

### ③ `term_candidates.mjs` — 术语自动候选

从转录里挑"该进术语表的词"：缩写/单位（`LUFS`、`15 Mbps`）、专名、高频长词、高频二元短语（`look celia`），并标注是否已在术语表。
长片 49 分钟 → **61 个候选**；l2 → 31 个，含单位术语。人只需要给中文写法，回填 `glossary_zh.json`。

## 4. 看对照 SRT（一眼看出差别）

- `case_l2_knowledge/bilingual_normalized.srt`（规范化后）

## 6. 限制（会随迭代变化）

- 分诊是启发式、单片段调参，阈值可能随素材漂移；输出里写的是"当前策略建议"，不是内容类型定义；
- 术语候选对全小写 ASR 只能靠频率，专名信号会弱（转写后大写才有）；
- 数值规范化目前覆盖 LUFS/dB/Mbps/fps/4K/分辨率，货币/百分比/时间未做；
- 中文数字转换覆盖 0–999。
