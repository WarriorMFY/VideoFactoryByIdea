## 6. 本轮修的 3 个 bug（都属于"市场化才暴露"）

1. 合片默认流选择取到了画面自带配乐 → 成片没口播、ASR 0 词（`acceptHits=7` 全空，极像模型坏了）→ 显式 `-map 0:v:0 -map 1:a:0`；
2. 手工写的 `zh_agent.json` 带 BOM → `make_subs` 解析崩 → 统一 `readJson()` 去 BOM；
3. TTS 词间无停顿 → `restore_punct` 把 7 句并成 5 句还串行 → 新增 **`align_script.mjs`**（有讲稿/官方字幕时按真值句子强制对齐词流，109 词 → 7 句，覆盖 100%）。

### 9.2 封面自检（挂账项③）——`case_ep01/cover_16x9.check.*`、`case_ep01_vertical/cover_9x16.check.*`

新增 `Tool/ops/check_cover.mjs`，用像素统计把"文字观感"变成可判定项（**不做 OCR**，错别字仍需人眼）：

| 检查项 | 16:9 封面 | 9:16 封面 |
| --- | --- | --- |
| 尺寸/比例 | ✅ 1280×720 | ✅ 1080×1920 |
| 文字带是暗底（下 38% 亮度均值） | ✅ 0.217 | ✅ 0.174 |
| 文字存在且不过曝（高亮占比） | ✅ 0.019 | ✅ 0.035 |
| 蒙版分隔（与上方 45–62% 条带的亮度差） | ✅ 0.199 | ✅ 0.213 |
| 320px 缩略图可读（std / 高亮） | ✅ 0.124 / 0.008 | ✅ 0.174 / 0.028 |
| 安全边距（四边 2% 条带亮像素） | ✅ ≤0.001 | ✅ ≤0.001 |

**因此修掉的两个真缺陷**（都是自检/看图发现的，不是猜的）：
1. **封面取帧撞车**：原来取成片第 2 秒，正好是 Big Buck Bunny 片头标题卡（白底蓝大字），且成片已烧字幕 → 封面标题 + 片头大字 + 字幕**三层文字糊在一起**，完全不可用。
   → 改为从**无字幕干净成片**取帧，并新增 `pick_cover_frame.mjs` 按"下半区够暗 + 有细节 + 不过曝"打分选帧（本期选到 20.3s）。
2. **竖屏封面文字溢出**：`make_cover` 原来字号只按画面高度算，1080×1920 时算出 163px、9 个汉字约 1467px > 1080 → 标题被裁到只剩中间几个字。
   → 改为按**宽度**估宽：超宽先缩字号、仍超宽再折两行；副标题/角标同样限宽。
