## 形态设计（为什么这样改）

- **单技巧**：全稿只讲「跳切」一个动作，信息密度让位于讲透一个点。
- **改前/改后对比**：同一条 CC-BY 素材（Big Buck Bunny 10s）演两遍——
  - 改前：一镜到底原速循环 18.5s，顶部角标「改前」；TTS 讲完后**留 10s 静默**，让"废话停顿"自己说话；
  - 改后：同素材切 [0-2][3.2-4.6][5.8-7.0][8-9] 重拼成 5.6s 跳切版循环，顶部角标「改后」，留 5s 静默让观众看节奏差。
- **结构**：钩子 5.8s → 改前 18.5s → 改后 11.4s → 拆步骤+收尾 27.3s。
