## 报告（原 `REPORT.md` 正文）

### loop29 · 细节取证报告（紫冥剑壹段 302.4–305.4s）

日期：2026-11-05 晚
目的：在动笔做"逆向逐层"试片之前，先回答一个问题——**这 3 秒素材里，到底有没有"没必要做但做了"的细节可挖**。
结论先行：**有，而且比预期多。共 5 条实锤（实录级）+ 2 条推断级，足够支撑 15s 取证试片。**

---

#### 〇、方法论事故与修正（先于一切结论）

取证第一轮全部作废，原因：本源（YouTube 下载 mp4）上 **input seek（`-ss` 在 `-i` 前）不逐帧丢弃、直接落到 keyframe**——不同 `-ss` 值输出相同画面，导致所有拼图的帧号标签与内容错位（曾把 302.5s 的画面标成 302.8s）。另外 `filter_complex` 中不带 `[0:v]` 标签的 `select` 会静默失效。

修正后的可信工线（"绝对时间码验证法"）：

```
ffmpeg -ss <keyframe前> -i src -ss <精确偏移> -t 0.5 \
  -vf "scale=1280:720,drawtext=text='%{pts\:hms}':...,tile=3x5" ...
```

input 粗跳 + output 逐帧精调，**把真实 pts 时间码直接印在每格画面上**，按时间码读内容，不信任任何手工帧号换算。

已验证可信的拼图：`.probe/ts_1.jpg`（302.5–303.0）、`ts_2.jpg`（303.0–303.5）、`ts_3.jpg`（303.5–304.0）、`ts_4.jpg`（304.5–305.0）。作废留档：`probe_*.jpg`、`hz_*.jpg`。

**连带修正**：loop28 的 `probe_A` 粗拼图（fps=10）同样经 input seek 生成，其"帧号 9072–9101"坐标不可信；但 v4 成片的剪辑是按画面内容定位的，成片本身不受影响。REPORT.md 中引用的绝对帧号（如 9072）应理解为"约 302.4s"，后续以时间码为准。

#### 一、壹段真实动作链（带时间码，实录级）

| 时间 | 动作 | 特效状态 |
|---|---|---|
| 302.50–302.57 | 收势预备，直立，剑在右后 | 无 |
| 302.60–302.77（约 6 帧） | **大幅度转体抡臂蓄力**，侧倾如鞭 | **无剑光** |
| 302.80–302.97 | 横撩：剑光出现与身体压低**同帧发生**，弓步到位 | 白色宽弧光 |
| 303.00–303.53（约 16 帧） | **撩后不站直，直接沉到近乎蹲底贴地滑行** | 剑光已消散 |
| 303.57–303.97 | **单膝跪地状态下的贴地大回环**（钟形光罩内蜷身平抡一周） | 钟形罩状光 |
| 304.00–304.50 | 收势衔接（未逐帧，待补） | — |
| 304.57–305.00 | 走位冲刺 + 下一动起手 | 细弧光再现 |

**整段是一次"由高到低"的持续下沉：站 → 弓步 → 蹲滑 → 跪。** v4 的三小节命名（横撩起手/低位连环/回旋劈杀）与实际动作对应良好。

#### 二、五条实锤细节（可直接进试片）

**D1 蓄力帧被完整保留**（302.60–302.77，实录）
转体蓄力 6 帧全程无剑光、无特效。引擎 1.4× 提速后压至约 4 帧（133ms），玩家不可感。
断言示范：「这一剑的力量不在手臂——剑光出现前 6 帧，身体已经转完了。加速后只剩 4 帧，我们放慢 20 倍给你看。」

**D2 特效与动捕逐帧对齐**（302.80，实录）
剑光出现 = 身体压低，同帧发生，不早不晚。特效帧位是对着动捕关键帧 K 的，不是糊一整段。
断言示范：「火花不是乱飞的——它亮起的瞬间，正是重心砸进前脚的那一帧。」

**D3 撩后贴地换步**（303.00–303.53，实录）
横撩后角色不回正，直接沉底滑行 0.5 秒。传统撩剑讲"撩必有压"（撩上必压回防反），这里是"撩→压→跪滑"完整表达。游戏速度下观众只看到两道剑光，这 0.5 秒完全隐形。
断言示范：「两道剑光之间，他蹲下去了半秒——这是撩剑的规矩：撩上去，就必须压回来。」

**D4 跪姿大回环**（303.57–303.97，实录）
第③小节不是站立的"回旋劈杀"，是**跪地贴身平抡一周**。低姿态贯穿全段：整段连段自带"高度叙事"（由高到低），这是武指编排层的主动设计，不是动作捕捉的副产品。
断言示范：「注意他全程没有站直过——从站立到跪地，这 3 秒是一个'压着打'的整体设计。」

**D5 特效先走、身体殿后**（303.87→303.97，实录）
钟形光罩 303.87 消散，角色跪滑姿态还保持了 3 帧以上。**动画时长 > 特效时长**，收势没有被特效掩盖——克制也是设计。

#### 三、推断级（片内须标注"推断"）

- I1：D1 的蓄力帧是动捕自带而非动画师补做。依据：蜷身转体各关节运动学连续，人工 K 帧极难做出这种"不帅"的过渡。需官方幕后佐证才能升级为实录。
- I2：贴地滑行段对应传统步型中的"仆步/歇步"家族。640×360 源分辨率下腿部细节不足，只能到"家族"级，不能指认具体步型。

#### 四、不可取证（本素材边界）

- 受击方反馈与位移（B 段杀气连段全程被金色剑气覆盖，C 段绝技被金光+烟尘覆盖，特效层完全压过动作层——B/C 两段对"动作取证"不可用，本身就是"演出层抹掉信息"的最佳例证）。
- 引擎提速精确倍率（1.3–1.5× 为文档口径，无法从成片独立测定）。
- 音画对位（本次素材无声轨分析）。

#### 五、对 15s 试片的直接建议

素材已够。试片只做壹段：D1（蓄力慢放）→ D3（贴地段 0.3×）→ D4（跪姿回环定格）→ D5（特效消失后身体殿后）。
字幕只写断言句（第二节的示范文案），不写形容词。角标三级：实录 / 推断 / 存疑。
D2 建议舍弃——"特效对齐帧位"需要并排对照才讲得清，15s 装不下，留给正片。
