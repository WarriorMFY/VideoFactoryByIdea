## 追记（同一条循环，人连续三次改向）

1. **改呼噜循环**（11:55）：人令背景音换成人打呼噜循环。`gen_snore.mjs` 纯 PCM 合成，吸气段（30Hz 腭颤 + 高腔体）+ 呼气段 + 屏息顿，周期约 4s、逐周期 ±8% 微扰、首尾淡入出；`-map 0:v -map 1:a` 视频流 copy，旧氛围音整轨丢弃（非叠加），视频流逐字节未动。
2. **改哨音式呼噜**（12:06）：人反馈"太假" → 改吹哨式鼾声（吸气上扬哨音 500→950Hz 弧线 + 5.5Hz 颤音 + 二泛音；呼气低一声下滑"嘟" 370→300Hz）；首混 -14dB 偏吵，压 5dB 至均值 -20dB / 峰值 -11dB。视频流始终未动。
3. **B 站头像**（12:46–13:08）：三版方案被否 → 人定向「真实草履虫 + 叛逆感」→ 显微镜暗场草履虫（周身程序化纤毛 + 莫霍克鸡冠刺头 + 半睁斜白眼 + 十字创可贴 + 左暖右冷轮辋光），三轮修正后 48px 下仍可辨认；最终人选极简 icon 版（绿草履虫圆环 + 提示符）并登录态上传成功，默认头像退役。产物在 `Workspace/tmp/avatar23/`（临时区，未入本目录）。

## 这轮踩到的坑

- `render_cards` 截图是**元素自适应尺寸**而非视口尺寸（588/1448/681/100 四种高度）→ 窗体固定高度 + 字号缩放；
- `api.json` 压缩单行截图只有 100px 高 → pretty-print 后再截；
- pan 固定 z=1.10 纵向行程不足 → 引入 `pan-d@1.35` 运镜变焦基数语法；
- 居中模式 id 必须挂外层 1080 容器（挂内层框会截出 1640×633）；
- ambience 时长手算错 9s（109.6 当 100.6）→ 结尾干音，重生成修复。
