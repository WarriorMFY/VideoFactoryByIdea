# 工程管线

> 两条管线分工：**生成管线交给大模型**（灵活生成、概率性），**剪辑管线交给 ffmpeg**（确定拆剪、可复现）。
> 依据：Circle2–14 实测、`Doc/RunningHub/APP/README.md`、`Doc/提示词工程.md`。

## 〇、一句话

| 管线 | 谁负责 | 特性 | 产出 |
| --- | --- | --- | --- |
| 生成管线 | 大模型（RunningHub AI 应用） | 灵活生成；事件级可控，时间／像素级有噪声 | 原始素材（mp4／png） |
| 剪辑管线 | ffmpeg（＋脚本判读） | 确定拆剪；同参数同输入，逐帧可复现 | 交付件（裁边、重剪、拼接、配音后的成片） |

分界：**生成管线的产物永远不是交付件**（有黑边、时间失准、同 prompt 噪声）；**剪辑管线永远不创作**（缺内容只能回生成端）。

配音是唯一的跨界项：**声音本身由模型生成**（属生成端），**对齐、混音、响度归一由 ffmpeg 做**（属剪辑端）。

## 一、生成管线

### 1.1 当前通道

| 类型 | webappId | 关键参数 | 实测成本 | 实测产出 |
| --- | --- | --- | --- | --- |
| 文生图 | `2046794551444119554` | `18:prompt`／`aspectRatio`／`resolution`（1k–4k） | 10.72–12.10／张 | png |
| 文生视频 | `2085304953094107137` | `250:prompt`、`115:aspect_ratio`、`225:select=1`（480P）、`205:select=1`（5s） | 10.54–13.26／条 | 124 帧／5.17s／960×544 |
| 首帧图生视频 | `2113790012012720129` | `140:image`、`142:value`、`133:value`（时长 s）、`115:aspect_ratio`、`115:megapixels=0.6` | 22.27（5s）／49.47（9s） | 124–226 帧；1216×512，左右各 122px 黑边 |

同类可挂的有：首尾帧插值、参考图生视频、视频重绘、TTS 配音。接入方式与上表一致——卡面正文直送、参数走 `--node`、成本记 `ledger.json`，脚本骨架不换。

### 1.2 写什么

- 文生图：像素级画面约束（位置、遮挡、材质、光照），见 `Doc/提示词工程.md` §二。
- 文生视频／图生视频：因果事件链（发生了什么→先后→终态），见 §一。
- 整卡直送：脚本只拼接卡片正文（剥 frontmatter），不抽字段、不改写；prompt 快照与 SHA1 随任务存档。
- 图生视频特有：首帧锚定生效（对源图 NCC≈0.956）；同 prompt 切点噪声 6–8 帧；动作会被改写但保留逻辑。

### 1.3 生成端边界

- 灵活但不精确：事件级接近 100%，时间数字 0/6 命中，数值约束（%／比例）不落点。
- 每次输出都是新样本：同 prompt 不可复现，必须留 prompt 快照、任务号、实扣。
- 成本按条／张，不按秒线性：9s≈2.2×5s。
- 质检不过即重生成；**不在生成端抠像素**（那是剪辑端的事）。

## 二、剪辑管线

### 2.1 职责

| 操作 | 说明 | 实测依据 |
| --- | --- | --- |
| 裁边 | 图生视频 21:9 输出左右各 122px 黑边，裁成有效 972×512 | Circle14 i2v |
| 切点重剪 | 按实测切点（帧差检测）拆段，不按卡面帧号 | Circle14 v1 实测 f50／86／105，卡面写 f31／62／93 |
| 拼接 | 多段裁切后 concat；转场按实测边界保留或硬切 | 分镜流程 |
| 抽帧／定格 | 导出关键帧作预览、封面、判读证据 | `Tool/analyze.py` |
| 配音 | 音频由 TTS／模型通道生成；ffmpeg 只负责对齐、混音、响度归一 | 待接入 |
| 字幕 | 按剪辑后时间轴挂字幕轨 | 待接入 |
| 转码／转封装 | 统一编码、改码率／分辨率、MOV→MP4 | 需 ffmpeg；`Skill` 里的 `fix_mov_to_mp4` 只改 ftyp 头，不重编码 |

### 2.2 原则

1. **判读先行**：先测（帧差切点、NCC、黑边宽度）再剪；卡面上的时间数字只当参考。
2. **确定性**：同一输入＋同一命令＝同一输出；所有参数写进脚本，不手调。
3. **不创作**：剪辑端只做时间与画幅上的重组，不生成新内容。
4. 帧精确裁剪必须重编码（`-c copy` 受关键帧限制）；只看不剪的操作可 `-c copy`。

### 2.3 ffmpeg 样例

```bash
# 裁掉 i2v 左右黑边（122px）
ffmpeg -i raw.mp4 -vf "crop=972:512:122:0" -c:v libx264 -crf 18 -an cropped.mp4

# 帧精确切段（按实测切点 f50 → f86）
ffmpeg -i cropped.mp4 -vf "trim=start_frame=50:end_frame=86,setpts=PTS-STARTPTS" -c:v libx264 -crf 18 seg1.mp4

# 拼接
ffmpeg -f concat -safe 0 -i list.txt -c copy joined.mp4

# 配音混音＋响度归一
ffmpeg -i joined.mp4 -i voice.wav -c:v copy \
  -filter_complex "[1:a]loudnorm=I=-16:TP=-1.5:LRA=11[a]" \
  -map 0:v -map "[a]" -shortest final.mp4
```

> 前置条件：ffmpeg／ffprobe 需安装并加入 PATH。**当前机器尚未安装**（`Get-Command ffmpeg` 为空），先装再用：`winget install Gyan.FFmpeg`，或解压便携版把 `bin` 加进 PATH，验证 `ffmpeg -version`。
> 判读与抽帧走 opencv（`Tool/analyze.py`），不需要 ffmpeg；ffmpeg 只在要出交付件时用。

### 2.4 剪辑端边界

- 剪辑不能创造未生成的内容：缺事件、缺景别、缺时长，只能回生成管线补拍。
- 图生视频的 V 形涟漪、落水水花等属于生成内容，剪辑端不能「补画」。
- 配音与口型不同步时，改时间轴只能救节奏，救不了口型——口型问题回生成端改事件。

## 三、接口与流程

```text
卡片（镜头／描述／动作）
   │  整卡直送
   ▼
生成管线（文生图／文生视频／图生视频）──> 原始素材＋prompt 快照＋任务号／实扣
   │
   ▼
判读（帧差切点／NCC／黑边宽度，opencv 脚本）
   │
   ▼
剪辑管线（ffmpeg：裁边→重剪→拼接→配音→字幕→转封装）
   │
   ▼
交付件 ──> 验收 ──> 入库
```

| 接口 | 内容 |
| --- | --- |
| 生成→剪辑 | mp4／png、prompt 快照、任务号、实扣、实测帧数与黑边 |
| 剪辑→生成 | 缺口清单（缺哪个事件／景别／时长），指明需重生成的片段 |
| 共同纪律 | 整卡直送、脚本只拼接、测量先行、全程留痕 |
