# 提示词工程

> 依据：本项目 Circle2–14 实测，及 `Doc/Cards/卡片工程总结.md`（语言特性／模型能力／镜头表达）。本文件只分两类提示词，不重复卡片写法。
> 「接近 100%」均指**本项目已测样本内**的对齐颗粒度，不外推到其他模型。

## 〇、一句话

| 类型 | 核心写什么 | 对齐颗粒度 |
| --- | --- | --- |
| 文字提示词（视频／动作） | **因果事件链**：发生了什么、先后顺序、结束成什么样 | 事件级接近 100%；时间级≈0 |
| 图片提示词（静帧） | **像素级画面约束**：谁占哪块、多大、被谁挡、什么色与光 | 区域／构图级高；事件无意义 |

## 一、文字提示词：因果事件链

### 1.1 机制

视频模型按帧去噪，执行的是「状态转移」——它没有秒表，但有因果。所以文字提示词的正写对象是事件链，不是时间点，也不是形容词堆叠。

- Circle14 宽景 9s：撑篙 → 后拉见船身 → 风浪 → 落水 → 空船，事件按序全中，包括「人物出画、空船留场」这种终态。
- 三卡拼装（镜头＋船身＋动作）没有互相稀释，整条链仍完整执行。
- 分镜卡：段数、段序、段内镜头状态 3/3 条成 4 段。
- 状态句可执行：「固定机位」「全程静止」在 Circle10／14 均成立。

### 1.2 写法清单

| 项 | 写法 | 反例 |
| --- | --- | --- |
| 事件 | 一条一个动词短语，显式先后（先…随后…最后…） | 把几件事混成一句 |
| 可见线索 | 每个事件给画面证据：水花、白浪、涟漪、衣摆 | 只写「大风」不写载体 |
| 结果态 | 终帧可判定：人出画、只剩空船、水面留涟漪 | 「气氛变得紧张」 |
| 状态句 | 可写：静止、固定机位、无剪辑、无变焦 | —— |
| 时间 | 只当标签；用事件顺序代替时间点 | 第 12 帧、0.5s 内、占 30% |
| 左右 | 不写；改用功能位（持械手／防御手）或画面位置 | 左手、向右拨 |
| 数值 | 不写精确值 | 脸宽 70%、唇厚 0.08 |

### 1.3 已测边界

- 时间数字不执行：6 个请求切点 0/6 命中，偏差 12–29 帧；同 prompt 的切点噪声 6–8 帧，这就是时间对齐的下限。
- 事件会被「改写但保留逻辑」：撑篙被读成举篙立定——所以要选模型有表征的动作，并给出画内可见的接触点。
- 氛围词只驱动它附着的可见物：只写「大风」只有水面起浪；要衣摆飞，就得把衣摆写进事件里。
- 内容反压：事件里角色、道具一多，会挤掉景别与构图（Circle14 r2 段 4 远景掉成中景）。

### 1.4 验收

判「事件是否按序出现、终态是否成立」；不判秒点。时间偏差记为噪声，不记为失败。

## 二、图片提示词：像素级画面约束

### 2.1 机制

文生图（通道 `2046794551444119554`）只有一张画布，没有「接下来」，只有「这里是什么」。所以提示词要按像素分区来写：位置、占比、遮挡、材质、光照、色调。

- 像素锚定生效：首帧对源图 NCC 0.956（Circle10）。
- 场景卡环境五要素 3/3 条全部兑现（Circle6）。

### 2.2 写法清单

| 项 | 写法 | 反例 |
| --- | --- | --- |
| 位置 | 画幅分区（左／右三分之一、前景／中景／背景）＋相对关系 | 「稍微居中一点」 |
| 占比 | 用相对大小与遮挡关系表达 | 脸宽占 70% |
| 层次 | 明确谁在前、谁挡谁 | 只列对象，不排层次 |
| 材质／色调 | 颜色、干湿、光泽、新旧、饱和度 | 「好看」「高级感」 |
| 光照 | 光源方向、软硬、色温、雾感 | 「光影很棒」 |
| 姿态 | 静姿可写（斜举竹篙、侧身而立） | 事件动词（正在倒下、随后转身） |
| 不写 | 事件、因果、时间、运动 | 「先…然后…」 |

### 2.3 已测边界

- 精确数字不落点：脸宽 70%、唇厚 0.08 从未兑现——数字只当近似语气，不要当约束。
- 背景一变，模型连带重画材质与皮肤（Circle10）——像素约束要连环境一起写。
- 区域性描述（描述卡）可跨镜头卡复用；但换渲染域不可比——换景别等于换渲染域，一致性判定必须分层。

### 2.4 验收

逐区比对：布局、遮挡、色调、材质；可用 NCC 或区域 patch。不判「事件是否完成」。

## 三、两类提示词的边界

| 轴 | 文字提示词 | 图片提示词 |
| --- | --- | --- |
| 生成单位 | 时间轴（帧序列） | 单帧画布 |
| 核心 | 因果事件链 | 像素级画面约束 |
| 执行档位 | 事件级接近 100%；时间级≈0 | 区域／构图级高 |
| 典型失败 | 事件被改写或合并；氛围词无可见载体 | 精确数值落空；换背景即换材质 |
| 主要载体 | 镜头卡、动作卡、成品卡 | 描述卡（单帧） |

一句话：把「接下来发生什么」交给文字，把「这一帧长什么样」交给图片。两者混写时，模型只会挑它听得懂的那一半执行。
