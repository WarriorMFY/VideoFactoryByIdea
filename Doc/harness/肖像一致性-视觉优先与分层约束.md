# 肖像一致性 · 视觉优先与分层约束

> 缘起：Circle10 文生视频系列实验（v1 带副卡 / v2 裸卡 / runway 走秀六条 / 中间景别四条 / 首帧图生视频两条）跑完后，2026-11-17 00:01 用户口述的结论。以下为原话 + 本轮证据 + 可操作化。

## 〇、原话

> 「肖像一致性本质上是视觉层面约束问题，要用视觉-图来约束视觉，语言描述有些时候限制力度还是不够。另外，肖像本身并非固定事物，而是在不同环境、不同光照、不同角度、不同远近距离下都是动态变化的，要想有效约束肖像一致性，必须动态分层次去考虑约束。」

## 一、「用视觉约束视觉」——本轮的语言层失败清单

卡里凡是写成自然语言形容词或百分比的要求，几乎全部落空：

| 卡里写的 | 实测 | 结论 |
| --- | --- | --- |
| 脸宽占画幅 70%、发顶留白 8% | 88%–100% / 0%（头顶一律切掉） | 数字无效 |
| 唇厚合计 0.08 脸高 | 一薄一厚两端摆，从未落在 0.08 | 数字无效 |
| 面上无痣无斑 | v1-b 颊侧出痣 | 否定式无效 |
| 着衣、不见裸肩 | 极特写下裸肩悬头 | 缺失即失效（没写身体=没有身体） |
| 零推拉摇移、第一人称静止 | v1-b 全过 | **状态描述有效** |

规律：**「不许动」这类状态约束能被执行，「长什么样」这类形态约束执行不了。** 语言能管住动作，管不住长相。

而视觉输入一旦上，立刻生效：

| 视觉手段 | 实测 |
| --- | --- |
| 首帧 = 源图 1086 | 第 0 帧 NCC **0.956** |
| c1b 全程静止 | 全程对源图 **0.959** |
| 六条走秀同 prompt | 特写段互比 **0.923**，但对样张只有 0.47–0.61 |

所以判断成立：视觉层是硬约束，语言层是软约束。当前卡片体系的问题不是「写得不够多」，而是**把只能由图像承担的那部分，交给了语言**。

## 二、「肖像不是固定事物」——本轮看到的四种变化

| 维度 | 同一张卡变出来的 | 可测后果 |
| --- | --- | --- |
| 角度 | 正脸 / 四分之三侧脸（v1-a 自加回正动作） | 侧脸时眼位对齐失效，NCC 掉到 0.5 档 |
| 距离 | 极特写（脸 88%–100%）/ 全身小人（脸 0.07） | 脸高 <0.18 后度量失效（瞳距 43px 时 Haar 给出物理不可能的 1.05） |
| 光照 | 自然光（样张）/ 平光美颜（特写簇） | 跨域 NCC 要打折，0.92 的稳定簇与 0.64 的样张不是同一把尺 |
| 环境 | 灰背景头肩 / 白底特写 / 走秀空间 | 背景一变，模型连带重画皮肤与光影 |

关键推论：**「一致性」没有唯一的绝对值，只有「同一层内的一致性」。** 拿特写簇的 0.923 去比样张的 0.64，比的不是同一个人像不像，而是两个渲染域像不像。

## 三、动态分层（可操作版）

| 层 | 管什么 | 本轮约束力 | 只能由谁给 | 何时权重上升 |
| --- | --- | --- | --- | --- |
| **L0 像素锚** | 某一帧的逐像素内容 | 0.956，但只活在第 0 帧；镜头一动掉到 0.402 | 首帧图 / 首尾帧 | 起手、定格、首尾构图 |
| **L1 结构锚** | 五官几何比例（瞳距、眼裂、内眦距、下颌宽） | 跨片眼几何差 <3%，最稳的一层 | 对齐后的量化数值 / 正面参考图 | 中近景，脸高 ≥0.18 可测 |
| **L2 材质层** | 皮肤质感、唇厚薄、眉浓淡、光泽 | 差异集中区：唇厚 > 下颌宽 > 眉浓 > 光泽 | 图 patch、局部参考图 | 特写，近距离 |
| **L3 语义域** | 「这个人」的整体描述（年龄、骨相、气质） | 六条走秀落在 0.92 的稳定簇——稳，但稳在一个不属于样张的新峰 | 卡文（弱）+ 视觉锚点（强） | 全程 |
| **L4 场景域** | 景别、光照、环境、机位 | 跨域即换渲染域，0.47–0.61，不可跨比 | 镜头卡 / 光照卡 / 首帧 | 每次换镜、换景别 |

**分层是"动态"的，不是静态清单**：同一张脸，远小脸时 L1 不可测（分辨率下限），权重全压到 L4；极特写时 L2 材质权重上升到第一位（唇厚两项就决定了像不像）；一旦镜头移动，L0 立刻失效，此时只能靠 L1/L3 接力。

## 四、对本项目卡片体系的推论

1. **肖像卡应降级为「语义域描述（L3）」，不再承载形态约束**——它现在写的脸宽 70%、唇厚 0.08 属于 L1/L2，交给语言注定失败。
2. **L1/L2 必须换成视觉件**：正脸图 + 侧脸图 + 一张特写材质图，作为参考图集，而不是三段形容词。
3. **视频类任务必须显式声明 L4**（景别/光照/机位），且要承认「换 L4 = 换渲染域」，跨域比较无效。
4. **判定标准要分层给**：L1 用几何比值（尺度不变）、L2 用局部 patch NCC、L3 用聚类归属、L4 单独记录景别档位。用单一 NCC 横跨四层，就是本轮出现「0.92 却不像」的根因。
