## 1 · 结论先行

1. **「有哪些接口」和「哪些能用」是两件事。** 官方标准模型 API 有 42 个文生图 + 60 个文生视频端点（D 快照），官网今日宣称 189 个图像模型 / 322 个视频模型（A）；但**本账号 `apiType=NORMAL`**（C，今日核实），标准模型 API 返回 `1014 标准模型API仅限企业级-共享API Key调用`（B §33.2）。**当前唯一能付费跑通的是「AI 应用 / webapp」通道。**
2. **价格是两套体系，不可直接换算。** 标准 API 走人民币目录价（文生图最低 **¥0.03/张**、文生视频最低 **¥0.3/秒**）；AI 应用走积分 `chargedPoint`（文生图约 **11 积分/张**、480P/5s 视频约 **10.54–13.26 积分/条**）。今日只读回查显示 `consumeMoney` / `consumeCoins` / `thirdPartyConsumeMoney` **全部为 null**（C），**API 层拿不到积分→人民币换算**。
3. **省钱的主战场不是换更便宜的模型，是减少付费次数。** 按仓库现有数据，一轮完整验证可从 **68.87 积分压到约 24.3 积分（−65%）**，靠的是零成本层前置、L3 一次只出一张、L4 只跑一条、失败只重跑失败层。

## 3 · 最佳性价比验证方案

### 3.1 设计原则（每条都有仓库证据）

| # | 原则 | 依据 |
| --- | --- | --- |
| P1 | **零成本层尽量多拦**：结构 / 语义 / 时序 / Prompt 逐字一致性全在本地 | B §8 记 L1+L2 **0 积分**；`Tool/smoke_test.py` + `stub_runner.py` 为无费用替身 |
| P2 | **付费前先只读核查节点**：`--info` 查 webapp 节点，锁死 1k / 480P / 5s / `default` | B §26 未显式覆盖默认值会翻几倍；`Workspace/_info_*.txt` 为只读快照 |
| P3 | **单次单变量**：一次只出一张关键帧，判完再决定下一张 | B §41 一次 5 张合计 55.61 积分，其中 K2 FAIL；B §86 单出 K4 一张（约 11 积分）就定位到「倒飞 × 触地」同帧矛盾 |
| P4 | **静帧对齐后才允许视频，视频只跑一条** | Circle2 判据①；B §87 证明 480P/5s 足够跑完五帧序列 |
| P5 | **模型画不出不改卡** | B §87.6 判「向外侧拨开」为当前写法下不可稳定实现；改卡只会触发整轮重跑 |

### 3.2 分层闸门与成本

| 层 | 动作 | 命令 / 通道 | 放行条件 | 成本 |
| --- | --- | --- | --- | --- |
| **S0** | 结构关 + L1 静态 + L2 语义/时序 + Prompt 逐字自检 | `validate.ps1`、`smoke_test.py`（stub）、`verify_prompt.py` | 无 FAIL、Prompt 与卡逐字一致 | **0** |
| **S1** | 只读核查通道节点与权限 | `runninghub_app.py --info <webappId>`、`--list` | 分辨率/时长/实例类型均为最低档 | **0** |
| **S2** | L3 静帧：只出**一张**最关键帧（峰值帧或最易错帧） | `2046794551444119554`，1k / 16:9 | 逐项判定 PASS | **≈11 积分** |
| **S3** | L4 视频：**一条** 480P / 5s / 16:9 | `2085304953094107137`，`default` 实例 | 序列级零 FAIL | **≈10.5–13.3 积分** |
| **S4** | 失败复跑：只重跑失败的那一层 | 同 S2 或 S3 | — | **≈11 或 ≈13** |
| **S5** | 入库：用户口头确认 | `RAG/` | 四条准入齐全 | **0** |

### 3.3 三档预算对比

| 路径 | 构成 | 合计 | 判定 |
| --- | --- | --- | --- |
| **现状**（B §41 + §87 的做法） | 5 张 L3 图 55.61 + 1 条 L4 13.26 | **68.87 积分** | 有至少 1 张在 K2 FAIL 时白烧 |
| **推荐**（本方案） | 1 张 L3 ≈11 + 1 条 L4 ≈13.26 | **≈24.3 积分**（−65%） | 靠闸门而非靠砍质量 |
| 跳过 L3 直接 L4 | 1 条 13.26 | 13.26 | **不允许**：违反 Circle2 判据① |
| 换 Enterprise-Shared Key 走标准 API | 文生图 ¥0.03–0.04 + 文生视频 ¥0.3/秒×5s=¥1.5 | ≈¥1.54 / 轮 | **A 目录价，本账号不可用、未实测**；且积分↔¥无换算，**不可与上两行直接比较** |

> 「标准 API 目录价看着便宜」是本次调研最容易踩的坑：单位不同、权限不通、结算口径不同，三者都没打通之前，不能得出「换通道更省」的结论。

### 3.4 止损纪律

1. 每轮设积分上限（建议 **30 积分**），触顶即停、先归因再决定是否追加。
2. 每个 task 实跑后只读回查 `usage.chargedPoint` 落盘留痕；**不按参数推算费用**（10.54 vs 20.57 的成因未查明）。
3. 失败先分两类：卡面可改 → 改后只重跑受影响层；模型边界 → 记边界、不改卡（P5）。
4. 应用市场不返价格，**不要为了「找更便宜的」批量试跑应用**；§33 一次四应用比价就花了 97.73 积分，接近推荐方案四轮的钱。
5. 非交互的批量送验可排在 00:00–10:00，但**先确认该折扣是否覆盖 AI 应用通道与当前 appId**（官网横幅只明确 H3 RH Enhanced）。
