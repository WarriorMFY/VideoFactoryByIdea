# 引用契约

## 一、单一真相源

基础卡**零外链**，装配关系全部集中在联合卡。同一张 `action-shield-sword-thrust` 可被任意多个联合卡复用，卡本身一字不改。

代价：加载器无法顺着子卡爬取，故 `composite.references` 必须**穷举**，九个键缺省写 `[]` 而非省略。

## 二、九槽位映射

| 槽位 | 目标 type | 必填 | 用途 |
| --- | --- | --- | --- |
| `figures` | `figure` | 是 | 解析 `主体A` / `主体B` |
| `faces` | `face` | 否 | 面部特写补充 |
| `moods` | `style` | 是 | 画风与全局氛围 |
| `actions` | `action` | 是 | 表演主体 |
| `cameras` | `camera` | 是 | 机位与运镜 |
| `voiceovers` | `voiceover` | 否 | 台词与音效 |
| `time_scales` | `time-scale` | 否 | 时间扭曲 |
| `ui` | `ui` | 否 | 世界空间提示 |
| `anti` | `anti` | 否 | 出图前质检 |

## 三、角色位解析

| 角色位 | 解析来源 | 说明 |
| --- | --- | --- |
| `主体A` | `references.figures[0]` | 默认施动方 |
| `主体B` | `references.figures[1]` | 默认受动方 |
| `主体<A/B>` | 按 UI 或镜头归属指定 | 须在位置列写明归属 |

若场景需要第三实体，说明应拆成两个联合卡。

## 四、装配算法

| 步 | 动作 | 失败处理 |
| --- | --- | --- |
| 1 | 解析 references，检查九键齐全 | 缺键即驳回联合卡 |
| 2 | 逐 name 存在性检查 + type 匹配 | 报「槽位/类型不匹配」并定位该行 |
| 3 | 静态资产合并：moods → figures → faces | 冲突时以序号小者为准 |
| 4 | 表演层合并：actions → cameras → voiceovers | 按 K 序号对齐 |
| 5 | 时序层合并：time_scales → ui | 以动作 K2 为锚点 |
| 6 | 质检层：anti 逐条执行排除指令 | 任一 blocker 未通过，退回步 4 |
| 7 | 输出 `prompt-final` | — |

## 五、锚点对齐

| 卡 | 锚点 | 说明 |
| --- | --- | --- |
| `action` | K2 = 峰值帧 | 全场景公共时间原点 |
| `camera` | K2 = 峰值 | 与动作 K2 同帧，保证冲击点入镜 |
| `time-scale` | T0 = 触发 | 通常对齐动作 K1 |
| `ui` | E0 = 弹出 | 通常在 T0 之后 1–2 帧 |

## 六、校验矩阵

| 校验项 | 执行位置 |
| --- | --- |
| name/type 前缀一致 | 单卡入库 |
| 两列表格结构 | 单卡入库 |
| 零外链 | 单卡入库 |
| 九槽位齐全 | 联合卡入库 |
| 槽位类型匹配 | 联合卡入库 |
| 关键帧连续 | 联合卡装配 |
| blocker 全通过 | 出图前 |
