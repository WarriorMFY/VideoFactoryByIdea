## 填写要点

- 「范围」写作用域：全局 / 仅主体A / 仅主体B / 主体A与B之间。
- 「持续」写真实时间（秒）而非帧，避免帧率变化时失控。
- 必须声明 UI 是否随之减速；世界空间 UI 通常冻结。
- 本卡只管时间，不描述画面内容与镜头。
