## 填写要点

- 「状态」列写形变与透明度：由小放大、呼吸脉动、淡出，不写情绪。
- 世界空间 UI 必须显式声明「时间缩放响应」，否则慢动作里 UI 会一起变慢。
- 文本一律给本地化 key，不直写中文正文。
- 本卡自带完整生命周期 E0→E3，不依赖某张动作卡存在。
