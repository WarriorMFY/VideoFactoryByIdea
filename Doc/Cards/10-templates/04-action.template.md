## 判定与接线

| 项目 | 取值 |
| --- | --- |
| scope 作用域 | execution=处决(锁定双方) / locomotion=位移 / reaction=受击 / interaction=交互 |
| level 结果 | terminal=不可打断导向死亡 / control=可打断导向硬直 / incap=导向失能倒地 |
| 命中判定窗口 | K<> 起 <> 帧 |
| 取消窗口 | K<> 起 <> 帧内可被闪避或格挡打断 |
| 受击反馈 | <硬直 / 后退 / 浮空 / 击倒 / 处决锁定> |
| 武器挂点 | <右手持剑 / 左手持盾 / 双持> |
| 双人对齐点 | 主体A <手部或插槽> ↔ 主体B <颈部或胸肩骨骼> |

## 填写要点

- 本卡只写动作几何：不指定外观、不指定镜头、不指定时间缩放。
- 「同步」列是核心，必须写清谁对齐谁的骨骼或插槽，不能只写「同时发生」。
- 位移只写矢量趋势（前移 / 后撤 / 原地），不写绝对值。
- K2 为峰值帧，是时间缩放与 UI 的公共锚点，须唯一。
