# 场景卡：黄昏土场（独立场景卡 v1.0）

> 自变量轴：空间层级（由大环境到空气介质）
> 因变量轴：环境状态（五元组定序：场地 → 地面 → 环境物 → 光线 → 大气）
> 实体约定：本卡只写「在哪打、光怎么落」，不含角色动作与镜头运动。
> 适用范围：可独立取用，不绑定任何特定动作或镜头；换动作、换镜头均不需改本卡。

| 空间层级（自变量：层级/对象） | 环境状态（因变量：可观测置景描述） |
| --- | --- |
| 场地 / 0 | 场地=室外空旷土质空地、四周无围墙无看台无观众；地面=场地整体平整硬实、向远处缓坡抬升；环境物=远景一道低矮断墙与稀疏枯草、无建筑无器物；光线=黄昏自然光、自场地一侧低角度入射、全场无人工光源；大气=空气通透无雾无雨、低空有少量浮尘 |
| 地面 / 1 | 场地=本层只指脚下承载面、不涉及远处空间；地面=压实黄土、表面覆 2–3 mm 细干土与 5–10 mm 碎石、无草皮无积水；环境物=地面散落少量碎石与干枯断枝、无杂物无血迹；光线=地面受光呈暖黄、双人影子落在干土上边缘清晰；大气=脚掌蹬地时踢起表层细土、身体落地处扬起 10–20 cm 高尘团、尘在低空停留约 1 s 后散开 |
| 环境物 / 2 | 场地=背景距主体 3–5 m、与场地同材质连续延伸；地面=背景地面与前景区同为干土、无草地无台阶；环境物=断墙高 0.8 m、墙面土黄斑驳、枯草高 0.4 m 成簇生长、无门无窗无旗无器械；光线=断墙与枯草被侧逆光勾出亮边、背光面压暗；大气=远景空气带灰调、与前景形成微弱纵深层次 |
| 光线 / 3 | 场地=光覆盖整个场地、无树荫无遮挡；地面=双人长投影朝同一方向、长度约为身高 2 倍、影缘硬朗；环境物=断墙与枯草在墙面与地面投出清晰硬影；光线=低角度侧逆光约 25°、色温 2900 K、硬光、明暗对比 0.8、无补光无反射板；大气=光柱中可见缓慢飘动的微尘颗粒 |
| 大气 / 4 | 场地=空气介质均匀充满全场、不改变场地形态；地面=浮尘主要集中在近地 0–30 cm、不遮挡脚部与接触点；环境物=远景因浮尘轻微发灰、轮廓仍可辨；光线=浮尘受光呈暖金色细颗粒、不产生光晕；大气=整体干燥、无雾无雨无烟、冲击与倒地时局部尘团浓度短暂升高 |
