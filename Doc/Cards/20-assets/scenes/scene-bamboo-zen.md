# 场景卡：晨雾竹林（独立场景卡 v1.0）

> 自变量轴：空间层级（由大环境到空气介质）
> 因变量轴：环境状态（五元组定序：场地 → 地面 → 环境物 → 光线 → 大气）
> 实体约定：本卡只写「在哪打、光怎么落」，不写角色动作；受力响应只写环境一侧的变化。
> 适用范围：可独立取用，不绑定任何特定动作或镜头；换动作、换镜头均不需改本卡。

| 空间层级（自变量：层级/对象） | 环境状态（因变量：可观测置景描述） |
| --- | --- |
| 场地 / 0 | 场地=竹林深处的林间空地、四周被立竹围合、无建筑无围墙无观众；地面=整片空地铺青石板、板缝间积薄层细土与干竹叶、向远处缓坡抬升；环境物=四周立竹直径 6–10 cm、高处竹冠交叠遮天、散布三两块苔石与一座石灯笼、无旗无器械；光线=清晨柔光自竹梢间隙斜落、全场无人工光源；大气=贴地薄雾、空气湿润、无雨 |
| 地面 / 1 | 场地=本层只指脚下承载面、不涉及林间纵深；地面=青石板表面微磨光、板缝间积 2–3 mm 细土与碎竹叶、落叶干脆易碎、无积水无泥；环境物=石缝生青苔、苔面湿润、板面散落几片枯竹叶与细枝；光线=石板受光呈青灰、缝隙与苔面压暗、光斑碎落在板面；大气=受踩踏与冲击时板缝浮土与碎叶扬起、扬起高度 10–20 cm、停留约 1 s 后落回 |
| 环境物 / 2 | 场地=背景竹林纵深 8–15 m、与前景同一种竹；地面=背景地面被落叶覆盖、青石板渐隐入林；环境物=竹竿直立成排、中景三两根竹竿略倾斜、苔石高约 0.6 m、石灯笼高 1.0 m 表面生苔、无门无窗无牌匾；光线=竹竿被侧光勾出亮边、背光侧沉入暗绿；大气=薄雾在竹林间分层、远处竹竿渐淡、形成纵深层次 |
| 光线 / 3 | 场地=柔光覆盖全场、竹冠遮挡形成斑驳；地面=石板上有清晰的竹叶投影与斜射光斑、投影边缘柔和；环境物=竹竿与苔石顶面受光、底部压暗；光线=清晨斜射柔光、冷绿主调夹暖白高光、漫射为主、明暗对比 0.5（0–1）、无补光无反射板；大气=斜射光穿过薄雾形成可见光柱、光柱内有细微浮尘 |
| 大气 / 4 | 场地=空气湿润、全场均匀薄雾、不改变场地形态；地面=雾主要贴地 0–20 cm、不遮脚部与接触点；环境物=远处竹林在雾中渐隐、轮廓仍可辨；光线=雾中光柱与光斑柔和、无光晕溢出；大气=无雨无烟、整体静谧、冲击与倒地时局部雾被搅动、浮土短暂升高 |
