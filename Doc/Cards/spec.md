# 卡片规范（建议）

> 本文件只在**新建卡片**时提供写法建议，不作强制校验，不判 `PASS` / `FAIL`。
> 卡片的实际内容、字段取舍、验收口径，由当轮**入库循环**定义，记录在 `Log/Circle<N>/` 与 `RAG/README.md`。
> `Doc/Cards/` 只有两样东西：本文件与 `Template/`。实例卡一律存放在 `RAG/`。

建议基线：一份卡片 = YAML frontmatter（`name` + `description`）+ 一张两列表格，表外不放正文段落。

## 全局规则

> 不限卡片类型，所有卡片通用；验收按此判，优先于下文的「建议」。

| # | 规则 | 替代写法 |
| --- | --- | --- |
| 1 | 卡片内不得出现「左脸」「左手」「右侧」等以左右区分部位的语句 | 改用功能或状态语义：遮布侧／露眼侧、伤侧／健侧、持盾侧／空手侧、主攻手／防御手、承重腿／发力腿 |

理由：左右随视角翻转。同一张卡两次生成，只要一次镜像，读到的就是「另一个人」——左右是身份漂移的第一来源。

## 一、元信息

| 项目 | 建议 |
| --- | --- |
| `name` | 与卡片标识一致——独立文件取文件名（去 `.md`），同名目录下的 `card.md` 取目录名；小写字母、数字、连字符，3–64 字符 |
| `description` | 非空；单行或 `\|` 文本块；控制在 200 字符内 |
| 其余键 | 建议不写 `type`、`source`、`tags`、`scope` 等；确有必要时由当轮入库循环决定是否保留 |

## 二、表格

| 项目 | 建议 |
| --- | --- |
| 数量 | 一张；参数表、词库表等附加内容并入主表右列，或另建一张卡 |
| 列数 | 每行两列；表头文字自由，建议左列 `<自变量轴>`、右列 `<因变量轴>` |
| 行轴 | 行数与行序由卡自己定；序号连续、`键=值；` 单元格格式等旧细则不再沿用 |
| 单元格 | 写什么由卡自己定；数值量纲、角色位写法、审美词禁用等旧约束不再沿用 |
| 表外 | 建议只保留一级标题与少量 `>` 声明；二级标题最多一个且须在主表之前 |

## 三、模板

| 项 | 说明 |
| --- | --- |
| 定位 | `Template/` 下 11 个文件是起草用骨架示例，不是合规样本 |
| 搬用前需裁剪 | 模板自带多表、参数表、`## 填写要点`、`## 校验` 与 `<>` 占位符，均属示例写法，进实例卡前按上表裁成单表 |

## 四、不再沿用

| 取消项 | 说明 |
| --- | --- |
| `type` 枚举与 `name` 前缀 | 卡片类型不由本文件定义 |
| 各类型必填键 | `scope`、`level`、`ui_kind`、`severity`、`references` 均不要求 |
| `description` 两段式 | 不再要求「介绍 ＋ 何时使用」句式 |
| 表格格式细则 | 表头模板、行标签 `<对象> / <序号>`、序号连续、`键=值；` 格式，全部取消 |
| 内容硬约束 | 零外链、角色位写法、审美词禁用、数值必须带量纲，全部取消 |
| 引用契约 | 九槽位装配、角色位解析、装配算法、锚点对齐、校验矩阵，全部取消 |
| 校验脚本 | 原 `validate.ps1` 已废止，不提供全量校验命令 |

上述各项如需恢复，由当轮入库循环单独提出并记入该轮 `Circle.md`，不在本文件统一规定。
