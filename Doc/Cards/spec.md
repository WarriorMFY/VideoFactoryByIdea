# 卡片规格

> 本文件是规格，不是卡片，不受自身规则约束。
> `Doc/Cards/` 只有两样东西：本文件与 `Template/`。实例卡一律存放在 `RAG/`。

一份卡片 = YAML frontmatter + 至少一张两列表格。**除本节写明的两条外，不作任何约束。**

## 一、元信息（严格校验）

| 字段 | 要求 |
| --- | --- |
| `name` | 必填；与卡片标识一致——独立文件取文件名（去 `.md`），放在同名目录下的 `card.md` 取目录名；`^[a-z0-9][a-z0-9-]*$`；3–64 字符；违反判 FAIL |
| `description` | 必填；非空；单行或 `\|` 文本块；≤ 200 字符；违反判 FAIL |

其余 frontmatter 键（`type`、`source`、`tags`、`scope` 等）允许出现，也可完全不写，**不作校验**。

## 二、表格（只校验两列）

| 检查项 | 要求 |
| --- | --- |
| 存在性 | 至少一张 markdown 表格；没有表判 FAIL |
| 列数 | 每一数据行恰好 2 列（表头分隔行不计）；多列或少列判 FAIL |
| 表头文字 | 不校验；建议写 `<自变量轴>` ｜ `<因变量轴>` |
| 行数与单元格内容 | 不校验；多少行、每格写什么，由各卡自己定义 |

## 三、模板豁免

| 项 | 说明 |
| --- | --- |
| 适用范围 | `Template/` 目录下的全部文件 |
| 豁免内容 | 本规格全部校验（模板正文含 `<>` 占位符、`name` 为示例值，属正常） |

## 四、已置空（不再有任何约束力）

| 取消项 | 说明 |
| --- | --- |
| `type` 枚举与 `name` 前缀 | 卡片类型不再由规范定义，`name` 前缀自由 |
| 各类型必填键 | `scope`、`level`、`ui_kind`、`severity`、`references` 一律不再必填 |
| `description` 两段式 | 不再要求「介绍 ＋ 何时使用」句式与字数分段 |
| 表格格式细则 | 表头模板、行标签 `<对象> / <序号>`、序号连续、单元格 `键=值；` 格式，全部取消 |
| 内容硬约束 | 零外链、角色位写法、审美词禁用、数值必须带量纲，全部取消 |
| 引用契约 | 九槽位装配、角色位解析、装配算法、锚点对齐、校验矩阵，全部取消 |
| 校验脚本 | 原 `validate.ps1` 已废止，不再提供全量校验命令 |
