# 反向卡 · 塑料感与穿模

> 自变量轴：风险维度（易错点 / 排错项）
> 因变量轴：负面描述与排除指令（三元组定序：错误表现 → 易发原因 → 排除指令）
> 定位约定：本卡是通用质检规则集，不绑定任何具体卡片。

| 风险维度（自变量：易错点/排错项） | 负面描述与排除指令（因变量：错误表现 / 纠错指令） |
| --- | --- |
| 穿模 / 0 | 错误表现=剑身穿过盾牌或直接没入无接触的胸腔；易发原因=盾与剑共用同一前向轨迹未做层级分离；排除指令=强制盾牌后收 8 cm 后才允许剑尖前送，二者轨迹至少错开 1 帧 |
| 质感失真 / 1 | 错误表现=盾牌与胸甲呈均匀哑光塑料面，无厚重金属感；易发原因=缺少粗糙度贴图与边缘磨损；排除指令=盾面粗糙度 0.55、边缘叠加锈蚀高光，胸甲加 3 处凹痕与划痕 |
| 解剖错误 / 2 | 错误表现=刺入点落在锁骨或下巴，主体B 颈部消失；易发原因=头颈后仰角度过大遮挡咽喉；排除指令=主体B 后仰上限 20°，甲状软骨下缘须全程可见 |
| 时序错乱 / 3 | 错误表现=慢动作中 UI 与布料同步变慢，节奏拖沓；易发原因=世界空间 UI 未脱离时间缩放；排除指令=UI 时间缩放响应固定为冻结，布料解算保持 0.35x 不透支 |
| 构图漂移 / 4 | 错误表现=峰值帧主体B 被主体A 肩甲完全遮挡；易发原因=机位与肩线夹角不足；排除指令=峰值帧机位侧移不小于 25°，保证剑尖与咽喉同框可见 |

## 填写要点

- 一张反向卡只约束一个风险主题，本卡聚焦「穿模 + 塑料感」，节奏问题已归为时序一行。
- 「排除指令」必须是可执行的约束或参数：「强制盾牌后收 8 cm」优于「不要穿模」。
- 一条风险只对应一个易发原因，多原因拆多行，便于定位。
- `severity`：blocker 违反即废图，warning 降低评分但可用。
