## 填写要点

- 「整体 / 0」必须能独立成句：只读这一行也应画出可辨识轮廓。
- 颜色写「色相 + 明度」，禁用「深色」「漂亮」等无量词词。
- 材质落到可渲染名词：金属 / 皮革 / 亚麻 / 陶瓷 / 骨骼。
- 「标志特征 / 5」只放 1–2 个记忆锚点，超出即噪声。
