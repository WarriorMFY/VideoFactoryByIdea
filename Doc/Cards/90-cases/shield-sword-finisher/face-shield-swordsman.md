# 脸部卡 · 方颌中年男面

> 自变量轴：面部层面（骨相 → 软组织 → 光学材质）
> 因变量轴：面部状态（五元组定序：形状 → 比例 → 结构起伏 → 材质纹理 → 细节特征）
> 实体约定：本卡是可独立复用的面部素材，不标注属于哪个角色。

| 面部层面（自变量：部位/对象） | 面部状态（因变量：可观测建模描述） |
| --- | --- |
| 整体骨相 / 0 | 形状=方颌宽颧；比例=面宽与面长比 4:5；结构起伏=颧弓外扩 6 mm、下颌角外翻；材质纹理=粗糙角质层；细节特征=左侧颧骨有硬币大凹陷 |
| 眼部结构 / 1 | 形状=深陷狭长眼；比例=眼裂长 30 mm、高 8 mm；结构起伏=眉弓前突 5 mm压出眼窝阴影；材质纹理=巩膜微黄、下眼睑细纹；细节特征=右眼睑有一道裂口旧疤 |
| 鼻部结构 / 2 | 形状=直挺带鹰钩；比例=鼻长占面长 1/3、鼻翼宽 38 mm；结构起伏=鼻梁微凸 2 mm、鼻头下垂；材质纹理=鼻翼毛孔粗大；细节特征=鼻梁中段有横向压痕 |
| 口唇与下颌 / 3 | 形状=薄唇紧闭、下颌方阔；比例=唇宽 48 mm、下颌角 120°；结构起伏=颏部前突 4 mm；材质纹理=唇纹纵向干裂；细节特征=下唇中央有愈合裂口 |
| 皮肤材质 SSS / 4 | 形状=贴合骨相无多余脂肪；比例=皮下脂肪层 2 mm；结构起伏=法令纹深 1.5 mm；材质纹理=风霜粗糙、混合油性；细节特征=左颊有烧伤瘢痕呈蜡质反光 |
| 表情肌与褶皱 / 5 | 形状=额肌与咬肌发达；比例=抬头纹间距 6 mm；结构起伏=皱眉时眉间竖纹两条；材质纹理=动态纹浅于静态纹；细节特征=右侧咬肌随咬牙隆起 |

## SSS 与表面参数（第 4 行必须填满）

| 参数 | 取值 |
| --- | --- |
| 次表面散射深度 | 2.4 mm |
| 散射半径 RGB | R=3.2 / G=1.6 / B=0.9 |
| 粗糙度 | 0.62（0–1） |
| 高光宽度 | 0.35 |
| 毛孔密度 / 尺度 | 320 个·cm⁻² / 0.08 mm |
| 泪腺与唇部湿润度 | 0.18（0–1） |

## 填写要点

- 先定颧弓、眉弓、下颌角三处棱线，再谈眼睛大小。
- 只写几何与光学，禁用「英俊」「好看」「有气质」。
- 褶皱按「静态纹归材质、表情纹归形态」分开写，两类不混。
- 换头不换骨相时需新建卡，不得在实例中写「参考某某脸」。
