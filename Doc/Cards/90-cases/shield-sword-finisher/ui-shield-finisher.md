# UI 提示卡 · 处决提示圆圈

> 自变量轴：事件点（事件编号 / 阶段 / 进度）
> 因变量轴：UI 状态（五元组定序：标识 → 文本 → 图标 → 位置 → 状态）
> 锚点约定：位置列一律写角色位，由联合卡解析为具体形象。

## 渲染与遮罩

| 项目 | 取值 |
| --- | --- |
| ui_kind | execution-prompt |
| 坐标系 | 世界空间(跟随骨骼) |
| 锚点 | 主体B 头顶骨骼，偏移 40 px |
| 时间缩放响应 | 冻结(不随减速) |
| 遮挡策略 | 穿透场景 |
| 可见性条件 | 相机距离 8 m 内 |

## 填写要点

- 「状态」列写形变与透明度：由小放大、呼吸脉动、淡出，不写情绪。
- 世界空间 UI 必须显式声明「时间缩放响应」，否则慢动作里 UI 会一起变慢。
- 文本一律给本地化 key，不直写中文正文。
- 本卡自带完整生命周期 E0→E3，不依赖某张动作卡存在。

- [x] `ui_kind` 在枚举内

- [x] 位置列锚点从 E0 到 E3 一致
