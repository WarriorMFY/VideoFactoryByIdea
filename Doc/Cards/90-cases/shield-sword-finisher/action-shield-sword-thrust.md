# 动作卡 · 盾撞刺喉

> 自变量轴：关键帧（帧号 / 阶段 / 进度）
> 因变量轴：动作状态（五元组定序：角色 → 武器接触 → 目标 → 位移 → 同步）
> 实体约定：一律以角色位书写，`主体A` 施动、`主体B` 受动。

| 关键帧（自变量：帧号/阶段/进度） | 动作状态（因变量：可观测动作描述） |
| --- | --- |
| K0 / 起手 / 0% | 角色=主体A左脚在前、重心后坐于右腿，躯干正对主体B；武器接触=主体A的盾面朝向主体B胸肩，单手剑收于自身右肘后；目标=主体B正面站立、双手垂落；位移=待发，双人胸距 150 cm，尚在盾击半径外；同步=盾心对齐主体B锁骨中线 |
| K1 / 接触 / 30% | 角色=主体A拧腰，重心前移至左脚、躯干向右转 20°、右肩前送；武器接触=主体A的盾缘撞击主体B胸骨柄；目标=主体B胸廓受力后仰 15°；位移=主体A 前冲 40 cm，双人胸距缩短至 110 cm；同步=盾缘接触点为胸骨柄，剑仍收于右肘后 |
| K2 / 峰值 / 55% | 角色=主体A躯干继续向右转至 45°、右臂半屈前送（肘弯 90°）、左臂回撤；武器接触=主体A的盾向左后回撤一掌宽 8 cm，为剑让出中线，剑尖刺入主体B咽喉；目标=主体B头颈后仰至极限、咽喉完全暴露（承 K1 盾击之势）；位移=主体B 因 K1 盾击余力累计后退 60 cm、双人胸距回到 170 cm，主体A 前脚落定不再前进；同步=剑尖对齐主体B甲状软骨下缘 |
| K3 / 收势 / 85% | 角色=主体A肩线回落、重心下沉；武器接触=主体A的剑身没入至护手，盾仍挂于左前臂垂于体侧；目标=主体B右膝先屈、重心后移、身体下沉；位移=主体A 原地，主体B 原地；同步=主体A左手松开盾柄，剑身保持刺入深度 |
| K4 / 复位 / 100% | 角色=主体A直立呼气；武器接触=主体A抽出剑，血沿刃口滑落；目标=主体B仰面倒地；位移=主体A后撤一步 50 cm；同步=剑尖回指地面 |
