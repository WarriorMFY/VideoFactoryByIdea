# 动作卡 · 盾撞刺喉

> 自变量轴：关键帧（帧号 / 阶段 / 进度）
> 因变量轴：动作状态（五元组定序：角色 → 武器接触 → 目标 → 位移 → 同步）
> 实体约定：一律以角色位书写，`主体A` 施动、`主体B` 受动。

| 关键帧（自变量：帧号/阶段/进度） | 动作状态（因变量：可观测动作描述） |
| --- | --- |
| K0 / 起手 / 0% | 角色=主体A左脚在前重心后坐；武器接触=盾面朝向主体B胸肩、剑收于右肘后；目标=主体B正面站立双手垂落；位移=前冲半步 40 cm；同步=盾心对齐主体B锁骨中线 |
| K1 / 接触 / 30% | 角色=主体A拧腰带动右肩前送；武器接触=盾缘撞击主体B胸骨柄；目标=主体B胸廓受力后仰 15°；位移=主体A再前移 30 cm；同步=盾缘接触点为胸骨柄，剑未离鞘口 |
| K2 / 峰值 / 55% | 角色=主体A躯干右旋 45°、左臂回撤；武器接触=盾回撤一掌宽 8 cm、剑尖刺入主体B咽喉；目标=主体B头颈后甩、咽喉完全暴露；位移=主体A前脚落定 0 cm；同步=剑尖对齐主体B甲状软骨下缘 |
| K3 / 收势 / 85% | 角色=主体A肩线回落重心下沉；武器接触=剑身没入至护手、盾垂于体侧；目标=主体B双膝屈曲身体下坠；位移=原地；同步=主体A左手松开盾带 |
| K4 / 复位 / 100% | 角色=主体A直立呼气；武器接触=抽剑、血沿刃口滑落；目标=主体B仰面倒地；位移=主体A后撤一步 50 cm；同步=剑尖回指地面 |

## 判定与接线

| 项目 | 取值 |
| --- | --- |
| scope 作用域 | execution=处决(锁定双方) |
| level 结果 | terminal=不可打断导向死亡 |
| 命中判定窗口 | K1 起 6 帧 |
| 取消窗口 | K0 起 4 帧内可被闪避或格挡打断 |
| 受击反馈 | 处决锁定，无击退 |
| 武器挂点 | 左手圆盾、右手单手剑 |
| 双人对齐点 | 主体A 剑尖插槽 ↔ 主体B 甲状软骨下缘骨骼 |

## 填写要点

- 本卡只写动作几何：不指定外观、不指定镜头、不指定时间缩放。
- 「同步」列是核心，必须写清谁对齐谁的骨骼或插槽，不能只写「同时发生」。
- 位移只写矢量趋势（前移 / 后撤 / 原地），不写绝对值。
- K2 为峰值帧，是时间缩放与 UI 的公共锚点，须唯一。
