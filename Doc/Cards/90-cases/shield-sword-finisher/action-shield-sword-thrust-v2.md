# 动作卡 · 盾撞刺喉（v2）

> 自变量轴：关键帧（帧号 / 阶段 / 进度）
> 因变量轴：动作状态（五元组定序：角色 → 武器接触 → 目标 → 位移 → 同步）
> 实体约定：一律以角色位书写，`主体A` 施动、`主体B` 受动；`主体A` 左手持圆盾（盾面直径 60 cm，盾面最远可达其胸前 70 cm）、右手持单手剑（刃长 100 cm）。

| 关键帧（自变量：帧号/阶段/进度） | 动作状态（因变量：可观测动作描述） |
| --- | --- |
| K0 / 起手 / 0% | 角色=主体A左脚在前、重心后坐于右腿，躯干正对主体B；武器接触=主体A的盾面朝向主体B胸肩，盾心对齐主体B锁骨中线，单手剑收于自身右肘后；目标=主体B正面站立、双手垂落；位移=待发，双人胸距 150 cm，尚在盾击半径外；同步=盾心与主体B锁骨中线等高 |
| K1 / 接触 / 30% | 角色=主体A拧腰，重心前移至左脚、躯干向右转 20°、右肩前送；武器接触=主体A的盾心撞击主体B胸骨柄；目标=主体B胸廓受力后仰 15°；位移=主体A 前冲 75 cm，双人胸距缩短至 75 cm；同步=盾心接触点为胸骨柄，剑仍收于右肘后 |
| K2 / 峰值 / 55% | 角色=主体A躯干继续向右转至 45°，右手将剑自右肘后向前送出、右臂半屈前送（肘弯 90°）、左臂回撤；武器接触=主体A的盾向左后回撤一掌宽 8 cm，为剑让出中线，剑尖刺入主体B咽喉；目标=主体B头颈后仰至极限、咽喉完全暴露（承 K1 盾击之势）；位移=主体B 因 K1 盾击余力累计后退 95 cm、双人胸距回到 170 cm，主体A 前脚落定、重心前压至前脚而不再前移；同步=剑尖入点为甲状软骨下缘 |
| K3 / 收势 / 85% | 角色=主体A肩线回落、重心下沉；武器接触=主体A的剑身穿透主体B颈部，剑身中段贯穿咽喉，剑尖自主体B后颈穿出；目标=主体B右膝先屈、重心后移、失力下沉；位移=主体A 原地，主体B 原地；同步=剑尖自主体B后颈露出约一掌宽 |
| K4 / 复位 / 100% | 角色=主体A直立呼气；武器接触=主体A抽出剑，血沿刃口滑落；目标=主体B仰面倒地；位移=主体A后撤一步 50 cm；同步=剑尖回指地面 |
