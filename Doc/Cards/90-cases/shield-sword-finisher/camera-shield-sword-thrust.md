# 镜头卡 · 盾撞刺喉跟拍

> 自变量轴：关键帧（帧号 / 阶段 / 进度）
> 因变量轴：镜头状态（五元组定序：景别 → 机位 → 运镜 → 焦点 → 切换）
> 对齐约定：K2 必须与所选动作卡的峰值帧同帧。

| 关键帧（自变量：帧号/阶段/进度） | 镜头状态（因变量：可观测镜头描述） |
| --- | --- |
| K0 / 起幅 / 0% | 景别=中景；机位=侧后 135° 略高于肩；运镜=缓推起手；焦点=锁定主体A盾面；切换=无切换 |
| K1 / 运动 / 40% | 景别=中近景；机位=随主体A前移同步跟随；运镜=推速提升至 0.4 m/s；焦点=由盾缘过渡至主体B胸肩；切换=无切换 |
| K2 / 峰值 / 55% | 景别=特写；机位=低角度仰拍 15°；运镜=推至静止、轻微手持呼吸；焦点=锁定主体B甲状软骨与剑尖；切换=无切换 |
| K3 / 落幅 / 100% | 景别=中景；机位=垂直升高至俯拍 40°；运镜=缓慢拉回；焦点=由咽喉拉至双人全身；切换=无切换 |

## 镜头参数

| 参数 | 取值 |
| --- | --- |
| 焦段 | 50 mm |
| 光圈 | f/2.0 |
| 快门角 | 90 ° |
| 稳定方式 | 斯坦尼康 |
| 画幅比 | 2.39:1 |
| 手持抖动强度 | 0.15（0–1） |

## 填写要点

- 景别用标准五级：大远景 / 全景 / 中景 / 近景 / 特写，不自造词。
- 机位写相对关系：低角度仰拍、越肩、正上方俯拍。
- 运镜写轨迹与速度：缓推、横移跟拍、快速甩镜，不写「动感」。
- 交接必写「切换」：硬切 / 叠化 / 无切换（长镜头）。
