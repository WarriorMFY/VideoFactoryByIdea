# 旁白卡 · 处决低语

> 自变量轴：事件点（事件编号 / 阶段 / 进度）
> 因变量轴：旁白状态（五元组定序：文本 → 语气 → 样式 → 时机 → 音效）
> 实体约定：台词中指代角色一律写作「他 / 她 / 它」，不写专名。

| 事件点（自变量：事件编号/阶段/进度） | 旁白状态（因变量：可观测视听描述） |
| --- | --- |
| E0 / 预备 / 0% | 文本=vo.shieldfinisher.e0；语气=屏息；样式=无字幕；时机=盾撞前 2 帧；音效=皮革摩擦 |

| E2 / 落点 / 70% | 文本=vo.shieldfinisher.e2；语气=气声收尾；样式=底部白字描边；时机=剑尖入喉同帧；音效=湿性穿刺短音 |
| E3 / 收尾 / 100% | 文本=vo.shieldfinisher.e3；语气=归于沉默；样式=淡出；时机=抽剑后 4 帧；音效=血滴落地 |

## 音频参数

| 参数 | 取值 |
| --- | --- |
| 语速 | 3.5 字/秒 |
| 音高 | 105 Hz |
| 混响时间 | 0.6 s |
| 声道位置 | 居中 |
| 字幕样式 | 底部白字描边 |
| 本地化 key | vo.shieldfinisher.e0 |

## 填写要点

- 「文本」列不直写中文正文，写本地化 key，便于多语言替换。
- 「时机」列锚定事件点，不写绝对秒数，避免与其他卡冲突。
- 「音效」列只写一次性点音效（金属撞击、闷响），持续环境声归画风卡。
- 语速与字数必须互相自洽，可据语速反推每行台词时长。
