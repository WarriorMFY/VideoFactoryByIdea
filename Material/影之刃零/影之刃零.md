## 一句话用途

一部源片 = 一个素材类目录：原始母带放题材层，抽好的处决镜头按「单位号」排好，
剪辑/对比/拼接全按 `uNN` 引用。结构逐字节对齐 `Prototype/loop38_exec_extract/clips1080p60`。

## 目录内容

| 条目 | 内容 | 数量 |
|---|---|---|
| `处决镜头/` | 46 个完整处决单位的母版片 + 缩略图 + HUD 字幕 + 清单 + 核对页 | 140 文件 |
| `源片/` | 原始处决合集母带（BV1ydx26rEWv，UP主 余掌事，173.035s / 10381 帧 / 224MB / 1920×1080@60） | 1 |

```
处决镜头/
  u01.mp4 … u46.mp4     # 1920×1080 / 60fps / yuv420p / CRF18 / 整幅构图 + ASS HUD（编号·场景·源时间码）
  u01.jpg … u46.jpg     # 960×540 中位帧缩略图
  u01.ass … u46.ass     # 与 mp4 同名的 HUD 字幕（改字幕必须重出 mp4，见 docs/入库操作.md 末条）
  catalog.csv           # id/kind/scene/move/t/dur/durOut/res/fps/beat/note/file
  index.html            # 带内嵌播放器的核对页（相对路径，本地打开即可逐个看）
源片/BV1ydx26rEWv_yzl_exec_1080p60.mp4
```

共 `3×46+2 = 140` 文件。`源片/` 在**题材层**（v1 起上提：同一部母带会被切成多类素材，
逐类各存一份就是 224MB × 类数）。`exec_extract export` 末尾自带结构自检，缺项直接失败。

## 已知局限

- 该合集是快剪结构，剪辑在击杀后 0.1–0.2s 即切镜，**收招落地帧在源片里不存在**，无法补回；
  需要完整收招的素材应换长镜头实机源（`exec-extract` 的 B 路线）
- `catalog_60.json` 无 `beat` / `srcLabel` 字段，故 ASS 底部节拍行与右上「源」字段为空——与 clip1080p60 一致，不是本轮丢字段
- 关键帧（起手/命中/收招 138 张）**未随迁**，仍只在 `Prototype/loop38_exec_extract/frames1080p60/`；
  `kinds.json` 里已声明 `关键帧`（files 型，`status: declared`），迁入后把 status 升 `active`
