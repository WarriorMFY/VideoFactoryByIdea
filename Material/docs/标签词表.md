# 标签词表（tags）

> **读到这里就够，除非**你要加一个新标签值，或者发现 `list --tag` 查不出想要的东西。
> 字段含义 → [`字段字典.md`](字段字典.md)；目录形状 → [`模板规范.md`](模板规范.md)。

## 先记住一句话

**`tags` 只放"会跨类复用、需要自由组合"的词。** 已经有专门字段的语义不许再塞进 tags——
v1 之前的 47 条就是这样烂掉的：一个数组里同时装着题材、规格、素材类、分级、场景、单位号、BV 号，
于是 `list --tag 标准` 和 `list --tag 火场` 落在同一个平面，谁也不是谁的上位词。

| 语义 | 该去哪 | 别再进 tags |
|---|---|---|
| 题材 | `topic` 字段 | ~~影之刃零~~ |
| 素材类 | `kind` 字段 | ~~处决镜头 / 源片~~ |
| 单位号 | `unit` 字段 | ~~u01 … u46~~ |
| 场景 / 招式 | `scene` / `move` 字段 | ~~夜祭坛 / 火场 / 崖边~~ |

## 受控值

### 题材（与目录名同字）
`影之刃零`

### 素材类（与 `kinds.json` 同名）
`处决镜头` `关键帧` `源片`

### 动作分级（仅 `处决镜头` 有）
| 值 | 判据 |
|---|---|
| `仪式级` | 出处决演出（运镜/停顿/特写），单条 ≥3s |
| `标准` | 完整起手→命中→收招 |
| `快杀` | 剪辑在命中后 0.1–0.2s 内切走，收招不完整 |

### 规格
`1080p60` `1080p` `2160p` `竖屏1080x1920`
（写法统一：`1080p60` 不写 `1080P60`、不写 `1080p/60fps`）

### 来源标识
`BV<10位>`（如 `BV1ydx26rEWv`）｜ `LOCAL<YYYYMMDD>`（自有录制/游戏内截取）

### 帧阶段（仅 `关键帧`）
`起手` `命中` `收招`

### 状态（人工加，表示素材本身的状态，不是审核流程）
`待核` `已核` `隔离`

## 加新词的流程

1. 先问：这个语义能不能用现有字段表达？能 → 不加。
2. 不能 → 在本册对应分类下加一行，写清判据（**没有判据的词就是噪声**）。
3. 加完跑一次 `node Tool/check/material_layout.mjs` 确认没把旧条目弄成不合规。
4. 一张新题材的素材入库后，回头检查本册有没有"只出现一次"的词——出现一次的多半该进字段而不是 tags。
