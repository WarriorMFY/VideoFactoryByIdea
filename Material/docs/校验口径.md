# 校验口径（material_layout v1）

> **读到这里就够，除非**校验报了错、或你想加一条新检查、或怀疑某条是误报。
> 工具：[`../../Tool/check/material_layout.mjs`](../../Tool/check/material_layout.mjs)｜规则源：[`模板规范.md`](模板规范.md) + [`../kinds.json`](../kinds.json)

## 怎么跑

```bash
node Tool/check/material_layout.mjs            # 人读
node Tool/check/material_layout.mjs --quiet    # 只出汇总（进 CI 用）
node Tool/check/material_layout.mjs --json     # 机器读，含 code/msg/warnings
```

退出码：**0 = 无错误**（告警不影响），**1 = 有错误**。告警也是信号，不要只看退出码。

## 错误码

| 码 | 含义 | 典型原因 | 怎么修 |
|---|---|---|---|
| `F1` | 账本条目指向的实体不存在 | 移动/删除了文件没改账本 | 跑 `archive --in-place` 重登记；文件真没了就从账本删该行 |
| `F2` | 题材目录缺同名索引 | 建了目录没写 `<题材>.md` | 照 `_template/题材名.md` 抄一份 |
| `F3` | 素材类不合 shape 声明 | units：编号跳号/缺 `.jpg`/`.ass`；files：命名不符 `namePattern` | 按 `kinds.json` 里该类的 `perUnit`/`namePattern` 补齐 |
| `F4` | rootFiles 缺件，或 `catalog.csv` 行数 ≠ 单位数 | 少 `catalog.csv`、手改过清单 | 重跑 `export`；不要手改 csv |
| `F5` | 缺 `index.html` 核对页 | 只拷了片段 | 重跑 `export` |
| `F6` | 缺 `源片/`、为空、命名不合规 | 母带还留在 `Workspace/tmp`（会被清） | 拷进 `题材/源片/`，命名 `<BVID>_…` 或 `LOCAL<日期>_…` |
| `F7` | 有实体无账 / `path` 与 `topic·kind` 不一致 | 手工放进目录没登记；账本字段与目录不同源 | 重跑 `archive`；不要手改 `path` |
| `F8` | 账本字段不合字典 | `kind` 空/未注册、`tier` 越界、`license_class` 非枚举 | 删手写值，用工具写入 |
| `F9` | 素材类目录未在 `kinds.json` 注册 | 先建了目录再想登记 | 在 `kinds.json` 声明 shape 与必备件 |

## 告警

| 码 | 含义 | 处理 |
|---|---|---|
| `W1` | 母版规格与 `masterSpec` 不符 / 有文件不符 `namePattern` | units 类可能是上采样或降帧；files 类多半是命名跑偏 |
| `W2` | `.gitignore` 缺该题材的「只放索引」排除 | 加两行，否则 400MB 片段会进 git |
| `W3` | 类标 `declared` 但磁盘上有实体 | 核实后把 `kinds.json` 里该类的 `status` 升 `active` 并补 `rootFiles` |

## 已知边界（不是 bug，别急着重构）

1. **只抽样首条查规格**（`W1`）。46 条逐条 ffprobe 要 20 秒，日常没必要；怀疑批量降级时手动逐条查。
2. **不查 `.ass` 与 `.mp4` 是否同步**。`.ass` 改了不重渲染，画面上的字还是旧的——这条只能靠人守（见 `入库操作.md` 末条）。
3. **不查近重复**（同镜头不同裁切/码率）。`sha256` 只对完全相同文件有效。触发条件：同一素材出现 2 个版本且都入了库。
4. **不查索引里的数字**（如"140 文件 / 47 条"）。手写死了会漂，但校验它需要解析 md 表格，收益低于成本；
   真要准确就现跑 `ls | wc -l` 和 `wc -l manifest.jsonl`。
5. **不给白名单/豁免**。不合规就修，不加 `--ignore`。有豁免口子，第一次用了就会有第二次。

## 加一条新检查的规矩

1. 能在 `kinds.json` 里用声明表达的，不加代码（例如新素材类、新必备件）；
2. 真要加代码：先在 `模板规范.md` 写清判据与"为什么"，再写检查，最后在本册登记错误码；
3. 错误码只增不改含义；废弃的码在表里标 `deprecated` 而不是删行。
