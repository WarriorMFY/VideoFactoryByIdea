# 入库操作（照着抄）

> **读到这里就够，除非**某一步报错、或你要入的素材不是"从源片抽取"这条路。
> 形状为什么这样 → [`模板规范.md`](模板规范.md)；命令报错对照 → [`校验口径.md`](校验口径.md)。

## 前置：账号与规格纪律

- **采集**走「为做真实的自己许诺」，默认 1080p60。不带 profile 会落到发布号目录（错号）：
  ```bash
  BILI_PROFILE=Workspace/run/bili_profile_B_326452892 node Tool/ops/dl_bili_hd.mjs <BVID> <out.mp4>
  ```
- **发布**走「草履虫爱剪辑」（默认 profile，不设变量）。
- 下载后**必须核实际流**：`playurl` 无权限时会静默降级成 720p/30fps，脚本会打印 `⚠ 实际档位` 告警，别忽略。

## 五步

```bash
# ① 抽：边界由 Skills/exec-extract 判据定；输出目录写绝对路径
node Tool/ops/exec_extract.mjs export <catalog.json> \
  "Material/<题材>/<素材类>" 1920x1080
#    ✅ 跑完必须看到 [结构自检] 通过：3N+2/3N+2 项齐备，否则就是缺件

# ② 放源片：上提到题材层，不进素材类目录
mkdir -p "Material/<题材>/源片"
cp <源片> "Material/<题材>/源片/<BVID>_<短名>_1080p60.mp4"

# ③ 入账：--in-place 只登记不复刻，账本 path 即实体位置
node Tool/ops/exec_extract.mjs archive <catalog.json> \
  --clips "Material/<题材>/<素材类>" \
  --frames "Material/<题材>/_noframes" \
  --src "Material/<题材>/源片/<文件名>" \
  --source-url <出处链接> --attribution <署名> \
  --license "<授权原文>" --license-raw "<原始声明，可空>" \
  --bvid <BVID> --run <批次号> --in-place

# ④ 写索引 Material/<题材>/<题材>.md（照 _template/题材名.md 抄，别自己发明小节）

# ⑤ 让 git 只收索引
#    .gitignore 加两行：Material/<题材>/*   +   !Material/<题材>/*.md
```

**⑥ 验收**

```bash
node Tool/check/material_layout.mjs      # 必须 ✓ 全部合规（告警也要看）
```

## 常见失败（都真发生过）

| 现象 | 原因 | 处理 |
|---|---|---|
| 片段散落在 `Prototype/`，`Material/` 里没有 | `export` 的输出目录给了相对路径，被拼到 catalog 所在目录 | 用**绝对路径**（v1 已支持，旧版会拼坏） |
| `[结构自检] 失败` | 单位数×3+2 对不上，通常少 `.ass` 或 `index.html` | 看日志里列出的缺失项，重跑 export |
| 账本报 `F1` 悬空 | 拷了/删了/改名了实体但没重跑 `archive` | 重跑 `archive --in-place`（路径变了要改 `--src/--clips`） |
| 账本报 `F7` 有实体无账 | 手工把文件放进目录没登记 | 同上，`archive` 会按目录重新登记 |
| 账本报 `F8` tier 越界 | 手写 `tier` 或用了旧的 `L0` 硬编码 | 删掉手写值，交给 `classifyLicense()` 推导 |
| 源片命名报 `F6` | 命名不像 `<来源标识>_…` | B 站素材用 `BV…_` 开头；自有录制裁成 `LOCALYYYYMMDD_…` |
| 下载只有 720p | 账号无权限，`playurl` 静默降级 | 换采集号（见前置），或接受降级并在 `note` 写明 |

## 不是"从源片抽取"的素材怎么入

| 来源 | 走哪条 |
|---|---|
| 网采（NASA/Wikimedia/Openverse） | `collect_material.mjs fetch`（自动分类授权、自动入账） |
| AI 生成 | `collect_material.mjs register --cost L3 --ai`（强制 `ai_generated=true`） |
| 自有录制 | 先 `cp` 进 `Material/<题材>/源片/LOCAL<日期>_…`，再按素材类归属决定是否切分 |
| 单张图/单个音效 | `register --path … --tags …`，`kind` 手填（注册表里先有该类） |

## 一条容易漏的

**改 `.ass` 不会改已经烧进字幕的 `.mp4`。** `.ass` 是留档可改的源，但 `uNN.mp4` 是最终渲染；
要改画面上的字，必须重跑 export。校验器看不出这两者脱钩——所以改完字幕**一定重出片段**。
