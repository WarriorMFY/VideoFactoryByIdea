# 字段字典（manifest.jsonl）

> **读到这里就够，除非**你要新增字段、要写查询脚本、或发现某字段的值"看着不对"。
> 只想入库 → [`入库操作.md`](入库操作.md)；只想知道能不能发 → [`授权与可发布.md`](授权与可发布.md)。
> 上级：[`../Material.md`](../Material.md)

一行一条素材（`jsonl`），**追加写**，幂等靠 `sha256`。字段名一旦发布就不再改含义（改 = 加新字段 + 旧的标记废弃）。

## 定位字段（v1 新增，解决"全塞 tags"的问题）

| 字段 | 谁写 | 取值 | 说明 |
|---|---|---|---|
| `topic` | `archive` / `register` | 题材目录名，如 `影之刃零` | 与 `path` 第一段必须一致（F7） |
| `kind` | `archive` | `kinds.json` 里的类名，如 `处决镜头` / `源片` / `关键帧` | 未注册即 F8 |
| `unit` | `archive` | `uNN`，可空 | 单位号是剪辑侧唯一引用 ID |
| `scene` | `archive` | 自由短名，如 `夜祭坛` | 原先塞在 tags 里，无法独立查询 |
| `move` | `archive` | 招式/动作描述 | 同上 |

## 授权与代价（两条正交的轴，最容易被混）

| 字段 | 谁写 | 取值 | 说明 |
|---|---|---|---|
| `tier` | `fetch` / `register` / `archive` | `L0` 库内复用 / `L1` 开放授权 / `L2` 待核 / `L3` AI 生成 | **只表示采集代价**，不表示放在哪 |
| `license` | 调用方 | 人读原文 | 例：`版权归原作者 · 研究/评论引用（非商业）` |
| `license_class` | `classifyLicense()` 自动 | `PD/CC0` `CC BY` `CC BY-SA` `REVIEW` `UNKNOWN` | **发布门槛的唯一判据**（`Tool/lib/license.mjs`） |
| `license_raw` | 调用方 | 授权原始声明 | 允许为空：无声明就写"未见明确许可声明" |
| `attribution` | 调用方 | 署名 | 发布时须原样出现在简介 |

> **历史 bug（已修）**：`exec_extract` 曾把 `tier` 硬写成 `L0`。L0 的定义是"库内复用、0 代价"，
> 而这批素材是从 B 站下载的外部版权片——`tier` 说"库里本来就有"，`license` 说"归别人"，自相矛盾。
> 现在 `tier` 由 `classifyLicense()` 推导（外部版权片 → `L2`）。**不要再手写 tier。**

### tier × license_class 对照（不是同一件事）

| | `license_class` 可发（PD/CC0、CC BY） | `license_class` 待核（REVIEW/UNKNOWN） |
|---|---|---|
| `tier=L1` | 网采直接进题材目录，可发布 | 不该出现（网采遇到 NC/ND 会落 L2） |
| `tier=L2` | 授权已核但来源是外部 → 可发布 | **当前 `影之刃零` 47 条都在这一格：可研究/评论引用，不可商用发布** |
| `tier=L3` | AI 生成，需成片声明 | 来源不明，查清再用 |

## 身份与来源

| 字段 | 谁写 | 取值 | 说明 |
|---|---|---|---|
| `id` | 自动 | `sha256` 前 10 位 | 全局唯一，重复采集靠它去重 |
| `sha256` | 自动 | 64 位 | 幂等键；同一文件重采只跳过 |
| `bytes` | 自动 | 字节数 | 用于容量统计 |
| `type` | 自动 | `video` / `image` | 预留 `audio`（**未实现**，入音效类前先补） |
| `source` | 调用方 | `bilibili` / `bilibili-derivative` / `ai-generated` / `manual` | 采集通道 |
| `source_url` | 调用方 | 出处链接 | 必须如实填（铁律） |
| `file_url` | `fetch` | 直链，可空 | 重采时用 |
| `width` / `height` / `duration` / `codec` | 自动 ffprobe | — | `duration` 秒，保留 2 位 |
| `ai_generated` | `register --cost L3` | `true`/`false` | 发布物 AI 声明纪律的判据 |
| `path` | 自动 | 相对 `Material/` 的路径 | **实体位置的唯一记录** |

## 组织与叙事

| 字段 | 谁写 | 取值 | 说明 |
|---|---|---|---|
| `tags` | 调用方 | 受控词表，见 [`标签词表.md`](标签词表.md) | **不再承载场景/单位号/题材**（已有专门字段） |
| `need` | 调用方 | 如 `影之刃零·处决镜头` | 采集需求名，用于分组 |
| `run_id` | 调用方 | 批次号，如 `loop44b_exec_rearchive` | 对应回执 `History/runs/materials/<run_id>.json` |
| `note` | 调用方 | 自由文本 | 放"人需要知道的例外"，不放结构化数据 |
| `acquired_at` | 自动 | ISO 时间 | — |

## 允许为空 & 不允许为空

- **不允许空**：`id` `sha256` `path` `topic` `kind` `tier` `license_class` `type`（`F8` 会拦）
- **允许空**：`unit` `scene` `move` `duration`（图片）`file_url` `license_raw` `note`
- `tags` 空时写 `["未分类"]`，不写空数组（`list --tag` 靠它兜底）

## 改字段的规矩

1. 加字段：可以，先写进本册，再改工具；旧条目允许缺该字段（校验器按"可空"处理）。
2. 改含义：不行。加新字段（如 `tier2`）并把旧的标 `deprecated`，保留历史可读。
3. 删字段：先确认没有脚本读它（`grep -rn "\.字段名" Tool/`），再从本册删除。
