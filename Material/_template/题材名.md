## 取用

```bash

# 本地逐个看

# 重建整批（清单在 <catalog.json 路径>，源片在 源片/）
node Tool/ops/exec_extract.mjs export <catalog.json> \
  "F:/AgentWorkArea/WorkBuddy/VideoFactory/Material/<题材>/<素材类>" 1920x1080
```
