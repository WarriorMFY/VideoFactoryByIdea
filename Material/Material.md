# Material — 素材库（本地实体 + 入库账本）

> 这一页只回答三件事：目录长什么样、账本怎么记、现在库里有什么。细则在 `docs/` 六册，机器真的在 `kinds.json`。

## 目录模板

```
Material/
├── Material.md                  # 本页（L0 入口）
├── kinds.json                   # 素材类注册表：加类只改这里
├── manifest.jsonl               # 总账：一条实体一行
├── docs/                        # 六册规范（模板/字段/词表/操作/授权/校验）
├── _template/题材名.md           # 新题材索引骨架
└── <题材>/
    ├── <题材>.md                # 题材索引（账本摘要 + 单位表）
    ├── 源片/                    # 母带（多类共用一份）
    └── <素材类>/                # 如 处决镜头/
        ├── uNN.mp4/.jpg/.ass    # 单位三件套
        ├── catalog.csv          # 单位清单（行数 = 单位数）
        └── index.html           # 核对页
```

## 入库五步

1. 母带进 `<题材>/源片/`，命名 `<BV号或LOCAL日期>_<短名>_<规格>.mp4`
2. `exec_extract export` 切单位到 `<题材>/<素材类>/`（自动出三件套 + catalog + index）
3. 账本 `manifest.jsonl` 追加：源片 1 条 + 每单位 1 条（`topic`/`kind`/`tier`/`license_class`/`path` 必填）
4. `node Tool/check/material_layout.mjs` 到 `✓ 全部合规`
5. 题材索引 `<题材>.md` 写单位表与账本摘要

## 现在有什么

| 题材 | 素材类 | 单位 | 授权 |
|---|---|---|---|
| `样例题材` | 处决镜头 | 2（合成演示） | PD/CC0 |

> 样例是合成素材，用来跑通管线与冒烟；真实题材请按 `_template/题材名.md` 新建。

## 三条铁律

1. **实体搬动必须同步账本**，否则 F1/F7。
2. **一层题材、一层素材类**，不许在题材下平铺散文件。
3. **账本里没有的实体不算入库**；账本里有但磁盘没有 = 悬空，F1。
