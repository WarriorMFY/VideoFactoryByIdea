# QC checklist · 散文影像

出片后逐条打勾。任何一条不过，就不进人闸门。

## A · 时长与容器

- [ ] 渲染器打印的总时长 = manifest 的 `total_s`（差 ≤0.05s）
- [ ] concat 后视频流时长校验通过（误差 ≤0.3s）
- [ ] 终合成后视频流时长校验通过（误差 ≤0.3s）
- [ ] 容器时长与视频流时长差 ≤0.3s（差太多 = 音轨被 apad 拉长）
- [ ] 1080p30 / yuv420p / AAC 160k / `+faststart` 在位

## B · 节奏（双峰是否成立）

- [ ] `shot_profile` 检出镜头数 = spec 镜头数 ±1（差太多 = 有镜头被判成静止）
- [ ] min ≤0.7s（快切簇存在）
- [ ] p90 ≥4s（长停簇存在）
- [ ] 中位数落在 3–8s 之间（不是全片极短或极长）
- [ ] 切点密度落在每分钟 8–16 个（低于 8 = 节奏没起来；高于 20 = 观感碎）

## C · 画面

- [ ] 抽帧 16 格，覆盖开场快切 / 卡 / 数据卡 / 图表 / 片尾
- [ ] 色温按叙事单调变化（不来回跳；末段有回升）
- [ ] 版式卡颜色与设计稿一致（没被调色推脏）
- [ ] 静帧推近处边缘不糊（原图不足 2000px 宽时会糊）
- [ ] 水印零残留（看每张照片底部与右下角）
- [ ] 花字不压卡片主数字，不压图表标题

## D · 字幕

- [ ] 每条旁白完整，末字没被切
- [ ] 字幕在底部安全区内，不超出左右 80px
- [ ] 花字与字幕不重叠（花字在中上，字幕在底部，正常不冲突；竖屏改版要重算）
- [ ] 标点与断句自然，没有单字成行

## E · 声音

- [ ] 人声段电平主导（约 -20dB 量级），静读卡 BGM 回升（约 -29dB 量级）
- [ ] 人声段与静读卡电平差 ≥6dB
- [ ] 快切段音效没有连成噪声（间隔 <0.7s 的切点密度高时要降音量或关）
- [ ] 章节首 impact 不盖住旁白第一字
- [ ] 全片无爆音、无削波（loudnorm TP=-1.5 应已兜住）
- [ ] 尾帧无突然断音（apad + afade 生效）

## F · 合规与文本

- [ ] 片尾卡有 AI 生成声明
- [ ] 数据有来源（机构 + 年份），且至少两处独立来源互相印证
- [ ] 没有出现外部视频画面
- [ ] 标题/简介不含夸大表述（"最/第一/唯一"需有据）

## G · 交付纪律

- [ ] 未上传、未发布
- [ ] manifest 与 spec 落在同目录，spec 路径写进 manifest
- [ ] 遗留问题写明（例：花字坐标固定导致的轻微重叠），不隐瞒
- [ ] 停在人闸门：等"能不能发 / 要不要量产"两个决定
