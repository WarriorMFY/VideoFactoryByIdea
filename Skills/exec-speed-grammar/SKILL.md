# 处决镜头速度语法剪辑（Exec Speed Grammar）

> 回链：[Skills 索引](../Skills.md) · [循环日志（来源）](../../History/CircleLog/log.md#loop42) · [实验现场](../../Prototype/loop42_speed_grammar/loop42_speed_grammar.md)
>
> 一句话：**同一段处决，改每个镜头的播放速率，让"这一刀有多重"被演出来——不是让整段变慢。**

## 一、边界（越界就停）

**只做一件事：改 `speed`（时间重映射）。** 画面内容、构图、时长结构全部由上游决定。

| 不做的事 | 归属 |
|---|---|
| 挑哪几个处决、首尾切在哪 | `exec-extract`（处决抽帧） |
| 音效 / 原声 / BGM / 混音 | 音频通道（`rebuild_audio.mjs`，或后续音频技能）。**本技能产出的成片无音轨是正常的** |
| 推近、裁窗、摇移、拖影、调色、字幕 | L2 镜头重加工（`recam` 的 `cam`/`blur`/`look`/`label`）。需要推近时，先由 L2 出重构图，本技能在其产物上只叠速率 |
| 转场、版式、节奏编排（多单位拼接顺序） | 剪辑编排 / `edit-craft-scouting` |
| 对外发布评审页 | `Tool/review/` |

**执行纪律**：配方里每镜 `cam` 一律 `{"type": "full"}`，不写 `blur`、不写 `label`。一旦要写这三样，说明越界了，停下来问人。

## 二、输入前提

1. 已切好的处决单位 MP4（1080p60 最佳，60fps 给慢放留了帧余量）。
2. **段内原生切点**（以该片段起点为 0 的秒数）——不知道就现测，别猜。
3. 每个镜头的**层角色**（见第三节）——这是唯一的配速依据。

## 三、层结构与层角色：配速只看"画面里发生了什么"

处决五层解剖（触发 → 前摇 → 命中 → 收招 → 余韵）在**剪辑层**收敛成四层：

| 层角色 | 画面判据（看内容，不看第几段） | 表达任务 | 速度档位 |
|---|---|---|---|
| `open` 起手 | 尚未接触：接近、对峙、交代空间与双方 | 铺陈，让观众看清位置 | 1.0x（C 档 1.2x） |
| `buildup` 蓄势 | 抓取 / 锁定 / 举刀 / 蓄力，**尚无命中特效** | 减速预告"重击将至" | 0.65x（A 档 1.0x） |
| `hit` 命中 | 命中特效 / 血雾 / 白闪 / 顿帧 / 受击反馈 | 升格压出重量 | 0.3x（A 0.5x / C 0.6x） |
| `tail` 余韵 | 站立收招 / 尸体落定 / 环境染色 / 即将切走 | 清理，把注意力还给下一刀 | 1.8x（A 1.5x / C 2.5x） |

**两条硬规矩**：

- **按角色映射，不按索引映射。** 快杀常常只有三层（没有 `buildup`），按"第 1/2/3/4 段"取速度会让尾层吃到 0.3x（loop42 实踩：B 合集虚长 3 秒）。
- **层边界 = 原生切点，不是动作节拍。** 速度窗口跨切点，升格会把切后的画面拉进切前的景别里。

## 四、三档取向（先选档，再填数）

| 档 | 取向 | 适用 | 逐层 speed |
|---|---|---|---|
| **A 克制** | 叙事向，只让命中减速 | 有台词/解说、要留呼吸的片子 | 1.0 / 1.0 / 0.5 / 1.5 |
| **B 重击** | 重量优先，四级递进 | 无音效或音效弱的集锦、单发立威 | 1.0 / 0.65 / 0.3 / 1.8 |
| **C 抽时** | 密度优先，整体压缩 | 长合集、混剪、节奏要快 | 1.2 / 1.0 / 0.6 / 2.5 |

经验值：`hit` 层 speed 必须**严格低于**同片其余所有层；A→B 的差别全在"命中与前一层的落差值"（1.0→0.5 vs 0.65→0.3）。

配方模板见 [`references/recipes.md`](references/recipes.md)。

## 五、流程

### 1. 测切点

用 `Tool/ops/exec_extract.mjs` 已有的取证能力，不要在 300px 缩略图上判切点：

```bash
# 带时间码的密集网格（先粗看结构，步长 0.15~0.25s）
node Tool/ops/exec_extract.mjs sheets <src> <outDir> --step 1 --grid 6x4
# 起疑的区间单独出条带（≥560px/帧，这是硬要求）
node Tool/ops/exec_extract.mjs strip <src> <t0> <t1> 6 --out probe/cut.png
```

判据：背景/景别/色调**突变**的那一帧。边界误差控制在 ±1 帧。

### 2. 标层角色

按第三节表格逐段命名，写成一行：`open 0–1.70 / buildup 1.70–2.52 / hit 2.52–2.80 / tail 2.80–3.65`。
缺层的写法：快杀三层的 `open 0–0.85 / hit 0.85–1.12 / tail 1.12–2.28`（**没有 buildup 就不写，不要硬塞**）。

### 3. 选档 → 4. 写配方

`hit` 层的 `t` 区间**只写到切点前 2 帧**（30fps: 0.067s / 60fps: 0.033s 以内收），这一段最容易出错。
镜头 `t` 必须**首尾相接**：`shot[i].t[1] === shot[i+1].t[0]`，不留空隙也不重叠。

### 5. 渲染

```bash
node Tool/ops/recam.mjs <src.mp4> <shots.json> <out.mp4>
```

`t` 是**段内时间**（`source.in` 记为 0），不是源片绝对时间。多单位批量：把配方模板循环生成后逐个渲染，再 concat 拼接（见 `references/recipes.md` 的批量段）。

### 6. 验收（四查，缺一不收工）

| 查 | 判据 | 怎么查 |
|---|---|---|
| 时长 | `out = Σ (t1−t0)/speed`，误差 ≤ 1 帧 | `ffprobe -show_entries format=duration` |
| 接缝 | `shot[i].t[1] == shot[i+1].t[0]` | 读配方自检 |
| 变速窗 | `hit` 层 `t1 ≤ 切点 − 2 帧` | 读配方自检 |
| 画面 | 12 帧网格里命中层内容与源一致，**无"切后画面进切前景别"** | 抽帧拼 `tile=4x3` 目验 |

`hit` 层速度最低这一条若被破坏，直接判不合格——那是本技能的核心不变量。

## 六、坑单

1. **缩图判切点**：300px 网格把近景内的挥刃误判成"切中景"两次。切点取证一律 ≥560px 单帧。
2. **层索引取速**：见第三节硬规矩第一条。
3. **升格窗越界**：镜尾多收 0.06s，把切点后 3 帧全景升格进特写框，出现"特写框里的全景"跳变；速度越慢错位放大越狠。
4. **整段统一慢放**：把 3.65s 拖成 7.30s，重量感被摊薄，"重击"这个概念直接消失。慢放必须稀缺。
5. **0.3x 已是常用下限**：再低（0.2x）帧重复肉眼可见；60fps 源可到 0.25x，30fps 源建议不低于 0.35x。
6. **段内时间 ≠ 源时间**：配方 `t` 从 `source.in` 起算，写错会整段偏移，且时长核算仍然"对得上"——最隐蔽的一类错。

## 七、已验证案例（loop42，2026-11-08）

| 单位 | 类型 | 段内切点 | 三层/四层 | 命中窗 |
|---|---|---|---|---|
| u01 | 标准 3.65s | 1.70 / 2.52 / 2.80 | open/buildup/hit/tail | 2.52–2.80 |
| u02 | 快杀 2.28s | 0.85 / 1.12 | open/hit/tail（缺 buildup） | 0.85–1.12 |
| u13 | 仪式级 5.81s | 0.40 / 2.70 / 3.22 | open/buildup/hit/tail | 2.70–3.22 |

- u01 单段 B 档：3.65s → 4.25s（升格膨胀被余韵加速抵消）；A 档 11.30s / B 档 13.82s / C 档 9.22s（三单位合集实测）
- 反例基线：整段 0.5x → 7.30s，判为不可用
- 证据链与全部配方：`Prototype/loop42_speed_grammar/`（`probe/` 取证、`Prototype/loop42_speed_grammar/sets/cfg/` 九份配方、`build_sets.mjs` 批量）

## 八、与上下游的接口

```
exec-extract（出单位 + 边界）
      ↓
[ 可选 ] L2 镜头重加工（需要推近/换景别时先出重构图）
      ↓
exec-speed-grammar（本技能：只改 speed）
      ↓
音频通道（rebuild_audio.mjs 套原声 / BGM）· Tool/review（评审页）
```

上游交付本技能时只需给三样：**片段文件、段内切点、层角色**。上游没给，就用第五节第 1 步自己测，不要用"看起来像"来估。
