# 剪辑技术侦察 · 执行清单

一轮完整流程的逐项勾选。任一项打不出勾，说明这轮只完成了"看"，没完成"学"。

## A. 选种（S1）

- [ ] **覆盖 ≥3 个内容域**，每域 1 头部 + 1 腰部（同赛道不作为范围依据）
- [ ] 检索词 ≥6 组，每组对应一个不同内容域，不是同一域换说法
- [ ] 样本 6–8 条，含 1 条反例（零剪辑）
- [ ] 每条样本过三判据：剪辑承载信息 / 技术可拆解 / **技术可迁移**（写明移植到哪条产线、替换掉现在哪个做法）
- [ ] 已剔除"靠嘉宾、靠素材、靠预算"的不可复制样本，或明确标注前提
- [ ] 记录每个样本的 BV 号、播放、时长、UP 主、所属内容域
- [ ] 样本手法已按**技术类别**聚类（卡点/变速/转场/字幕层/音效/分屏/动效…），不是按分区聚类

## B. 拆解（S2）

- [ ] 每条样本跑量化：ASL、切点密度、短镜头占比、min/p10/中位/p90
- [ ] 抽帧 8 格覆盖：首帧 / 金句卡 / 转场 / 信息最密帧 / 片尾卡
- [ ] **完整看过连续 30 秒**（不是只看抽帧）
- [ ] 记录字幕样式（位置/双语/描边/高亮）与大字卡停留秒数
- [ ] 记录音效密度与 BGM 有无（切点是否配音效）
- [ ] 每条样本写出 3 条可操作手法 + 1 条不可复制前提
- [ ] 手法写成**可执行编辑操作**（切点位置/字号/时长/曲线），不是形容词
- [ ] 同一手法在不同域的**变形**已并列记录（大字卡=情绪锚点/信息结论/击杀确认…）
- [ ] 所有数据落 `History/loops/loopNN/`，命令可复现

## C. 假设（S3）

- [ ] 写成"如果…那么…用…判定，阈值…"
- [ ] 写明否定条件（什么结果算我错）
- [ ] 写明成本上界（时间/算力/渲染次数）
- [ ] 本轮变量数 ≤3

## D. 实验（S4）

- [ ] 同源对照：同一素材、同一 spec，只改一个变量
- [ ] Demo 可播放，30–60s 或一条完整摘要
- [ ] TTS / 切片 / 素材缓存已复用（未重复等待）
- [ ] 实验目录独立，可单独重跑

## E. 判卷（S5）

- [ ] 客观指标对照表（改前 / 改后 / 阈值 / 命中与否）
- [ ] 目验记录（抽帧 + 完整播放各一次）
- [ ] 结论落到"支持 / 反驳 / 不确定"三档之一
- [ ] 人为主观判定已征询，未用 Agent 自评代替
- [ ] 反驳结论已进坑位清单（不是删掉了事）

## F. 工具化与交付（S6/S7）

- [ ] 新工具满足：可重复 / 参数化 / 失败可诊断
- [ ] 新脚本落轮次目录，**未擅自升格**进 `Tool/`
- [ ] 交付含三块：看到了什么 / 学到了什么 / 值不值得留
- [ ] 附量化数字、抽帧路径、复现命令
- [ ] 明确声明：未发布、未归档、未提炼 Skill
- [ ] 停在人闸门，等人裁决两项决策（工具归档 / Skill 提炼）

## G. 视野自检（最容易漏）

- [ ] 结论里至少 1 条手法属于"我们从未用过的技术类别"（不是字幕、不是节奏快慢）
- [ ] 若结论全部落在"字幕/节奏"层面 → 判定**覆盖域不足**，回去补样本，不许当成本轮学完了
- [ ] 已记录每域"我们学不来的部分"（素材/预算/版权/嘉宾），避免把资源差距当技术差距
