# 师夷长技：剪辑技术侦察与自研

工作站的目标只有一个：**剪辑技术侧的成长与迭代**。
这条技能是它的主干管道——不是"去B站抄手法"，而是"把别人的手法变成我们能验证、能复用、能出工具的技术资产"。

四段流水线，一个人闸门：

```text
S1 选种 → S2 拆解 → S3 假设 → S4 最小实验 → S5 判卷 → S6 工具化 → S7 交付
                                                              ↓
                                              【人闸门】归档进 Tool/ ？提炼为 Skill ？
```

**没有判卷数据的手法，不许进工具链；没有工具的手感，不许进结论。**

## 什么时候用

- 用户说「去B站学学别人怎么剪」「扒一下剪辑手法」「师夷长技」「对标优秀视频」
- 自家成片被判定"节奏不对/不好看"，需要外部参照系定位差距
- 想验证一个剪辑假设（如"关键词停留 2s 比 1s 好"）并落成工具
- 每条新视频形态线立项前（竖屏切片、讲义页、混剪）的技术侦察

**不适用**：纯选题调研（那是市场侦查，不产出技术）；纯素材搬运（无自研环节）。

## 视野纪律（第一原则，先于一切判据）

**剪辑是通用技术，不是赛道属性。** 卡点、变速斜坡、遮罩转场、动效字幕、分屏对比、J-cut 声音先行——这些语法在任何内容域都成立，只是被不同赛道的创作者各自发展出了极致版本。

所以：

1. **禁止以"同赛道"作为选种范围。** 同赛道只提供一个用途：知道观众此刻在为什么买单。它不告诉你技术上限在哪。
2. **每轮必须跨 ≥3 个内容域**，优先选该域**技术密度最高**的样本，而不是该域播放量最高的样本。
3. 学的是**手法**，不是**内容**。看到"知识区都在慢讲"，正确结论不是"我们也该慢"，而是"他们用什么结构把长内容留住了人"。
4. 同一手法在不同赛道的**变形**要记下来（如"大字卡"在混剪=情绪锚点、在测评=信息结论、在游戏=击杀确认），变形清单本身就是技术资产。

**反面教材（实盘）**：loop19/21 两轮都把范围锁在演讲/TED 赛道，结论收敛到"字幕工程 + 金句卡"两条，而全站真正领先的技术（速度斜坡、遮罩转场、动效图表、音画错位、分屏论证）一条都没进视野。这不是样本不够，是视野被自己锁死了。

## S1 · 选种：什么样的视频值得拆

先定判据，再检索，避免被播放量牵着走。

### 三条入选判据（缺一不选）

| 判据 | 含义 | 怎么验 |
| --- | --- | --- |
| **剪辑承载信息** | 删掉剪辑，信息/情绪会明显受损（讲义页、金句卡、卡点、插入素材） | 快进静音看一遍：还能看懂吗？能 → 剪辑不是主技术 |
| **技术可拆解** | 手法能被量化或目验复现，不是纯个人表演/演讲能力 | 能否写出"它做了什么操作"的句子 |
| **技术可迁移** | 该手法能**脱离原内容域**装到我们产线上（说清"移植到哪条产线、替换掉我们现在哪个做法"） | 能否写出"我们第 X 步改成它这样" |

> 第三条曾写作"有对照价值（同赛道/同受众/同素材）"，这是错的：它把"内容相似"混同于"技术可用"，直接导致视野自我锁死。**同赛道不是加分项，反而要警惕**——同赛道样本最容易只学到内容套路。

### 内容域 × 技术特长速查（选种时的地图，不是穷举）

每轮从中挑 ≥3 个域，优先挑我们**最不熟悉**的域：

| 内容域 | 该域被练到极致的技术 | 常见可迁移项 |
| --- | --- | --- |
| 影视解说 / 混剪 | 叙事结构、悬念钩子、资料片与解说对位 | 章节钩子、画面-旁白对位、留白 |
| 游戏高能 / 集锦 | 节拍卡点、击杀确认音效、瞬时变速、HUD 处理 | 卡点切、音效包、speed ramp |
| 科技 / 纪录（影视飓风类） | 信息图表动效、数据可视化、微距与高速摄影、B-roll 编排 | 动效图表、数据卡、素材分层 |
| 综艺二创 / 鬼畜 | 音画错位、重复强调、花字贴纸、反应镜头 | 花字包、重复强调、反差剪辑 |
| AMV / 静止系 MAD | 色彩匹配剪辑、遮罩转场、逐帧节拍对齐 | 遮罩转场、match cut、节拍网格 |
| 运动 / 极限 | 速度斜坡、第一人称沉浸、环境音设计、多机位同步 | speed ramp、音效分层 |
| 美食 / 治愈 Vlog | 慢节奏留白、ASMR 声设计、自然光调色、match cut | 声设计、留白节奏、调色 LUT |
| 数码测评 | 结论前置、分屏对比、放大特写、快速信息卡 | 分屏论证、信息卡、特写插入 |
| 知识科普 / 动画 | 动态图形解释、隐喻可视化、逐帧手绘 | 动效图解、隐喻镜头 |
| MV / 音乐可视化 | 卡点、L-cut / J-cut、歌词动效 | 声音先行、歌词动效 |

### 样本配比（每轮 6–8 条）

- **跨 ≥3 个内容域**，每域 1–2 条（这是硬约束，不是建议）
- 每个域内：**1 条头部**（该域播放前 10%，代表平台偏好）+ **1 条腰部**（5–50 万，代表可复制的技术档位）
- **1 条反例**（零剪辑/纯口播）：证明"剪辑到底带来了什么"
- 若某域只能找到"内容强、剪辑弱"的样本，**整域换掉**，不要凑数

### 可信度纪律（硬性）

1. 官方文档 > 一手创作者自述 > 从业者经验帖 > 营销号。营销号的精确数字一律不采信。
2. **播放量 ≠ 技术优劣**。实盘教训：B站 TED 赛道 541 万播放的冠军是零剪辑+双语字幕，超快剪的只有 12 万。播放量只能用来定"平台偏好区间"，不能用来给技术打分。
3. 评论区只取"观众抱怨/夸赞的具体点"，不取情绪总量——它反映内容，不反映剪辑。

## S2 · 拆解：把"好看"翻译成数字与帧

每个观察都必须落成**可复现命令 + 数据文件**，否则不算拆解，只算观后感。

### 量化维度（能算的必须算）

| 维度 | 指标 | 读法 |
| --- | --- | --- |
| 节奏 | ASL（平均镜头长）、切点密度、短镜头占比 | 先看分布再看均值 |
| 结构 | 切点是否对齐语义单元（章节/金句/转折） | 抽 5 个切点前后各 2s 目验 |
| 视觉 | 明度/对比/色彩（黑白或暗调占比）、字幕位置与字号 | 抽帧拼图对比 |
| 信息 | 关键词/大字卡停留时长、同时屏上信息量 | 逐帧数"停留秒数" |
| 声音 | 音效密度（切点是否配 whoosh/impact）、BGM 有无 | 听 + 看波形峰值 |

### 目验最小集（每样本 8 格抽帧）

必须覆盖：**首帧（钩子）、金句/大字卡帧、转场瞬间、信息最密帧、片尾卡**。
抽帧只是取样，**判定前必须打开成片看完整 30 秒**——静帧会骗人，节奏骗不了眼睛。

### 拆解产物

一条样本一张卡片：`流派一句话 | 量化表 | 抽帧图路径 | 3 条可操作手法 | 1 条不可复制的前提`。

手法必须写成**可执行的编辑操作**，不是形容词：

- ❌「节奏很快」 → ✅「切点落在鼓点，平均 1.2s 一刀，攻击动作起手帧前 3 帧切」
- ❌「字幕很酷」 → ✅「关键词独立成层，字号 120pt，弹出用 scale 55→100 / 150ms，停留 2.5s，硬出不淡出」

最后一条最重要：**哪些是因为他有素材/有嘉宾/有预算/有版权库，我们学不来的。**

## S3 · 假设：把观察变成能被打死的句子

写法固定，三要素缺一不可：

> **如果**（改一个变量）**那么**（预期变化），**用**（指标）**判定，阈值**（数字）。

示例：如果关键词弹出停留从 1s 拉到 2.5s，那么完播率与章节留存上升，用 3s 跳出率判定，阈值 ≤ 现在 -10%。

规矩：

- 一轮只验 **1–3 条**变量，多了就分不清是谁的功劳
- 必须写**否定条件**（什么结果算我错）
- 必须写**成本上界**（这实验最多花多久/多少钱），超了直接放弃

## S4 · 最小实验：同源单变量

- **同源对照**：同一素材、同一 spec，只改被验变量。跨素材对比等于没对照。
- **规模**：Demo 片段 30–60s，或一条完整摘要；不重跑全系列。
- **复用**：TTS、切片、素材缓存一律复用，避免把等待时间当成实验成本。
- **一次一改**：改两个变量就重开一轮。

## S5 · 判卷：三档结论，不许自评

| 结论 | 条件 | 处理 |
| --- | --- | --- |
| 支持 | 客观指标达标 + 目验无异常 | 进 S6 工具化 |
| 反驳 | 指标反向或持平 | 写进坑位清单，**同样有价值** |
| 不确定 | 指标打架/样本不足 | 不许写成成功；标注"需再验"并说明缺什么 |

**人的主观判定不可省略**：成片好不好看最终由人裁决，Agent 只提供数字与差异点。自评"效果很好"属于红线。

## S6 · 工具化：什么才配进工具链

三条判据，缺一不升格：

1. **可重复**：换素材、换机器、换人跑，结果一致
2. **参数化**：变量是参数，不是硬编码；默认值有依据
3. **失败可诊断**：出错能定位到具体环节，不静默

落位规矩：

- 新脚本**先落当轮目录**（History/loops/loop<编号>/ 或 Prototype/loop<编号>_*/），跑通两轮以上再谈升格
- 升格进 `Tool/ops/` 必须由**人批准**
- 每次升格同步写 `Tool/ops/ops.md` 的工具表与坑位清单——坑不写下来就等于没踩过

## S7 · 交付：给人裁决的材料包

交付只说三件事，别写成长篇总结：

| 材料 | 内容 |
| --- | --- |
| **看到了什么** | 流派表（含量化数字）+ 抽帧证据路径 |
| **学到了什么** | 假设 → 实验结果 → 支持/反驳，含否定条件 |
| **值不值得留** | 工具清单（新/改/待升格）+ 建议归档项 + 风险 |

同时必须声明：**未发布、未归档、未提炼 Skill**——这三件事都不由 Agent 决定。

## 人闸门（两个决策，Agent 只提材料）

| 决策 | 人的选择 | 后续 |
| --- | --- | --- |
| ① 工具是否归档 | 升 `Tool/ops/` / 留在轮次目录 / 丢弃 | 升格则补 ops.md 工具表 + 坑位 |
| ② 是否提炼为 Skill | 是（写方法论、路径引用工具）/ 否 | 是则按 `Skills/capability-packaging/SKILL.md` 的范式落盘 |

Agent 的默认动作是**停在这里等人**，不替人做"这条经验值得沉淀"的判断。

## 红线

1. **版权**：外部视频只下载公开低清流用于技术研究，不二次分发、不进入交付物；成片里不出现对方素材。
2. **只读公开接口**：不绕登录、不抓私域数据、不做批量爬取。
3. **不伪造指标**：跑不出数据就写"不确定"，不许用形容词代替数字。
4. **不越权发布**：技术验证产物一律不发布，发布由人决定。
5. **不把平台偏好当技术真理**：播放量分布只说明平台口味，不说明手法优劣。

## 坑位（实盘踩过，会静默失败）

1. **只看均值不看分布**：ASL 7s 可能是"1 个长镜头 + 90 个 0.2s 闪切"。必须看 min/p10/中位/p90。
2. **静帧骗人**：抽帧全对，播放起来节奏垮。判定前必须看连续 30 秒。
3. **播放量当技术分**：541 万冠军零剪辑（实盘），若按播放量反推"应该更慢"会得出反向结论。
4. **跨素材对照**：换了素材就同时换了变量，结论不可信。同源单变量。
5. **静默截断**：视频流只剩一半而容器时长正常（音频撑住）——校验必须查**视频流时长**，不是容器时长。
6. **丢了 `-y` 的假象**：ffmpeg 遇已存在输出会询问后退出，脚本却拿旧文件做校验，得出"修了没用"的错误结论。
7. **剪辑阈值想当然**：镜头切分阈值 0.15 对多机位演讲精度约 92%，对高运动素材会过切；换素材类型要重新抽 10 个切点人工核对。
8. **把"火"的评论区当需求**：混剪区是打卡文化（立 flag），学习区是内容讨论，两套反馈不可混用。
9. **视野自我锁死（最贵的坑）**：连续两轮只拆同赛道，会把"该赛道的共同做法"误当成"剪辑技术的上限"。实盘：loop19/21 只拆演讲赛道，两轮结论都收敛到"字幕 + 金句卡"，而速度斜坡、遮罩转场、动效图表、音画错位等技术一条没进视野。**判据：一轮结束后若结论全是"字幕/节奏"层面，说明覆盖域不够，而不是学完了。**
10. **内容域 ≠ 技术类型**：同域两条样本可能技术完全不同（如同为游戏区：集锦靠卡点、攻略靠图解）。域只是检索入口，选种按**手法**聚类，不按分区聚类。

## 完成判据

逐条打勾才算交付，细则见 [`references/checklist.md`](references/checklist.md)：

1. 样本 6–8 条，**跨 ≥3 个内容域**，每域 1 头部 1 腰部，另含 1 条反例，每条过三判据
2. 每样本有量化表 + 抽帧图 + 可复现命令，手法写成可执行操作
3. 假设写成"如果/那么/用/阈值"，含否定条件与成本上界
4. 实验同源单变量，Demo 可播放
5. 结论三档明确，无"感觉更好"式表述
6. 工具满足可重复/参数化/失败可诊断，落位在轮次目录
7. 交付含"看到了什么/学到了什么/值不值得留"三块 + 未发布声明
8. 停在人闸门前，未自行归档、未自行建 Skill
9. **跨域覆盖自检**：结论里至少有一条手法来自"我们从未用过的技术类别"（不是字幕、不是节奏快慢这类老结论）
