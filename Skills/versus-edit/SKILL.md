# 对比剪辑流（Versus Edit）方法论

从 loop35「中式武术美学 VS 西方暴力美学」完整沉淀。核心观点：**对比剪辑不解释，只对位**——观众自己从画面对位中读出差异。

## 一、核心原则

1. **语义对位优先于素材堆砌**：每组左右画面必须共享一个「叙事时刻」（同为处决高潮/同为杀后反应/同为收尾），差异才可读。对位维度清单：
   - 色彩（泼染 vs 糊屏）、爆发方式（腾空带染 vs 落地砸击）
   - 杀后行为（收势留白 vs 仰天怒吼）——价值观差异最强的一组
   - 节奏（长镜 vs 碎切）、终结方式（利落 vs 满溢）
2. **真差异要先量化验证**：动手前先确认差异立得住（运动强度剖面、色偏 U/V 统计、切点率）。血多血少不一定是真差异；「把杀拍成术还是果」才是。
3. **克制**：无旁白、硬切、每侧只放一个语义词大字 + 片名小字。BGM 一条到底尾部淡出。

## 二、三阶段协作流程（loop36 定版，**默认走此流程**）

**阶段 1 · 候选池**：扫库选 10–12 组候选（覆盖不同语义维度），用 `Tool/ops/vs_curate.mjs` 批量渲染每组小片（960×540 左右分屏预览，含组号/语义角标）并生成 `table.html` + `table.csv`，交用户核验。配置格式同 vs_split，多了 `dim`（维度）、`status`、`note`（卖点说明）、`risk`（UI/水印风险）字段。
```
node Tool/ops/vs_curate.mjs <candidates.json> [outDir]
# 产出 out/grp_NN.mp4 × N + table.html + table.csv
```
**阶段 2 · 用户核验**：等用户反馈「保留哪些组 / 换段时间 / 调 cropX」。不要跳过此阶段自行定稿。
**阶段 3 · 合成**：把核验通过的组写进 vs_split 配置（含片头卡/片尾/BGM），`node Tool/ops/vs_split.mjs <config.json>` 出正式版，QC 抽帧后交付。

## 二点五、处决单位边界规则（loop37 定版）

对比「处决/终结技」时，**必须截完整处决单位**，不能只截高潮：

- **五层解剖**：触发（R3/E 提示出现）→ 前摇（抓取/锁定/踉跄）→ 命中（顿帧/慢放/血雾）→ 收招（惯性跟随/喘息）→ 余韵（尸体落定/环境染色/角色站定）。
- **开始帧 = min(抓取/锁定发生, 处决提示出现)**，不是出手帧。影零常以踉跄/电光缠身进入演出态；战神以 R3 圆圈出现为标志。
- **结束帧 = min(角色回待机, 尸体物理落定, 镜头切走)**，再多留 0.3–0.5s 余韵。宁多勿悬（悬空尸块帧=完整性差）。
- **处决内部切机位 ≠ 单位边界**，切点必须包含在段内。
- 实战单位长度：快杀 2.5–3s / 标准 4.5–5.5s / 仪式级大招 8–11s。
- 工具：`Tool/ops/exec_bound.mjs`（tblend difference YDIF 运动曲线提议边界 + 取证条带）；
  边界提议只做候选，**首尾帧必须人工目验**（曲线分不清"处决结束"和"下一个敌人走近"）。
- 完整报告：Prototype/loop37_exec_bound/loop37_exec_bound.md。

## 三、单人道快速流程（用户明确要最快出样片时）

1. **取材**：`node Tool/ops/dl_bili_hd.mjs <BV号> <输出> 80`（1080p，流式+备用源回退）
2. **扫库**：每 5s 一帧带时间戳网格（`fps=1/5,tile=6x6` + drawtext 秒数标签），目读全片结构
3. **验窗**：候选窗口出 1x3 条带（每 1.5s 一帧）验证连续性、主体水平位置（决定 cropX）、水印/UI 遮挡
4. **定组**：4–6 组、每组 3–4s；两侧起点错开躲开提示框/转场；相邻组可让单侧连续（劈杀→怒吼）形成节奏
5. **出片**：`node Tool/ops/vs_split.mjs <config.json> [out.mp4]`
6. **QC**：片头 1.0s / 每组中段 / 片尾各抽一帧，核对标注颜色、分隔线、主体入画、水印遮挡

## 四、工具 vs_split.mjs 配置要点

```json
{
  "layout": "lr",                          // lr 左右 | tb 上下
  "sides": { "a": {"src": "...", "pack": "片名", "color": "FFC850"},
             "b": {"src": "...", "pack": "片名", "color": "FF6B5A"} },
  "head": { "dur": 2, "aTitle": "...", "aSub": "...", "bTitle": "...", "bSub": "...", "foot": "..." },
  "pairs": [ { "a": {"t": 59.4, "cropX": 540}, "b": {"t": 55.2, "cropX": 480},
               "tag": {"a": "泼染", "b": "糊屏"}, "dur": 3.2 } ],
  "tail": { "a": {"t": 170.8, "cropX": 480}, "dur": 2.2 },   // b 缺省 = 纯黑屏
  "bgm":  { "src": "...", "start": 0, "fadeOut": 1.5 }
}
```

- `cropX`（左右版）指定竖裁窗口左边界，主体不居中时用它；不填则居中裁
- `layout: "tb"` 自动改上下版（每侧 1920×540）
- `tail.b` 给 `{src, t}` 可做双侧片尾对位；不给则右侧黑屏
- 颜色填 **RGB** 十六进制（工具内部自动转 ASS 的 BGR）
- 源片比例不同会自动按目标半幅比例做最大内接裁切再 scale

## 五、版式选择

- **左右（lr）**：每侧 960×1080 竖裁 ≈ 半幅特写，冲击力强、色彩满——适合单组特写与终版
- **上下（tb）**：每侧 1920×540 保完整 16:9，信息全——适合展示全身动作与草稿评审
- 同一项目可先上下版审选段、定稿换左右版

## 六、坑位（实踩，详见 Tool/ops/ops.md 坑 32–36）

- 中文字幕一律每段独立 ASS（cwd=构建目录相对路径），drawtext/execSync 中文必坏
- 逐段独立渲染 crf16 中间件 → concat demuxer，禁 filter_complex 混拼多段时间轴
- ASS 颜色是 `&HBBGGRR&` 顺序，RGB 直填会变色（琥珀 FFC850 → 须写 50C8FF）
- 无限 lavfi 源（color=black）配 `-shortest` 不终止 ffmpeg，输出必须加 `-t`
- 源片 UI（BOSS 名横幅、挑战提示框）会在 crop 特写里放大成主体遮挡——选窗时用条带图逐帧排查，起点错开 1–2s 常可绕开
- 搬运源片带水印（如 Gamespot/SPOILERS）：取镜避让其常驻位置
