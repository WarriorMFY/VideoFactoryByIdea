# 处决单位无缝衔接（Exec Seam Stitch）

> 回链：[Skills 索引](../Skills.md) · [循环日志（来源）](../../History/CircleLog/log.md#loop43) · [实验现场](../../Prototype/loop43_skill_verify_bgm/loop43_skill_verify_bgm.md)
>
> 一句话：**衔接质量是选序问题，不是渲染问题——排对了顺序，硬切就是无缝的。**

## 一、边界（越界就停）

**只做两件事：选序（决定排列顺序）+ 接缝验收（逐缝取证）。** 不碰每个单位内部。

| 不做的事 | 归属 |
|---|---|
| 从原片提取处决单位、定首尾边界 | `exec-extract` |
| 单位内部的速率调整（open/buildup/hit/tail） | `exec-speed-grammar` |
| 音效 / 原声 / BGM / 混音 | 音频通道 |
| 推近、调色、字幕等画面加工 | L2 镜头重加工 |
| 对外发布评审页 | `Tool/review/` |

**执行纪律**：拼接一律 `concat -c copy` 硬切，不加过渡特效、不做调色匹配、不改速率。想要"用叠化遮住接缝"，说明选序失败了——回去重排，而不是加特效掩盖。

## 二、核心规则：无缝三条件（缺一则跳）

一条接缝无缝，需要同时满足（2026-11-08 帧级取证确立，样本持续扩充中）：

1. **姿态相容**：前单位尾帧的人物姿态 ≈ 后单位首帧的人物姿态。最优对：背对↔背对、动作归位站立↔起手未发力。人物剪影连贯，读作"同一个人走入下一场"。
2. **色调明度相近**：两帧同色系、明度差小（暗绿↔暗绿 ✓；暖橙↔灰绿 ✗）。
3. **余温切入**：切点落在前单位余韵特效（血雾/光尘）未散尽时，情绪动量延续；前单位 tail 加速已把收招压到最短，归位即走。

**速度底座免费复用**：前单位 tail 1.8x + 后单位 open 1.0x 由 `exec-speed-grammar` 的常规配速自动提供，本技能不另调速率。已证明速度曲线相同而姿态/色调不匹配的接缝仍是跳切——速度是必要非充分条件。

## 三、接缝分级

| 级 | 判据 | 处置 |
|---|---|---|
| **无缝级** | 三条件全满足 | 默认目标 |
| **弱匹配级** | 姿态或色调有一项近似但不完美 | 可用；合集内少量存在可接受 |
| **转场级** | 色调明度断裂（跨色系）或姿态完全断裂 | 只能当有意转场用；发布合集需显式标注，不许混充无缝 |

## 四、流程

### 1. 建尾手卡库（选序的唯一证据）

对全部候选单位抽首帧 + 尾帧，拼带编号网格目验：

```bash
# 首帧 + 尾帧各一张（480px 候选级；定序后接缝取证仍须 ≥560px 单帧）
ffmpeg -i u05.mp4 -frames:v 1 -vf scale=480:-1 lib/u05_open.png
ffmpeg -sseof -0.05 -i u05.mp4 -frames:v 1 -vf scale=480:-1 lib/u05_tail.png
```

**硬规矩：选序只认帧画面。** catalog/元数据的 scene 字段只能粗筛分组——仪式级单位的尾帧可能落在完全不同的场景里（loop43 实踩：u17 catalog 写"崖瀑"，尾帧实际是暖橙木台收尾，元数据直接导致一条跳缝）。

### 2. 按三条件排链

分组（色系）→ 组内按尾手姿态矩阵排链 → 逐缝写下预测（无缝级/弱匹配级/转场级）。预测写在拼接之前，拼完对答案。

### 3. 拼接

```bash
printf "file 'out_%s_B.mp4'\n" u05 u30 u11 u17 u39 > concat.txt
ffmpeg -f concat -safe 0 -i concat.txt -c copy compile.mp4
```

前提：各单位成片编码参数一致（同源 recam 产出即满足）。

### 4. 验收（逐缝取证，缺一不收工）

每条接缝前后 ±2 帧抽出纵向堆叠，对照第二步的预测：

```bash
# 接缝时刻 ±2 帧（60fps 步长 1/60s），≥560px
ffmpeg -ss <接缝时刻> -i compile.mp4 -frames:v 1 -vf scale=720:-1 seam_t.png
```

预测与实测不符的接缝：要么改选序重拼，要么降级标注。**合集整体核算 0.3x 输出占比 ≤35%**（超标的快杀单位走合集稀释，见速度语法技能坑单）。

## 五、坑单

1. **元数据替代帧目验**：catalog scene 是提取点场景，不是尾帧场景。仪式级/多段处决几乎必然"尾帧离题"。选序前先看尾手卡。
2. **首帧印象当尾帧判断**：看单位看多了会记住"开头什么样"，尾帧必须单独取证——u17 案例中错误正是从首帧印象来的。
3. **景别差**：姿态色调都配但远景↔近景相接仍会有轻微跳感（u30→u11 实测可接受），列弱匹配级，不追求消除。
4. **特效色当场景色**：u17 尾帧的"暗蓝雪雾"是环境，中间段的"紫电"是特效色——以切点那一帧的实际色调为准。
5. **无音轨拼接**：速度语法产出的单位成片无音轨是常态，BGM 时间轴规格（hits/拼缝）由音频通道消费本技能的接缝时刻表。

## 六、已验证案例（loop43，2026-11-08）

合集 `Prototype/loop43_skill_verify_bgm/seam_match_v2_compile.mp4`（28.97s，u05→u30→u11→u17→u39，全部 B 档单镜/双波峰单位）：

| 接缝 | 尾帧 → 首帧 | 预测 | 实测 |
|---|---|---|---|
| u05→u17（v1 首验） | 背对站立绿光 → 背对站立紫电，暗绿↔暗绿 | 无缝级 | **无缝**（用户复核发现） |
| u30→u11 | 远景背对站立 → 中景背对起手，灰白↔灰绿 | 弱匹配级 | 顺（景别差轻微跳感） |
| u11→u17 | 背对血雾灰白 → 背对紫电暗绿 | 弱匹配级 | 良好（明度差轻微） |
| u17→u39 | 兽尸收尾暖橙 → 挥剑起手红叶 | 弱匹配级 | 顺（暖系相接） |
| u17→u11（v1 反例） | 暖橙木台 → 灰绿山道 | （失误排序） | **跳切**——速度曲线与其它缝完全相同，纯色调断裂所致，反证速度必要非充分 |

证据链：`Prototype/loop43_skill_verify_bgm/probe/` 下 `seam_lib/`（46 单位尾手卡 + 网格）、`seam_8617|seam_2633/`（首发接缝对照）、`seam_exp/`、`seam_v2/`（逐缝 ±2 帧堆叠）。

## 七、与上下游的接口

```
exec-extract（出单位）
      ↓
exec-speed-grammar（逐单位配速，产出无音轨成片）
      ↓
exec-seam-stitch（本技能：尾手卡 → 选序 → 硬切拼接 → 逐缝验收）
      ↓
音频通道（原声/BGM，消费接缝时刻表）· Tool/review（评审页）
```

上游交付本技能只需给：**各单位成片文件**。尾手卡库本技能自建；接缝时刻表（每缝的累计时长）随验收一并产出，供 BGM 卡点消费。
