## 七、已知偏差

| 项 | 说明 |
| --- | --- |
| 输出尺寸二选一 | 同一 app 内并存两套「1k」像素预算：1.042 MP → 880×1184；1.573 MP → 1086×1448。提交参数恒定时由服务端按请求分派，脚本侧无法指定（实证见 `Log/Circle8/Circle.md` 15:02–15:22） |
| 上庭偏短 | 1.0 MP 通道在发际线上方保留头发，可见上庭被压缩，三庭偏 19:29:27 |
| 宽方通道 | 1.5 MP 通道脸型转宽方（1.33）、脸宽 97%、额顶被切，与「长方脸」行偏离 |
| 无 seed 节点 | 同卡异图无法逐像素复现，约 80% 一致性即当前上限 |
| 判定口径 | 90% 为整体相似度判定，非逐条全等；上表两处「部分」已计入并通过 |
