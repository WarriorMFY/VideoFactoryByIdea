## 七、已知偏差

| 项 | 说明 |
| --- | --- |
| 输出尺寸二选一 | 同一 app 并存两套「1k」像素预算：1.042 MP → 880×1184；1.573 MP → 1086×1448。提交参数恒定，服务端按请求分派，无法指定 |
| 发际线条款不可兼得 | 1.0 MP 通道保留头发（上缘在发际线上方），1.5 MP 通道切掉额顶（无可见发际线）；当前通道下「上缘正好落在发际线上」只能部分兑现 |
| 颈部条款随通道翻转 | 1.0 MP 通道出颈，1.5 MP 通道不出颈；与发际线项互斥，故 `画幅`／`遮挡` 两行判为「部分」 |
| 无 seed 节点 | 同卡异图不能逐像素复现，约 80% 一致性为上限 |
