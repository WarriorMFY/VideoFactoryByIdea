# 盾击处决·咽喉刺（三帧一气呵成版）
## 关键帧列表
| 关键帧（自变量：帧号/阶段/进度） | 动作状态（因变量：可观测动作描述） |
|---|---|
| K0 / 持盾前冲 / 0% | 角色=主体A的左脚在前、主体A的身体前倾，主体A的左手持盾前置，主体A的右手持单手剑收于体侧；武器/接触=主体A的盾面朝前，主体A的剑未出；目标=主体B正面站立、主体B的上身正直；位移=主体A的冲步启动，主体A的重心连续前压；同步=主体A的盾面朝向主体B的胸肩，主体A的前冲方向锁定主体B的中线 |
| K1 / 盾撞换架一击刺喉 / 50% | 角色=主体A的前冲贯穿全程：主体A的盾面撞上主体B的胸肩的同一拍，主体A的躯干顺势扭腰换架，**主体A的左肩向后回撤**（带动左盾手转为后手），**主体A的右肩向前送出**（带动右剑手由体侧直接前刺）；武器/接触=主体A的盾面触主体B的胸肩即借力后收，不独立停顿，主体A的单手剑紧随盾撞与右肩前送的同一动力链一击前刺，主体A的剑尖贯入主体B的咽喉；目标=主体B的胸肩受撞即后仰失衡、主体B的咽喉暴露，主体B在剑尖到达的同一拍被刺中并瞬间失去行动；位移=主体A的前冲步贯穿撞击、换架、刺喉，主体A的重心连续前移，不回收、不落定；同步=主体A的盾面触主体B胸肩的瞬间，主体A的左肩后撤与右肩前送同步；主体A的剑尖在主体B后仰暴露咽喉的同一拍对齐主体B的咽喉 |
| K2 / 拔剑收招回正 / 100% | 角色=主体A沿刺入反方向拔剑，主体A的盾牌回前，主体A的身体收正恢复正面站姿；武器/接触=主体A的剑从主体B的咽喉抽出并收至主体A的体侧，主体A的盾回到主体A的前手防御位；目标=主体B的咽喉受刺后仰倒地，彻底失去行动能力；位移=主体A拔剑同时顺势后退半步回正，无多余停顿；同步=主体A的拔剑方向与刺入方向相反，主体A的根节点回正至起始朝向 |
