# 造型卡 · 全身站姿（含服装与机位）

> 本卡是**造型卡**，不是肖像卡。肖像卡（`portraits/`）只写脸——骨相、比例、五官、肤质，脸以外一条不写；造型卡把一个人「怎么呈现」的部分整体承载下来，**服装、体态、构图、机位、动作都在卡内**，这些本来就属于造型，不该被切成半张卡。
> 长相仍交给 `01-pass-still-880x1184.png`，卡面只写能落到数字与几何上的东西。凡是「肤白、貌美、大长腿」这类形容词一律不写——它们在本轮之前的四组对照里从未被执行过。

| 项 | 取值 |
| --- | --- |
| 人物基线 | 22 岁东亚女性，气质安静内敛，站姿自然松弛；全身出镜 |
| 脸与五官 | 鹅蛋脸；杏眼、眼裂中等偏长；鼻梁细直、鼻头小巧；唇形饱满、唇色淡；眉形平缓自然；淡妆 |
| 肤色与肤质 | 冷白皮，全脸色度均匀；皮肤细腻且有真实纹理与极细绒毛，不磨皮、无油光 |
| 发型 | 黑色长直发、中分，发梢垂到肩胛；发丝有细微走光，鬓发可被手指带起 |
| 上装 | 白色短款针织圆领长袖，衣摆收在腰线上，织纹可见 |
| 下装 | 浅蓝高腰直筒牛仔裤，裤腰高过肚脐，裤脚盖住鞋面，水洗纹理自然 |
| 鞋 | 白色厚底运动鞋，鞋底厚约 3 cm |
| 体态比例 | 裤腰线在人物身高的 35% 处，下半身占 65%；人物高宽比 1.90；双脚与肩同宽，一只脚在前、重心落在后腿，肩线相对髋部转 15° |
| 构图 | 全身入画：头顶留白约 2%、鞋底贴画幅下缘、人物高占画幅 97% 以上（实测值，用于核对产出，不作句子约束）；机位高度与人物胸线齐平，镜头无俯仰；人物居中 |
| 光与背景 | 柔光自人物前上方 45° 略偏一侧，另一侧补光弱一档；浅灰白无缝背景；脚下有淡接触阴影 |
| 机位 | 固定不动，五秒一镜到底，不变焦、不推拉、不摇移、不切镜 |
| 动作 | 先轻微换一次重心；随后用一只手把鬓侧一缕头发别到耳后，停半秒，放下手回到站姿，嘴角微起 |
| 明确不写 | 不指定用哪只手（见 `Doc/Cards/spec.md` 全局规则 1）；不写「肤白、貌美、大长腿」这类形容词——长相与取景都由首帧图承担，卡面不重复下达。frontmatter 里对该词的拆解（肤白＝冷白皮／大长腿＝腰线 35%）只是检索与验收用的定义，不参与投递 |
