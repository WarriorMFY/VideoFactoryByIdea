## 2 · 与模型的对齐度（四样本实测）

### 2.1 通道层：零方差

同 prompt 4 个独立样本，尺寸 960×544、24fps / 124 帧、5.17s、一镜到底**完全一致**；能量曲线同构（前段低平 → 2.5s 抬起 → 峰值 2.8–4.2s → 缓降）。**不确定性全在语义层，不在通道层。**

### 2.2 容易对齐

| 项 | 命中 | 说明 |
| --- | --- | --- |
| K0 起势对峙 | **4/4** | 最稳的一帧 |
| K4 终态（B 倒地、A 站定、无接触、拉开） | **4/4** | 差异只在幅度（横飞 ↔ 坐倒） |
| 后仰反应 | **4/4** | 稳定 |

### 2.3 不容易对齐

| 项 | 命中 | 实测与归因 |
| --- | --- | --- |
| K1 接触面（拳面顶住小臂中段） | **0/4** | 四轮一律「竖掌在来拳上方迎挡」。**写法维度错了**：写的是受击面，模型读成施动动作 |
| K2 向外侧拨开 | **1/4** | 其余为下压／抓带／推拍，b1 未接触。4 个样本可定论：当前写法不可稳定实现 |
| K3 部位「胸口正中」 | **0/4** | 4/4 全落在上胸／锁骨下方——**系统性偏高，不是误差** |
| 扬尘 | **0/4** | 四轮均无 |
| 风格 | 0/4 一致 | 舞蹈室 / 古装武侠 / 白棚 / 灰底，四轮四样；卡内无风格句 |
| 左右手分工 | 需显式声明 | 不写就会被模型自由分配（「左手推掌」事件） |

## 3 · 硬结论

1. **通道零方差、语义高方差。** 复现性讨论要分两层：管道层可重复，语义层不可重复。这一条与 Circle5 的「改一句＝整卡重掷」互补。
2. **写受击面会被读成施动动作。** 要模型画出接触，得写施动侧（「掌根抵住拳面」），或承认接触发生在「来臂与竖掌之间」。
3. **系统性偏差照它改，别当误差忍。** 4/4 同一偏移＝卡的写法与模型语汇不对位；把「胸口正中」改成「上胸」才能止损，而不是每轮固定欠一项。
4. **节奏判读不能靠抽帧。** 0.57s 间隔跨过 0.1–0.2s 事件；抽帧只做段落导航，判定必须通看全片（承 Circle2）。
5. **单一动作链 + 单一接触点才可验。** 「两仪顶」这类复合专名形态：模型不认识，人也没法归因——复杂度本身就是失败源（§0 用户裁定）。
6. **技能铁律：改一列，L1/L2 结论作废，须重跑。** 本轮多次靠这条拦住「改完直接送验」。
7. **姿态重叠条款（3.2）。** 相邻两帧不得姿态重叠：后一帧要求的部位若前一帧已在该位置，须写出起点与位移差。K1「帧间无动作差」就是这么查出来的。
