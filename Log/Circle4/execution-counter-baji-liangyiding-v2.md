# 动作卡：八极防反·两仪顶击飞（交互事件导向版）
> **【兼容性声明】**：本卡不限制主体A的左右手分配，只要满足“先格挡，后近身肘臂顶击”的物理逻辑，即为合格生成。
> **【镜头调度声明】**：本卡仅记录核心攻防动作链，不加多余动作。八极拳“贴身发力”的短促节奏与打击停顿，由镜头卡通过推拉摇移（如顶击瞬间的镜头震颤或极短慢动作）来实现时间对齐。
## 关键帧列表
| 关键帧（自变量：帧号/阶段/进度） | 动作状态（因变量：可观测动作描述） |
|---|---|
| K0 / 攻击与格挡 / 0% | 角色=主体B的重心前压，主攻手向主体A面部挥出重拳；主体A重心微沉，防御手抬起在身体中线前方；武器/接触=主体A的防御手小臂/手腕与主体B的主攻手发生**物理接触（格挡成立）**；目标=主体B的出拳轨迹被阻挡；位移=双方均原地站立，接触产生轻微后坐力；同步=主体B的拳面/小臂与主体A的防御手在画面中形成明显撞击点 |
| K1 / 贴身两仪顶一气呵成 / 50% | 角色=主体A在接触的同一拍，防御手向外侧拨开对方来拳，**身体瞬间向前贴身突进**，另一只手屈臂成肘（或前臂），以极短的发力距离向主体B胸口猛顶；武器/接触=主体A的另一只手臂（两仪顶）**死死砸中/顶入主体B的胸口正中（接触的高光瞬间）**；目标=主体B胸口受短促巨力冲击，躯干瞬间佝偻、随后猛烈向后倒飞；位移=主体A脚下趟步/震脚前压，重心极度下沉且前贯，不回收；同步=主体A防御手拨开对方、另一只手顶中胸口的瞬间，伴随主体A的下盘沉坠，形成“整劲”爆发 |
| K2 / 击飞与收招定势 / 100% | 角色=主体A保持两仪顶发力后的余威，手臂微屈护住中线，**沉肩坠肘，重心下沉稳固如铁塔般站立**；主体B躯干向后倒飞、四肢因惯性松展；武器/接触=**无接触，主体A的顶击手臂已脱离主体B的胸口，双方拉开空间距离**；目标=主体B向后倒飞并重重砸向地面，彻底失去反抗能力；位移=主体B向后发生大幅度位移并触地，主体A双脚踏平定住重心；同步=主体A的铁塔定势与主体B背部砸地（或砸出尘土/碎屑）的瞬间同步 |
