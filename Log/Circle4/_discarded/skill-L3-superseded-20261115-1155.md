# L3 送验与判图

**一条规则：卡内原文逐字进 prompt，景别由镜头规则补，都不改卡。**

## 参考体系必须先于动作原文（单帧生图硬要求）

模型不知道「右掌」是谁的右掌。每张单帧图的正向文本**开头必须先放卡内【空间基准声明】逐字**，动作原文紧随其后；声明与动作不得拆到两处、不得改写、不得只放其中一半（左右/内外漏一条就等于没锚定）。

- 来源：卡片正文的 `> **【空间基准声明】**：…` 行，仅去掉 `>` 与 `**`，其余逐字。
- 位置：**段 0**，在动作原文之前。放尾缀里等于失效。
- 理由：声明定义的是「左右＝各主体自身解剖学视角、两套不得互推」，是动作原文里所有「右掌/左外侧」能落地的前提；缺它时模型按观众视角硬猜，正侧位机位下必然左右反。

## 送验 prompt = 四段拼接，顺序不可变

| 段 | 内容 | 属卡片 |
| --- | --- | --- |
| 0 | 【空间基准声明】，逐字，置于最前 | **是** |
| 1 | 该帧右列原文，逐字，一字不改 | **是**（唯一真相） |
| 2 | 画质尾缀 | 否（通道要求） |
| 3 | 镜头规则尾缀 | 否（通道要求） |

自检三条：拼装结果须以声明开头；须以「声明 + 卡内原文」开头且两段均逐字同源；须等于「声明 + 原文 + 段 2 + 段 3」。发送快照落盘 `<out>.prompt.txt`，事后可核。

## 镜头规则：固定一句，且不得超过动作原文的 1/10

镜头描述一旦变长就会抢注意力，把动作挤成背景。**prompt 里只放这一句固定内容，一字不改、不加释义：**

> 清晰看出动作主体的所有动作细节。

- 不写机位角度、不写景别、不写留白与裁切——这些全部交给判图环节，不写进 prompt。
- 长度硬上限：`len(镜头规则) × 10 ≤ len(该帧动作原文)`。超了就是错，脚本须报错拦下（K4 最短，217 字 → 上限 21 字；本句 16 字，全帧合规）。
- 视频版同规则，另接「一镜到底不切镜」这一条视频必需约束。

**机位不写进 prompt，不等于不要机位。** 若出图落在纯侧位、左右手不可判读，属「口径不足」：可另加机位约束，但必须仍满足 1/10 上限，且不得挤掉动作。正侧位下两人的前后轴铺满画面左右、左右轴退回纵深，同一帧里分不出右掌与左掌——凡涉左右的判定都是猜；3/4 侧前才分得开（近侧＝右手、远侧＝左手）。

## 判图时才用的四条可见性验收

prompt 不写，判图必查：

1. 双脚与地面的接触线
2. 头顶与脚下各留余量
3. 两人完整同框、身位互不遮挡
4. 步法与站位的前后关系

负向词须含：`特写，半身构图，胸像，肢体裁切，只拍上半身，双腿出画`

## 判图

1. **先判景别**：步法、支撑脚、站位看不见 → 判「景别不符」，归 `[口径]`，重出图，**不改卡**。
2. **再判动作**：逐项对照该帧五元组，给 `PASS` / `FAIL` / `PARTIAL`（静帧不可判）。
3. 步法与接触点须在同一张图内可核验；缺一即不能作为后续帧的基准。
