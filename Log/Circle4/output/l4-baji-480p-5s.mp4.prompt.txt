# 动作卡：防反·两仪顶处决（交互事件导向版）
> **【兼容性声明】**：本卡不限制主体A使用左手或右手，只要满足“先接触格挡，后掌击胸口，再以肘尖顶胸口终结”的物理逻辑，即为合格生成。
## 关键帧列表
| 关键帧（自变量：帧号/阶段/进度） | 动作状态（因变量：可观测动作描述） |
|---|---|
| K0 / 迎拳与格挡 / 0% | 角色=主体B重心前压，进攻手向前挥出重拳；主体A重心微沉，格挡手抬起、以小臂横在自身胸前；武器/接触=主体A的格挡手小臂外侧与主体B的重拳拳面相撞，接触成立；目标=主体B的重拳被挡在主体A躯干之外，未触到主体A身体；位移=双方双脚原地不动，接触瞬间双方上身各后仰约一拳；同步=主体B拳面砸上主体A小臂的瞬间，主体A的小臂已横稳不晃 |
| K1 / 拨拳与掌击 / 50% | 角色=主体A的格挡手向自身外侧拨开主体B的来拳，同一拍内主体A的进攻手成掌、掌指朝上、自腹前向前推出；武器/接触=主体A的进攻手掌根拍在主体B的胸口正中，双方其余部位均不接触；目标=主体B胸口受掌根拍击、上身向自身正后方仰起、下颌上扬；位移=主体A前脚向前趟出半步、重心压到前腿，主体B后脚向后退半步、脚跟碾地；同步=主体B来拳被拨开与主体A掌根落到主体B胸口在同一拍完成 |
| K2 / 上步两仪顶定格 / 100% | 角色=主体A双脚踏成马步、双腿屈膝下沉、两膝向外撑开，两脚横向相距约三个脚长、脚尖内扣；主体A的进攻手屈起手肘、拳收至腮下、拳心朝下，肘尖朝前下方顶出；主体A的格挡手屈肘抱于自身胸前乳下、掌心朝下、五指微屈；武器/接触=主体A的肘尖顶在主体B的胸口正中，双方其余部位均不接触；目标=主体B胸口被肘尖顶实、双脚离地向自身正后方飞出、四肢松展；位移=主体A停在马步原位、躯干中正，主体B向自身正后方腾空约一个身位并背部触地；同步=主体A肘尖顶实与主体B双脚离地在同一拍完成，主体A在马步定势上静止定格 |
