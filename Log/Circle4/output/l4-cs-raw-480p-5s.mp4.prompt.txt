# 动作卡：防反·直击胸口（交互事件导向版）
> **【兼容性声明】**：本卡不限制主体A使用左手或右手，只要满足“先接触格挡，后反击胸口中线”的物理逻辑，即为合格生成。
## 关键帧列表
| 关键帧（自变量：帧号/阶段/进度） | 动作状态（因变量：可观测动作描述） |
|---|---|
| K0 / 攻击与格挡 / 0% | 角色=主体B的重心前压，主攻手向主体A面部挥出重拳；主体A重心微沉，前手抬起在身体中线前方；武器/接触=主体A的前手小臂/手腕与主体B的主攻手发生**物理接触（格挡成立）**；目标=主体B的出拳轨迹被阻挡；位移=双方均原地站立，接触产生轻微后坐力；同步=主体B的拳面/小臂与主体A的防守手臂在画面中形成明显撞击点 |
| K1 / 顺势反击一气呵成 / 50% | 角色=主体A在格挡接触的同一拍，前手顺势向外侧下压或拨开主体B的来拳，同时主体A的后手（拳或掌）直线向前送出，身体重心随之后手前压；武器/接触=主体A的后手准确击中主体B的胸口正中（**接触的高光瞬间**）；目标=主体B胸口受力，上半身猛烈后仰，双脚开始离地；位移=主体A后腿蹬地，重心向前贯穿；同步=主体A前手拨开对方的瞬间，后手击中对方胸口，防守解除与攻击命中在同一拍完成 |
| K2 / 击飞与收招定势 / 100% | 角色=主体A保持出拳后的余势，手臂微屈或前伸，重心下沉稳固，如磐石般站立；主体B躯干向后倒飞、四肢因惯性松展；武器/接触=**无接触，主体A的攻击手已脱离主体B的胸口，双方产生明显的空间距离**；目标=主体B向后倒飞并重重砸向地面，彻底失去反抗能力；位移=主体B向后发生大幅度位移并触地，主体A前脚落地定住重心；同步=主体A的收势定格与主体B背部触地（或砸出尘土/碎屑）的瞬间同步 |
