# 武术处决·迎面推山掌（五帧版）
> **【空间基准声明】**：左右＝主体A、主体B各自躯干解剖学视角（第一人称），两套不得互推；前后＝各主体自身躯干正前（面朝方向），转身后随之改变；上下＝地面重力方向，向地心为下、反之为上；内外＝以体表为界，朝向自身躯干一侧为内、反之为外。
| 关键帧（自变量：帧号/阶段/进度） | 动作状态（因变量：可观测动作描述） |
|---|---|
| K0 / 起势对峙 / 0% | 角色=主体A左脚在前、右脚在后，双腿微屈、重心微沉，双手抬起作防守势，主体A的左手五指并拢成掌、掌心朝向主体B、停在自身左胸前，主体A的右掌停在自身右胸前，主体B右脚在前、左脚在后、双拳护于自身胸前、两肘内收，双方均未发出攻击动作；武器接触=徒手，双方尚未接触，两人前脚脚尖之间保持约主体A一臂半的距离；目标=双方对峙，无任何一侧前压或后退，四只脚均着地不动；位移=主体A与主体B均原地不动，重心不前后移动；同步=主体A的双手抬至胸前与主体B的双拳护至胸前在同一拍完成，两人的站架同时立定 |
| K1 / 来拳入位 / 25% | 角色=主体B的右拳自自身胸前向自身正前方打出，右臂送出大半、尚未伸直，拳面到达主体A胸口正前方约一掌宽处，主体B的右肩随之送出、重心前移，双脚均未离地，主体A的左手自自身左胸前向来拳方向抬起、掌指抬至与自身肩同高、停在自身左胸外侧，尚未碰到来拳，主体A的右掌仍停在自身右胸前；武器接触=徒手，双方尚未接触，主体B的右拳拳面与主体A的胸口之间留有一掌宽的空隙；目标=主体B的右拳送到位、拳锋指向主体A胸口，主体A的左手已挡在来拳的行进路线上；位移=主体B右脚原地蹬地、重心向自身正前方前移，双脚均未离地，主体A原地不动；同步=主体B的右拳送出与主体A的左手抬起在同一拍完成 |
| K2 / 拨开来拳 / 50% | 角色=主体A的左手沿主体A左侧向外（背离主体A躯干的方向）拨中主体B右小臂外侧（该小臂背离主体B躯干的一侧），主体B的右拳被带离两人躯干之间的连线、拳锋偏向主体A的左侧，主体B的上身随之前倾，主体A的右掌自自身右胸前向自身正前方送出、掌心朝向主体B胸口，右臂尚未伸直、掌根尚未触及主体B；武器接触=主体A的左手掌指贴住主体B右小臂外侧，此为双方唯一接触点，主体A的右掌与主体B胸口尚未接触；目标=主体B的右拳被拨离两人躯干之间的连线、来拳落空，主体A的右掌已对准主体B胸口；位移=主体A双脚均未离地、原地以自身纵轴为轴微转，重心由两腿之间压向右腿，主体B双脚未移动；同步=左手拨中与右掌送出在同一拍完成 |
| K3 / 上步推掌 / 75% | 角色=主体A的左脚向自身正前方迈出半步、脚尖落稳，右肩向自身正前方送出、右臂伸直，右掌掌根抵在主体B的胸口正中，主体A的左手已放开主体B的右小臂、收在自身左侧胸前，主体B胸口受掌根推击、上身向自身正后方仰起、后脚脚跟离地，主体B的右拳仍被拨在自身右外侧、未再前送；武器接触=主体A的右掌掌根按在主体B的胸口正中，此处取代上一帧的左手接触成为唯一接触点；目标=主体B胸口受掌根推击、重心被推向自身正后方，主体B后腿未及退步、支撑已失；位移=主体A的左脚落在自身正前方、两前脚相距约半步，重心前移到左腿，主体B向自身正后方失去平衡、尚未倒地；同步=左脚落地、右掌抵胸与主体B重心被推离在同一拍完成 |
| K4 / 按胸压制 / 100% | 角色=主体A的右掌根沿推击方向继续前送、压住主体B胸口，脊柱随之前俯、重心下沉，主体A的左手垂在自身左侧腰际，主体B仰面倒地、背部贴地、四肢摊开；武器接触=主体A的右掌根持续压住主体B胸口，压向与主体B后倒方向一致（向后、向下）；目标=主体B背部触地、被主体A的右掌压定，无法起身；位移=主体A向自身正前方跟进半步、重心前移下沉，主体B向自身正后方倒地、背部触地；同步=主体B背部触地时主体A的右掌压至最低位，两事件同一拍完成、无先后 |
