# 《封坛》

| 项 | 值 |
| --- | --- |
| 类型 | 无对白动作短场 |
| 时长 | 10s（2 分镜 × 5s） |
| 画幅 | 成片 3:4 竖幅（出图 2:3，居中裁上下各 10%） |
| 场数 | 1（酒坊内 · 午后侧光） |
| 人物 | 1 |
| 档位 | L3 单人版：两镜同场景同人，锚复用首次受检 |
| 关键设定 | 封坛只封一遍——这一下压不实，酒就漏气 |

## 人物

**师傅**，六十上下，酒坊守窖人。蓝布围裙，袖口卷到小臂，手上全是老茧。不说话，也不看镜头。

## 场 · 午后 · 酒坊 · 侧光

靠墙一排陶坛，木架横过画面，砖地有尘。窗纸透进来的光从左后方斜切到坛口，坛身亮半边、暗半边。桌上一只待封的坛，一张红纸，半碗清水。

## 分镜

| # | 时长 | 景别 | 机位 | 动作 | 终态 |
| --- | --- | --- | --- | --- | --- |
| 1 | 5s | 中景 | 固定，略高于肩，与坛成 30° 侧 | 红纸覆上坛口，掌心自中心向外抹一圈 | 纸面服帖，靠镜头这一侧还翘着一指宽 |
| 2 | 5s | 近景 | 同轴推近，不换轴 | 人低头看坛口；掌根压住翘边，向下碾，停住 | 纸边贴住坛口，手不动，红纸压出一道暗痕 |

两镜同一空间、同一人、同一轴线，只有景别推进一步。

## 戏眼

**掌根压住纸边后没有立刻抬起，停了至少半秒；纸边服帖，不再回翘。**

- 判成立：镜 2 里手压住后 ≥0.5s 不动，纸边与坛口之间看不到缝。
- 判不成立：手压一下就抬；或离手后纸边重新翘起。

## 为什么这个难度合适

| 已知边界（`reference/core.md` §4） | 本剧本怎么绕 |
| --- | --- |
| 运动方向由首帧主导，prompt 改不动 | 两镜同轴，无转身、无朝向翻转，运动只有「向下压」 |
| 自动缓慢推镜关不掉 | 中景起；镜 2 只沿轴推近，近景帧留推近余量 |
| 长镜头上限 5–6s | 每镜 5s，不碰 8s 档 |
| 首帧必被重绘（hf 掉 3.5–3.8） | 笔触靠剪辑保，不在视频端抠像素 |
| 声音三轨全未实测 | 无对白、无音效硬要求 |
| 身份锚 `ncc ≥0.75` 从未落数 | 单人单场，只守一次；两镜都把下颌与颈线留在画内，便于落数 |
| 图生图会重画主体 | 动作靠掌根碾纸，不靠提示词锁手指 |

## 与前面实验的差别

- 圈 28《雨夜灯笼铺》：也是两镜同人，但镜 1 有跨门槛（朝向变化）→ 本剧本把朝向整条抽掉。
- 圈 29《多一勺》：两人关系变化 + 正反打 → 本剧本退回单人，不加第二人。
- 本圈变量只有一个：**两镜之间推进一步景别**，场景、人、轴线全锁死。
