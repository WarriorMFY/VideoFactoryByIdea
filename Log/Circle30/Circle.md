## 结论：对齐度

**容易对齐**

1. **风格锚 → 空间锚**：同一锚外推 2:3，`lap`/`sat` ×0.97–0.98，一次出片即可用。
2. **同场景同人复用**：两镜同屋、同人、同衣，两段视频肉眼无跳色无变形；锚复用首次受检通过。
3. **姿态类小动作**：下压、前倾、手停住，H3 都演得出（motion 10.67 / 14.41，集中在中段）。
4. **硬切拼接**：两段源规格已一致（672×928@24），零黑帧、零尺寸跳，剪辑零积分。

**不容易对齐**

1. **否定式约束**：prompt 写「不要文字」，Flux3 三处照留「酒」字；只能正面描述或后期压。
2. **首帧必被重绘**：首帧 NCC 0.8309 / 0.8308，笔触类风格在 i2v 里必被抹（core §4 复证）。
3. **SSIM 判据在「加人」场景失效**：0.431 / 0.304 低于 0.45，因加人改构图，属该阈值写明的失效条件。
4. **ar 3:4 单档 805**：Flux3 需 2:3 出图再裁 3:4 才稳。

**待优化**

1. **抽帧不足以判状态联动**：我先用 4 帧拼条判「纸压不平」，判错。拼条采样间隔 1.67s，跳过压纸中段的状态峰值。状态改变类戏眼必须看原速/慢放动态，抽帧只判构图、接缝、溶解、多手、尺寸。
2. **身份锚 `ncc ≥0.75` 仍未落数**：人工框 + 角度光照差，量出 0.15–0.19，无判别力。
3. **声音三轨全未实测**：本圈无对白，未做声。
