## 目标描述 (Desc)

无人值守卡片训练：先定义一个「地貌卡」元卡片（宏观地理与生态信息），再实例化「修仙世界黄枫谷地貌卡」，然后用文生图、文生视频两段实跑，验证卡片与模型的实际对齐度（70%~100% 即通过）。不对齐时先分清是「卡片问题」还是「模型技术边界」，卡问题回炉改卡并归档旧版，模型问题多样本佐证后继续。累计消耗 100 积分即停。交付迭代序列、两张逐项对齐表、重大发现。

## 量化指标 (Spec)

### 1. 环境／预算层

| # | 指标 | 口径 |
| --- | --- | --- |
| E1 | 起始积分 | `remainPoint` = 346.33（2026-11-17 11:02 实测），写入账本首行 |

### 2. 产物／对象层

| # | 产物 | 判定 |
| --- | --- | --- |
| O1 | 地貌卡元卡片 | 1 张，落到 `Doc/Cards/Template/12-terrain.md`；给出「写什么／不写什么／与场景卡边界」三块 |
| O2 | 黄枫谷地貌卡实例 | 1 张，单表；主表 6~9 行，一行一个宏观维度；全文不含人物、服装、镜头、光线、瞬时天气、左右方位 |
| O3 | 文生图样本 | 同 prompt ≥ 3 张（多样本用于分辨卡问题／模型边界） |
| O4 | 文生视频样本 | 同 prompt ≥ 2 条（5s、一镜到底） |
| O5 | 迭代记录 | 每版卡留 `prompt-v<N>.txt` 与改动理由，旧版进 `Log/Circle11/archive/` |

### 3. 对齐／判定层

| # | 指标 | 口径 |
| --- | --- | --- |
| M1 | 逐项得分 | 卡主表 1 行 = 1 检查项；命中 1 分、部分命中 0.5 分、未命中 0 分 |
| M2 | 对齐度 | 得分和 ÷ 项数 × 100%，四舍五入整数 |
| M3 | 通过线 | 图片段 ≥ 70%、视频段 ≥ 70%，各自独立判定 |
| M4 | 卡问题判据 | 同卡同 prompt 下 ≥ 2 个样本对同一项均为 0 或 0.5，且该项在卡内有歧义／矛盾／与其它行冲突 |
| M5 | 模型边界判据 | 同卡同 prompt 下该项样本间不一致（忽有忽无），或改动措辞两版均无法稳定命中 |
| M6 | 反模式检查 | 报告只检查地貌卡自身行项；不额外检查人物服装镜头；不评价其它卡片 |
