# 地貌卡 · 黄枫谷

| 维度 | 内容 |
| --- | --- |
| 位置与范围 | 越国北部建州境内，太岳山脉中段；谷地夹在连绵群峰之间，方圆数千里，北面与元武国接壤 |
| 地形骨架 | 群山环抱的谷地：四壁峰峦浑圆连绵，山脊逐级向外抬升，谷底开阔平缓，谷口窄、谷腹宽 |
| 水系 | 一条主溪自谷腹纵贯至谷口，两侧崖壁数道瀑布跌落入溪，溪畔泉眼成群 |
| 气候带 | 垂直气候分带：雪线以上为裸岩与积雪，山腰四季分明，谷底温暖湿润、终年少霜 |
| 植被带 | 山坡遍生黄枫：峰顶黄枫矮曲稀疏，山腰黄枫密林成片，谷底灵药田纵横成行 |
| 动物种群 | 林间多走兽与猛禽，谷中驯养灵狐与灵鹤，溪中灵鱼成群 |
| 灵脉与异常 | 太岳灵脉一支穿谷而过：成片枫树树体粗壮、根系外露盘结，枫叶通体金黄 |
