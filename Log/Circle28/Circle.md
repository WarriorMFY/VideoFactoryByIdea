## 一句话

不计成本走通「AI 导演工作流」最小链路：传统八阶段骨架不动，中段三处替换（勘景→造景、选角→锁脸、现场→抽卡+修复）串成一条完整链，从剧本走到成片 mp4，每段有产物、有账、有判据结论。spec 见 `spec-ai-director-minimal.md`，过程见 `log.md`，阶段报告见 `report.md`。

## 结论：对齐度

**容易对齐**

1. **锚链外推**：风格锚 → 空间锚（Flux3 2:3）→ 关键帧，`dsat` −1.5%、SSIM 0.52，一次出片可用。
2. **双图位合成**：主图=空间锚、图 2=身份锚，场景守住（SSIM 0.22 → 0.50+）且身份不漂，无贴图感。
3. **姿态类小动作**：H3 演得出「走出站定」「缓缓抬头」，人未漂。
4. **硬切拼接**：两段原生 672×928@24，concat 零黑帧、零尺寸跳、零积分。

**不容易对齐**

1. **朝向类指令**：H3 对「身体朝左 / 不要看镜头」零响应；同首帧换 prompt 两条逐帧 `mean_ncc` 0.8075，轨迹几乎不变——运动由首帧构图主导。
2. **镜头固定不可控**：prompt 反复写「固定」仍缓慢推近（镜 2 从胸以上收到头肩）。
3. **否定式约束**：写「不要…」易失效，只能正面描述。
4. **805 通道故障**：Flux3 ar 3:4 单档必 805（零扣费）；官流无锚 t2i 必 805。

**待优化**

1. **SSIM 量不出身份**：K2c 0.32 与漂移废片 K2b 0.30 区分不开；身份判定需 face embedding（本机无 mediapipe / dlib）。
2. **`ncc ≥0.75` 这条判据未落成稳定数**：人工框 + 角度光照差，量出值无判别力。
3. **声音三轨全未实测**（本圈 spec 未要求）。
