## 一、结论摘要

1. **AI 导演最小链路走通**：四类锚（风格→空间→身份→关键帧）→ 抽卡出视频 → 剪辑成片，六段均有产物、有账、有判据结论；成片 2 镜 10.333s。
2. **空间锚必须进关键帧**，且只能靠**双图位**（主图=空间锚、图 2=身份锚）。单图链会把场景画丢（SSIM 0.22 vs 0.50+）。
3. **单图锚在“景别推近＋姿态改动”叠加时丢身份**（K2b 实证：换脸变年轻）；双图第二图位可救回（K2c）。→ 应升级为规则：大变化关键帧一律双图。
4. **i2v 的能力边界**：姿态类小动作可做（抬头 ✓）；朝向类指令零响应（走向/转身 ✗，运动方向由首帧构图主导——同首帧换 prompt 的两条逐帧 mean_ncc 0.8075，轨迹未变）；“镜头固定”不可控（H3 会缓慢自动推近）。
5. **全圈实扣 427.99**（软上限 1000 内），其中废片 78.03（首版单图 K1/K2 48.28 + K2b 25.33 + S1-v2 4.42）。剪辑零积分。

## 四、边界点清单（供 RAG/技能沉淀）

1. **运动由首帧主导**：H3 对"身体朝向/转身/别看镜头"无响应，同首帧换 prompt 运动轨迹几乎不变（S1 v1/v2 ncc 均 0.7622）。要不同走向只能换首帧构图。
2. **自动推镜**：prompt 反复写"镜头固定"仍缓慢推近（S2 从胸以上收到头肩）。近景帧要预留推近余量。
3. **景别变化后 SSIM 失效**：SSIM 度量不了身份（K2c 0.32 vs 漂移 K2b 0.30），也度量不了"推近后的场景连续"；身份判据必须用 face embedding。
4. **推近+姿态叠加丢身份**：单图锚的失效条件明确化——大景别变化（中景→近景）叠加姿态改动时必须双图。
5. **多图位用法**：主图放"要编辑的底"（场景），图 2 放"要保持的人"，prompt 里用"图1/图2"指代，融合自然、无贴图感。
6. **2:3 图进 3:4 视频**：居中裁上下各 ~10%（1184×1760 → 1184×1579）安全，人物构图无恙。
7. **805 零扣费**：Flux3/官流报 805 均零扣费，原样重试约 50% 成功；不视为实验失败。
