## 一句话

一张二十余人的发射控制中心实景图，串起 i2i 改内容、本地合成、官流改属性、首尾帧到首帧视频五条通道：**「至少 N 人」「只改表情」两类意图能对上，「去掉几分之几」「改成 XX 风格」全崩**；视频侧只有 MiniMax H3 首帧通道一次给出画面 + 中文广播音轨，但要它「镜头任意调度」就会丢脸。

## 对齐度：容易对的

| 意图 | 证据 | 代价 |
| --- | --- | --- |
| 下限数量词（保留至少 10 人） | V4b：20+ → 9 / 11 人，要素全保，`face_diff 14.9–16.2` 全圈最低 | Flux3 i2i 22.95 |
| 只改表情、其余照旧 | V7 官流全能图 V2：表情全改，机位/景别/裁切/大屏占比/人物左右位全守住 | 75.74（2k），Flux3 的 4 倍 |
| 固定机位的连续情绪变化 | V8 首尾帧：两端 NCC ≥0.97，情绪 0s 屏息 → 10s 大笑鼓掌，无崩帧无换脸 | 33.49 |
| 画面 + 中文广播一次成型 | V10 H3 首帧：自带 AAC 音轨，转录「倒计时，54321，点火」，绕过 t2v 无音轨与 TTS 1014 两条死路 | 36.21 |

| 只改影调 | V6 本地调色：低饱和 + 冷调 + 颗粒 + 暗角，构图零风险 | 0 积分 |

## 对齐度：对不上的

| 意图 | 实测结果 | 归因 |
| --- | --- | --- |
| 「去掉三分之二」 | 20+ → 3 人（剔除 85%） | 比例词被读成「删掉大部分」 |
| 「去掉远景人像」 | 20+ → 2 人，还误删中景女工程师 | 范围词被读成「只留主体」 |
| 「改成纪录片风格，其他都不变」 | 风格成了，构图全崩：机位前推、后脑勺占屏、大屏被遮 | Flux3 上等于重画一张同题材图 |
| 「镜头任意调度」 | 四种机位都出现过：不动 / 推近 / 绕到背后 / 推成大特写 | 「向前推近」类句子的执行强度不受控；不写才稳 |
| 视频里的大屏倒计时 | 六版全部乱跳，无一处严格递减 | 通道能力边界，非提示词可解 |
| 台词干净 | 只有 V10 干净；其余把叙述句（「都不说话，只有…」）当台词念 | 叙述与台词未隔离；加「画外播报」标注反被念进去 |

## 三条可复用的结论

1. **数量要写下限，不写比例与范围**：比例词 → 3 人，范围词 → 2 人，下限词「至少 10 人」→ 9 / 11 人。
2. **改属性走官流 V2，改风格走后期**：Flux3 上「改风格」必连带改构图，「其他都不变」无效；要保构图只能调色/加颗粒，或换 V2 付 4 倍价。
3. **视频提示词只写「不切镜 + 轻微手持晃动」，不写推轨推近绕行**；台词单独成行、逐字加标点，叙述句仍可能被念，要绝对干净只能后期替换音轨。

## 待优化

- **切镜**：本圈所有视频都是单镜到底，大屏倒计时与「点火」事件始终没在画面里发生。真切镜需三段拼（控制室 5s + 发射台 8s + 控制室 7s，≈65 积分），未跑。
- **音轨**：V10f 开头 0–2.3s 仍有一长段碎旁白（0 积分可剪），且缺「四」，数字不严格 5→1。
- **成品合成**：画面取 V10f、音轨取 V10 或后期替换，两条都 0 积分，未做。
- **规则沉淀**：提示词原话单存 `*.原话.txt` + 改写留 diff + 发送前过目，需用户点头后写入 `AGENTS.md`。
