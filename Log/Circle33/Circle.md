## 需求拆解（来自用户指令）

1. 网页端，不是桌面程序。
2. 左栏：**项目列表**。
3. 右栏：**项目视图区**，每个项目固定 tab = `1.剧本 / 2.风格 / 3.锚图 / 4.分镜 / 5.合成`。
4. 先出**快速原型**，再讨论。

## 原型位置

`Workspace/director-editor/`（AI 自治区，可随时删改）：

| 文件 | 作用 |
| --- | --- |
| `index.html` | 骨架：侧栏 + 主区 + tab |
| `styles.css` | 深色工作台样式（琥珀强调色，贴合 NASApunk 片子的视觉） |
| `data.js` | 种子数据：圈 32（NASApunk 30s）与圈 31（锈日 25s）两个项目，按 5 tab 的结构填 |
| `app.js` | 状态、渲染、localStorage 持久化、图片临时挂载 |

零依赖：双击 `index.html` 即可打开；也可 `python -m http.server` 起本地端口。

**落盘快照**：`Log/Circle33/editor/`（2026-11-24 与 Workspace 同步的 5 个文件：`index.html` / `styles.css` / `data.js` / `app.js` / `_smoke.js`）。Log 只记当时，后续改动只进 Workspace；快照在副本目录里重跑冒烟可通过。
