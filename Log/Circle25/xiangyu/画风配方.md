# 古画风配方 · 《香玉》三镜实测后收敛

> 这份配方不是从画论推的，是从三条实跑片里留下的东西反推的。
> 凡标「立住」的，片子还在；凡标「崩」的，原样留着当反例。
> 实验现场：`Log/Circle25/xiangyu/`，成片 `out/xiangyu-15s.mp4`。

---

## 0. 一句话

**三层一开关，共用一张绢底；线与色分开管，动与变分开管。**

三层是底、人、变；一开关是白描。所有层先画在同一张绢上，再谈动——古画风的成败在接缝，不在单层。

---

## 1. 分层表

| 层 | 画种 | 管什么 | 本轮实测 |
| --- | --- | --- | --- |
| **底** | 元人水墨（南宗） | 夜、天、墙、留白 | **立住**。S1 的夜不压黑，靠淡墨积染留出来；绢纹从首帧到末帧没丢 |
| **人** | 工笔重彩人物（铁线描） | 主体形、服饰、遮挡关系 | **立住但会跑**。S1 人从「半掩花间」被自己走到全露，主体自动放大 |
| **变** | 减笔泼墨 | 非人显形、突变、爆点 | 本轮没到爆点，未用。留作 S4 之后 |
| **宅** | 界画 | 门、窗、墙、廊、屏 | 未单独用，但 S1 那道门框已证明「先有直，才有直被掰弯」 |
| **开关** | 白描 | 显形／隐去的转场 | **半成**。S3 线在动，但没聚成人——见 §6 |

三层不必每镜都上。**一镜只验一层**，混着上会得到「说不清是谁造成的」结论（同 i2v-probe 铁律 1）。

## 2. 三档底：用明度讲时间

从三张首帧里直接取的 k-means 主色（HEX，括号内为明度）：

| 档 | 主色 | 用在 | 出处 |
| --- | --- | --- | --- |
| **夜** | `#4E5050` `#5D5D5A` `#424444`（L 31–37%） | 初遇、夜谈、鬼至 | S1，占画面 71% |
| **晨** | `#B8A080` `#BCA385`（L 70%） | 花劫、别离、将明未明 | S2，占画面 89% |
| **昼/留白** | `#E1D5C5` `#E3D8C8`（L 87%） | 复生、回忆、纯白描段 | S3，占画面 94% |

**关键**：这三档不是调色盘，是**叙事进度条**。一个故事从夜走到昼，只推底明度，不换画风——观众感知到的是「时间过去了」，不是「风格变了」。

反过来说：**同一场戏里不要跨档**。S1 若在中途提亮，观众会以为天亮了。

## 3. 首帧提示词骨架

六段，缺一段就出幺蛾子。已验可用，直接改中括号。

```
绢本设色[立轴｜空景小品]，中国工笔重彩人物画，宋人院体笔意。
[场景一句：地点 + 季节 + 时辰]
[主体：位置 + 被什么遮住多少 + 服饰 + 姿态]。只露出[半张脸／一肩／一段衣带]。
[光：单一光源从X方向来，只照亮[花与半个人]]。
背景不作黑，只用淡墨积染数层留出夜色。
[远处一个发光点，可选：一扇窗棂透出一豆灯火]。
笔法：[铁线描／游丝描／干笔皴擦]，[某物用蛤白平涂后以细线勾边]。
平视构图，不用焦点透视，留白约占[四]成，绢纹隐约可见。
整幅画面干净，无题跋、无印章、无签名。
no text, no seal, no signature, no watermark, no modern element
```

### 三个必须写死的地方

1. **遮多少要写数字**。写「掩映花间」不够，要写「只露出半张脸、一侧肩膀和一段垂落的衣带」。S1 靠这句才没画成标准肖像。
2. **花瓣要写形态**。S2 第一次跑出「一群白鹅趴在地上」——因为只写了「散落十余片残白花瓣」。改成「薄薄的椭圆形片状，边缘微微卷起，三三两两叠在一起，用蛤白平涂后以细线勾边」才正常。**凡是「点染」二字，模型都会理解成点状小物体。**
3. **土、石、坑要写「不作明暗体积」**。S2 首版土坑是 3D 透视的，加了「只用墨线勾出轮廓再以干笔淡赭皴擦，不作明暗体积」才压平。

## 4. 动作提示词骨架

三段式：**外因 → 主体的一个动作 → 余动**。一句一件事，别堆。

```
[风/光的外因]，[什么被带动]。
[主体做一个动作]，[衣／袖／带随之怎样]。
[余动：某物轻轻颤动／某处晃一下]。
机位完全不动。
```

S1 实例：
> 夜风自右侧吹入，前景花丛轻摇。花丛后的素衣女子缓缓侧身回望，衣袖与衣带随之扬起又落回。远处窗内的一豆灯火轻轻晃动一下。机位完全不动，月光方向保持不变。

### 三条禁忌（都有实跑代价）

| 禁忌 | 为什么 |
| --- | --- |
| **不写「人物不动」** | Circle20 的 O5 已证：否定式会被读成「要有这个人物」，模型会凭空补人 |
| **不写两个主体的动作** | 5s 只够一件事做完。S1 同时要「花摇 + 人回望 + 灯晃」，人就被推到了画面中央 |
| **不写「镜头不动」以外的机位词** | 写「机位完全不动」也没锁住。模型默认推近（见 §6），这一条只能靠剪辑侧补偿 |

## 5. 三条实测

| 镜 | 层 | 锚 ncc | motion_max | 判决 |
| --- | --- | --- | --- | --- |
| S1 花间见 | 工笔人物 + 墨夜 | 0.9034（松动） | 21.05（格4，左上） | **质感立住，构图跑了**。人从半掩走到全露，衣带飞舞像广告片 |
| S2 掘花 | 水墨空景 | 0.7887（失效） | 11.10（格8） | **最静，也最像古画**。全片只落一片花瓣，5s 内事件偏少 |
| S3 复生 | 白描转场 | 0.7241（失效） | 8.60（格8） | **最古的一条**。线在摆动，但始终没聚成人 |

锚强度全部低于 0.95 的门槛（Circle20 的 16:9 是 0.9276）。而这三条输入的分辨率、比例都比当时好——**说明不是画幅问题，是这条通道对任何输入都会重新构图**。

分区运动也印证了：S1 的运动全压在格 4、5、6（中上），那是人物所在；四周格 1、2、3 只有 0.8–1.1，等于背景被冻住。**人物在动，绢没在动**——这恰好是古画该有的样子，但也是「人像贴上去」的隐患。

## 6. 边界：哪些不能交给生成

这三条最重要的产出不是片子，是划出了三条线。

### 6.1 主体自动放大 —— 必输

模型有一个稳定的倾向：**把主体做大、做满、推到中间**。S1 的原始构图是「人被花与门框遮住半边」，5s 后她站到了花前，整个轮廓都露出来。写「机位完全不动」无效。

对策不是改提示词，是**在剪辑侧抵掉**：以首帧为基准做反向缩放（每帧按主体包围盒做 1.0→0.92 的缓慢缩），或者干脆**接受它**——把「走近」写成戏的一部分。
更省事的办法：**首帧的留白要比你想保留的多留一成**，让模型吃掉那一成。

### 6.2 由线成影 —— 只能做一半

S3 要的是「线聚成人 → 颜色自下而上浮现」。实际得到的是「线一直在摆，人始终是淡的」。

模型能演 **线的运动**（摆动、飘、盘旋），演不了 **线的凝聚**（从无到有地长出一个形）。这是拓扑变化，不是位移。

结论：**「由线成影」的成形帧必须手绘一张**，生成端只负责它成形之后的飘动。这条语法没被 AI 攻克，也正因为没被攻克，它还是空地。

### 6.3 留白会被填满

S2 给了五成留白，模型基本守住了（这是水墨空景能成立的原因）。但 S1 只给四成，5s 后剩不到两成。

规律：**首帧留白 ≤ 四成时，留白一定被吃掉；≥ 五成时才守得住。**

## 7. 参数与成本

| 项 | 值 |
| --- | --- |
| 通道 | i2v `2113790012012720129`（MiniMax+H3+首帧图生视频） |
| 档位 | `--ar 3:4 --mp 0.6 --dur 5`，输出 672×928 / 124 帧 / 5.167s |
| 报价 | 21.42 ／条 |
| **实扣** | **21.42 / 17.51 / 17.68** —— 同参数差 3.91（22%），三条合计 **56.61** |
| 首帧 | 内置 ImageGen，1024×1536，约 5–10 积分/张；出 4 张（S2 重跑一次），实收 3 张 |
| 合计 | i2v 56.61 + 首帧 4 张 |

**「同参数不同价」第二次被证实**（上次是 Circle20 记的 20.57 例外）。所以报价只能当上限估，账要按 `chargedPoint` 逐条记。

### 一个必须知道的坑

首帧必须先裁成精确比例再喂。ImageGen 出 1024×1536（2:3），通道出 672×928（0.724），两者都不是严格 3:4。裁到 1024×1365 后喂进去，锚 ncc 仍在 0.72–0.90 —— **裁切不是主因，重构图才是**。但裁切能顺手切掉工具水印（在底部 11% 内）。

## 8. 复现

```bash
# 首帧：裁成 3:4 并切掉右下角水印
python Log/Circle25/xiangyu/prep.py

# 三条（一条一账，不并发）
P=Skill/hub/generation/i2v-probe/scripts
python $P/probe.py --id S1-花间见 --group XY \
  --frame Log/Circle25/xiangyu/frames/S1.png \
  --prompt-file Log/Circle25/xiangyu/prompts/S1-motion.txt \
  --dur 5 --ar 3:4 --mp 0.6 --out Log/Circle25/xiangyu/out

# 度量 + 对照条 + 串片
python $P/measure.py --run Log/Circle25/xiangyu/out/runs/S1-花间见
python Log/Circle25/xiangyu/strip.py
```

> `measure.py` 已修中文路径：Windows 下 `cv2.imread` 不认非 ASCII，改走 `np.fromfile` + `imdecode`。

## 9. 下一镜该验什么

按本配方，剩下没验的只有**「变」这一层**——减笔泼墨做非人显形。香玉的故事里对应的是「花神现身」或「黄生化牡丹」。

建议 S4：黄生卒后化牡丹那一镜，用泼墨从土里爆出一株，只给 1.5s，剩下 3.5s 让墨自己散。这是配方里唯一还空着的格子，也是三条线之外唯一没被证伪的假设。
