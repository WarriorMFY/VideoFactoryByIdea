## 结论

1. **元规范先立**：`Skill/Meta/README.md` 由用户手写五条（触发边界、30–40 行、模块化、单一真相源、自包含），此后 LLM 只读。现成技能全部回头对齐。
2. **卡片实验链拆成 v2**：编排者 39 行＋四阶段 40/37/40/40，v1 原地冻结。阶段技能之间只靠产物接缝，不靠共享代码。
3. **自包含是硬门槛**：清了 9 处树外引用（`AGENTS.md` 5、`Doc/` 4），另清掉 1273 行 RHclaw 客户端依赖，改写 `scripts/rh_api.py`（约 190 行，纯标准库＋curl）。
4. **冒烟四阶段全通**：真跑一图一片，charged 11.32＋12.75，产物 1360×768／5.17s。脚本链可用，模型能力未验。
5. **归档立了三层**：链内 `manifest`（原始判读，不改）→ 循环 `log.md`（候选暂存）→ 技能 `evidence/`（验收后入库，一句话索引）。先放循环，删掉不伤流程。

## 对齐度（实测）

| 容易对齐 | 不容易对齐 |
| --- | --- |
| 有名实体（护目镜、赤红围巾、柴犬、纯白无缝底） | 画面占比（要 2/3 得 3/4；要脸宽 70% 得 88–100%） |
| 材质与光线（亚光皮肤、锐利高光） | 可数量词（绕两圈只得一圈的量感） |
| 整体景别档与单段运镜 | 左右指派（模型只认语义，不认解剖） |
| 时长档位（5 秒档稳定复现 5.17s） | 精确切点（秒数不被读取，刀落别处） |
