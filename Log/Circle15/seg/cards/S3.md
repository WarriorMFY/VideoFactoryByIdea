---
name: s3-teacup-ripple
desc: 茶盏汤面起涟漪、白汽升起，后方茶壶续水，机位不动
axis: 起因（注水）→ 传导（汤面涟漪／白汽／桌面光斑）→ 结果（汤面近平、汽上散）
---

| 项 | 内容 |
| --- | --- |
| 主体 | 青绿描红鱼纹瓷盏，置于旧木桌，后方虚焦茶壶正注水，画面底部有硬字幕 |
| 起始态 | 汤面平，无汽，暖侧光 |
| 动作时序 | 0–1.2s 水线注入盏内，汤面起同心涟漪；1.2–3.5s 白汽自汤面升起被侧光打亮；3.5–5s 注水停止，涟漪衰减，汽向上散 |
| 接触事件 | 水线与汤面、汽与光 |
| 位移 | 波纹由中心向外；汽柱向上 |
| 结果态 | 盏内汤面近乎平复，盏身花纹与桌面位置不变 |
| 禁止 | 不切镜、不移盏、不改釉色、不动字幕、不出现第二只手 |
