---
name: s2-pendant-turn
desc: 杖头铜框圆牌轻转，牌心金面佛像转向镜头，铜面掠过一道火光
axis: 起因（吊环轻震）→ 传导（牌体转动／佛像转向／铜面反光）→ 结果（停为正对镜头）
---

| 项 | 内容 |
| --- | --- |
| 主体 | 杖头悬挂的铜框圆牌，牌心是金面佛像，背景红柱虚焦，画面底部有硬字幕 |
| 起始态 | 圆牌略偏，佛面侧对镜头，浅景深暖调 |
| 动作时序 | 0–2s 牌体绕过吊环缓慢转动；2–4s 牌心佛面随之转向正对镜头，铜锈面掠过一道横向火光；4–5s 转速衰减，停住 |
| 接触事件 | 吊环与牌体、火光与铜面 |
| 位移 | 牌体角度变化约二三十度；杖与背景不动 |
| 结果态 | 牌面基本正对镜头，佛面清晰，背景虚焦不变 |
| 禁止 | 不切镜、不改景别、不改背景柱色、不移字幕位置、不出现手 |
