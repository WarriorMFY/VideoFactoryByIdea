desc: 山窟巨佛大殿，机位不动，穿堂风压低灯火、带起香灰与雾
axis: 起因（风）→ 传导（火焰／雾／灯笼）→ 结果（火星上飘、雾升至膝部）

| 项 | 内容 |
| --- | --- |
| 主体 | 山窟内依崖凿成的巨佛坐像，红袈裟，两侧多层木廊，佛前地面数盏油灯 |
| 起始态 | 灯火直立，雾气贴地，殿内暗、火光暖 |
| 动作时序 | 0–1.5s 火焰齐向一侧压弯，火星离焰；1.5–3.5s 贴地雾被带起，升到佛像膝部；3.5–5.0s 两侧木廊灯笼轻晃，火星飘到画面上部 |
| 接触事件 | 风与火焰、风与雾、风与灯笼 |
| 位移 | 火焰倒伏方向一致；雾整体向上；佛像本体不动 |
| 结果态 | 火光偏亮一档，雾停在膝部，殿内仍暗 |
| 禁止 | 不切镜、不改景别与机位、不增删建筑构件、不让人物入画、不出现文字 |
