| 项 | 内容 |
| --- | --- |
| 主体 | 山窟内依崖凿成的巨佛坐像，红袈裟，两侧多层木廊，佛前地面数盏油灯 |
| 起始态 | 右侧木廊栏杆完整；油灯火焰直立；雾贴地；殿内暗、火光暖 |
| 动作时序 | 0–1.0s 殿内静止，只有灯火与贴地雾在动；1.0–1.4s 右侧木廊中段栏杆的榫接处先松脱，木屑落下；1.4–2.4s 整段栏杆脱离廊沿、翻转坠落；2.4–3.0s 砸在佛前石台上，断成数段，木屑与积尘腾起；3.0–5.0s 尘缓慢下沉，缺口留在原处，断木静止 |
| 接触事件 | 断木与石台、断段彼此、尘与地面 |
| 位移 | 栏杆整体向下坠落，落点在佛前石台台面；断段向两侧散开 |
| 结果态 | 木廊留下一处可见缺口；石台前散落断木数段；地面覆一层薄尘，灯火被尘压暗一档 |
| 禁止 | 不切镜、不改景别与机位、不让人物入画、不出现文字、佛像本体不移动 |
