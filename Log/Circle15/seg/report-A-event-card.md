## 目视（放大右侧后重看）

证据图：`out/s1e-crop-zoom.png`（右下角，1.0–3.5s 每 0.25s）、`out/s1e-right-zoom.png`（右侧 45%，每 0.5s）、`out/diff-5_0s.png`（末帧差异热力）。

时间线：

- **1.0s** 右侧木廊下方出现一根垂直下垂的深色木条——原片此处是斜向栏板，它断开后垂下。
- **1.25–2.0s** 该木条一边倾斜一边下落，形态由"条"变成"片"。
- **2.0–3.5s** 碎成多块黑色碎片散落，雾与尘从右下同时涌起，把落点盖住。
- **3.5–5.0s** 碎片继续下沉，雾漫到木廊底部。

**卡里写的"整段栏杆脱离廊沿、砸在石台、断成数段"被执行成了"一段栏板垂落、碎成数片"。方向对，尺度缩水一个量级，落点也被雾遮住。**

差异热力图上，橙色暖区只覆盖右侧木廊与右下角；佛像、左侧廊道、中央全部为冷色——**其余 90% 的画面一帧未变**。

## 判读（四条，已按分区数据改写）

1. **结构改写确实能做，但只做"局部贴片"**。模型愿意在指定位置让一个构件断裂、坠落、碎裂，但它把"整段栏板"简化成"一根木条"，把"砸在石台"简化成"碎块散落"。结构事件的形态与尺度都会被压缩。
2. **位置指令有效，范围指令无效**。"画面右侧"被精确响应（右半 14.66，左半 5.10）；但事件不会外溢成场景变化，佛像与佛前石台完全没有参与。
3. **事件占用了注意力，把全幅氛围压掉了**。对照组雾漫全场（左半 25.55、中央 13.43），事件组只从右下角涌（左半 5.10、中央 6.00）。写了"坠落"，模型连"雾"都少做了。
4. **全幅指标不适合衡量局部事件**。这是本轮的方法论错误：用末帧 NCC 与全幅平均差判"变了多少"，等于按面积投票——一个占画面 5% 的坠落事件，无论多剧烈都拉不动全幅均值。以后这类判断必须分区量（至少 3×3 网格）后再看。

## 由此修正的判断

「太像」的准确说法是：**内容自由度到"局部小事件"这一级，到不了"场景重写"这一级**。写事件的收益是把变化集中到一处、可指认；代价是其余部分被锁死，整片看上去仍是原片的复刻。

要跨到场景级改写，仍只有三条路：

| 路 | 做法 | 代价 |
| --- | --- | --- |
| B① 改首帧再送 | 先把首帧图改掉（换主体材质／换天气／换构件），再走 i2v。改动发生在锚之前，不受局部限制 | 每段多一张图（约 11 积分） |
| B② 降质锚 | 首帧压到 480P／加轻噪／降饱和，削弱像素保真度，让模型自己补细节 | 0 增量，但可能只是"糊"而不是"变" |
| C 换多参通道 | 用文生视频的 9 个参考图位，把源帧当风格参考而非首帧。图只借风格，不复制构图 | 0 增量，代价是段间无法按帧衔接 |

若目标是"整片换内容但保留镜头语言"，B① 是唯一同时满足「画风留」与「内容确实变」的路，因为"变"被移到了 i2v 上游。
