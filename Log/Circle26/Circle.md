## 一句话

给 **一张关键帧**（或一段提示词），生成一条**首尾相接、可无限播放**的视频。生成端只负责"有运动"，**咬合交给剪辑**——模型不保证对齐，也不指望它对齐。

## 用户原话

> 我想搭建一条给定"1.提示词，或 2.关键帧"能够生成"一种可以无限循环播放的视频"，之所以可以无限循环是因为帧序列存在"首尾相接"特性，例如"一张山水图-大部分事物是静态的，但是云雾，鸟儿是其中的动态主体，比如说鸟儿，从第一帧开始从左向右飞，到最后一帧刚好飞出镜头。在此基础上，继续从第一帧放又从左到右飞，依次类推可以无限循环"，像当前的桌面循环播放背景。

> 不是让大模型生成，是给图生视频一个关键帧，然后动态提示词中要写明运动主体在最后一帧的状态，大模型生成后不一定对齐，我们需要靠后期剪辑工具再保证首帧与尾帧的咬合特性，最后写个脚本来实现这个视频完成几个周期的循环，先根据我说的跑一个视频，挑简单的来，比如一张静态古风山水画，里面只有水动，这种天然就能无限循环播放。

> 一张关键帧，不是两张。

## 定案方案

```
一张关键帧 ──► i2v 5s（提示词写明末帧状态）──► 判据筛 ──► crossfade 缝合 ──► 拼 N 圈
   底图            有运动即可，不指望对齐          loop-check.py      loop.py
```

**关键认知**：i2v 的第一帧并不是你给的那张图。实测末帧与底图 NCC 只有 0.65–0.68，而末帧与**视频首帧**是 0.95。也就是说模型会先把底图重绘一版，之后才在里面运动。

所以「接缝好不好」的基准不是底图，是**视频自己的首帧**；而可接受度也不该跟绝对阈值比，要跟**帧间正常变化**比——古画绢纹是高频，绝对 NCC 天然偏低。

## 三个脚本

| 文件 | 干什么 |
| --- | --- |
| `loop-check.py` | 判一条片子能不能接：`seam`（末帧 vs 底图）、`ratio`（接缝 ÷ 帧间基线）、`drift`（背景有没有被顺手改写，低频差，挖掉主体区再算）、`exit`（主体走完没）、`dir`（末段与首段运动方向差） |
| `loop.py` | crossfade 缝合 + 拼 N 圈。代价是短 K 帧；用 smoothstep 缩短「半透明停留」 |
| `water-flow.py` | 零积分：水面纹理横向平铺 + 缓慢平移（字面方案，代价是重排水面） |
| `water-wave.py` | 零积分：横向行波位移场，像素值不变只移位（保原画方案） |
| `probe.py`（复用 `i2v-probe`） | 出底片 |

| --- | --- | --- | --- |
| L1 | `2124506867140091905` | 21.42 | **废**：水面浮出白色同心圆涟漪，是 3D 水面的先验，不是水墨 |

L2 缝合结果：**接缝 0.9504 → 0.9995**（帧间基线 0.9959），单元 116 帧 / 4.83s，十圈 48.3s 的九个接缝全部 0.993–0.9994。

## 零积分对照：纯剪辑能不能做

同一个镜头，不调生成通道，只有剪辑脚本：

| 版本 | 脚本 | 积分 | 接缝 | 与原画 NCC | 帧间 Δ | 单元 |
| --- | --- | --- | --- | --- | --- | --- |
| i2v L2 | `loop.py` | 18.53 | 0.9504 → 0.9995（须缝合） | **0.666**（模型重绘过） | 0.549 | 4.83s |
| 纹理平移 | `water-flow.py` | **0** | 0.9943（不必缝合） | 平均 0.974，中段 **0.59** | 0.602 | 12s |
| 位移场 | `water-wave.py` | **0** | **0.9974**（比值 1.000） | **0.891** | 0.594 | 6s |

（NCC 一栏是 8 个等距帧与底图的均值，统一缩放到成片尺寸后计算。）

### 两条纯剪辑都是零积分，但差别很大

`water-flow.py` 走字面要求：水面纹理横向平铺 + 缓慢平移。确实做到零积分、绝对无缝、动感最强。**代价是把水面重排了**——可平铺纹理必须先裁掉两端再交叉融合，纹理宽度一定小于水面宽度，平铺后画面里是「同一小段水纹重复三次」。中段帧与原画 NCC 只有 0.59，近淡远浓的层次没了。它不是「原画在动」，是「原画的水被换掉了」。

`water-wave.py` 换做法：**像素一个都不生成，只改采样位置**。横向行波位移场，像素值全部来自原画，只是位置移了几像素。于是画风 100% 保留（0.891 的差全部来自形变，不是新内容），接缝比值 1.000（位移场是 t 的周期函数，t=T 与 t=0 相位相同），且不需要任何过渡帧。

### 一条绕不过去的约束

**单向平移、无重复、严格无缝，三者互斥。**

- 无缝要求偏移量按周期 P 回环；
- 无重复要求 P ≥ 画面宽；
- 两条同时满足时，纹理就是画面本身，而它首尾本不相接——只能靠过渡段（crossfade 会让水纹变淡，见第 3 条）或靠重复来补。

所以「像水在流」与「一点不变形」只能选一个。要两头都占，得让动态主体周期性离场（鸟飞出去那一类），把接缝落在空画面上——正是待验第一条。

### 一个操作层面的发现

**水平短线只有上下起伏才看得出在动。** 古画水纹是横向拉长的笔触，横向挪十来像素时线条端点几乎不动，肉眼无感（帧间 Δ 仅 0.05）。把纵向分量提到与横向相同、振幅加到 16px 后，水纹才呈波浪状起伏，帧间 Δ 达 0.574，与原画 NCC 仍保持 0.891。

### 判据：什么时候该走剪辑

一段要动的，**是不是原来的像素换了个位置**？是 → 剪辑；不是（有形状变化、有新内容进场、有遮挡交互）→ 模型。

- **剪辑占优**：纯位移主体（水、云、雾、烟、光斑、雨雪）；基座不可重绘（古画、带字界面、设计稿）；要求帧级严格闭合（壁纸、展陈长播）；长时长高分辨率。
- **模型不可替代**：拓扑变化（由线化人、花开、显形）；需生成原画里没有的东西（入场、镜头运动、光照）；主体与遮挡物要有正确交互；非刚性有机形变（衣袂、毛发、水花）。

剪辑另有两条模型给不了的性质：**确定性**（同输入同输出，可复现可批量）与**不降级**（本轮剪辑 1800x1012 原生，i2v 只给 1056x608）。对靠绢纹与飞白立命的古画，分辨率本身就是画风。

## 第二条路线：首帧 → 图生图出尾帧 → 首尾帧生视频 → 乒乓环

用户定的路线：

```
首帧 A ──flux3-edit──► 尾帧 B ──wf-firstlast──► 3s 底片 ──pingpong.py──► 无限环
         (模型给"光怎么变")       (两端都是像素锚)        (正放+倒放，跳变为 0)
```

素材：`deer/in/src.png`（1189×759，青绿山壁里的发光白鹿），裁成 3:2 锚 `A.png`（1137×758）。

### 尾帧不能直接用模型出图

`flux3-edit` 出了两张（实扣 22.10），与原图 NCC 分别 0.9179 / 0.9607。但**鹿被重画了**：归一化白剪影 IoU 只有 0.60 / 0.63，面积掉 34%，质心右移 31px。提示词写了「不改变姿态、角度、四足落点」，无效——图生图必然重绘整幅。

改法：**模型只提供"光怎么变"，像素结构仍取自首帧**。

```
gain = blur(B / A, σ=40)            # 只留光照的缓慢变化，抹掉模型改的纹理与轮廓
gain = gain·(1−core) + 1.0·core      # core = 鹿芯（亮度过 165 的纯白区），护住不打暗
B' = A × gain
```

结果：`ncc(A,B') = 0.9886`，全图亮度 −11.4%，鹿芯 209.6→195.2，鹿的轮廓**像素级不动**。

### 首尾帧视频

`wf-firstlast`，720×480 / 49 帧 / 16fps ≈ 3.06s，实扣 **23.12**（同技能此前记过 12.75 / 16.32，第三次证实价格不稳）。

| 对齐项 | NCC | SSIM |
| --- | --- | --- |
| 视频首帧 vs A | **0.9972** | 0.9487 |
| 视频末帧 vs B' | **0.9948** | 0.9369 |

两端都锁住了。但要注意：A 与 B' 本身就差 0.9886，所以交叉项（首帧 vs B'）也有 0.989——**差距小是因为两端设计得太近**，不是通道不灵。

### 乒乓环

`pingpong.py`：单元 = `f0..fN-1` + `fN-2..f1`，末帧 f1 与下一单元首帧 f0 是原片的相邻帧，**接缝跳变严格为 0**，不需要 crossfade。

实测：单元 96 帧 / 6.00s，两处折返 NCC **1.0000 / 0.9988**（帧间中位 0.9999），十圈 60s。

**这是首尾帧路线真正的价值**：乒乓环的折返点正好落在你设计的两张锚上。A 亮、B 暗，一圈就是"光盛 → 光衰 → 光盛"。代价是所有有方向的运动会被倒放反转，只能用无方向的周期运动。

### 但这一版动得太少

亮度曲线：135.0 →（1 秒内掉到）119.7 →（缓慢回升到）122.4。首末差 −12.6，方向对，但**帧间 Δ 中位仅 0.296**，全局运动量 10–15（0–255 尺度），基本是"一张静图在缓慢明暗"。作为壁纸能跑，但没有"活气"。

原因不在通道，在**两端设计得太近**：A→B' 只差 11% 亮度，模型没有可插值的余量。下一步要么把摆动加大（压到 −25%、光晕收得更狠），要么让 B 里多一样真会动的东西（雾的形态变化、光尘位移），而不是只改亮度。

## 四条要记的

1. **"涟漪"这个词会触发出 3D 同心圆**。改成「淡墨横向的细长笔触，水纹是水平方向拉长的短线」才回到水墨。**凡物理现象词，模型都按渲染理解；只有笔法词能约束画风。**
2. **i2v 会先重绘底图**。第一帧就已经不是原图（NCC 0.65）。想让画面忠于原画，这条路做不到；只能接受"同一张画的另一版"。
3. **crossfade 的代价是水纹变淡**。两套相位不同的波纹平均会互相抵消，过渡段水面像"静了一下"。K=8（0.33s）+ smoothstep 是可接受的下限。
4. **判据要跟帧间基线比，不能跟 1.0 比**。古画接缝 0.95 看着低，但全片帧间也就 0.9959，实际差 0.045 不到；换成照片会完全不同。

## 待验

- 离场型主体（鸟飞出去）——本轮只验了原地型（水）。
- K 更小时（4–6 帧）接缝会不会露。
- 相位对齐缝合（把末段按光流 warp 到首帧相位再混），能否消掉"变淡"。
- 提示词路线（无关键帧）。
