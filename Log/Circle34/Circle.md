## 一句话

四条文生图把一座「单独一个总控台 + 下方多排多列 + 无人」的 NASApunk 发射总控厅跑出来了（T4 最好）；两张图生图在同一场地上加出了「一名主工程师 + 多名工程师」的群像（V2 最好）；两条文生视频则证明**动作能演、但场地与人物接不上**。

## 卡片与模型的对齐度

**容易对齐（一次就灵，无重试）**

- **机位**：一句「镜头从主控制台看向子控制台」同时锁死三件事——主控台只能是单体、子控台被推成多排多列阵列、挂旗的墙被大屏挡在画面外。全圈最大杠杆。
- **风格词**：「NASA朋克风格，」立竿见影，调性从明亮机构风直接切到暗舱霓虹。
- **否定词**：「禁止组织Logo」一点就灵，没出现“越禁越画”。
- **群体构成**：统一工装、有男有女、各种年龄体型多样，四条 i2i 样本里三条一次到位。
- **动作序列**：t2v 能把「坐→起立→紧张注视→伸手按」按顺序演完，全镜无跳变，紧张表情稳定不漂。

**不容易对齐**

- **数量语义**：「单独一个总控制台」在 T2 被冲成一排台；「主工程师」在 V1 给成 2–3 人。不加数量词就不锁单数，加了也受采样主导。
- **文字**：不提也会自己加（中文招牌 → 真英文大字报 + 商标 → 胸牌小字）。只能事后否定，不能事前预控。
- **声音**：t2v 出的 mp4 无音轨，广播声只可能被烧成字幕，且烧不烧是随机的（V1 烧了两句，V2 一句没烧）。
- **时间点同步**：「喊到 1 的瞬间按下」在 5s 里不成立，按下始终落在末尾 0.5s。
- **场景连续性**：t2v 无锚会自造场地，与已有总控厅毫无关系——要接场地必须 i2v。
- **固定解**：V2 两张的主工程师是同一名金棕色长卷发女性，锁了单数就锁死了人。
- **性别配比**：同一句「有男有女」，V1 两张一均衡、一偏女。

## 通道行为（本轮新记录）

- t2i（G-2.0 低价）：同组同档 16:9·1k 出**两种像素**（1672×941 / 1360×768）；耗时 54–143s、实扣 10.93–12.28，比 SKILL 旧记录宽。
- i2i（Flux3）：**固定出 2 张**，`72:value=1` 无效、扣费不减半；单次实扣 23.8 / 46.07 / 25.33，**与 n 无关**，预算得按 50 估。
- t2v（MiniMax H3 加速）：5s 档实测 5.167s、124 帧、24fps；同参数实扣 14.28 / 11.73。

## 待优化

1. 数量词要写死（「仅一人、独自」），不能指望默认。
2. 需要干净场地时显式否定文字；需要封闭暗舱时补「不开窗」。
3. i2i 固定出 2 张——只能买两张用一张，或换通道。
4. 要接已有场地与人，走 i2v；声音一律后期。
5. 同 prompt 重跑不是重采样而是换构图解：单张不能当基线，只能当样本。
