## 一、实验设计

Circle11 判「视频通道对小要素归零」是模型边界，但当时用的是「远景 + 地貌卡 7 行全表」，尺度本身就把小要素压没了。本轮把尺度压到近景，把**写法**当成唯一变量，跑三版：

| 版本 | 水系 | 植被带 | 动物种群 | 灵脉与异常 |
| --- | --- | --- | --- | --- |
| v1 静态 | 溪畔泉眼成群 | 谷底灵药田纵横成行 | 林间多走兽与猛禽，谷中驯养灵狐与灵鹤，溪中灵鱼成群 | 原文不动（对照组） |
| v2 动态 | 近岸浅水潭里泉眼汩汩上涌、水面翻起串串水泡 | 谷底灵药田纵横成行，随风翻动起伏成浪 | 浅潭里灵鱼成群跃出水面；岸边石上灵鹤振翅；枫树下灵狐伏卧抬头 | 原文不动（对照组） |
| v3 换词 | 同 v2 | **近岸缓坡上一畦畦灵草药垄整齐排开，草叶随风摆动** | 同 v2 | 同上 |

镜头卡三版完全不动：近景／贴地半人高平视略仰／静止不动／焦点下三分之一前景／无切换，全正向陈述，无任何否定式镜头锁。

## 四、核心发现：元素容量守恒

| 元素 | 图片 | v1 | v2 | v3 |
| --- | --- | --- | --- | --- |
| 泉眼成群 | 无 | 无 | **有** | **有** |
| 巨枫盘根 | 有 | 无 | **有** | 无 |
| 灵狐／灵鹤 | 无 | 无 | **有** | **有** |
| 灵药田／药垄 | 有 | 无 | 无 | **有** |
| 黄枫、瀑布、溪 | 有 | 有 | 有 | 有 |

- v2 与 v3 得分完全相同（3/4），但**命中的行不同**：v2 拿到泉眼＋盘根＋狐鹤，v3 拿到药垄＋泉眼＋狐鹤，**灵脉被药垄挤掉**。
- 结论：**一条 5s 视频的画面容量约等于 3 行**。四行内容全部可画，但装不下同一条。这不是「通道画不出」，而是「镜头近景＋单条的构图预算有限」。
- 灵药田之所以连 v2 都不出，是**词与场景冲突**：「田」被读成人工农田，与原始山谷不符；换成「缓坡上的畦与垄」后立刻出现。

## 五、归因

| 现象 | 归因 | 依据 |
| --- | --- | --- |
| v1 → v2 泉眼、盘根、狐鹤从 0 变有 | **写法问题**，非通道边界 | 同通道、同镜头卡，仅改三行文本 |
| 灵药田 v2 仍 0 → v3 换词后 1 | **词与场景冲突** | 同一位置、同一动态，只换名词 |
| v3 灵脉从 1 掉到 0.5 | **构图容量守恒** | 药垄占左侧缓坡后，巨树盘根消失 |
| 三条视频镜头零位移 | **镜头卡有效** | 各 5 帧零位移 |
| 鹤未振翅、鱼跃存疑 | **单帧动作难抓**，需通看全片复核 | 按抽帧判为部分命中 |

## 六、结论

1. **「视频通道是硬边界」应精确化为「静态名词画不出 + 单条容量约 3 行」**。硬的不是小要素本身。
2. **镜头必须做成结构化镜头卡**：四帧五元组 + 正向陈述，三样本 4/4；否定式镜头锁一律无效。
3. **地貌卡上视频的正确姿势**：卡片裁到镜头可覆盖的行 → 外挂镜头卡 → 小要素全部改写成「有位置 + 带动态 + 与场景不冲突的名词」。
4. **要 4/4 必须拆条**：一条 5s 只装 3 行，需按镜头拆成两条（如「泉眼＋药垄」「盘根＋狐鹤」），或延长到 9–10s。
5. **费用不可预估**：同参数四次实扣 10.90（图）／24.33／11.22／18.53。
