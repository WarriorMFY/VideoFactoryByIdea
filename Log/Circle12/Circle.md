## 口径

- 送验 = 镜头卡全文 + 地貌卡「该镜头可视行」逐字照抄。宏观行（尺度与格局／地形骨架／气候带）本轮**不送、不评**——近景里它们物理上不可见，送了只会把画面拉远，正是 Circle11 的失败原因。
- 两张表分别打分：①镜头五元组（景别／机位／运镜／焦点）是否听话；②地貌卡小要素 4 行是否出现。
- 三档打分 1／0.5／0；≥70% 通过；≥2 样本同项失分才可归因卡问题。

## 本轮核心结论

1. **镜头卡有效**：四帧五元组 + 正向陈述 → 三条视频均 4/4 听话（各 5 帧零位移）。Circle11「否定式镜头锁无效」升级为「否定式无效、结构化正向有效」。
2. **「视频硬边界」应精确化为「静态名词画不出 + 单条容量约 3 行」**：改成动态写法 37.5% → **75%**；但 v2 与 v3 同分且命中行不同（药垄进、盘根出），四行都能画但装不下一条 5s。
3. **灵药田不是画不出，是词与场景冲突**：换「近岸缓坡上一畦畦灵草药垄」后立即出现。
4. 地貌卡上视频的正确姿势：**卡裁到镜头可覆盖行 + 外挂镜头卡 + 小要素全部动态化；要 4/4 必需拆条或延长时长**。
5. 费用不可预估：同参数四次实扣 10.90（图）／24.33／11.22／18.53。
