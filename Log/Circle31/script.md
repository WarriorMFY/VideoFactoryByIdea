# 剧本 · 锈日（15s / 3 镜 / 无声）

## 一句话

废弃厂房里，一台锈蚀的旧款人形服务机器人重新通电、起身，第一次抬头看向天光。

## 视觉设定

| 项 | 值 |
| --- | --- |
| 风格 | 复古未来主义：胶片颗粒 + CRT 扫描感 + 轻微色散；暖橙 × 青绿双色板 |
| 场景 | 倒塌的厂房内部，锈蚀钢梁，破口漏下天光，地面薄尘与碎砖 |
| 主体 | 人形旧款服务机：圆顶头、单条横向传感器、胸口圆形指示灯、关节裸露线缆、外壳斑驳 |
| 机位 | 低机位为主，贴近地面；镜头克制，不炫技 |
| 光 | 唯一光源＝顶部破口的天光，青绿冷调；机器人指示灯为暖橙点光 |

## 三镜

| 镜 | 时长 | 内容 | 戏眼（必须成立） | 类型 |
| --- | --- | --- | --- | --- |
| 1 | 5s | 躺在地上的机器人静止；胸口指示灯由灭转亮，手指轻微抽动 | 指示灯亮起 | 定点微动 |
| 2 | 5s | 撑地，缓慢坐起，再站直；尘土滑落 | 身体到站姿终态 | 位移 |
| 3 | 5s | 站定，头部缓缓抬起，正对镜头；天光落在面部 | 头部抬起并注视 | 定点微推 |

## 约束

- 全片无对白、无字幕、无文字招牌（靠正面描述「素净墙面」规避）。
- 单镜一条 5s，不做尾帧；镜 2 的起身必须一镜完成（不拆两段）。
- 缝接只允许硬切，不做叠化。
