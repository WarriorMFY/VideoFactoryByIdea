# 视频生视频 · 真正可跑的通道（社区 webapp）

> 只读探查，零积分。数据源：`/api/search/workflow`（站内搜索，POST，带 KEY 可读）+ `/api/portal/workflow/detail`。
> 前一份 `v2v-interfaces.md` 查的是**标准 API 目录**（本账号 apiType=NORMAL，不可用）；本文查的是**市场里真正能调的工作流 app**。

## 一、技能目录现状（`Skill/hub/generation/workflow/`）

四桶六技能，**没有 video-to-video 桶**：

| 桶 | 技能 | 通道 |
| --- | --- | --- |
| text-to-image | t2i-probe | 写死 webappId 的对照实验台 |
| image-to-image | i2i-probe、flux3-edit | 同上 / Flux3 Kontext 编辑 |
| image-to-video | i2v-probe、wf-firstlast | MiniMax H3 首帧 / VACE-Fun 首尾帧 |
| text-to-video | t2v-probe | 文生视频对照台 |

共同模式：`SKILL.md`（通道表+判据）+ `scripts/`（probe/measure/retime，webappId 写死）+ `reference/`；一次一账，出口统一走 `runninghub/scripts/runninghub_app.py`。
**结论：要做视频生视频，得照这个模式新建第五桶 `video-to-video/`。**

## 四、费用

- **webapp 没有价格接口**：试了 10 条候选路径（`/api/portal/webapp/*`、`/api/portal/template/detail` 等）全部 404；`/api/openapi/*` 返回 412 TOKEN_INVALID（标准 API 本账号不可用）；detail 里也无 price/cost/fee 字段。
- 页面能看到的「运行消耗」不进 API。**唯一可靠办法：实跑一条记账**（跑完读 `/user/current` 余额差）。
- 估算锚：同为本机跑的本地工作流，`i2v-probe` 5s/0.6MP 实扣 21.4 积分/条；Animate 14B 这类重节点、多段采样，按 2–3 倍估（约 40–70 积分/条 5s）。
- 标准 API 目录价仍在 `v2v-interfaces.md`（15 个有价，如可灵 o3 std ¥0.81/秒、PixVerse V6 ¥0.16/秒），但本账号调不了。

## 六、口径

- 有 app 才可脚本化调用；没 app 的只能网页复制工作流，进不了 i2v-probe 式「一条一账」。
- 先小成本验证 1 条（如 SeedVR2 超分），拿到真实实扣再决定第二条——与 v2 铁律「先量后看、一条一账」一致。
