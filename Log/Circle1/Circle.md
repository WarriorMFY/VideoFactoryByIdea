## 2 · 与模型的对齐度

| 容易对齐 | 依据 |
| --- | --- |
| 线条（无描边、硬边） | 两轮都成立，空镜里建筑与石阶边缘也锐利 |
| 色彩（低饱和青灰＋锈红点缀） | 两轮都成立，色调与点缀稳定 |

| 不容易对齐 | 依据 | 原因 |
| --- | --- | --- |
| 材质渲染（写实厚涂、金属与织物） | 空镜版整体剪影化，材质全不可见；静物版全部可见 | **取决于载体**：卡里没写「画面上有什么物件」 |
| 光影硬度（单侧硬主光） | 空镜版偏柔，静物版成立 | 同上，空镜没有可承光影的近景表面 |
| 明暗关系（主体亮、背景暗） | 空镜版完全反转 | 剪影一动，明暗前提就不存在 |

## 3 · 硬结论

1. **失败先查送验环节，别先改卡。** 一个卡外词 `simple silhouette` 同时打崩材质、光影、明暗三项，看起来像「卡不准」，实为编译错误。对应表漏一条＝没做。
2. **载体是细节层的开关。** 同一张卡，空镜只出氛围，静物载体激活全部材质项——验画风卡必须给近景可触物。
3. **中文 Prompt 完全可行。** 31 个中文短语全部落到图上，无一错位；英文版风格一致、细节更少，翻译是纯增熵。
4. **卡片零改动也是结论。** 两次失败都归因于送验，卡本身无需改——这条定了后续「卡是唯一真相」的调子。
