### 5 · 归因（DONE）

结论：**不是卡的问题，是 Prompt 编译错误。**

`prompt.txt` 第 1 行含 `simple silhouette`，该词不存在于卡片任何一行，是送验时自行加入的。模型照做，把主体压成纯剪影，连带遮蔽材质渲染，并把明暗关系反转为「主体暗、背景亮」。

更严重的是：该词没有被登记进 `submit.md` 的对应表，是漏登。对应表漏一条，就等于没做。

| 归因类别 | 判定 | 理由 |
| --- | --- | --- |
| 卡不准 | 否 | 其余四项与卡一致 |
| 模型不能 | 否 | 模型忠实执行了 Prompt |
| 工作流不对 | 否 | Lite 通道与参数无异常 |
| Prompt 编译错误 | 是 | 混入无来源词 |

第 2 轮五项均通过，无需归因。三条可复用结论：
