## 结论（按重要性）

1. **接口分档成立**：`image-to-video` 72 个里只有 37 个纯首帧，23 个首尾双锚；**420 个接口 MASK 类型为 0**，抠图/分割没有原生接口，必须本地做。
2. **不必建企业号**：Model API / LLM API 限 Enterprise，但 AI App API 与 Workflow API 对普通号开放。
3. **API 能"跑"自己的图，不能"存"自己的图**：`workflow` 字段整份塞图 + 占位 `workflowId` 即可，`code=0` 已验两次。
4. **双锚约束力实测**（同一对锚，中心裁 16:9）：

| 通道 | 首 × 起点锚 | 末 × 掠过锚 |
| --- | --- | --- |

| 市场应用 `2103693788333039617` | 0.9303 / 0.8011 | 0.7390 / 0.7578 |

→ 尾端从 0.74 抬到 0.99，是本轮最大收益；**中段不受两端约束**（悬崖背景照旧漂移）。
