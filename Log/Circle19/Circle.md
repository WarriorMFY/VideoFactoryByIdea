## 结论

### 一、本轮立下的规则

| 层 | 出链 |
| --- | --- |
| 基础层 `Doc/` `Tool/` | 无出链 |
| 原料层 `Log/` | 只读 `RAG/` 数据 |
| 成品库 `RAG/` | 只描述自身归档规则 |
| 专用层 `Skill/` | 只向 `Tool/`（代码）、`Doc/`（理念）、`Skill/hub/`（共享） |

三条配套判据：

1. **生成／剪辑的分界**从「模型 vs 算法」改为「同一输入重跑输出是否唯一」——不唯一（采样）归 generation，唯一（确定性重组）归 editing。看采样不看模型，未来本地跑扩散模型也不会失效。
2. **凭据单点**：`Skill/hub/generation/runninghub/credential.txt` 全库唯一，链侧 `credential.py` 只做 6 行转发。
3. **技能自包含**：样本进 `meta/smoke-test/fixtures/`，不再读 `Log/` 历史文件；产物写到当轮 `Log/Circle<N>/` 属输出，不算引用。

### 二、卡片与模型对齐度（本轮迁移固化的既有实测，非本轮新跑）

**容易对齐**：

| 维度 | 实测 |
| --- | --- |
| 因果事件链 | 事件级接近 100%，撑篙→落水→空船按序全中 |
| 状态句 | 「静止」「固定机位」「无剪辑」Circle10／14 均成立 |
| 结果态 | 终帧可判定时最稳，K4 终态 4/4 |
| 首帧像素锚 | 对源图 NCC 0.956，但只活在第 0 帧 |
| 段结构 | 分镜卡段数／段序 3/3 条命中 |

**不容易对齐**：

| 维度 | 实测 |
| --- | --- |
| 时间点 | 6 个请求切点 0/6 命中，偏差 12–29 帧；同 prompt 切点噪声 6–8 帧 |
| 精确数值 | 脸宽 70%、唇厚 0.08 从未兑现 |
| 左右手 | 模型换手但动作逻辑不误——只有动作，没有解剖 |
| 否定式约束 | 「无痣无斑」仍出痣；「不见裸肩」极特写下失效 |
| 氛围词 | 只驱动它附着的可见物，无载体即空转 |
| 跨景别比较 | 换 L4 即换渲染域，0.923 的簇对样张只有 0.47–0.61 |

一句话：**语言管得住「发生什么」和「别动」，管不住「长什么样」和「第几秒」。**
