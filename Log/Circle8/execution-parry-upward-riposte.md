# 动作卡 · 上格反撩（格挡转反击）

> 左列＝关键帧（帧号 / 阶段 / 进度），右列＝该帧可观测动作，五段顺读：角色 → 武器/接触 → 目标 → 位移 → 同步。
> 主体A施动、主体B受动；本卡不指定画风、镜头与台词。

## 关键帧

| 关键帧 | 动作状态 |
| --- | --- |
| K0 / 起势 / 0% | 角色=主体A刀在身前斜持45°、重心沉在后脚，主体B刀举过头顶蓄势；武器/接触=无接触，两刀相距约1.2步；目标=双方各自锁住对方中线，尚未交手；位移=双方站定，间距不变；同步=主体B刀举到最高点的同一拍，主体A后脚落实 |
| K1 / 接刀 / 20% | 角色=主体B下劈落刀，主体A抬刀斜向上迎、刀刃朝外；武器/接触=主体A刀身中段接住主体B刀身前段并压向其右外侧，接触在落刀瞬间成立，接触点停在中线偏右；目标=主体B的下劈被顶停、劈不到底；位移=主体A后脚承重不退，主体B前压半步；同步=刀落触刀与主体A沉肩同一拍 |
| K2 / 压刀 / 45% | 角色=主体A沿接触点下压并向外送，主体B双手被压得下沉；武器/接触=接触由顶住转为滑压，主体B的刀被推离中线约一肩宽；目标=主体B门户打开、右腹肋暴露；位移=双方原地，主体B上身前倾、肩线转过15°；同步=压刀到底与主体B躯干前倾同一拍 |
| K3 / 反撩 / 75% | 角色=主体A借压刀反力转腕，刀尖自下而上撩出；武器/接触=主体A刀刃中段撩中主体B右下腹肋，形成第二接触点，主体B的刀已被甩在外侧；目标=主体B受撩抬身、咽喉暴露、双手松刀；位移=主体A前脚进半步、重心贯穿，主体B后撤半步并仰身；同步=刀刃触腹与主体B抬身同一拍 |
| K4 / 收势 / 100% | 角色=主体A撩势走完、刀尖上扬后收回胸前防御位，主体B捂腹脱手；武器/接触=无接触，两刀分离、主体B的刀脱手落地；目标=主体B失衡后撤，失去反击能力；位移=主体A退半步稳桩，主体B连退两步；同步=主体A收刀定式的定格与主体B第二脚落地同一拍 |
