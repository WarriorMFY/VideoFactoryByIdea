# 肖像一致性评价指标 v0.1

> 问题：同一张肖像卡（`figure-veiled-cartographer`）用同一 Prompt、同一参数独立生成两次视频，两次里的「人」是不是同一个。
> 原则：**指标不靠人眼自由裁量，断言从卡里解析出来**。卡是唯一真相源，指标只是卡上每一格的收敛度。

## 0 两个前提

| 项 | 约定 |
| --- | --- |
| 变量控制 | 同一 `card.md`、同一 Prompt 文本、同一模型与应用版本；唯一变量是平台随机性（seed／实例） |
| 分层 | **卡→片 符合度**（每片是否兑现卡）与**片→片 一致性**（两片是否互相同）分开测，不混算 |

为什么必须分开：两片都符合卡，不等于两片互相像——卡没写的维度（具体五官形状、眉间距）本来就自由。混成一个分会把「卡写得不够细」误判成「模型不稳定」。

## 1 指标总表

| ID | 指标 | 测什么 | 数据来源 | 通过阈值 | 计分 |
| --- | --- | --- | --- | --- | --- |
| M1 | 锚点复现率 ARR | 卡里 `特征=` 段的断言，两片是否都兑现 | 逐帧目视＋截图 | ≥ 0.80 | 权重 0.45 |
| M2 | 可判率 CR | 锚点中有多少在帧内可辨（遮挡、出画即不可判） | 同上 | ≥ 0.60；低于则整份报告作废 | 不作权重，作门 |
| M3 | 颜色保真 | 卡指定的色相／明度关系，跨片是否稳定 | 像素取样 → Lab | ΔE00 ≤ 6 且色比同序 | 权重 0.20 |
| M4 | 比例偏差 Pb | 卡给了数值的比例（肩宽 2.2 头高、眼距 0.36 脸宽等） | 正脸帧像素测量 | 跨片相对偏差 ≤ 10% | 权重 0.20 |
| M5 | 锚点位置偏移 Sp | 烧伤、纵疤、布条、圆规的位置 | 归一化坐标（以脸宽为单位） | ≤ 0.05 脸宽 | 权重 0.15 |
| M7 | 片内时序漂移 TD | 单片内首／中／末帧的锚点偏移 | 同 M5，逐帧 | ≤ 0.08 脸宽 | 记录，不计分 |
| M8 | 结构相似 SSIM／LPIPS | 几何对齐后的像素级相似 | 工具层 | SSIM ≥ 0.72 或 LPIPS ≤ 0.18（**待标定**） | 工具层，暂不计分 |
| M9 | 人脸身份相似 | ArcFace embedding 余弦 | 工具层 | ≥ 0.45（遮脸时为 N/A） | 工具层，暂不计分 |
| M10 | 自由度漂移 DF | 卡未锚定维度的跨片差异 | 两片盲比 | 无阈值，只记录 | 不计分 |

M8／M9 标「待标定」，是因为这张卡半张脸被布条遮住，人脸检测大概率丢失遮布侧半脸，ArcFace 的分数会失真；先用 M1–M5 与 M7 跑通一轮，再决定是否引入。

**M6 已废除**（2026-11-16）：现有模型对左右侧别的识别不可靠，判不出的东西不能进总分，所以整个指标项取消，不以「权重转小」的形式保留。编号不重排，M6 位置留空，避免旧记录引用错位。卡内左右表述已在 `spec.md` 全局规则 1 中禁用，侧别错位改由 M1 的成对关系断言承担（例：「烧伤在同一侧且与遮布侧相邻」）。

## 2 断言从卡里来（规格驱动的落点）

指标不自己造判断对象，全部由卡解析：

| 卡内键 | 自动归到 | 说明 |
| --- | --- | --- |
| `特征=` 含「左／右」 | 规则 1 违规 | 不计入指标；按 `spec.md` 全局规则 1 改写为关系式，否则不入库 |
| `特征=` 其余 | M1 | 锚点，逐条判「兑现／未兑现／不可判」 |
| `比例=` | M4 | 抽成比值，量化测量 |
| `颜色=` | M3 | 抽成色相／明度，转 Lab 比 ΔE |
| `材质=` | M1 | 材质可辨性（亚麻 vs 熟铁 是否分得开） |
| `外形=` | M1 | 几何形状断言 |

由此每张卡自动产出一张断言清单，编号 `R<行号>.<键>.<序号>`，例如 `R4.特征.2`。解析脚本：`extract_assertions.py`。

## 3 抽样与对齐（数字成立的前提）

| 规则 | 内容 |
| --- | --- |
| 抽帧 | 每片取 0／20／40／60／80／100% 六个点，外加全部「正脸可判帧」，每片不少于 5 帧 |
| 正脸判据 | 偏航角 \|yaw\| ≤ 15°，否则该帧对 M3／M4／M5 记不可判 |
| 尺度归一 | 以眼距或头高归一，禁止用像素绝对值跨片比较 |
| 姿态对齐 | 禁止拿 A 片低头帧与 B 片正脸帧比位置；姿态不同就先标「不可比」，不判 FAIL |
| 光照 | 不做白平衡校正，改用**相对色比**：以布条（亚麻灰）为基准，比「肤色 − 布条」「赭红领口 − 布条」的 Lab 差值向量 |

## 4 计分

各项先按阈值线性归一：达标 = 1，2 倍阈值外 = 0。

```
Score = 100 × ( 0.45·f(M1) + 0.20·f(M4) + 0.20·f(M3) + 0.15·f(M5) )
```

| 等级 | 分数 | 处置 |
| --- | --- | --- |
| 一致 | ≥ 85 | 可视为同一人，卡可复用 |
| 基本一致 | 70–84 | 同人但需人工二次确认，记录漂移维度 |
| 不一致 | < 70 | 判为两次不同形象，卡不改则不可复用 |
| 直接否决 | 任一成立 | M1 < 0.80；M2 < 0.60 —— 不看总分 |

M6 原有的 0.20 权重这样分：M1 从 0.35 升到 0.45（锚点是身份的主干），M3／M4 各从 0.15 升到 0.20（颜色与比例是本卡唯一写死到数值的两项）。

## 5 报告格式

逐行对照，不放总评先行：

| 断言 ID | 部位 | 断言 | 片A | 片B | 跨片 | 偏差 | 判定 |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `R1.特征.1` | 整体轮廓 | 遮布侧下颌至耳根被布条压住 | 是 | 是 | 同关系 | 0.02 脸宽 | PASS |

尾部汇总：ARR／CR／Pb／ΔE／Sp／Score／等级／归因。

## 6 归因（决定下一步改什么）

| 情形 | 归因 | 动作 |
| --- | --- | --- |
| 两片都兑现，跨片一致 | — | 该锚点稳态，无需动 |
| 两片都兑现，但位置差大 | 卡写了「有」，没写「多大、在哪」 | 卡欠定义 → 补数值 → hash 变更 → 证据重跑 |
| 一片兑现一片不兑现 | 平台随机性 | 记 Task ID 与 seed，累计多次看命中率 |
| 两片都未兑现 | 卡写得不可渲染，或 Prompt 稀释 | 先查 Prompt 是否覆盖该格，再改卡 |
| 成对关系错位（布压在一侧，疤却在对侧） | 卡把两部位分开写，未写相对关系 | 卡内补两部位的位置关系 → hash 变更 → 证据重跑；不追写左右 |

## 7 与卡的关系

指标不改卡。只有当 M1 因「卡欠定义」掉分时才改卡，而改卡即破 hash（`RAG/README.md` §四），旧证据自动失效——所以这张卡目前留在 `Log/Circle8/`，验完再决定是否入库 `RAG/figures/`。
