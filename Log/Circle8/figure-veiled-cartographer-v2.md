# 肖像卡 · 蒙面制图师（半身）

> 侧别基准：布条压住的一侧称「遮布侧」，露出单眼的一侧称「露眼侧」。全卡只用这两个名字定位，镜像后关系不变。
> 布条是全卡唯一的方向锚，其余所有成对部位都挂在它上面。

## 部位

| 可视部位 | 该部位的可观测外观 |
| --- | --- |
| 整体轮廓 | 外形=窄肩长颈、头部前倾约10°、肩线平直；比例=肩宽约2.2头高、颈长0.35头高、下颌到锁骨0.5头高；颜色=亚麻灰60°/18%为底、皮革褐25°/22%、黄铜40°/55°点缀；材质=粗织亚麻、鞣制牛皮、氧化黄铜；特征=布条从遮布侧下颌斜压到该侧耳根，把这一侧下颌线压成斜线，露眼侧下颌线完整外露 |
| 头骨与脸型 | 外形=长方脸、颧弓外扩、下巴方正；比例=脸长1.4头高、脸宽0.75头高、下颌角外翻约120°；颜色=肤色黄褐30°/62%、颧部再暗5%；材质=皮肤亚光、T区微油；特征=遮布侧颧弓上方、布条上缘之上露出的那块皮肉有鸡蛋大的旧烧伤，表面光滑反光 |
| 眼部与眉弓 | 外形=眉弓低平、眼窝浅、内眦略下垂；比例=眼裂长约0.32脸宽、两内眦间距0.36脸宽；颜色=虹膜深褐20°/25%、巩膜象牙白；材质=角膜高光锐利、下眼睑有细纹；特征=露眼侧上睑一道纵疤把该侧眉毛切断，遮布侧整只眼被布条盖住，只余布下眼窝的隆起 |
| 鼻口与下颌 | 外形=鼻梁直、鼻头圆钝、唇薄而紧抿；比例=鼻长0.33脸高、鼻翼宽0.28脸宽、唇厚0.08脸高；颜色=鼻头与唇色偏红10°/45%；材质=鼻翼毛孔可见、唇部干裂起皮；特征=下唇一道白色旧疤自中线斜向露眼侧延伸约半个唇宽，疤尾停在唇角 |
| 皮肤与须发 | 外形=短发贴头皮、下颌胡茬断续；比例=发际线距眉弓0.5脸高、鬓角连至耳根；颜色=发色近黑0°/8%、胡茬青灰；材质=发丝粗硬、皮肤干燥起屑；特征=露眼侧鬓角有一撮灰白，胡须在下巴处断成两簇 |
| 衣领与配饰 | 外形=立领对襟、单肩加厚护片，护片只装在露眼侧；比例=立领高0.25头高、护片盖住该侧肩宽1/3；颜色=领口内衬赭红15°/35%、护片铁灰0°/30%；材质=麻衬里、熟铁铆钉、粗麻缝线；特征=颈侧挂黄铜圆规一副，圆规与遮布侧同侧，链子垂到锁骨 |
