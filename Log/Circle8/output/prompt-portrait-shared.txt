# 肖像卡 · 对称正脸（纯脸部）

> 只描脸部本体：骨相、比例、五官、肤质。脸以外的信息一律不写，画面裁到只剩脸。
> 全卡只写两侧一致的特征，不设任何单侧细节；既然两侧无差别，翻面也不产生差异。

## 部位

| 可视部位 | 该部位的可观测外观 |
| --- | --- |
| 脸型与轮廓 | 外形=长方脸、颧弓外扩、下颌线内收成方下巴；比例=脸高比脸宽约1.4:0.75、颧弓最宽处落在中庭、下颌角两侧均外翻约120°；颜色=肤色黄褐30°/62%、额与颊明度差不超过3%；材质=皮肤亚光、面颊饱满不凹陷；特征=中线把脸分成相等的两半，两侧颧弓高度与下颌角角度一致，脸缘无歪斜 |
| 颅颌比例 | 外形=额部平直、颞部不凹陷、颅顶圆整；比例=三庭等比1:1:1、中庭占0.33脸高、两颧间距0.75脸宽；颜色=额部微亮、颞部略暗，与颊部的明度差同值；材质=皮下脂肪均匀、无凹陷无浮肿；特征=三庭分界水平、两颧对称、颅与颌的中线同轴 |
| 眼部与眉弓 | 外形=眉弓低平、眼窝浅、眼型偏长、内眦略下垂；比例=眼裂长约0.32脸宽、两内眦间距0.36脸宽、两眼等高；颜色=虹膜深褐20°/25%、巩膜象牙白；材质=角膜高光锐利、下眼睑两道细纹；特征=两侧眉形与眉粗完全一致，双眼平视镜头，无遮挡无斜视，眼周无痣 |
| 鼻部 | 外形=鼻梁直、鼻头圆钝、鼻翼不张；比例=鼻长0.33脸高、鼻翼宽0.28脸宽、鼻梁宽0.12脸宽；颜色=鼻头偏红10°/45%；材质=鼻翼毛孔可见、鼻背皮肤薄；特征=鼻梁沿中线不歪，两侧鼻翼等大，鼻尖居中，鼻面无斑 |
| 口唇与下巴 | 外形=唇薄而紧抿、唇线清晰、下巴方正居中；比例=唇厚0.08脸高、口宽0.42脸宽、下巴高0.12脸高；颜色=唇色偏红15°/45%、唇缘略深5%；材质=唇面干裂起皮、下巴皮肤平滑；特征=唇峰与唇谷居中，嘴角两侧等高，唇面与下巴无疤 |
| 皮肤与纹理 | 外形=面颊饱满、法令线浅；比例=纹理密度两侧取样一致、毛孔直径约0.004脸宽；颜色=肤色黄褐30°/62%、T区油光呈中性灰高光；材质=皮肤亚光、T区微油、毛孔可见、干燥起屑；特征=两侧纹理与光泽一致，面上无痣无斑无疤，无单侧高光差 |
