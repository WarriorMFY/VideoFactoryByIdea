# 肖像卡 · 蒙面制图师（半身）

> 左列＝可视部位，由整体轮廓排到局部配饰；右列＝该部位的可观测外观，五段顺读：外形 → 比例 → 颜色 → 材质 → 特征。
> 本卡是半身肖像，不含动作、场景与镜头，也不指定画风。

## 部位

| 可视部位 | 外观状态 |
| --- | --- |
| 整体轮廓 | 外形=窄肩长颈、头部前倾约10°、肩线平直；比例=肩宽约2.2头高、颈长0.35头高、下颌到锁骨0.5头高；颜色=亚麻灰60°/18%为底、皮革褐25°/22%、黄铜40°/55%点缀；材质=粗织亚麻、鞣制牛皮、氧化黄铜；特征=右侧下颌至耳根被布条斜向压住，剪影左右不对称 |

| 眼部与眉弓 | 外形=眉弓低平、眼窝浅、内眦略下垂；比例=眼裂长约0.32脸宽、两眼间距0.36脸宽；颜色=虹膜深褐20°/25%、巩膜象牙白；材质=角膜高光锐利、下眼睑有细纹；特征=右眼上睑一道纵疤把眉毛切断，右眼是唯一露出布外的五官 |

| 皮肤与须发 | 外形=短发贴头皮、下颌胡茬断续；比例=发际线距眉弓0.5脸高、鬓角连至耳根；颜色=发色近黑0°/8%、胡茬青灰；材质=发丝粗硬、皮肤干燥起屑；特征=右鬓角有一撮灰白，胡须在下巴处断成两簇 |
| 衣领与配饰 | 外形=立领对襟、右肩单侧加厚护片；比例=立领高0.25头高、护片盖住肩宽1/3；颜色=领口内衬赭红15°/35%、护片铁灰0°/30%；材质=麻衬里、熟铁铆钉、粗麻缝线；特征=颈侧挂黄铜圆规一副，链子垂到锁骨 |
