# 固定变量卡 · 肖像（配 figure-symmetric-cartographer）

> 本卡只管怎么拍，不管拍谁：画幅、机位、光照、景深、背景全部在这里定死，基础卡一条都不重复。
> 冲突时以肖像卡为主：画面让步，长相不让步。
> 用法：第二列逐条首尾相接成一段，整段置于基础卡正文之前送出。

## 变量

| 变量 | 固定语句（原样送验） |
| --- | --- |
| 优先级 | 当肖像描述与固定变量冲突时，以肖像描述为主。 |
| 画幅 | 3:4 竖幅，脸宽占画面宽度的 70%，下巴距画面底边 2%，画面最上缘正好落在发际线上、其上不出现头发。 |
| 遮挡 | 画面内不出现颈部、肩部、衣领与饰品。 |
| 机位 | 85mm 人像镜头，与面部等高正对鼻梁中轴，水平偏转与俯仰偏转均为零度。 |
| 视线 | 双眼平视镜头，瞳孔落在眼眶中央，不斜视、不闭眼、不看画外。 |
| 表情 | 中性表情，不笑不怒不讶异，双唇轻闭合，眉不上扬也不皱。 |
| 光照 | 正面均匀柔光，鼻梁与两颊的高光沿中线对称，不设侧光、顶光与逆光。 |
| 背景 | 中性灰纯色背景，无渐变、无纹理、无道具、无投影。 |
| 景深 | 从额部到下巴全脸等清晰，不出现虚化。 |
| 风格 | 写实摄影质感，毛孔与干裂唇纹清晰可辨，不磨皮、不美颜、不做风格化。 |
| 排除 | 画面内不出现文字、表格、分栏、边框、水印与标识，只出现一张脸，不出现拼接与多视角。 |
