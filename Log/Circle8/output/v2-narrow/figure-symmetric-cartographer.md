# 肖像卡 · 对称正脸（纯脸部）

> 只描脸部本体：骨相、比例、五官、肤质。机位、光照、表情、画幅交给伴生卡，本卡一条不写。
> 全卡只写两侧一致的特征，不设任何单侧细节；既然两侧无差别，翻面也不产生差异。
