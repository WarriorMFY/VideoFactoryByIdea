# 镜头卡：防反·推掌辅助镜头（一卡一绑版 v2）

> **【对齐声明】**：本卡为一对一派生态辅助镜头卡，只服务绑定指纹 `3292E2510FB9` 的五帧动作卡，不作通用复用。K0–K4 与该动作卡**同号同进度、逐帧一一对应**，无映射、无缺帧。两者同为关键帧表结构，逐帧对齐。镜头只做强化：放大高光，掩掉模型会变形的动作，并交代攻守先后。冲突时以动作卡为准。

## 关键帧列表

| 关键帧（自变量：帧号/阶段/进度） | 镜头状态（因变量：可观测镜头描述） |
|---|---|
| K0 / 起幅 / 0% | 景别=中景、双人膝上；机位=正侧80°、稍高于肩；运镜=极缓推0.05m/s；焦点=双人之间空处；切换=无切换 |
| K1 / 迎拳 / 10% | 景别=中近景；机位=正侧80°、肩高；运镜=随主体B的拳快速横移、到接触点即停；焦点=中线上的接触点；切换=无切换 |
| K2 / 拨开 / 40% | 景别=近景；机位=正侧80°、肩下；运镜=0.35s横摇带过手部；焦点=主体B的躯干；切换=无切换 |
| K3 / 推掌 / 70% | 景别=近景、腰上；机位=正侧80°、仰拍、降至胸高；运镜=推至静止、命中顿0.2s；焦点=主体B的上胸至下颌；切换=无切换 |
| K4 / 击飞 / 100% | 景别=中景转中远景；机位=正侧80°、升至俯拍40°；运镜=后拉升高、末帧定格；焦点=双人全身与地面；切换=无切换 |
