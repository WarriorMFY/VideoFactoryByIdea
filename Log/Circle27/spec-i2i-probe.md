## 五、提示词层

- 模板：`把<目标变量>改为<档位>；其余全部保持不变：<逐项锁定清单>`。
- 锁定清单逐项点名：主体外形与位置、构图、景别、光线方向与色温、画风与笔触、细节、文字。
- 一条只描述一个变化；禁止「优化／美化／提升清晰度」类词（Circle24 实证会触发磨皮）。
- 每条 prompt 落 `prompts/<run-id>.txt` 并记 `prompt_sha1`；同组锁定段逐字一致，只换目标句。

## 六、度量／判定层

| 指标 | 算法（OpenCV/numpy） | 回答什么 |
| --- | --- | --- |
| `ncc_global` | 灰度归一化互相关 | 整体像不像原图 |
| `ssim_gray` | 灰度 SSIM | 结构保真 |
| `edge_ssim` | Canny 边缘图 SSIM | **构图锁定**（对光线/画风变化更鲁棒） |
| `luma_mean` / `luma_std` | 亮度均值／方差 | 光线是否按预期变 |
| `sat_mean` / `hist_l1` | 饱和度均值／色彩直方图 L1 距离 | 画风/色彩漂移 |
| `lap_var` | 拉普拉斯方差 | 锐度/笔触变化 |
| `face_ratio` | Haar 人脸框高 ÷ 图高 | 景别代理（人物锚） |
| `text_keep` | 目检布尔 | 文字/字幕是否保住（通道硬指标） |

- **目标变量达成**：该变量代理指标相对基线变化达到初值阈值（景别 `face_ratio` ±20%；光线 `luma_mean` ±10%；画风 `hist_l1` ≥0.15 且 `sat_mean` 明显变；表情/视角/道具走人工三档判定）。
- **非目标漂移**：`edge_ssim` ≥0.90 无／0.80–0.90 轻微／<0.80 明显；画风组对 `edge_ssim` 放宽（画风变化必然动纹理），改看主体轮廓与构图位置。
- 首轮跑完用基线校准上述阈值，校准记录写进报告。
- 顺序铁律：先出数字，再人工看片（两两对照三联图：锚｜输出1｜输出2）。
