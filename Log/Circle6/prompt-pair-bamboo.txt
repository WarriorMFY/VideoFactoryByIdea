# 动作卡：防反·拨开推掌（交互事件导向版 v2）
> **【兼容性声明】**：本卡不限制主体A用哪只手格挡、哪只手推击，只要求“先接触格挡，后向外拨开，再推中胸口中线”的因果顺序成立，即为合格生成。
## 关键帧列表
| 关键帧（自变量：帧号/阶段/进度） | 动作状态（因变量：可观测动作描述） |
|---|---|
| K0 / 起势对峙 / 0% | 角色=主体A与主体B相对而立、间距约一臂，双方双脚站立、重心居中，主体A的防御手收在胸前、尚未抬起，主体B的主攻手握拳收在身前；武器/接触=双方**无接触**；目标=尚未交手，双方均未受力；位移=双方站定，间距保持不变；同步=双方各自戒备，无人先行 |
| K1 / 迎拳与格挡 / 10% | 角色=主体B重心前压、主攻手朝主体A中线挥出重拳，主体A重心微沉，在拳到之前把防御手自胸前向前迎出、掌心朝向来拳；武器/接触=主体B的来拳撞在主体A防御手的前臂上、被顶停，格挡在接触的这一刻成立；目标=主体B的出拳在中线前被截住、无法继续前送；位移=主体A脚下不挪位、只有防御手向前递出，主体B的拳停在接触点；同步=主体A的手迎出的同时主体B的拳到达，两者在接触点相遇 |
| K2 / 拨开门户 / 40% | 角色=主体A的防御手贴住来拳向外侧拨开，主体B的手臂被带偏、胸前空档暴露；武器/接触=接触由格挡转为**拨带**，主体B的小臂被拨离中线；目标=主体B的上半身被带得歪斜、重心前倾；位移=双方仍原地，主体B上身向侧面偏转；同步=拨开与主体B躯干歪斜在同一拍发生 |
| K3 / 推掌命中 / 70% | 角色=主体A的进攻手（掌）自中线直线推出，掌心朝向主体B，重心随之前压，主体B躯干尚未回正；武器/接触=主体A的掌心推中主体B**胸口正中**（接触的高光瞬间）；目标=主体B胸口受力，上半身猛烈后仰、双脚离地；位移=主体A蹬地前送、重心贯穿，主体B开始向后腾起；同步=掌根贴住胸口与主体B后仰在同一拍 |
| K4 / 击飞与收招定势 / 100% | 角色=主体A保持推击余势，掌心前伸，重心下沉稳固站立，主体B躯干向后倒飞、四肢因惯性松展；武器/接触=**无接触**，主体A的进攻手已脱离主体B胸口，双方拉开明显距离；目标=主体B向后砸向地面，彻底失去反抗能力；位移=主体B向后大幅度位移并触地，主体A支撑脚落地定住重心；同步=主体A的收势定格与主体B背部触地扬尘的瞬间同步 |

# 场景卡：晨雾竹林（一卡一绑版 v1.0）

> 自变量轴：空间层级（由大环境到空气介质）
> 因变量轴：环境状态（五元组定序：场地 → 地面 → 环境物 → 光线 → 大气）
> 实体约定：本卡只写「在哪打、光怎么落」，不写角色动作；受力响应只写环境一侧的变化。

| 空间层级（自变量：层级/对象） | 环境状态（因变量：可观测置景描述） |
| --- | --- |
| 场地 / 0 | 场地=竹林深处的林间空地、四周被立竹围合、无建筑无围墙无观众；地面=整片空地铺青石板、板缝间积薄层细土与干竹叶、向远处缓坡抬升；环境物=四周立竹直径 6–10 cm、高处竹冠交叠遮天、散布三两块苔石与一座石灯笼、无旗无器械；光线=清晨柔光自竹梢间隙斜落、全场无人工光源；大气=贴地薄雾、空气湿润、无雨 |
| 地面 / 1 | 场地=本层只指脚下承载面、不涉及林间纵深；地面=青石板表面微磨光、板缝间积 2–3 mm 细土与碎竹叶、落叶干脆易碎、无积水无泥；环境物=石缝生青苔、苔面湿润、板面散落几片枯竹叶与细枝；光线=石板受光呈青灰、缝隙与苔面压暗、光斑碎落在板面；大气=受踩踏与冲击时板缝浮土与碎叶扬起、扬起高度 10–20 cm、停留约 1 s 后落回 |
| 环境物 / 2 | 场地=背景竹林纵深 8–15 m、与前景同一种竹；地面=背景地面被落叶覆盖、青石板渐隐入林；环境物=竹竿直立成排、中景三两根竹竿略倾斜、苔石高约 0.6 m、石灯笼高 1.0 m 表面生苔、无门无窗无牌匾；光线=竹竿被侧光勾出亮边、背光侧沉入暗绿；大气=薄雾在竹林间分层、远处竹竿渐淡、形成纵深层次 |
| 光线 / 3 | 场地=柔光覆盖全场、竹冠遮挡形成斑驳；地面=石板上有清晰的竹叶投影与斜射光斑、投影边缘柔和；环境物=竹竿与苔石顶面受光、底部压暗；光线=清晨斜射柔光、冷绿主调夹暖白高光、漫射为主、明暗对比 0.5（0–1）、无补光无反射板；大气=斜射光穿过薄雾形成可见光柱、光柱内有细微浮尘 |
| 大气 / 4 | 场地=空气湿润、全场均匀薄雾、不改变场地形态；地面=雾主要贴地 0–20 cm、不遮脚部与接触点；环境物=远处竹林在雾中渐隐、轮廓仍可辨；光线=雾中光柱与光斑柔和、无光晕溢出；大气=无雨无烟、整体静谧、冲击与倒地时局部雾被搅动、浮土短暂升高 |
