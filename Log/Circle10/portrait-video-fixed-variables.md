# 固定变量卡 · 肖像视频版（配 figure-symmetric-cartographer）

> 本卡只管怎么拍，不管拍谁：画幅、景别、机位、运动、光照、背景全部在这里定死，肖像卡一条都不重复。
> 冲突时以肖像卡为主：取景让步，长相不让步。
> 用法：第二列逐条首尾相接成一段，整段置于肖像卡正文之前送出。

## 变量

| 变量 | 固定语句（原样送验） |
| --- | --- |
| 优先级 | 当肖像描述与本卡取景冲突时，以肖像描述为主。 |
| 画幅 | 3:4 竖幅，全头完整入画，发顶距画面顶边约 8%，画面下缘落在锁骨上方，脸的宽度占画面宽度的 70%，人脸位于画面水平中央。 |
| 景别 | 头肩特写，画面范围从发顶到锁骨上方，不出现腰、不出现手、不出现道具、不出现第二个人。 |
| 机位 | 机位与面部等高、正对鼻梁中轴，水平偏转与俯仰偏转均为零，画面无透视变形，面部不被拉宽也不被压扁。 |
| 运动 | 三脚架固定机位，全程零推拉摇移、零变焦、无剪辑、无转场，一镜到底五秒，镜头不抖。 |
| 主体动作 | 正视镜头、匀速呼吸、肩线只有轻微起伏，只在第二秒到第三秒之间缓慢眨眼一次，全程不转头、不位移、不开口、不做表情动作。 |
| 视线 | 双眼平视镜头，瞳孔落在眼眶中央，不斜视、不闭眼（仅那一次眨眼除外）、不看画外。 |
| 表情 | 中性表情，不笑不怒不讶异，双唇轻闭合，眉不上扬也不皱。 |
| 光照 | 正面均匀柔光，鼻梁与两颊的高光沿中线对称，不设侧光、顶光与逆光，全程光照不变、不闪不跳。 |
| 背景 | 中性灰纯色背景，无渐变、无纹理、无道具、无投影，全程背景不动、景深不变化。 |
| 材质 | 写实摄影质感，毛孔与干裂唇纹清晰可辨，不磨皮、不美颜、不做风格化、不加颗粒与滤镜。 |
| 排除 | 画面内不出现文字、字幕、水印、边框与标识，不出现分屏、多视角、拼接与转场。 |
