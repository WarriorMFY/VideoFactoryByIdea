# 固定变量卡 · 走秀版（配 figure-symmetric-cartographer）

> 本卡只管在哪拍、穿什么、怎么走、镜头怎么动，不管拍谁。
> 冲突时以肖像卡为主：长相不让步，取景让步。
> 用法：第二列逐条首尾相接成一段，置于肖像卡正文之前送出。

## 变量

| 变量 | 固定语句（原样送验） |
| --- | --- |
| 优先级 | 当肖像描述与本卡冲突时，以肖像描述为主。 |
| 场景 | 极简室内秀场，纯白无缝背景，地面为同色浅灰哑光，无观众、无座椅、无道具、无标识，画面里只有这一个人。 |
| 服装 | 上身穿深灰圆领长袖针织衫，领口落在锁骨下方，下身黑色直筒长裤，深灰系带皮鞋，衣料平整无图案无 logo。 |
| 动作 | 从画面纵深匀速向镜头走来，步频稳定，双臂屈肘小幅自然摆动，走到距镜头一步远时放慢停住，站定后正视镜头，全程不转头、不侧身、不回头。 |
| 镜头 | 固定机位一个镜头拍完五秒，机位与站定后的胸口等高，全程不推拉、不摇移、不变焦、不剪辑、无转场，镜头不抖。 |
| 景别 | 开头是全身入画，头顶到鞋底都在画面内；随着人走近，画面连续收窄，结尾停在胸像，画面下缘落在胸线附近，中间不切不跳。 |
| 构图 | 人始终处在画面水平中央，头顶留白由宽渐窄，脚下地面逐渐走完，全程不出现第二个人。 |
| 光照 | 正面均匀柔光，脸部受光均匀，不设侧光、顶光与逆光，全程光照不变、不闪不跳，地面不出现强反光。 |
| 视线 | 行走时眼看前方一步，站定后双眼平视镜头，不斜视、不看画外。 |
| 表情 | 中性表情，不笑不怒，双唇轻闭，站定时不张嘴、不挑眉。 |
| 材质 | 写实摄影质感，皮肤毛孔与织物纹理清晰可辨，不磨皮、不美颜、不做风格化、不加颗粒与滤镜。 |
| 排除 | 画面内不出现文字、字幕、水印、边框与标识，不出现分屏、多视角、拼接、慢动作回放与转场。 |
