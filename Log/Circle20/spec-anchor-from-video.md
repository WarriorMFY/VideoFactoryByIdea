# Spec · 从视频链接到实验锚

> 由 `desc-to-spec` 转译（2026-11-19，选择模式盘问 5 题后定稿）。  
> 原文（Desc）：锚定一个视频链接 → 下载本地 → 分段 → 每段首帧作每轮实验的锚；网页能输入链接并分段、从段里选首帧；每次实验产出与原片的对照视图。

## 一、输入层

| 项      | 规格                                                                          | 来源    |
| ------ | --------------------------------------------------------------------------- | ----- |
| 输入形态   | 三种全支持：① 分享短链（`b23.tv` 等）② 直链 `mp4` ③ 本地文件                                   | 定稿 Q1 |
| 下载清晰度  | ≤ 1080p，优先 720p（与生成端 0.6MP 同量级）                                             | 定稿    |
| 单条时长上限 | 120 s，超出截前 120 s 并在页面标注                                                     | 定稿 Q2 |
| 落盘     | `Log/Circle20/src/<video-id>/src.mp4`；`<video-id>` = 链接最后一段的 SHA1 前 8 位     | 定稿    |
| 依赖     | 短链需 `yt-dlp`（**本机未装**）；直链用标准库 `urllib`；不用裸 `ffmpeg` 命令，一律经 `Tool/ffmpeg.py` | 已实测   |

## 二、分段层

| 项      | 规格                                           | 来源                                                |
| ------ | -------------------------------------------- | ------------------------------------------------- |
| 采样率    | 10 fps                                       | 沿用 `Skill/chain/shot-repaint/scripts/seg_scan.py` |
| 硬切判据   | 相邻帧直方图 `hist_l1 > 0.30`（同镜实测最大 0.088）        | 沿用 Circle15                                       |
| 机位稳定判据 | 全局位移速率 ≤ 1%/s 视为不动                           | 沿用 Circle15                                       |
| 段长     | 下限 5.0 s（短段**不丢**，生成按 5.0 s 跑再裁回原长）；上限 9.0 s | 下限沿用旧循环；上限定稿 Q2                                   |
| 段数上限   | 12 段；超出按等间隔抽样保留，丢弃的段在页面明示条数                  | 定稿 Q2                                             |
| 丢弃规则   | 时长 < 1.0 s、黑帧段（均值 <16 且方差 <25）、纯字幕段          | 定稿                                                |
| 切点精度   | ± 0.1 s（10 fps 粒度），落盘时换算成帧号                  | 推导                                                |

## 三、锚层

| 项    | 规格                                                                         | 来源    |
| ---- | -------------------------------------------------------------------------- | ----- |
| 锚定义  | 每段首帧 `f0`；`f0` 判黑帧/转场残留时退到 `f0 + 0.2 s`                                    | 定稿    |
| 锚文件名 | `Log/Circle20/src/<video-id>/anchors/S<nn>_f0.png`，段与锚一一对应                 | 推导    |
| 锚分辨率 | 原分辨率入库；送生成只由 `115:megapixels` 控制（0.6 档）                                    | 通道约束  |
| 质量闸门 | 自动打分 + 人工可覆盖：`var(Laplacian) < 60` 或黑帧 → 标灰并写明原因，**仍可选**；60 为初值，首次实跑后按分布校准 | 定稿 Q3 |

## 四、实验层

| 项    | 规格                                                            | 来源                    |
| ---- | ------------------------------------------------------------- | --------------------- |
| 绑定关系 | 每条实验必带 `(video_id, seg_id, anchor_sha1, prompt_sha1, params)` | `probe.py` 契约 + 新增两字段 |
| 请求时长 | `min(段长, 15.0)` 取到 0.1 s；段长 < 5 s 时按 5.0 s 请求、出片后裁回段长         | 沿用 Circle15           |
| 积分闸门 | 单批 ≤ 120 积分（0.6MP·5s 单价 ≈21.4，约 5–6 条）；超限即停、逐条问               | 定稿 Q5                 |
| 记录   | `run.json` + `experiments.jsonl`，新增 `video_id`／`seg_id`       | 推导                    |

## 五、对照层（原片 vs 生成）

| 项    | 规格                                                                   | 来源          |
| ---- | -------------------------------------------------------------------- | ----------- |
| 主视图  | 双联：左源段、右生成，同帧号对齐，左上角各标 `SRC` / `GEN`                                 | 定稿 Q4       |
| 副视图  | 一行 3×3 分区差异色块（drift 九格着色），不另出第三条视频轨                                  | 定稿 Q4       |
| 时长不等 | 首帧对齐、以短者为准裁齐，长者在角标 `+0.7s`                                           | 推导          |
| 落盘   | `cmp/<run-id>.mp4`（双联）＋ `cmp/<run-id>.png`（首/中/末三帧三联）                | 沿用 Circle15 |
| 新增数字 | `motion_ratio = 生成 motion_max / 源段 motion_max`，回答「动得比原片多还是少」         | 推导          |
| 不变数字 | `anchor_ncc`／`motion_max`／`drift_max` 仍按 `judging.md` 算；对照视图是人看的第二证据 | 沿用          |

## 六、网页层

| 项    | 规格                                                                                                        | 来源       |
| ---- | --------------------------------------------------------------------------------------------------------- | -------- |
| 形态   | 本地 Python 服务 `127.0.0.1:8765` + 单页（**必须有后端**：浏览器不能下 bilibili、也不能切视频）                                      | 硬约束      |
| 端点   | `POST /api/ingest`（链接/文件 → 下载+分段）｜`GET /api/segments`｜`POST /api/anchor`｜`POST /api/run`｜`GET /api/state` | 推导       |
| 交互流  | 粘链接 → 段条（缩略图＋时长＋时间码＋闸门标）→ 点段选锚 → 填提示词 → 跑 → 出双联对照卡                                                        | 定稿 Q1–Q4 |
| 不做   | 账号、云端、批量并发、移动端适配                                                                                          | 边界声明     |
| 失败口径 | 下载失败／切不出段／余额不足 → 页面顶部一条红字，不弹窗、不留半条记录                                                                      | 推导       |

## 八、下一步建议

- [ ] 补 `yt-dlp`（只短链需要；不装则短链入口报「缺依赖」，直链与本地文件照常）
- [ ] 分段复用 `shot-repaint/scripts/seg_scan.py`，不新写判据——避免两套阈值分叉
- [ ] 先做「本地文件 → 分段 → 选锚 → 双联对照」闭环（零网络依赖），再接短链
- [ ] 首次实跑后校准两处初值：Laplacian 阈值 60、段长上限 9 s
