| 自变量轴 | 因变量轴 |
| --- | --- |
| 主体 / 01 | 与起始帧同一名女子：军绿色旧式军装上衣与长裤、军绿色军帽（正面红五星）、白色运动鞋，脸、发型、服装不变；武器为同一支深棕木质长枪道具（细长枪管、一条细绳背带），手中始终只有这一支枪，不换枪、不出现第二支枪、不多出手臂 |
| 起始 / 02 | 第 0 帧与起始帧一致：双手端枪斜举，枪口朝画面右上方，身体半侧对镜头，正在笑 |
| 动作 / 03 | 缓慢匀速地把枪从斜举位置收到胸前，双臂前伸、枪托靠近身体，枪管由斜向转为沿纵深正对镜头：透视缩短，终态只见枪口圆孔与一小段枪管；全程不甩枪、不抖枪、枪口不左右试探 |
| 表情 / 04 | 全程带笑、眼神看向镜头；枪口对准镜头时挑眉或轻眨一下眼，俏皮而非凶狠 |
| 口型 / 05 | 最后说一声“biu”：双唇先闭紧，再突然张开成圆口，随后收拢成小圆唇；只做一次，唇部动作清晰可见 |
| 结果 / 06 | 枪口稳定对准镜头、人保持笑容不动；食指留在扳机护圈外不扣扳机，无开火、无火光、无硝烟、无弹壳，画面不加任何特效 |
