# 动作卡 · 脸部定格、枪口对准（120 帧单镜）

| 自变量轴 | 因变量轴 |
| --- | --- |
| 主体 / 01 | 与起始帧同一名女子：军绿色旧式军装上衣与长裤、军绿色军帽（正面红五星）、白色运动鞋；武器为同一支深棕木质长枪（细长枪管、细绳背带），**枪管长度不变**，手中始终只有这一支枪，不换枪、不出现第二支枪、不多出手臂 |
| 起始 / 02 | 第 0 帧与起始帧一致：双手端枪斜举，枪口朝画面右上方，身体半侧对镜头，正在笑 |
| 姿态锁定 / 03 | 头部角度、面部朝向、视线方向、躯干角度、双脚位置全片锁定，与起始帧一致；不转头、不低头、不扭身、不换站位、不前后移动 |
| 面部 / 04 | 表情定格在起始帧的微笑；只允许眨眼（1–2 次），不笑开、不露齿、不眯眼、不皱眉、不挑眉；脸颊、眉眼、嘴形的位置与起始帧保持一致 |
| 口型 / 05 | 最多一次极小幅度开口（“biu”的口型）：双唇轻闭后微张成小圆再收拢，幅度要小，不带动下巴大幅下坠、不牵动脸颊与眼睛；若与面部定格冲突，优先保持面部不动 |
| 动作 / 06 | 只有手臂与枪移动：缓慢把枪从斜举收到胸前、枪管由斜向转为沿纵深正对镜头；同一支长枪只发生透视缩短，终态只见枪口圆孔与一段枪管，枪身不得变短变细成手枪 |
| 结果 / 07 | 枪口稳定对准镜头、人保持起始帧的微笑与朝向不动；食指留在扳机护圈外不扣扳机，无开火、无火光、无硝烟、无弹壳，画面不加任何特效 |
| 镜头 / 08 | 固定机位，无推拉摇移、无变焦、无剪辑 |
