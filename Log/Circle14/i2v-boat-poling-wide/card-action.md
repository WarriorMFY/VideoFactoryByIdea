# 动作卡 · 撑船与落水（216 帧单镜）

| 自变量轴 | 因变量轴 |
| --- | --- |
| 主体 / 01 | 白衣束发青年，立于船头，双手持一根竹篙；面容、发髻、服装与起始帧一致，不换人、不改相貌 |
| 起始 / 02 | 竹篙斜举过肩、与起始帧同角度；第 0 帧不得跳变 |
| 动作 / 03 | 先完成一次完整撑篙：篙尖转入水面 → 身体前倾压篙 → 篙身向后收 → 直身把篙提起；只做一次，不重复 |
| 转折 / 04 | 随后湖面骤起大风：水面翻起白浪，衣摆与发带被风掀起，船身明显摇晃，竹篙脱手斜落船头 |
| 结果 / 05 | 人失去平衡跌入湖中，溅起明显水花；最后只剩空船在风浪里摇晃，人物不再入画 |
| 镜头 / 06 | 前 12 帧轻后拉到中景（可见船头至船身中段），第 13 帧起固定；无其他推拉摇移、无变焦、无剪辑 |
