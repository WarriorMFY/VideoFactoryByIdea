# 镜头卡 · 中景（含船身）

| 自变量轴 | 因变量轴 |
| --- | --- |
| 取景 / 01 | 中景：画面下缘可见船头至船身中段，人物腰部以上；船身完整，不被画框切掉 |
| 开场 / 02 | 第 0 帧贴合起始帧；第 1–12 帧轻后拉到上述取景，第 13 帧起机位固定，无其他推拉摇移、无变焦、无剪辑 |
| 构图 / 03 | 人物位于画面右三分之一，竹篙与船头指向画面另一侧；湖面留白 |
| 时长 / 04 | 总长 216 帧（24fps），单镜 |

# 船身描述卡 · 江南木撑船

| 自变量轴 | 因变量轴 |
| --- | --- |
| 船型 / 01 | 小型木质平底撑船，船长约四到五米；船头平阔，可容一人站立撑篙；无发动机、无现代五金件 |
| 船身 / 02 | 船壳深褐木色，木纹与湿水光泽可见，吃水线附近颜色更深；整体低饱和，与起始帧的雾青色调一致 |
| 船舷 / 03 | 两侧船舷沿边装竹制护竿，原竹色（与竹篙同色），接口用麻绳绑扎，呈弯曲的竹节弧线 |
| 中后舱 / 04 | 中后部有拱形乌篷（深灰竹席编成），篷口半垂竹帘；篷高不超过立姿人的肩 |
| 行船 / 05 | 船行时船头分开水面，两侧留下 V 形涟漪；船身随撑篙轻微俯仰，幅度很小 |

# 动作卡 · 撑船与落水（216 帧单镜）

| 自变量轴 | 因变量轴 |
| --- | --- |
| 主体 / 01 | 白衣束发青年，立于船头，双手持一根竹篙；面容、发髻、服装与起始帧一致，不换人、不改相貌 |
| 起始 / 02 | 竹篙斜举过肩、与起始帧同角度；第 0 帧不得跳变 |
| 动作 / 03 | 先完成一次完整撑篙：篙尖转入水面 → 身体前倾压篙 → 篙身向后收 → 直身把篙提起；只做一次，不重复 |
| 转折 / 04 | 随后湖面骤起大风：水面翻起白浪，衣摆与发带被风掀起，船身明显摇晃，竹篙脱手斜落船头 |
| 结果 / 05 | 人失去平衡跌入湖中，溅起明显水花；最后只剩空船在风浪里摇晃，人物不再入画 |
| 镜头 / 06 | 前 12 帧轻后拉到中景（可见船头至船身中段），第 13 帧起固定；无其他推拉摇移、无变焦、无剪辑 |
