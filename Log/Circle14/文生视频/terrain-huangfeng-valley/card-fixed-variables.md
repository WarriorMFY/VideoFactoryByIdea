# 固定变量卡 · 地貌视频版（配 terrain-huangfeng-valley-camseq）

> 本卡只管怎么拍，不管拍什么：画幅、质感、光照、色彩、稳定、对焦全部在这里定死，主卡一条都不重复。
> 冲突时以主卡为主：内容、段界、景别、机位让步于主卡，本卡只补主卡没写的成像变量。
> 用法：第二列逐条首尾相接成一段，整段置于主卡正文之前送出。

## 变量

| 变量 | 固定语句（原样送验） |
| --- | --- |
| 优先级 | 当主卡与本卡冲突时，以主卡为准：内容、段数、段界、景别、机位、运镜一律按主卡执行。 |
| 画幅 | 16:9 横幅，画面撑满画框，无黑边、无信框、无留白边框。 |
| 质感 | 写实实拍摄影质感，真实镜头光学成像，不做风格化渲染、不加滤镜、不加颗粒、不做动画感。 |
| 光照 | 自然日光，段内光源方向与色温保持不变，云影不扫过主体。 |
| 色彩 | 自然饱和度，山体灰褐、落叶金黄、田畴常绿，不做 HDR 过曝，不加青橙滤镜。 |
| 稳定 | 全程画面稳定，无抖动、无闪烁、无撕裂、无果冻效应。 |
| 对焦 | 每段焦点清晰落在焦点物上，焦平面不做呼吸式漂移，背景虚化自然。 |
| 排除 | 画面内不出现人物、文字、字幕、水印、边框、标识、分屏、多视角与拼接；不使用叠化、划像、闪白等转场特效。 |
