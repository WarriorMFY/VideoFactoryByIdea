# 反向卡 · 地貌视频六类风险

> 自变量轴：风险维度（易错点 / 排错项）
> 因变量轴：负面描述与排除指令（三元组定序：错误表现 → 易发原因 → 排除指令）
> 定位约定：本卡是通用质检规则集，不绑定任何具体卡片；与主卡冲突时以主卡为准。

| 风险维度（自变量：易错点/排错项） | 负面描述与排除指令（因变量：错误表现 / 纠错指令） |
| --- | --- |
| 人物误入 / 0 | 错误表现=画面出现人或类人角色，动物被拟人化；易发原因=四足动物被写成直立或穿衣；排除指令=动物保持本物种自然姿态与足数，四足动物四足伏卧、禽类双足站立，不拟人 |
| 文字水印 / 1 | 错误表现=画面出现字幕、角落水印、边框标识；易发原因=长文本被当成说明文字排版；排除指令=全片任何一帧都不出现字形与图标，画面四边留出干净区域 |
| 景别漂移 / 2 | 错误表现=近景段被拉成中景或远景；易发原因=段内出现尺度词，模型自选更远的景别；排除指令=近景段画面下缘始终可见地面细节，主体占画面高度三分之一以上 |
| 切点丢失 / 3 | 错误表现=硬切变成叠化，或干脆不切；易发原因=相邻段机位描述雷同，模型没有切换依据；排除指令=按主卡写明的段界秒数出现瞬时切换，切换前后两帧构图完全不同 |
| 镜头漂移 / 4 | 错误表现=近景段自行推拉摇移；易发原因=段内无可动主体时用运动填时长；排除指令=景框四角在段内固定不动，画面内只有主体自身的动作 |
| 画风漂移 / 5 | 错误表现=画面变成插画、CG 或游戏画面；易发原因=写实词不足、饱和度被拉高；排除指令=保持实拍照片质感，树皮纹理与水面反射可见真实细节 |

## 反向词注入

| 词库槽位 | 反向词 |
| --- | --- |
| 材质 | 塑料感、磨皮、CG 渲染 |
| 画风 | 插画、动漫、游戏画面 |
| 光影 | 平光、闪光、溢光 |
| 构图 | 分屏、边框、字幕区 |

## 填写要点

- 一张反向卡只约束一个风险主题，跨主题请拆卡。
- 「排除指令」必须是可执行的约束或参数：「在 2.7 秒处出现瞬时切换」优于「不要渐变」。
- 一条风险只对应一个易发原因，多原因拆多行，便于定位。
- `severity`：blocker 违反即废片，warning 降低评分但可用。

## 校验

- [x] `severity` ∈ {blocker, warning}
- [x] 每行「排除指令」含具体数值或具体对象
- [x] 全文无卡名、无角色专名
- [x] 反向词不与生图语义词库的 negative 槽位重复冗余
