# 镜头覆盖卡 · 黄枫谷

> 上游设定卡：`card.md`（7 行，原样保留）
> 本卡只做两件事：①按景别层切分；②把所覆盖的行改写成**近景可动主体**能承载的写法。
> 送验口径：外挂镜头卡 K0 状态的一行 ＋ 本卡「行写法」逐字拼接。

## 规则

1. 一条 shot 只取**一个景别层**，2–3 行，且必须能在**同一画面同框**（同一视域）。
2. 行写法 = **容器 ＋ 位置 ＋ 动态**，落到可动的近景主体上；只增可见性，不增设定。
3. 远层（尺度／骨架／气候）与近层（水系／植被／动物／灵脉）**不放在同一条 shot**。
4. 设定卡不改；要换镜头只改本卡与镜头卡。

## S1 · 谷底近岸

| 项 | 值 |
| --- | --- |
| 景别层 | 近景 |
| 外挂镜头卡 | `camera-ground-static-closeup` |
| 时长 | 5s |
| 覆盖维度 | 水系、植被带 |
| 实测 | **2/2 = 100%**（Circle13 A1v2，5 帧零位移） |

**行写法**

- 水系：近岸浅水潭里泉眼汩汩上涌、水面翻起串串水泡；一条主溪从潭边流过。
- 植被带：近岸缓坡上一畦畦灵草药垄整齐排开，草叶随风摆动。

## S2 · 枫树下

| 项 | 值 |
| --- | --- |
| 景别层 | 近景 |
| 外挂镜头卡 | `camera-ground-static-closeup` |
| 时长 | 5s |
| 覆盖维度 | 动物种群、灵脉与异常 |
| 实测 | **2/2 = 100%**（Circle13 A2，5 帧零位移） |

**行写法**

- 动物种群：枫树下灵狐伏卧抬头；溪边石上灵鹤振翅。
- 灵脉与异常：太岳灵脉一支穿谷而过：成片枫树树体粗壮、根系外露盘结，枫叶通体金黄。

## S3 · 全谷宏观（待补远景镜头卡）

| 项 | 值 |
| --- | --- |
| 景别层 | 远景 |
| 外挂镜头卡 | **缺失**，需新写 `camera-high-aerial-slow`（高位俯瞰、极缓前推、焦点在中景山脊） |
| 时长 | 5s |
| 覆盖维度 | 尺度与格局、地形骨架、气候带 |
| 实测 | 未跑 |

**行写法（待镜头卡到位后送验）**

- 尺度与格局：连绵群山层层退向天际，近中远至少三层山脊，谷地纵深远。
- 地形骨架：群山环抱的谷地：四壁峰峦浑圆连绵，山脊逐级向外抬升，谷底开阔平缓。
- 气候带：峰顶雪线裸岩，向下山腰落叶林带，谷底常绿田畴。

## 为什么 S2 曾经只拿 25%

同一组两行、同一镜头卡、同一通道，用设定卡原文（「林间多走兽与猛禽，谷中驯养灵狐与灵鹤，溪中灵鱼成群」）送验，得到的是**林地推进空镜**：动物 0/1、灵脉 0.5、运镜锁一并失效（Circle14 S2 首跑）。差别只在本卡「行写法」这一列——原文是环境描述，改后是画面主体。
