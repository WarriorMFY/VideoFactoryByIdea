【固定变量卡】
# 固定变量卡 · 地貌视频版（配 terrain-huangfeng-valley-camseq）

> 本卡只管怎么拍，不管拍什么：画幅、质感、光照、色彩、稳定、对焦全部在这里定死，主卡一条都不重复。
> 冲突时以主卡为主：内容、段界、景别、机位让步于主卡，本卡只补主卡没写的成像变量。
> 用法：第二列逐条首尾相接成一段，整段置于主卡正文之前送出。

## 变量

| 变量 | 固定语句（原样送验） |
| --- | --- |
| 优先级 | 当主卡与本卡冲突时，以主卡为准：内容、段数、段界、景别、机位、运镜一律按主卡执行。 |
| 画幅 | 16:9 横幅，画面撑满画框，无黑边、无信框、无留白边框。 |
| 质感 | 写实实拍摄影质感，真实镜头光学成像，不做风格化渲染、不加滤镜、不加颗粒、不做动画感。 |
| 光照 | 自然日光，段内光源方向与色温保持不变，云影不扫过主体。 |
| 色彩 | 自然饱和度，山体灰褐、落叶金黄、田畴常绿，不做 HDR 过曝，不加青橙滤镜。 |
| 稳定 | 全程画面稳定，无抖动、无闪烁、无撕裂、无果冻效应。 |
| 对焦 | 每段焦点清晰落在焦点物上，焦平面不做呼吸式漂移，背景虚化自然。 |
| 排除 | 画面内不出现人物、文字、字幕、水印、边框、标识、分屏、多视角与拼接；不使用叠化、划像、闪白等转场特效。 |

【反向卡】
# 反向卡 · 地貌视频六类风险

> 自变量轴：风险维度（易错点 / 排错项）
> 因变量轴：负面描述与排除指令（三元组定序：错误表现 → 易发原因 → 排除指令）
> 定位约定：本卡是通用质检规则集，不绑定任何具体卡片；与主卡冲突时以主卡为准。

| 风险维度（自变量：易错点/排错项） | 负面描述与排除指令（因变量：错误表现 / 纠错指令） |
| --- | --- |
| 人物误入 / 0 | 错误表现=画面出现人或类人角色，动物被拟人化；易发原因=四足动物被写成直立或穿衣；排除指令=动物保持本物种自然姿态与足数，四足动物四足伏卧、禽类双足站立，不拟人 |
| 文字水印 / 1 | 错误表现=画面出现字幕、角落水印、边框标识；易发原因=长文本被当成说明文字排版；排除指令=全片任何一帧都不出现字形与图标，画面四边留出干净区域 |
| 景别漂移 / 2 | 错误表现=近景段被拉成中景或远景；易发原因=段内出现尺度词，模型自选更远的景别；排除指令=近景段画面下缘始终可见地面细节，主体占画面高度三分之一以上 |
| 切点丢失 / 3 | 错误表现=硬切变成叠化，或干脆不切；易发原因=相邻段机位描述雷同，模型没有切换依据；排除指令=按主卡写明的段界秒数出现瞬时切换，切换前后两帧构图完全不同 |
| 镜头漂移 / 4 | 错误表现=近景段自行推拉摇移；易发原因=段内无可动主体时用运动填时长；排除指令=景框四角在段内固定不动，画面内只有主体自身的动作 |
| 画风漂移 / 5 | 错误表现=画面变成插画、CG 或游戏画面；易发原因=写实词不足、饱和度被拉高；排除指令=保持实拍照片质感，树皮纹理与水面反射可见真实细节 |

## 反向词注入

| 词库槽位 | 反向词 |
| --- | --- |
| 材质 | 塑料感、磨皮、CG 渲染 |
| 画风 | 插画、动漫、游戏画面 |
| 光影 | 平光、闪光、溢光 |
| 构图 | 分屏、边框、字幕区 |

## 填写要点

- 一张反向卡只约束一个风险主题，跨主题请拆卡。
- 「排除指令」必须是可执行的约束或参数：「在 2.7 秒处出现瞬时切换」优于「不要渐变」。
- 一条风险只对应一个易发原因，多原因拆多行，便于定位。
- `severity`：blocker 违反即废片，warning 降低评分但可用。

## 校验

- [x] `severity` ∈ {blocker, warning}
- [x] 每行「排除指令」含具体数值或具体对象
- [x] 全文无卡名、无角色专名
- [x] 反向词不与生图语义词库的 negative 槽位重复冗余

# 镜头-地貌卡 · 黄枫谷（三镜切分）

> 自变量轴：镜头段（起止秒数与段间切换）。
> 因变量轴：每段的镜头五元组与该段承载的地貌维度。
> 实体约定：段＝两个硬切之间的连续画面；覆盖＝该段必须出现的设定卡维度，按行写法送验；切换＝本段内的切换状态与该段的切出点。段与段以硬切连接。

| 对象 / 序号 | 说明 |
| --- | --- |
| 总长 / 01 | 时长＝9.0 秒；段数＝3；切换＝2 处 |
| 镜头段 / 01 | 时长＝0.0 秒至 2.7 秒；景别＝远景；机位＝高位俯瞰，镜头下俯约 15 度，高度足以看见整条谷地；运镜＝极缓前推，全程推进不超过画面高度的十分之一；焦点＝谷腹中部的山脊；切换＝本段内无切换，于 2.7 秒处硬切至潭边近景。画面：连绵群山层层退向天际，近中远至少三层山脊，谷地纵深远；群山环抱的谷地，四壁峰峦浑圆连绵，山脊逐级向外抬升，谷底开阔平缓；峰顶雪线裸岩，向下山腰落叶林带，谷底常绿田畴。 |
