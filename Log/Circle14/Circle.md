## 核心结论（卡与模型对齐度）

1. **卡的原文是「设定语言」，不能直接送视频。** S2 用卡的静态名词（无容器、无位置、无动态），模型读成环境描述，给了一段金色落叶林地前推空镜：0.5/2 = 25%，且「静止不动」连带失效。同一组两行改成「枫树下灵狐伏卧抬头」后是 100%（Circle13 A2）。**对齐的是写法，不是维度结构。**
2. **切镜是容量的解，拉时长不是。** 单镜上界 3 行（Circle13）；本卡用 2 次硬切把 7 行拆成 3/2/2，每段都在容量内，9s 一条即 7/7。对比 Circle13 B9：9s 单镜 4 行仍 75%，还把景别撑成中远景。
3. **镜头与覆盖必须写在同一段里。** 把镜头字段（景别/机位/运镜/焦点/切换）塞进同一行的 `覆盖＝` 之前，模型才在段内锁机位、在段界切；外挂成另一份镜头卡时，它更容易把镜头当背景描述。
4. **进度百分比不生效。** 设计 30.0% / 36.7% / 33.3%，实际 59.2% / 21.2% / 19.5%。规律是「首段≈5s，剩余时长均分给后两段」。要控段长只能按总长倒推，百分比只当语义标签。

   **修正（17:25）**：不是模型不听话，是生成器把 `时长＝` 整列丢了——413 字的 prompt 里 0 处秒数，只送了百分比。现已改为三卡直送，时间只留秒数，模型第一次拿到 2.7 / 6.0 秒。
5. **容易对齐的**：景别分层（远景吃宏观三行、近景吃小要素四行）、段内的「静止 vs 极缓前推」、七行的具体名词与颜色。**不易对齐的**：分段时刻、多段之间的时长比例、少于 2s 段内的完整动作（鹤只展翅到收翅，振翅过程被压缩）。
6. **待优化**：近景两段各只有约 2s。若一段里要放「完整动作」，得把总长加到 12–15s，或把段数压到 2（宏观＋近景），换取每段 ≥4s。
