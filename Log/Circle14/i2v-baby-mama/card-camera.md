# 镜头卡 · 床面固定机位（120 帧）

| 自变量轴 | 因变量轴 |
| --- | --- |
| 取景 / 01 | 低角度平视床面，中近景：画面含幼儿全身（含双脚）、棕色抱枕、后方婴儿床与逆光窗帘；幼儿头部不被画框切掉 |
| 机位 / 02 | 与起始帧同机位同焦段，第 0 帧必须贴合；全片固定，无推拉摇移、无变焦、无手持晃动、无剪辑 |
| 构图 / 03 | 幼儿位于画面下半中部，朝向画面内侧；床面占下三分之二，窗帘逆光在背景，光比与起始帧一致 |
| 时长 / 04 | 总长 120 帧（24fps≈5s），单镜 |
