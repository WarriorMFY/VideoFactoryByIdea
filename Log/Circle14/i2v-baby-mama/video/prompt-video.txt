# 镜头卡 · 床面固定机位（120 帧）

| 自变量轴 | 因变量轴 |
| --- | --- |
| 取景 / 01 | 低角度平视床面，中近景：画面含幼儿全身（含双脚）、棕色抱枕、后方婴儿床与逆光窗帘；幼儿头部不被画框切掉 |
| 机位 / 02 | 与起始帧同机位同焦段，第 0 帧必须贴合；全片固定，无推拉摇移、无变焦、无手持晃动、无剪辑 |
| 构图 / 03 | 幼儿位于画面下半中部，朝向画面内侧；床面占下三分之二，窗帘逆光在背景，光比与起始帧一致 |
| 时长 / 04 | 总长 120 帧（24fps≈5s），单镜 |

# 动作卡 · 回头微笑叫妈妈（120 帧单镜）

| 自变量轴 | 因变量轴 |
| --- | --- |
| 主体 / 01 | 与起始帧同一名幼儿：黄色绒面小鸡连体服、小鸡头套（浅黄绒毛、蓝色五角星、黄色尖嘴）、脚踝浅蓝护套；头套一直戴着只露脸，不脱帽、不换装、不换人；不出现第二个婴儿或多余肢体 |
| 起始 / 02 | 第 0 帧与起始帧一致：趴卧在白色床面，头埋向左侧棕色抱枕，背对镜头，只见后脑与头套 |
| 动作 / 03 | 先抬头离枕，再以肩带躯干侧转（肩线与床面约 45°），最后才转头看镜头；身体始终趴卧，双脚位置基本不动，不站起、不爬走、不翻身成仰卧 |
| 颈部 / 04 | 头相对躯干只转约 45–60°，下巴不过肩线；转不到镜头方向时靠上身侧转补足，不靠加拧脖子；禁止 180° 拧颈、头贴到背上、脖子拉长或扭曲 |
| 表情 / 05 | 面向镜头微笑，嘴角上提、眼睛微弯，视线保持在镜头上，不看别处 |
| 口型 / 06 | 慢慢张口叫“妈妈”：下颌张开再闭合，连续两次，两次之间短暂停顿；必须看见两次完整的唇部开合，只张一次或全程不张口都算未完成 |
| 结果 / 07 | 收口，仍保持微笑看着镜头；整体回到安静状态，不哭、不挥手、不躺倒 |
| 镜头 / 08 | 固定机位，无推拉摇移、无变焦、无剪辑 |
