# 动作卡 · 竹篙撑船（5s 单镜）

| 自变量轴 | 因变量轴 |
| --- | --- |
| 主体 / 01 | 白衣束发青年，立于船头，双手持一根竹篙；面容、发髻、服装与起始帧一致，不换人、不改相貌 |
| 起始 / 02 | 竹篙斜举过肩、与起始帧同角度，篙尖离水；第 0 帧不得跳变 |
| 动作 / 03 | 篙尖转入水面 → 身体前倾压篙 → 篙身向后收 → 直身把篙提起；只做一次完整循环，不重复；双手分工不限左右，只要求动作逻辑成立 |
| 结果 / 04 | 人收回竹篙、直身站稳；船侧水面留一圈向外扩散的涟漪 |
| 镜头 / 05 | 固定机位，中景，无推拉摇移、无变焦、无剪辑；船身随撑篙缓慢前行，背景树影与雾色轻微后移，光线不变 |
