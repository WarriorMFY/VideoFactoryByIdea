# 派生卡 · 地貌卡转视频

> 自变量轴：送验粒度（覆盖维度行数、景别层、时长）。
> 因变量轴：视频段可呈现性（命中维度数、镜头五元组达标项）。
> 实体约定：行＝设定卡的一个维度；shot＝一次送验的一条镜头；容量＝单条 shot 能同时成立的维度数；达标＝命中数／覆盖数≥70.0%。

| 对象 / 序号 | 说明 |
| --- | --- |
| 容量 / 01 | 上界＝3 行；2 行＝100.0%（2/2，2 例）；3 行＝100.0%（3/3，1 例）；4 行＝75.0%（3/4，3 例：5s 两次、9s 一次） |
| 容量 / 02 | 时长无效：4 行由 5s（5.17s）拉到 9s（9.42s），命中仍为 75.0%，成本升至 22.61 |
| 景别 / 01 | 单条只含一个景别层；远近混层时模型自选远景，小要素命中 0/2（7 行全表远景） |
| 景别 / 02 | 行数反噬景别：4 行 9s 把近景撑成中远景，镜头五元组 3.5/4（景别 0.5、焦点 0.5） |
| 写法 / 01 | 行＝容器＋位置＋动态；缺容器倒退：泉眼去「潭」命中 0.5/1，补「潭」命中 1/1 |
| 写法 / 02 | 静态名词被读成环境描述：卡原文两行动物行→林地推进空镜，命中 0.5/2（25.0%），运镜锁同时失效（3/4） |
| 写法 / 03 | 改写成主体后同组两行→命中 2/2（100.0%），镜头 4/4、5 帧零位移 |
| 分工 / 01 | 设定卡 card.md＝世界设定，7 行全留；不为视频删行、不改语义 |
| 分工 / 02 | 覆盖卡 card-shots.md＝分镜语言，按景别层切 shot，给出逐字可送验的行写法 |
| 分工 / 03 | 镜头卡 card-camera.md＝四帧五元组，全正向陈述；否定式镜头锁实测两版均失效 |
| 送验 / 01 | prompt＝镜头卡 K0 状态一行＋覆盖卡行写法逐字拼接＋固定头尾；三段均照抄，不手写 |
| 送验 / 02 | 产物落 <卡名>/<shot>/NN-<tag>.mp4，并留 <tag>.mp4.prompt.txt 快照；抽帧条作证据 |
| 判读 / 01 | 三档打分 1／0.5／0；≥70.0% 通过；≥2 样本同项失分才归因卡问题 |
| 判读 / 02 | 镜头五元组与要素分表打分；抽帧只做导航，结论须通看全片 |
| 成本 / 01 | 480P·5s 实测 13.94–19.21；480P·9s 实测 22.61；同参数逐条波动，不按参数推算 |
| 边界 / 01 | 观测样本＝地貌卡 1 张、镜头卡 1 张、通道 1 个（MiniMax H3 加速版）；换通道需重测上界 |
