## 2 · 与模型的对齐度

| 容易对齐 | 依据 |
| --- | --- |
| 姿态、受力反应、距离、重心、让位 | v2 静帧六项里五项全对 |
| 段落级动作（冲、撞、刺、倒） | L4 通看全片与卡一致 |

| 不容易对齐 | 依据 | 性质 |
| --- | --- | --- |
| 精确落点（剑尖到甲状软骨下缘） | v1 偏差到下颌，v2 仍偏上 4–5 cm | 系统性偏高一档，不是随机 |
| 角度数值（肘 90°） | 模型改直臂、配稍短剑，落点仍对 | 数值型约束在图像通道不生效 |
| 左右手分工 / 部件数 | 出现第三条手臂（左臂叉腰＋右臂持剑＋第三条持盾） | 多部件同动时必崩 |
| 几何自洽 | 「没入至护手」与颈厚 12 cm 互斥；「对齐」被读成贴住 | 卡自身算不通时模型只会更乱 |
| 图注 vs 画面 | 图注框里是模型抄写的 Prompt，被当成执行证据 | 等于让被验对象自己打分 |

## 3 · 硬结论（后续循环一直在用）

1. **单帧判据看「同步」列，不看「武器接触」的动作词。** K2 的落点是「剑尖对齐甲状软骨下缘」，「刺入」是动作意图；前两轮 FAIL 全因违反此条。
2. **视频必须通看全片。** 9 帧拼图间隔 0.57s，盾撞与刺入是 0.1–0.2s 事件，必然漏在帧间；稀疏抽帧只能定位段落。
3. **L2 要做两遍：先七类矛盾，再武术七问。** 格子填满不等于逻辑通，前者靠串句与算式，后者靠「这一下打不打得了」。
4. **改卡的边界。** 卡自身逻辑错（矛盾、几何不自洽、缺因果）→ 改；模型画不出 → 不改，记通道限制。为过验而降低动作标准＝伪造证据。
5. **链路顺序：卡片 → 图片先对齐，之后才允许 卡片 → 视频。** 图片关没有稳定可核验的对齐，视频关结论没有前提；两条链分开建，不并行、不互相背书。
6. **卡片是最终真相，也是唯一真相。** 落盘文件 ≠ 线上请求；图注、判读、中间产物都不得改写卡片，也不得反过来当判据。
