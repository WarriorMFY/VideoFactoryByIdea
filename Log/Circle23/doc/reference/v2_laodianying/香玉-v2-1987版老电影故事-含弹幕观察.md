## 这一版讲了什么（和原文的三处大改）

这是 1987 年电视剧《聊斋·香玉》的解说。它给黄生补了一整条“婚姻”前史：

| | 原著 | 1987 版 |
| --- | --- | --- |
| 黄生的来历 | 胶州黄生借读下清宫，无妻 | **被御史公强塞一个妻子，夫妻吵架，他逃到太清宫** |
| 香玉怎么死 | 即墨蓝氏游客挖走牡丹 | **御史公来找人，找不到，迁怒挖走牡丹** |
| 复活过程 | 香玉教他用药末浇水，第二年花开 | **加了一整场“花神考验”：美色、金钱、地位、折寿，黄生全部拒绝** |
| 结局 | 黄生化芽 → 被小道士砍掉 → 牡丹、耐冬俱死 | **改团圆：化芽与二女长相守** |

**一句话**：1987 版把“一个书生的越轨”改成了“一个不幸婚姻里的男人的出逃”，并把原著“一死两殉”的惨尾改成团圆。

## 对我们 50s 版本的七条硬结论

1. **绝不能出现“他家里有妻子”的任何暗示。** 弹幕第一条反应就是道德审判，一旦观众想到“原配”，后面所有唯美都作废。我们的黄生必须是“没有家的人”：一个人住在荒废道观，只有一盏灯笼。**这不是回避，是必须的减法。**
2. **用“性转测试”当设计闸门。** 把男女互换，故事还成立吗？我们的设计（她主动折花给他，他只敢伸到半空）互换后依然成立，因为**主动权在她**。这就是这个结构最硬的地方。
3. **结尾不碰“殉情”。** 弹幕对殉情的反感是明确的、成规模的。停在“他接住了”，是数据支持的选择，不是我的个人偏好。
4. **必须留一点“凉”，否则会被骂糖水。** “改得太和谐”是这一版最集中的批评。我们的“凉”有两处：她没有影子（只作背景细节）、那枝花是从她自己身上折下来的。
5. **画风合同被这条弹幕实证支持**：“夸那个年代打光、骂磨皮美颜”。低饱和、真实光位、不磨皮是对的；但**“妖气版女主”要防止滑向网红磨皮脸**——这一条是这一轮的实证校准。
6. **任何时间/空间跳跃都会被弹幕抓。** “白天怎么变黑夜了”就是例子。我们“一次连续相遇、不跳时间”的结构，是对的选择。
7. **1987 版加的“花神考验”一场戏，50s 一个字都不能要。** 那是电视剧为了撑时长加的因果，50s 里塞进去就是灾难。
