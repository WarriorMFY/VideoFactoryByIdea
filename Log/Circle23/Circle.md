## 方法（用户指定，不可擅改）

**主体方法 = 首帧生成。** 任何一个视频序列都可以拆成 5s（或几秒）子镜头，每个子镜头由一张首帧生成；再从该子镜头的成片里找出可用帧，作为下一子镜头的首帧，如此链式推进，理论上可以拼出任意长度的视频。

中间允许使用 RunningHub 上的其他工作流（首尾帧、放大、补帧等），但只能作为辅助，不得替换首帧生成这条主线。

## 计划（待剧本到位后细化）

1. 读剧本 → 拆场次 → 拆子镜头（约 10 个 5s 段覆盖 50s，按事件最小可读之和分配，不强求等长）
2. 定画风合同 → 定首帧生成方式 → 逐段出首帧
3. 逐段跑首帧通道 → 量帧对齐 → 从成片挑下一段首帧
4. 拼接（零重编码优先）→ 接缝核验 → 成片

## 画风合同（2026-11-21 用户口径修正）

两张样片（`style_test_02` 男主 / `style_test_04_female_uncanny` 女主）**只作为整体氛围对齐的原型参考**：
- 不是剧本男女主的长相，不是固定服装，也不是每场都要这样复刻。

**要继承的（氛围基因，六条）**
1. 主调：青灰冷打底，饱和度压低，暗部不死黑、带薄雾
2. 暖色只有一点（胭脂红 / 烛火琥珀），面积 <10%，全画唯一
3. 光：单一天光自上而下或逆光，光不落在人脸上，只落一小片地面/檐角
4. 材质：粗麻、旧木、湿石、半透绢；一切带旧与湿
5. 雾：两层（贴地到小腿 + 远景一层）
6. 构图上「大面积留黑 + 人物偏幅不居中 + 低机位」

**不继承的（每场重写）**
- 人物长相、发式、服装配色、绣鞋等具体造型
- 具体场景物件与布局（石柱、台阶、破寺的摆位）
- 构图左右方向（本次男主靠左、女主靠右，仅为对视轴巧合）
- 「雾中第二重影」这一手法（只在静帧可用，视频段禁写）
