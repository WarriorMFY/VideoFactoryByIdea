## 一句话

同一张雾谷骑虎背影首帧，把变量一个个往上加（纯镜头 → 识别骑兽 → 加动作 → 改机位 → 改时长 → 弃卡改自然语言），18 次提交摸清了这个通道**吃什么、不吃什么**。

## 一、对得上的：可复用

| 写法 | 实证 |
| --- | --- |
| 帧轴代替秒 | 镜头卡的因变量轴改用帧号后，后拉节奏才可控 |
| **一句话 > 一堆卡** | v16 用 24 字拿到第一人称；v13 一千多字的四卡拼接反而丢了动作 |
| 锚图用**模型自产帧** | 首帧 NCC 0.9952 / 0.9953 / 0.9911；用原图（2147×893）做锚一律 0.93（被重绘） |
| 只给「视角 + 终点」 | "第一人称骑虎下山视角，虎在5s内完成自然跳跃下坡" 即成立，不必写怎么动 |
| 可见范围约束 | "能看到前方坡面与每一处落点" 把虎头占幅从 55.1% 压到 29.5%（面积降 58%） |
| 地形名词 | 写「台级」「乱石」，画面里真的长出岩台与坎沿 |
| 时长 ≥ 事件最小可读之和 | 四拍（发亮→下虎→交互→进屋）在 7s 全部按序兑现，5s 内从未超过两拍 |
| 上一段末帧作锚 | 接缝帧差 5.02，小于常规帧间 6.67，肉眼不可见 |
| 否定句**限幅**（对象本就在场） | "不要让虎头盖住整个视野" 未引出任何新对象 |

## 二、一定被改写的：写也白写

| 写法 | 实际结果 |
| --- | --- |
| 辅助卡（毛色 / 质感 / 参考图） | **四次全被覆盖**，一律回到亮橙条纹虎 |
| 「固定机位」+ 主体大幅移动 | 二者互斥，机位必跟 |
| 动作卡里写四肢步序 | 景别必被拉宽到全身（P0-12、P0-14） |
| 强度类模糊词 | 「高速」→ 贴地跟拍 + 拖影；「微微发亮」→ 满格能量剑 |
| 时间点（第几秒发生什么） | 不执行 |
| 否定句禁「本不该存在的东西」 | "不要动" → 凭空造出**第二只虎** |
| 第一人称 + 要求演动作 | 同一次里造第二只虎当演员（P0-15） |
| 镜头大幅移动 | **场景重写**（三次：谷口→裸岩、谷口→裸岩、村口→雪地） |

## 三、还没解决的

1. **起势与收步**：静止开场、猛然停住，十四版零兑现。
2. **终点进不了画**：「5s 内到坡底 / 到村口」从未达成，村舍作为终点始终在画外。
3. **强度只有两档**：没有"微"和"中"，只有"没有"和"满格"。
4. **尾段必塌**：P0-14 / P0-17 / P0-18 的最后 0.5–1s 都出现退化（重写地貌、主体胀大）。
5. **地貌不连续**：镜头一动世界就换，跨镜头的连续场景在本通道内做不出来。
