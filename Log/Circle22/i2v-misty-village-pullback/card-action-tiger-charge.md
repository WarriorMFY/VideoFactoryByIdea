# 动作卡 · 骑虎下山冲刺（124 帧单镜）

| 自变量轴（帧号 / 阶段 / 进度） | 因变量轴（可观测动作描述） |
| --- | --- |
| 第 0 帧 / 起势 / 0% | 虎停在坡沿，骑者端坐虎背，谷底村舍在下方 |
| 第 1–30 帧 / 起步 / 1–24% | 虎头压低，前爪踏出坡沿，后腿蹬地，身体开始下落 |
| 第 31–70 帧 / 加速 / 25–56% | 虎步幅拉开，落爪间隔变短，骑者上身前倾，衣袍向后扬起 |
| 第 71–110 帧 / 高速 / 57–89% | 虎背压低，颈肩向前顶出，虎身随步下沉，村舍迅速放大 |
| 第 111–124 帧 / 村口收速 / 90–100% | 虎冲到村舍前猛然收步，蹄前尘土扬起，屋脊从画面中段逼近 |
| 结果 / 末帧 / 100% | 虎停在村口前，骑者仍在虎背上，朝向村内 |
