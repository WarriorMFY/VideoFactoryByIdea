# 动作卡 · 连续交错跳下乱石坡（124 帧单镜）

| 自变量轴（帧号 / 阶段 / 进度） | 因变量轴（可观测动作描述） |
| --- | --- |
| 第 0–6 帧 / 起势 / 0–5% | 虎站在坡顶一块凸出的岩唇上，头探向坡下；坡面全是大小不一的乱石与土坎，没有一处等高 |
| 第 7–20 帧 / 第一跳 / 6–16% | 后身一坐，虎身扑出离地，越过第一道坎，落在斜下方一块凸起的窄岩上 |
| 第 21–34 帧 / 一沾即起 / 17–27% | 落点只沾一下就再发力，下一跳的落点偏到上一处落点的侧前方，路线开始走之字 |
| 第 35–52 帧 / 第三跳 / 28–42% | 这一跳更陡，落点是一处被雨水冲出的土台，比上一处小，落差更大 |
| 第 53–70 帧 / 第四跳 / 43–56% | 落点又偏回另一侧，虎身在空中扭正，避开一块竖起的乱石 |
| 第 71–88 帧 / 第五跳 / 57–71% | 跳幅收小、频率变快，落点密集在一段碎石坡上，一处比一处低 |
| 第 89–106 帧 / 最后一跳 / 72–85% | 从最后一块岩唇跃出，越过最陡的落差，落向坡底平地 |
| 第 107–124 帧 / 落地滑半步 / 86–100% | 落地滑出半步稳住，扬尘慢慢落下，虎身伏低 |
