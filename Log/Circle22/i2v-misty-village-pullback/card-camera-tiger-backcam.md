# 镜头卡 · 骑在虎背上（124 帧单镜）

| 自变量轴（帧号 / 阶段 / 进度） | 因变量轴（可观测镜头描述） |
| --- | --- |
| 第 0 帧 / 起幅 / 0% | 与起始帧一致 |
| 第 1–124 帧 / 机位 | 视点压在骑者背后、几乎贴住虎背，与骑者同步移动，全程一镜，无切镜 |
| 第 1–124 帧 / 景别 | 画幅下缘止于虎背与虎肩，虎的四肢始终落在画外 |
| 第 1–124 帧 / 起伏 | 虎腾空时镜头轻浮起，落爪时砸下，落点有沉坠感，不是平滑轨道 |
| 第 1–124 帧 / 晃动 | 机身随虎步歪斜晃出小幅弧线，抖动不规则，像手持而非稳定器 |
| 第 1–124 帧 / 视线 | 视线越过骑者肩头压向前方村舍，虎背始终占住画幅下缘 |
| 帧数 / 总长 | 124 帧（24fps），单镜 |
