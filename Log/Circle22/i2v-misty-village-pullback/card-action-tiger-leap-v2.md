# 动作卡 · 三跳下坡（节律版，124 帧单镜）

| 自变量轴（帧号 / 阶段 / 进度） | 因变量轴（可观测动作描述） |
| --- | --- |
| 第 0 帧 / 起势 / 0% | 虎伏在坡沿，脊背压低，骑者端坐虎背 |
| 第 1–20 帧 / 蓄力 / 1–16% | 虎身向后坐，脊背拱起，骑者随之上抬一点 |
| 第 21–45 帧 / 第一跳 / 17–36% | 虎身向前送出，骑者被托起又压下，落地一顿，尘土从画幅下缘涌起 |
| 第 46–80 帧 / 第二跳 / 37–65% | 起伏间隔缩短，这一跳比上一跳更陡，骑者连续被托起压下 |
| 第 81–110 帧 / 第三跳 / 66–89% | 最后一跳最短促，落地的震动沿虎背传到骑者肩头 |
| 第 111–124 帧 / 坡底收势 / 90–100% | 起伏收住，虎身沉回静止 |
| 结果 / 末帧 / 100% | 虎停在村口前，骑者仍在虎背上，朝向村内 |
