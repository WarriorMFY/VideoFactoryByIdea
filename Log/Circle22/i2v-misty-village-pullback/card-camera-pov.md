# 镜头卡 · 第一人称骑乘（124 帧单镜）

| 自变量轴（帧号 / 阶段 / 进度） | 因变量轴（可观测镜头描述） |
| --- | --- |
| 第 0 帧 / 起幅 / 0% | 与起始帧一致 |
| 第 1–124 帧 / 视点 | 视点就是骑者的双眼，压在虎颈上方，随虎一起前冲，全程一镜，无切镜 |
| 第 1–124 帧 / 景别 | 画幅下缘是虎颈与虎耳，虎头随每次起跳下探又抬起 |
| 第 1–124 帧 / 视线 | 视线压向前下方的坎沿与落点，越过下一处落点能看到更低的坡底与村舍 |
| 第 1–124 帧 / 起伏 | 每次起跳整框先浮起，落爪时砸下一顿，扬尘从画幅下缘扑上来 |
| 第 1–124 帧 / 晃动 | 越过坎沿时视点跟着虎头往下探，机身轻微歪斜，像手持而不是稳定器 |
| 帧数 / 总长 | 124 帧（24fps），单镜 |
