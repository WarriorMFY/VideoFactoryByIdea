# 动作卡 · 骑虎下山（124 帧单镜）

| 自变量轴（帧号 / 阶段 / 进度） | 因变量轴（可观测动作描述） |
| --- | --- |
| 第 0 帧 / 起势 / 0% | 虎立于山脊，骑者端坐虎背，面朝谷底村舍 |
| 第 1–40 帧 / 起步 / 1–32% | 虎低头看向坡下，前爪踏上坡沿，重心前移 |
| 第 41–90 帧 / 下行 / 33–73% | 虎四爪交替踏着草坡与碎石一步步下行，骑者随虎背起伏，随虎身一起降低 |
| 第 91–124 帧 / 到坡 / 74–100% | 虎走到坡下缓地，脚步放慢，村舍在画面前方变近 |
| 结果 / 末帧 / 100% | 虎停步，骑者仍稳坐虎背，望向村口 |
