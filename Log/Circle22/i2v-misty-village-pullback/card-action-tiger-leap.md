# 动作卡 · 骑虎交叉跳下坡（124 帧单镜）

| 自变量轴（帧号 / 阶段 / 进度） | 因变量轴（可观测动作描述） |
| --- | --- |
| 第 0 帧 / 起势 / 0% | 虎停在坡沿，四爪收拢，脊背压低，骑者端坐虎背 |
| 第 1–24 帧 / 蓄力 / 1–19% | 虎后腿屈起，脊背拱成弓形，重心后坐，前爪轻轻抓地 |
| 第 25–60 帧 / 首次交叉跳 / 20–48% | 前爪扑出离地，虎身在空中拉长，后爪随即落在前爪刚踩过的位置，落下时脊背重新拱起 |
| 第 61–100 帧 / 连跳 / 49–81% | 一跳接一跳下坡，每次落点都低于上一跳，落爪瞬间尘土炸开，骑者被反复托起又压下 |
| 第 101–124 帧 / 坡底收势 / 82–100% | 跳幅收短，四爪同时触地，虎蹲低定住 |
| 结果 / 末帧 / 100% | 虎伏低停在村口前，肩背起伏放缓，骑者仍在虎背上 |
