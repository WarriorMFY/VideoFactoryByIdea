# 镜头卡 · 固定机位（124 帧单镜）

| 自变量轴（帧号 / 阶段 / 进度） | 因变量轴（可观测镜头描述） |
| --- | --- |
| 第 0 帧 / 起幅 / 0% | 与起始帧一致 |
| 第 1–124 帧 / 机位 | 机位固定在骑者背后上方 |
| 第 1–124 帧 / 视角 | 画面同时容纳山脊与谷底村舍 |
| 第 1–124 帧 / 下压 | 虎下行时视角随之下压少许，虎与骑者始终留在画面内 |
| 帧数 / 总长 | 124 帧（24fps），单镜 |
