# 动作卡 · 逐级跳下台地（124 帧单镜）

| 自变量轴（帧号 / 阶段 / 进度） | 因变量轴（可观测动作描述） |
| --- | --- |
| 第 0–8 帧 / 定在第 1 级 / 0–6% | 虎立在第 1 级台面边缘，四爪收拢，脊背压低，头探向下一级 |
| 第 9–20 帧 / 蓄 / 7–16% | 后身往后坐，脊背拱成弓形，肩背顶起，重心压回台面 |
| 第 21–36 帧 / 弹向第 2 级 / 17–29% | 前身扑出，身体在空中拉长成斜线越过坎沿，脚下露出第 2 级石台 |
| 第 37–46 帧 / 砸 / 30–37% | 前身先触到第 2 级石面，后身跟着砸下，脊背压缩，尘土从落点炸开 |
| 第 47–56 帧 / 定 / 38–45% | 身体定住半拍，脊背仍伏着，头再探向下一级 |
| 第 57–84 帧 / 弹向第 3 级 / 46–68% | 再弹一次，越坎、砸下、压缩，节拍与上一跳相同，只短促一点 |
| 第 85–110 帧 / 落向坡底 / 69–89% | 最后一跳最短促，越过最后一道坎沿，落到坡底平地 |
| 第 111–124 帧 / 坡底稳住 / 90–100% | 四爪站稳，虎蹲低定住，扬尘慢慢落下 |
