# 结论 · AI 导演链成立，但双 LLM 不能担保提示词质量

> 来源：用户指令原文，2026-11-24（圈 32 暂停时下达）。
> 状态：**全链暂停**，等待「稳定提示词规则」成形后再议增速。

## 一、用户结论（原样保留）

1. **AI 导演链成立**。
2. 但随着**视频复杂度提高**，不能依赖双 LLM ——「助手 LLM（写提示词）+ 视频 LLM（执行）」。
3. 原因：**任何大模型对空间语义的理解都还不够**。
4. 推论：如果依赖助手 LLM 生成「视频提示词」，**提示词质量实在难以保证**。
5. 所以：**必须先靠人工把握提示词的质量**，形成一套「**稳定提示词规则**」之后，再考虑使用双 LLM 增速。

## 二、本轮实证（素材，供规则制定取证）

| 条目 | 提示词写法 | 模型实际产出 |

归纳：**写死参照物与可见证据的能成；写状态词、写方位词、写多方案并列的，全崩。**

## 三、待成形的规则方向（初步观察，非定稿）

1. **朝向**：必须写「背对镜头／背对门／面朝门缝」这类「参照物 + 人体部位」的绝对关系，不能只写「侧着身」「斜对」。
2. **门/遮挡等空间状态**：要写可见的物理证据（缝多宽、能不能看见门板厚度、光落在哪里），不能只写状态词（半开、正在合）。
3. **不要在一句里并列多个输出方案**：「生成图1=…生成图2=…」会被画进同一张画布（双联画）。
4. **数值的两套效力**：画面内的相对位置/占比（人的位置、身高占画面多少）基本有效；物理尺度（20cm 缝、脸宽 70%）基本无效，只能当语气。
5. **身份/道具**：不写就会掉（夹板、靴子款式在 K3b 里直接消失）。
