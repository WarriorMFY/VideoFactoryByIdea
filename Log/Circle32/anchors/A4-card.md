## 结论

- **锚该管的两件事（机位 + 材质）成立**：镜 3 的「正面 / 微仰 / 门居中 / 走廊同一世界」全锁住，可直接作 K3 的机位基准。
- **一次性状态（门缝 + 灯）不成立**：门是关死的，灯变成对称双亮。
- 处置建议（**不重跑 A4**）：缝与灯交给 K3 关键帧改写——K3 本来就要「加人 + 门滑开一道缝 + 人侧身扣缝」，一张图解决；且预算仅余 ~48，重锚会直接断掉 M3。
- 若必须让锚本身带缝（作为 M3 固定背景），则需重抽一次（~19），之后只剩一次 K3 的余量，M3 须申请超额。
- 副作用（对镜 3 有利）：门比设想远、占幅 36%，中景里装得下人的全身与扣门动作，不必再担心「门太大装不下人」。
