# 剧本 · 最后一次联锁（30s / 6 镜 / NASApunk）

## 一句话

NASApunk 白色工厂里，工程师在点火前跑完最后一道手动联锁、穿过走廊、扒开卡住的气闸门，赶到观测位，看火箭拖着烟柱离塔升空。

## 视觉设定

| 项 | 值 |
| --- | --- |
| 风格 | NASApunk：哑光陶瓷白 + NASA 橙 `#E56020` + 航蓝 + 金箔 MLI + 中性灰；高调冷白顶光，少量暖橙点光；材质哑光、结构管线整齐外露 |

- 全片无对白、无字幕；室内避免可读英文长句。
- 每镜一条 5s，逐镜独立出片；接缝只许硬切。
- 工程师一致性三件套：白工作服 + 橙背带 + 挂脖护目镜（每镜提示词都写死这三件）。
