## 本轮结论（用户定，2026-11-24）

1. AI 导演链本身成立。
2. 视频复杂度提升后，**不能依赖双 LLM**（助手 LLM 写提示词 + 视频 LLM 执行）。
3. 根因：任何大模型对**空间语义**的理解都不够，助手 LLM 生成的视频提示词质量无法保证。
4. 所以：**先人工把握提示词质量**，沉淀出「**稳定提示词规则**」，再考虑用双 LLM 增速。
5. 实证与规则方向见 `conclusion-双LLM与提示词规则.md`（朝向必须写死参照物、空间状态要写可见证据、不要并列多输出方案、物理数值无效）。
