# 后端设计（script/serve.py）

单文件、只用 Python 标准库的本地 HTTP 服务：静态托管 `html/` + 项目目录读写 + 挂图/锁定 + t2i 转发。

## 启动

```bash
cd Tool/director-editor
python script/serve.py            # 默认 http://127.0.0.1:8347/
```

`SCRIPT = 本文件目录` → `ROOT = 应用根` → `WEB = ROOT/html`（静态根）→ `REPO = ROOT.parents[1]`（仓库根，
用于找 Skill 里的通道脚本）；项目默认根 `Workspace/Projects`。只用 `ThreadingHTTPServer` 绑 `127.0.0.1`。

## 一个项目 = 一个目录

```
<项目目录>/
├─ project.json     唯一真源（前端整份写回）
├─ script.md        由 project.json 单向派生的可读剧本，手改会被覆盖
├─ assets/          定稿区：锁定过的图
│  └─ uplock/       撤回区：解锁下来的图
└─ t2i/runs/<id>/   未定稿生成物（out.png / run.json / prompt.txt / ref.png）
```

目录可由用户在任意盘指定；`Workspace/Projects/_index.json` 记 `id → 绝对目录`，`_trash/` 留给删除项目。
**锁定状态不落字段**，由图片路径推导（`assets/` 根=锁定、`assets/uplock/`=已撤、其余=未锁）。

## 接口

| 方法 | 路径 | 作用 |
| --- | --- | --- |
| GET | `/api/health` | 版本、仓库根、静态根、项目根、通道脚本是否在位 |
| GET | `/api/state` | 扫盘列出全部项目 |
| GET | `/api/project/<id>` | 读单个项目 + 真实目录 |
| POST | `/api/project` | 新建（首次落默认根） |
| PUT | `/api/project/<id>` | 整份写回 |
| POST | `/api/project/<id>/move` | 改项目目录 |
| POST | `/api/project/<id>/pickfile` | 系统选图框，起点=项目目录，选完拷进 `assets/` |
| POST | `/api/project/<id>/asset` | 浏览器上传兜底（裸 body） |
| POST | `/api/project/<id>/lock` | 锁定：复制进 `assets/`（从 `uplock/` 取回是移动） |
| POST | `/api/project/<id>/unlock` | 解锁：移入 `assets/uplock/` |
| POST | `/api/t2i` | 出图：`{channel, prompt, refs[], ar, res}` |
| GET | `/projfile/<id>/<rel>` | 项目内文件静态读，越界 404 |

## 写盘

- **前端整份 PUT**，服务端直接覆盖：去抖与串行只在前端做，服务端无版本号、无 mtime 比对。
- 已知风险：多个标签页同时开着会互相覆盖（旧页面的 PUT 会把别处新增的引用冲掉）。修法待定：
  `PUT` 带 `updatedAt`，与服务端磁盘 mtime 比对，不一致返回 409 让页面选「重载 / 覆盖」。

## 护栏

- 路径越界一律 400/404：`/projfile/`、`/projects/` 都先 `resolve()` 再验 `is_under`。
- 改目录拒盘根、拒系统目录（Windows/Program Files/ProgramData，macOS 与 Linux 对应根）、拒非空目录。
- 静态层按扩展名静默屏蔽 `.py/.pyc/.tmp`（返回不存在的路径），源码不会被页面拉走。
- 一律 `Cache-Control: no-store`，改完代码刷新即生效。
- 选图走 PowerShell `OpenFileDialog`：脚本纯 ASCII 用 `-EncodedCommand` 传、路径走环境变量、
  回执 UTF-8 文件四态（OK/CANCEL/ERROR/空），不可用则前端退回浏览器上传。

## t2i 转发

通道表 `CHANNELS`：`g2`（G-2.0 文生图，0 张参考图）/ `flux3`（图编辑，1–3 张）。服务端再挡一遍：
未知通道 400、图生图零参考图 400、参考图不在项目目录内 400；`g2` 收到参考图直接忽略。
子进程跑 Skill 通道脚本，产物与 `run.json` 落 `t2i/runs/<runId>/`，回 `{taskId, charged, files[]}`。
**这是页面唯一会花钱的动作**，前端负责先弹确认框，服务端不重复确认。
