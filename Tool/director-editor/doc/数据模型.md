# 数据模型：锚图 Anchor

业务层四张表之一。锚图是**视觉资产的定稿**：无序、无工序、可跨场次复用，不在主链上。

## 字段

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | str | 主键，项目内唯一 |
| `kind` | enum | `角色｜场景｜道具` |
| `name` | str | 与剧本 cast 软对应 |
| `imageId` | ref | → Image，可空（未生成） |
| `promptId` | ref | → Text，可空（空则按模板自动拼） |
| `refs` | ref[] | → Anchor，自引用，元素 `{id, pin}` |

不带工程 id：归属由所在项目的 `project.json` 决定，锚图自身不指认工程。

## 引用关系

| 源 | 目标 | 基数 | 可空 | 语义 |
| --- | --- | --- | --- | --- |
| Anchor.imageId | Image | 1—1 | 是 | 主图，定稿后的那一张 |
| Anchor.promptId | Text | 1—1 | 是 | 提示词本体 |
| Anchor.refs | Anchor | N—N | 是 | 锚图互引，构成资产图不是树 |
| Shot.anchorRefs | **Anchor** | N—N | 是 | 入边：锚图被镜头消费 |

## 约定

1. **无顺序**。锚图不是工序，没有 `seq`；顺序只属于分镜与短剧。
2. **弱引用不级联**。`refs` 解析不到就显示「源失效」，不删父也不删子。
3. **参数不落在锚图上**。通道与参数属于生成动作，出图时由调用方带入。
