# 前端设计（html/）

原生 JS，无框架、无构建、无依赖：`index.html` 骨架 + `styles.css` 深色主题 + `app.js`（状态、渲染、事件）。

## 布局

左栏项目列表（＋新项目）｜中栏项目头（状态、预算、目录、来源）｜右栏五个 tab，数字键 1–5 直切：
**剧本 / 风格 / 锚图 / 分镜 / 合成**。URL hash 可直达（`#anchors`），`?open=all` 一次展开所有卡片。

## 状态分三层

| 层 | 存什么 | 特点 |
| --- | --- | --- |
| 磁盘 `project.json` | 全部业务数据 | 唯一真源；改后去抖 PUT 整份写回，串行发送 |
| `localStorage` | `ui`（当前项目 / 当前 tab）、`folds`（哪些卡片展开） | 纯偏好，丢了不影响数据 |
| 内存 | 抽屉选择、引用选择器开合、生成中标记 | 刷新即失，故意不落库 |

启动时 `GET /api/state` 扫盘，磁盘空则把 `data.js` 种子落盘。旧格式自动迁移：缺 `styles` 或
`anchorGroups` 的项目补默认抽屉与单张风格卡。

## 卡片

三种卡共用一套「头 → 图 → 体」结构：头＝名称（可直改）+ 折叠三角 + `×`；图＝点图即挂本地；
体（折叠后隐藏）＝卡片各自的细节。

- **风格卡**：色板（可增删色块）+ 关键词 + 规则 + 风格图；多卡并存但**只能锁一张**当风格锚。
- **锚图卡**：主图 + 参考图列表 + 提示词。**没有锁概念**，锚与锚、锚与风格卡互相引用，后续也能被分镜卡引用。
- **分镜卡**：首帧与段落的引用。

## 图位语义（和 prompt 严格对齐）

**本卡自己的图 = 图1，参考图从图2 起**（`off = a.src ? 2 : 1`）。缩略图左上角标的数字就是图位号，
提示词里的「以图1为底…图2作参考」直接对应，不用心算。

## 引用是活指针

`refs[]` 只存指针 `{kind: style|anchor|asset, sid | gid+aid | rel}`，渲染时按 id 现查源；不复制文件。
源图被删 → 显示虚线「源失效」，不静默变空白。选择器内联在卡片里，列出本项目所有带图的锚与风格卡。

## 提示词

留空则自动拼：`以图1（本卡）为底，保持空间关系与光向；<从引用的风格卡继承关键词/色板>。图2（…）作参考。`
色板与质感**只从风格卡继承**，不许锚卡手写 —— 保证锚不离风格锚。手写即标「自定义」并给「恢复自动」。

## 生成条（卡底）

`[文生图][图生图]` 分段 + 通道下拉（G-2.0 / Flux3）+ 报价 + 橙色「生成」；模式与通道双向联动。
三处**必弹确认**：① 选不吃图的通道但卡上有图（会顶掉主图）；② 图多于通道图位（点名丢哪几张）；
③ 有失效引用。取消即中止。

## 锁钉与挂载

锁钉在图位右上角（`🔒 图已锁定 / 🔓 图未锁定`），状态由路径推导，不另存字段。点图＝挂本地（弹系统
选择框，起点是本项目目录）；带 `data-action` 的点击不冒泡到图位，避免「点按钮又弹一次选图」。
